Part A · 01 · Introduction

蜂窝基础与技术演进

为什么要把一大片服务区切成很多小区？这一节梳理蜂窝概念的核心动机、系统的六大组件、一次呼叫的完整流程，以及 1G 到 4G 的演进主线。

为什么需要蜂窝概念

传统做法是用一个大功率发射机覆盖整个区域，但频谱有限而用户不断增长。蜂窝的核心思路是用大量低功率发射机各自覆盖一小块区域（小区，cell），让相隔足够远的小区重复使用同一组频率——这就是频率复用。

四个关键要素：① 低功率发射机 + 小覆盖区；② 频率复用；③ 切换（handoff）与集中控制；④ 小区分裂扩容。后面所有章节都是围绕这四点展开。

小区画成正六边形，是因为它是唯一能无缝铺满平面、且中心到六个顶点距离都相等的正多边形；若小区半径为 R，则相邻小区中心间距 d = √3·R。实际部署会因地形、传播条件和天线设置而偏离理想六边形。

系统组成：六大基本组件

除 移动台 MS 与 基站 BS 外，还有四个基本组件，全部通过移动交换局 MTSO 串联成系统。

① 有线网关

与 PSTN / Internet / 其他 PLMN 互通：信令转换、语音编码转换、路由与计费接口。

② 数据库

HLR 签约与归属信息、VLR 漫游临时记录、EIR 设备识别；寻呼、漫游、切换、计费都依赖它。

③ 安全机制

鉴权（防号码盗用）、空口加密（防窃听）、临时标识（身份保密）。

④ 空中接口标准

规定频段、信道间隔、多址与双工方式、调制编码、帧结构、功控与切换信令，是互通与国际漫游的前提。

两类逻辑信道

控制信道：呼叫建立、维持、位置更新等信令。
业务信道：承载语音或数据本身。

MTSO 的职责

连接移动用户之间及与固网之间的呼叫；寻呼被叫；分配业务信道；协调切换。

展开：一次呼叫建立的完整流程（五步）

1. 移动台初始化：开机后扫描并锁定信号最强的建立控制信道，与 MTSO 通过 BS 握手确认身份和位置；随移动周期性重复，离开该小区后由新 BS 接管。

2. 主叫发起：在选定的建立信道上（先侦听是否空闲）发送被叫号码，BS 转发请求给 MTSO。

3. 寻呼：MTSO 依据被叫号码向相关 BS 群发寻呼消息，各 BS 在其建立信道上发出寻呼信号。

4. 被叫应答：被叫识别自己的号码并应答；MTSO 在两侧小区各选一条空闲业务信道，通知双方调谐过去。

5. 切换：通话中移动台离开当前小区时，业务信道无缝切换到新小区分配的信道，通信不中断。

多址接入与双工技术

多个用户如何共享同一段有限频谱，是"多址"要回答的问题；上下行如何分开，是"双工"要回答的问题。

互动动画 · 四种多址方式如何瓜分时频资源

切换按钮观察同一块"时间 × 频率"资源被不同方式分割的方式。

三种基本多址方式

技术共享维度原理代价
FDMA频率频段切成等宽信道，每次通话独占一个频率，不限时间需要保护频带；信道数受带宽限制
TDMA时间一个频率按周期切成时隙，多用户轮流使用（宽带 TDMA 用整个频段，窄带 TDMA 只用部分）需要保护时间与同步序列；瞬时速率高易受 ISI
CDMA码字所有用户同时同频，用正交码区分，不限时间也不限频率严格功率控制（远近效应）；码字非完全正交

TDMA 中上行（MS→BS）是突发发送，下行（BS→MS）连续发送而移动台只在分配时隙中接收。TDMA 复用 M 个用户的比特流，瞬时比特率更高，多径时延扩展会造成符号间干扰（ISI），因此接收端必须做信道均衡；好处是每用户的基站设备成本下降为 1/M，并且可以为新的语音编码引入更多时隙。

三种 TDMA 制式与 GSM 参数

IS-54 北美数字蜂窝　GSM 全球移动通信系统　PDC 日本个人数字蜂窝

GSM：最初频谱 25MHz + 25MHz（基站发 935–960MHz，移动台发 890–915MHz）；FDMA + TDMA 混合；每个射频载波 200kHz，共 125 个全双工信道。

CDMA 与扩频

扩频（SS）把信号带宽扩展到远大于传输信息所需的最小带宽。直接序列扩频（DS）用宽带伪噪声码（PN code）调制窄带信号，每个信号分配不同的码；接收端用同一 PN 序列做互相关，其它码字的信号与噪声相关结果近似为零。

CDMA 的容量优势来自两点：① 采用 Walsh 正交函数（经过真实射频/中频滤波后并非严格正交）；② 所有发射机处于精确的扩频功率控制之下，每 1ms 更新一次。CDMA 还带来更少的基站数、更强的抗多径能力、更好的话音质量与定位能力。

双工方式与 4G 关键技术

FDD 频分双工

上下行各占一段独立频率，可同时收发，两段之间有明确间隔。

TDD 时分双工

上下行共用同一频率、在不同时隙交替；优势是可灵活支持非对称的上下行流量。

LTE 的四项关键技术

OFDMA（下行）抗多径衰落能力强；SC-FDMA（上行）单载波降低峰均比、省电；MIMO 多天线显著提升频谱效率与可靠性；Turbo 码 + HARQ——Turbo 码逼近容量极限并配合 OFDM 利用频率分集，HARQ 把前向纠错与重传结合起来。

Part A · 03 · Spectral Efficiency

频谱效率

频谱效率衡量"同一段频谱、同一块面积能承载多少话务"。它被拆成两个独立部分：调制频谱效率 ηm（与小区几何、复用因子有关）和多址频谱效率 ηa（与接入方式有关），总效率 η = ηm·ηa。

调制频谱效率 ηm

信道数形式ηm = (Bw/Bc) / (Bw·Ac·N) = 1 / (Bc·Ac·N)　[信道/MHz/km²]
话务量形式ηm = 系统承载总话务 / (Bw·总覆盖面积)　[Erlang/MHz/km²]

Bc 信道间隔(MHz)、Ac 小区面积(km²)、N 簇尺寸。注意 Bw 被约掉——ηm 与系统总带宽无关，只取决于信道间隔、小区面积与复用因子。与干线效率 ηt（= 特定 GoS 下承载话务 / 总信道数）结合即可在两种形式之间换算。

多址频谱效率 ηa

FDMAηa = Be·Nt / Bw ≤ 1
宽带 TDMAηa = Ts·Mt / Tf
窄带 TDMAηa = (Ts·Mt/Tf) · (Bu·Nu/Bw)

定义为"用于语音/数据的时频域"与"系统可用总时频域"之比。Ts 为承载纯信息的时隙时长，Tf 为帧长，Mt 为每帧时隙数；窄带 TDMA 把总带宽再分成若干子带、每个子带内做 TDMA，故多一个频域因子。

电波传播与路径损耗

信号从基站到移动台经历自由空间扩散、地面反射、遮挡与散射。工程上用一组经验公式估计路径损耗 L 与接收功率 PR。

自由空间模型

FriisPR = PTGTGR / L，　L = (4πd/λ)²，　λ = c/f
分贝形式（本课程）L(dB) = 32 + 20 log f(MHz) + 20 log d(km)

标准教材常数通常写作 32.44，讲义取整为 32。注意远场假设：蜂窝系统中接收机基本都处于远场。

两径（平面地球）模型与通用经验形式

L(dB) = A + B·log f + C·log hT + D·log hR + E·log d

真实环境难以纯理论建模，因此用大量实测拟合 A~E（可以是 hT, hR, f 的函数）。大距离下平面地球两径模型给出 40dB/decade 的衰减，比自由空间的 20dB/decade 陡得多。

环境P₀（dBm）γ（dB/decade）

蜂窝几何与同频干扰

簇尺寸 N 怎么取？复用距离和通话质量如何权衡？这一节把几何与干扰理论串起来——它是整门课最核心的一节。

互动动画 · 频率复用网格

切换簇尺寸 N，观察同色（同频）小区如何重新排布、复用距离 D 如何变化。

簇、复用距离与复用比

若干小区组成簇（cluster）共同用尽整个分配频谱，簇内小区数记为 N（频率复用因子）。只有满足 N = i² + ij + j²（i, j 为非负整数）的 N 才能实现无缝六边形复用：1, 3, 4, 7, 9, 12, 13, 16, 19, 21…

D = R√(3N)　　　Q = D/R = √(3N)　　　总信道数 T = C × N × (S/N) = C × S

实现步骤：整个服务区划成若干小区 → N 个小区成簇 → 每簇用尽全部 S 条信道，均匀固定分配时每小区 S/N 条 → 整个服务区由 C 个簇拼成。

核心权衡：N ↑ → Q ↑ → 同频干扰 ↓ 通话质量 ↑，但每小区信道数 S/N ↓ → 容量 ↓。N 的选择就是容量与质量之间的折中。

同频干扰与 SIR

定义S/I = S / (N₀ + Σ Ii)　（干扰受限环境下忽略噪声 N₀）

信号损失来自路径损耗、慢衰落（地形阴影）与快衰落（多径）。若只考虑路径损耗且各基站功率相同，第 i 个干扰源的功率 ∝ Di−n，n 为路径损耗指数（2–5）。

三种常用估计口径

① 简化近似（6 个干扰源都在距离 D）S/I = Qn/6 = (3N)n/2/6
② 最坏情况 · 一般式（移动台位于小区边缘，六个干扰源距离各异）S/I = 1 / [2(Q−1)−n + 2Q−n + 2(Q+1)−n]
③ 最坏情况 · 保守式（六个干扰源都按最近距离 D−R 计）S/I = (Q−1)n/6

假设：任意 N 下第一层同频干扰小区恒为 6 个；忽略第二层（距离太远）；移动台位于小区边缘；D ≫ R。N=7、n=4 时三式分别给出 18.66 / 17.27 / 14.39 dB。

例题：要求 SIR ≥ 10dB、n=4。N=1→1.76dB，N=3→11.30dB，N=4→13.80dB，N=7→18.66dB，N=9→20.85dB，N=12→23.34dB，N=13→24.04dB。 N≥3 即可满足 10dB，但语音质量通常要求 >18dB，因此工程上取 N=7。

Part A · 06 · Channel Assignment & Capacity

信道分配与容量提升

频谱有限而用户增长，工程上有三条出路：更聪明地分配信道、把小区切得更小、用定向天线切成扇区。

信道分配：FCA vs DCA

固定分配 FCA

每小区预分配固定信道组。均匀 FCA 各小区数量相等（S/N）；非均匀 FCA 按话务负载分配。信道用尽即阻塞——即使邻小区有空闲信道也用不上，这是 FCA 的根本缺陷。

例：系统共 210 条信道、N=7 → 每小区 30 条，其中 1 条作控制信道，实际可用 29 条。

动态分配 DCA

信道不永久属于某小区。新呼叫到来时按算法（未来阻塞预测、信道复用距离、其它代价函数）从池中借用，只要不违反基本干扰约束——同一信道不得在复用距离 D 内被重复使用。话务重的小区可以拿到更多信道。借用的信道会被持续监测，通话结束后归还。

动画 · 小区分裂

小区分裂（Cell Splitting）

把拥塞小区细分为更小的微小区，各自部署基站，天线更低、功率更小。单位面积信道数增加，容量提升且不牺牲干线效率。

Pr[原小区] ∝ Pt1R−n，Pr[微小区] ∝ Pt2(R/k)−n ⟹ Pt2 = Pt1/kn，ΔdB = 10n·log k
  • 典型分裂模式：N=3 用 4:1，N=4 用 3:1，N=7 用 3:1 或 4:1，N=9 用 4:1。
  • 4:1 分裂：新小区位于两个原小区交界中点，半径为原来的 1/2。
  • 3:1 分裂：新小区位于三个小区交角处，半径为原来的 1/√3。
  • 原小区信道要拆成两组：一组给微小区复用，一组留给大小区（大小区服务高速用户可减少切换）。初期只给微小区分配少量信道，随话务增长逐步扩展，最终全区分裂。
  • 代价：小区越小，跨越边界越频繁。半径缩小 4 倍，每用户切换率上升约 10 倍，处理负荷显著增加，需要做成本效益分析。

讲义例题：基站均 60 信道，原半径 1km，微小区 0.5km，3km×3km 区域内约 4 个大区 → 240 信道；分裂后约 15 个微小区 → 900 信道，约 4 倍提升。

扇区化（Sectoring）与覆盖区

Part A · 07 · Traffic Theory

话务理论与 Erlang 公式

一个小区有多少信道是物理问题；这些信道能服务多少用户、达到什么服务质量，是排队论问题。

排队系统与 Kendall 记号

Kendall 记号A / S / N / C / P / D　＝　到达分布 / 服务分布 / 服务器数 / 系统容量 / 用户总体 / 排队规则

A、S 可为 M（马尔可夫/指数）、D（确定性）、G（一般分布）；排队规则有 FCFS、LCFS、优先级、随机。常见简写：M/M/1、M/M/1/S、M/M/m。

话务强度A = λ/μ　[Erlang]　　系统利用率（m 个服务器）ρ = λ/(mμ) = A/m

λ 为平均呼叫到达率，1/μ 为平均占用时长（平均通话时长 h）。GoS（服务等级）为呼叫被阻塞或延迟的概率：1%–2% 为理想，>5% 用户明显不满。

两种模型：呼损制与排队制

呼损制 M/M/m/m（Erlang B）

信道全忙时新呼叫被直接拒绝丢弃，无队列。假设无限用户总体，A = λh = Mρ。

PB = (AM/M!) / Σk=0M(Ak/k!)

承载话务 C = A(1−PB)，被丢弃话务 = A·PB；PB 较小时 C ≈ A。

排队制 M/M/m（Erlang C）

信道全忙时新呼叫进队列等待。计算被延迟概率 PD、平均等待时间与队长。

W = PD·h/(M−A)　　Nq = PD·A/(M−A)

高容量网络对给定 GoS 更高效，但也更容易因过载而使 GoS 急剧恶化。

干线增益与干线效率

干线增益 = 特定 GoS 下一组信道服务的用户数 / 信道数。干线效率 = 承载话务 / 信道数（Erlang/信道，介于 0 和 1）。

例：λ=1.2 次/小时、h=100s → Au = 0.033 Erlang。GoS 2% 时 M=50 可承载 40.3 Erlang，即 40.3/0.033 ≈ 1210 个用户，干线增益 = 1210/50 ≈ 24.2。M 越大增益越大；GoS 放宽（数值变大）时增益也变大。
集中优于分散：GoS 1% 时 10 条集中信道承载 4.46 Erlang（效率 44.6%）；拆成两组 5 条则各 1.36 Erlang，合计 2.72（效率 27.2%）——一组 10 条比两组 5 条多承载 60%。但分成两组的 SIR 可能更好，这是另一种权衡。

簇尺寸与地域

城区用户密度高，为保证 GoS 需要每小区信道数 M 大 → 宜用小簇尺寸（3、4、7）；农村密度低，可用大 M 且 GoS 仍可接受 → 可用 13、19、21 等大簇；郊区通常 7 左右。因此城区的小区与簇面积远小于郊区和农村。

Part A · 08 · Handover & Power Control

越区切换与功率控制

小区分裂和扇区化都会制造更多边界、更多切换。这一节讲切换如何触发、软硬切换的差别，以及功率控制如何反过来压制干扰。

互动动画 · 切换门限 Δ 的取舍

拖动 Δ 滑块并提高移动速度，观察"切换太晚导致掉话"与"切换太早导致频繁切换"两种失衡。

切换的触发与门限

Δ = PHO − Pmin

Pmin（约 −90 至 −100dBm）是维持可接受通话质量的最小接收电平；PHO 是触发切换的门限，略高于 Pmin。 Δ 太大 → 过早、过于频繁地切换（乒乓效应，浪费网络资源）；Δ 太小 → 来不及完成切换，信号跌破 Pmin 而掉话。

切换失败（掉话）的三个原因

① 新小区没有空闲信道；② MSC 时延过大或 Δ 太小导致时间不够；③ 切换执行过程中目标链路失败。

切换的范围分类

小区内切换（intra-cell）：同一小区内为改善质量更换信道。小区间切换（inter-cell）：同一 MSC 下从一个小区/基站移动到另一个。切换过程需要识别新基站，并为语音/数据和相关控制信令分配新信道。

硬切换 vs 软切换

硬切换 Hard Handover

先断后连（break before make）：先释放与旧 BS 的信道，再建立与新 BS 的信道。
优点：实现简单。缺点：通信短暂中断，可能掉话。
用于 FDMA/TDMA 系统：GSM、IS-136。

软切换 Soft Handover

先连后断（make before break）：新信道与旧信道并行建立，两条链路同时用于通信。
优点：无中断，并因分集改善边界通话质量。
用于 CDMA 系统：IS-95、WCDMA、cdma2000。

降低切换掉话率

切换呼叫（进行中的通话）被中断比新呼叫被阻塞更令人反感，因此网络给切换呼叫更高优先级：
切换排队——信道全忙时把切换请求放入缓冲区（缓冲区满才放弃）；切换预留——预留 r 条信道专供切换使用，空闲信道数 ≤ r 时新呼叫直接被阻塞。

功率控制

同频干扰（CCI）是限制蜂窝容量的主要因素之一，功率控制正是用来压低它的手段：信号太弱就提高发射功率，太强就降低。理念是"没有人使用超过所需的功率"，从而延长终端电池寿命并整体降低系统内干扰水平。

闭环操作：MS/BS 估计下行/上行的接收 SIR → 若优于所需 SIR，接收端命令发射端降低功率；若差于所需 SIR，则命令提高功率。

与 CDMA 的关系：CDMA 所有用户同频，强信号会淹没弱信号（远近效应），因此功控精度要求最高，更新周期短至 1ms。

Part B · 01 · Wireless LAN

无线局域网 IEEE 802.11

蜂窝网靠集中调度分配资源，WLAN 则靠分布式竞争。这一节的核心是：无线网卡为什么不能做碰撞检测，以及 802.11 用什么替代方案解决这个问题。

基本特征与应用

物理特征

AP 与移动设备构成一个 cell（也可只有移动设备）；覆盖 50–500m；每个 cell 只有一个物理信道——收发双方共用一个频率，上下行也共用；速率 1–54Mbps。

四类应用

LAN 扩展（有线骨干 + 无线接入开阔区域，如厂房、交易大厅、仓库）；跨楼互联（点对点无线链路连接网桥/路由器）；游牧接入（校园等中等距离移动办公）；Ad Hoc 组网（会议临时对等网络）。

网络架构：BSS / ESS / DS

DS 分布式系统：连接各 AP 的骨干。AP 接入点：网桥兼中央协调功能。BSS 基本服务集：竞争同一无线介质的一组站点，可孤立存在，也可通过 AP 接入 DS，它就是 DS 中的一个 cell。ESS 扩展服务集：两个或多个 BSS 经 DS 互连。

这是 Part B 最核心的一张图：DIFS → 随机退避 → RTS/CTS → DATA → ACK，以及其它站如何用 NAV 保持静默。切换到"碰撞"场景可看二进制指数退避如何工作。

MAC 层：DFWMAC = DCF + PCF

DCF 分布式协调功能

基础方案，采用 CSMA/CA 竞争算法，适合异步/突发业务。无线网卡无法边发边听，因此不做碰撞检测（CSMA/CD）而做碰撞避免，并用 ACK 确认代替。

PCF 点协调功能

可选，建立在 DCF 之上并与之共存。由 AP 实现集中轮询，支持面向连接、无碰撞、有时限保证的业务。

三种帧间间隔（IFS）

IFS长度用途
SIFS最短需要立即响应的动作：ACK、CTS、轮询响应——优先级最高
PIFS中等PCF 中集中控制器发起轮询，优先于普通竞争业务
DIFS最长异步帧竞争接入的最小等待时间——优先级最低
优先级三级：ACK 包 > 时限业务包 > 非时限数据包，正是通过 SIFS < PIFS < DIFS 实现的。

二进制指数退避

退避时间在 0 ~ CW−1 个时隙中均匀选取；首次尝试 CW = CWmin；每次失败后 CW 翻倍，到 CWmax 为止。IEEE 802.11 推荐 CWmin=32，CWmax=256。

互动计算器 · 退避窗口与 MAC 开销

看清 802.11 的"协议开销税"：即使 PHY 速率 54Mbps，一次 RTS/CTS 交互后有效吞吐往往只剩一半左右。

可靠交付与信道预约

两帧交换

源站发数据 → 目的站做 CRC 校验 → 正确则回 ACK；源站收不到 ACK 就重传。

四帧交换（更健壮，解决隐藏节点）

RTS → CTS → DATA → ACK。RTS/CTS 都携带本次 MSDU/ACK 传输的时长信息。

NAV 虚拟载波侦听：周围节点根据帧中的 duration 更新内部计时器 NAV，在 NAV 归零前推迟发送。即使某节点听不到源站的 RTS，也能收到目的站的 CTS 并据此设置 NAV。

展开：信道预约的三方操作细节

发送方：侦听信道空闲达 DIFS → 发 RTS 预约 → 收到 CTS 后等待 SIFS → 发送数据包。

接收方：等待 SIFS → 回 CTS → 收到数据后等待 SIFS → 回 ACK。

其它站：监听信道 → 读取 duration ID 设置 NAV → 推迟 NAV 时长 + DIFS → 然后进入退避。

互动动画 · 隐藏节点问题与 RTS/CTS 的解法

超帧结构：CFP + CP

PCF 操作与超帧

PCF 轮询：AP 发 CF-Poll 帧给某个移动节点（若 AP 自己有数据待发，可把 CF-Poll 捎带在数据帧上）；被轮询节点回 Data+CF-ACK 或 CF-ACK；一个节点交互完成后 AP 轮询下一个；全部轮询完或 CFP 时间到，AP 广播 CF-End 宣告 CFP 结束。

超帧规则：DTIM 信标帧提供同步与定时，标记 CFP 开始；CFP 期间 AP 用轮询调度收发，CP 期间各站用 DCF 竞争。CFP 不能被 CP 打断（SIFS<PIFS<DIFS）。CFP 在所有站都被轮询一次后结束；CP 长度可由 AP 作为系统参数调整。CP 结束时 AP 用 PIFS 竞争信道：信道空闲则立即取得信道，忙则须等待，于是下一周期的超帧被缩短。AP 在信标中广播实际 CFP 时长供各站更新 NAV；CFP 结束时所有节点把 NAV 清零。

连接建立与帧类型

加入 BSS 的三步

① 扫描：被动扫描（等待 AP 的 Beacon）或主动扫描（发 Probe Request 等 Probe Response）；② 认证：双方证明掌握给定口令；③ 关联：交换节点与 BSS 能力信息，把节点当前位置告知 DS。只有关联完成后才能收发数据帧。

三类 MAC 帧

数据帧传数据；控制帧用于信道预约、数据接收确认等；管理帧用于关联/解关联、定时同步、安全控制。

数据帧格式字段

帧控制（类型：控制/数据/管理）→ 时长/连接 ID（微秒级信道占用时间）→ 地址（目的、源、BSS、发送方或接收方）→ 序号控制（分片与重组）→ 帧体（MSDU 或其分片）→ 帧校验序列（32 位 CRC）。

802.11e：QoS 增强

引入两种新模式：EDCA 定义 8 个业务类，各类有独立的退避参数，接入方式类似 DCF 但增加了仲裁帧间间隔 AIFS；节点内每个业务类有独立队列，先竞争"虚拟信道"，胜出的帧再像普通 DCF 那样竞争介质。HCCA 类似 PCF，由混合协调器 HC 维护各节点状态，并按各站每类业务的负载智能分配无竞争传输机会。

MANET 的定义与特征

移动自组织网络（MANET）是一组无线移动节点自由、动态地自组织成任意临时拓扑的系统，可在没有基础设施的区域实现互联。它是对等网络：无固定控制器，控制功能由参与通信的各站动态选举或分布式承担。

Ad Hoc 网络是自创建、自组织、自管理的：控制与管理功能由节点间的交互产生。IEEE 802.11 因其极度简单而适合实现单跳 ad hoc 网络；利用 802.11 技术也能构建覆盖数平方公里的多跳网络；更小尺度上，蓝牙可构建半径 10m 内的人体域/个域 Ad Hoc 网络。

运行原理

  • 若 A 与 B 之间有传播条件足够好的无线信道，就单跳直接通信；否则需要一个或多个中间节点充当中继（路由器）。
  • Ad Hoc 网络的标志性特点：所有节点都必须能按需充当路由器。
  • 选路的基本要求：路径必须无环，无环的路径才称为一条 route。
  • 建网过程：至少两个节点广播信标（beaconing）宣告存在，携带地址与位置信息 → 通过交换控制消息确认可直连后各自更新路由表 → 第三个节点加入时，要么全部可直连，要么只有部分节点能听到它，此时路由更新在 B↔C、B↔A、B↔C 之间依次进行，最终确认 A 与 C 可经 B 互达。

运行稳定性（组合稳定性）

节点移动、电池耗尽、软硬件故障都会改变可达关系，需要路由更新；而拓扑更新本身会消耗带宽。组合稳定（combinatorially stable）的定义是：在给定时间窗内，拓扑变化足够慢，使所有必要的拓扑更新都能成功传播完成。它不只取决于网络连通性，还取决于路由协议的复杂度与节点的瞬时计算能力。

Ad Hoc 路由

所有 Ad Hoc 路由协议都要完成两项基本功能：路由识别（为一对节点找到路径，是通信的前提）与路由重构（在主机/链路故障、拥塞等不利事件后恢复）。

基于拓扑的方法

周期性（表驱动）：无论是否有数据要发，都定期交换路由信息以维护到所有节点的当前路由；每个节点负责传播因连通性变化而产生的拓扑更新。
按需（on-demand）：只有需要承载流量时才创建路由；通信前先做路由发现，通信期间维持该路由。
混合：局部区域内用周期性协议，跨区域用按需协议。

基于位置的方法

转发只需要自身位置、目的位置和邻居位置：源节点通过位置服务查到目的位置并写进报文；无需显式建立或维护路由，也不需要路由表和表更新。邻居通过有限范围的信标消息与时间戳机制识别；信标含距离限制，超出范围的接收节点直接丢弃。
前提是各节点都有及时准确的位置信息，需要一个或多个节点充当位置服务器协调。

带 QoS 要求的路由

QoS 是网络在传输数据流时应满足的一组服务要求，即对端到端时延、时延抖动、可用带宽、丢包率与吞吐量等可测量指标的保证。服务调用期间必须有足够的网络资源来兑现这一保证。移动无线 Ad Hoc 网络既要满足不同业务流的 QoS，又要保持高效路由，因此产生了 QoS 路由这一难题。

无线传感器网络（WSN）

低成本、低功耗、多功能的微型传感节点由感知、数据处理与通信三部分构成，大量密集部署在被观测现象内部或附近，可随机布撒于人难以进入的地形或救灾场景中。协议与算法必须具备自组织能力，节点必须有效协作。

通信架构与协议栈

架构：传感节点散布在传感场中，各自采集数据并通过多跳、无基础设施的方式把数据路由回汇聚节点 sink；sink 再经 Internet 或卫星与任务管理节点通信。设计受可靠性、可扩展性、生产成本、工作环境、网络拓扑、硬件约束、传输介质与功耗等因素影响。

协议栈五层 + 三个管理平面：物理层需简单而健壮的调制收发；MAC 层必须功耗感知并尽量减少与邻居广播的碰撞；网络层负责路由；传输层维持数据流；应用层承载各类应用。横跨各层的功率、移动性、任务管理平面负责监控功耗、移动与任务分配，促成节点间的协同。

Part B · 03 · 4G LTE

4G LTE 网络

LTE 是 UMTS 的演进，目标是在移动过程中为用户设备（UE）与分组数据网（PDN）之间提供不中断的无缝 IP 连接。

系统架构：EPS = EPC + E-UTRAN

整个系统称为演进分组系统 EPS，由两部分组成：SAE 系统架构演进（即核心网 EPC）与 LTE（即无线接入网 E-UTRAN，其接入技术为 E-UTRA）。EPC 由多个逻辑节点构成，而接入网基本上只有一种节点——eNodeB，各网元之间用标准化接口互连以支持多厂商互操作。

接口：eNodeB 之间用 X2 互连；eNodeB 到 EPC 用 S1——到 MME 是 S1-MME，到 S-GW 是 S1-U；eNodeB 与 UE 之间运行 AS（接入层）协议。

E-UTRAN 的职责（全部功能都在 eNodeB 内）

  • 无线资源管理：无线承载控制、无线接入准入控制、无线移动性控制、上下行资源的调度与动态分配
  • 头压缩：压缩 IP 包头以减少开销
  • 安全：所有经空口发送的数据都加密
  • 与 EPC 的连接：面向 MME 的信令与面向 S-GW 的承载通道

E-UTRA 的四大特性

可伸缩带宽

物理信道带宽 1.4MHz 到 20MHz 可伸缩。

高数据率

4×4 MIMO 时下行峰值 >300Mbps，上行可达 86Mbps。

高移动性

针对 ≤15km/h 低速优化，同时支持 350 甚至 500km/h。

可伸缩覆盖

从家庭 femtocell 到 100km 大区。

帧结构与资源网格

FDD 模式

无线帧 10ms = 10 个 1ms 子帧；每子帧 = 2 个 0.5ms 时隙。

TDD 模式

10ms 帧 = 2 个 5ms 半帧；每半帧 = 5 个 1ms 子帧。第一个半帧含 4 个普通子帧（各 2 个 0.5ms 时隙）+ 1 个特殊子帧（DwPTS + GP + UpPTS，合计 1ms）；第二个半帧是否含特殊子帧取决于上下行配置是 5ms 还是 10ms 周期。

资源网格：一个时隙内的资源在时域与频域上构成资源网格，划分为若干资源块 RB——每个 RB 在时域占 1 个时隙、在频域占 12 个子载波。时域上，常规 CP 为 7 个 OFDM 符号、扩展 CP 为 6 个（小区较大时用扩展 CP）。频域子载波数取决于系统带宽。网格中占 1 个子载波 × 1 个 OFDM 符号的最小单元称为资源单元 RE。

互动计算器 · LTE 峰值速率

用默认值（20MHz、64QAM、4×4 MIMO）即可复现讲义中"下行峰值 >300Mbps"的结论。

QoS 框架：承载、QCI 与 ARP

LTE 承载全 IP 业务，QoS 至关重要。EPS 用 EPS 承载（bearer）把 IP 流量从 PDN 网关路由到 UE——承载就是网关与 UE 之间具有确定 QoS 的 IP 包流，本质上是不同节点之间为某个业务流建立的逻辑连接。E-UTRAN 与 EPC 按应用需要建立和释放承载，而在接入网侧，保证承载在空口上的 QoS 是 eNodeB 的职责。

GBR 承载

有最小保证比特率，建立/修改时永久分配专用传输资源，适合 VoIP。资源允许时可超过 GBR，此时用 MBR 参数设定上限。

non-GBR 承载

不保证特定比特率，不永久分配带宽资源，适合网页浏览、FTP。

默认承载必须是 non-GBR，在 UE 接入网络时创建，用于初始连接；专用承载可以是 GBR 或 non-GBR，在出现具有不同 QoS 需求的新业务时建立。

QCI（QoS 类标识）

每个 QCI 由优先级、包时延预算、可接受丢包率三要素刻画，决定该承载在 eNodeB 中的处理方式，从而保证无论 eNodeB 来自哪个厂商，全网的业务处理行为都一致（由 EPS 中的 PCRF 从标准 QCI 集合中选取）。
QCI 的优先级与时延预算决定了 RLC 模式配置、调度策略、队列管理与整形策略：高优先级包先被调度；对丢包敏感的承载用 RLC 确认模式 AM 确保可靠交付。
LTE 空口调度器的三类输入：UE 的无线条件、承载的 QoS 属性、邻区干扰状况。

ARP（分配与保持优先级）

用于呼叫准入控制：无线拥塞时决定是否建立该承载；也决定新承载建立请求到来时该承载被抢占的优先级；系统过载时决定丢弃哪些连接以保住高优先级连接。承载一旦成功建立，ARP 不再影响包级转发——包转发只由 QCI、GBR、MBR 等承载级参数决定。

开放研究问题：移动性管理、连接准入控制、负载均衡、业务调度、链路自适应、功率控制、安全——都是 LTE/LTE-A QoS 保障中尚未解决的方向。
Part B · 04 · Internet of Things

物联网 IoT

IoT 的本质是把尚未连接的物体连接起来，让设备能感知和控制物理世界。难点不在"连上"，而在规模、约束与数据管理。

定义与五大挑战

IoT 让原本不在网络中的物体接入互联网，与人和其它物体通信互动，使物理世界与计算系统更紧密结合，从而提升效率、准确性与自动化水平。IoT 涉及的组件与协议极其繁杂，更像是一把涵盖各种概念、协议与技术的"伞"，具体内容取决于行业。

挑战说明
可扩展性系统要支撑数以百万计的设备；网络层可用 IPv6 提供足够的地址空间
安全攻击面大幅扩大；一个设备被攻陷就可能成为攻击其它设备和系统的跳板
隐私传感器采集的大量数据与个人及其活动强相关，可能含敏感信息与凭据，如何保护与共享是关键问题
大数据与分析海量数据必须被及时处理才能产生价值；难点是对来自不同来源、不同形式的数据做实时评估
互操作性各种专有与开放的协议、架构竞争；新标准有所缓解，但仍存在多种协议与实现

架构标准与简化框架

oneM2M（ETSI 的 M2M 技术委员会 2012 年提出）：目标是构建公共服务层，可嵌入现场设备以便与应用服务器通信，聚焦智能电表、智能电网、智慧城市、电子健康与车联网。
IoTWF（IoT 世界论坛 2014 年提出）：七层参考模型，涵盖边缘计算、数据存储与访问；控制流从云端数据中心流向边缘（传感器、设备、机器等智能末端），数据则自边缘沿栈向北汇聚到中心。

两者的共性：IoT 端点设备连到一个网络，网络把数据传输到最终使用它的应用（在数据中心、云端或各管理点）。讲义采用的简化框架把 IoT 架构拆成两个并行的三层栈：

接入技术的通信范围谱

第 2 层：通信网络层的三个决定因素

  • ② 单元内对象数量：目标对象数结合传输范围与吞吐要求，反过来决定"采集单元（cell）"的大小。
  • ③ 成本：需综合权衡成本、范围、功耗与可用带宽。

拓扑结构

点对点：一个对象只与一个网关通信。点对多点：一点与多点通信，是 IoT 的主流，细分为星型、簇星型与网状（mesh）。

网关与回传 / 网络传输 / 网络管理子层

网关负责跨介质通信：智能对象在有限区域内静止或移动，网关通常固定。网络传输子层需要开放、标准化的协议以适配多行业多介质，并满足可扩展（单网数千至百万传感器）与安全的要求——IP 恰好满足这些条件，并能嵌入性质迥异的对象、跨越低功耗低带宽高丢包的网络；其上的 TCP/UDP 则决定由网络（TCP）还是应用（UDP）来控制数据交付。管理子层负责智能对象与其它系统之间的数据传输协议：基于 TCP 的 HTTP（传感器作客户端连到 IoT 应用），以及适配低内存、低功耗、低带宽和高丢包环境的轻量协议 WebSocket（提供简单的双向连接）。

第 3 层：应用与分析；以及为什么需要雾计算

两类应用

分析类：汇集多个智能对象的数据、处理并展示（历史报表、统计、趋势或单个系统状态）。控制类：控制智能对象的行为，尤其适合那些无法在单个对象内部编程实现的复杂逻辑。

两类分析

数据分析：把采集数据处理组合成对系统的智能视图，也可监控 IoT 系统自身；分为静态（监控元素与分析内容固定，常见于工业场景）与灵活（可随时增加传感器、支持上下游操作）两种。网络分析：连通性的丢失或劣化会直接影响效率，甚至造成严重后果，因此对连接系统必不可少。多数应用同时使用两者。

集中上云的五个问题

① 末端 IoT 网络可用带宽非常有限；② 时延过高、失去实时响应能力；③ 网关的回传常依赖 3G/LTE 甚至卫星链路，可靠性不足；④ 回传的数据量过大以致难以处理；⑤ 数据越来越大，实时分析与响应几乎不可能。

雾计算的五个特征

上下文位置感知与低时延（雾节点尽量贴近端点）；地理分布（服务与应用本身就要求广泛分布式部署）；部署在 IoT 端点附近（面对大量端点）；与端点之间用无线通信（最容易实现大规模可扩展）；用于实时交互（在雾节点预处理后，上层应用只需对数据子集做批处理）。

边缘（mist）计算把这一思路推到极致：部分新型 IoT 端点自身就有足够算力，可完成低级分析与过滤并做出基本决策。边缘与雾并不取代云，而是充当过滤、分析与管理数据的第一道防线，避免云端被每个节点的每个事件反复查询。三层的分工是：最时延敏感的数据在边缘/雾就地处理；可等待数秒到数分钟的交给聚合节点；时效性最低的送云端做历史分析、大数据分析与长期存储。

设计准则：设计 IoT 网络时，先评估待分析的数据量与数据的时间敏感性，再决定只用云计算是否足够，还是需要引入边缘/雾层来提升系统效率。

地球是球面而无线电沿直线传播，所以远距离通信需要"中继站"。卫星正是理想的中继位置——它能一次覆盖极大的地理范围。

卫星最初用于替代跨洋电话电缆、提供长途电话业务；如今扩展到电信、遥感、气象、导航与 GPS、侦察、移动/个人卫星电话等。业务重心已从电话转向视频与数据，其中电视广播、导航与移动卫星通信最具前景。

GEO 的四个缺点

① 经 35,000km 后信号很弱；② 极区与高纬度地区服务差；③ 传播时延大——地面→星→地面约 0.24s；④ 覆盖面积过大，对广播有利但对点对点通信是频谱浪费。

Little LEO：工作频率 <1GHz、带宽 <5MHz、速率 ≤10kbps，面向寻呼、跟踪与低速消息。
Big LEO：工作频率 >1GHz、速率可达数 Mbps，在 Little LEO 的业务之上还提供语音与定位。

卫星几何与链路性能

仰角、覆盖角、斜距三者由简单的三角关系联系起来，它们又直接决定了时延、覆盖面积与链路质量。

几何关系

仰角 θ：天线对准卫星时，主波束中心与地球站所在水平面（地表切线）之间的夹角。为获得最大覆盖，理想的最小仰角是 0°，此时卫星覆盖可延伸至光学地平线；但低仰角意味着电波穿过更厚的大气。
覆盖角 β：在给定最小仰角下，卫星可见的地表范围所对应的角度。

中心角γ = 90° − θ − ψ　　斜距d = (RE + h)·sin γ / cos θ

链路性能的三大影响因素

  1. 卫星天线与地球站天线之间的距离：频率越高、卫星越高，信号功率损耗越大。
  2. （下行）地球站与卫星波束"瞄准点"之间的地面距离：卫星波束对准地面某一点，覆盖区中心信号最强，越偏离中心功率下降越多。
  3. 大气衰减：受氧气、水汽、仰角与频率影响。仰角越小，电波穿过的大气越厚，衰减越严重。

Part C · 03 · Capacity & Networks

容量分配与卫星网络

卫星的总容量先用 FDMA 切成物理信道，再在每个信道内部做进一步分配。核心问题是：容量应当固定分配还是按需分配。

互动动画 · 三种容量分配方式

容量分配：FAMA 与 DAMA

卫星总容量先由 FDMA 切成物理信道。例：C 波段 500MHz 带宽经频率复用切成 24 个 40MHz 信道，每个 40MHz 信道内含 4MHz 保护频带。

FAMA 固定分配

容量在多个站之间固定划分。由于需求会波动，这会造成严重的容量闲置。FAMA-FDMA：各站链路带宽预先指定，用不同频段接入卫星。

DAMA 按需分配

容量分配随需求变化而改变，以最优方式响应各站需求波动。

DAMA-FDMA 的实现

把一个信道内的一组子信道视为可用链路池；两站要建立全双工通信时，按需动态分配一对子信道。按需分配以分布式方式由地球站通过公共信令信道 CSC 完成：CSC 传送重复的 TDMA 帧，共 50 个时隙，第 1 个时隙用于同步，其余 49 个固定分配给 49 个站。某站选用一个或多个子信道后，就在自己的时隙里广播所选子信道的标识，其它站便不能再选这些信道。为公平使用子信道，还需要集中调度器。

TDMA 与 SS/TDMA

TDMA：传输为重复的帧序列，每帧分为若干时隙，各帧中相同位置的时隙固定属于某个用户；每站分配一个或多个时隙，轮流使用上行信道；卫星把收到的传输重发并广播给所有站。各站必须知道用哪个时隙发、用哪个时隙收。

为什么 TDMA 通常比 FDMA 高效：TDMA 的保护时间与控制比特所占用的容量，小于 FDMA 所需的保护频带。在 Ku 与 K 等更高频段，效率优势更明显。

高频段的卫星波束可以做得很窄，因而能在同一频率上向不同区域发射多个波束，每个区域内含若干地球站。同一区域内的站之间用普通 FAMA-TDMA 通信；不同区域之间的通信则要求卫星能把时隙从一个波束交换到另一个波束——这就是星上交换 SS/TDMA。

SS/TDMA 是 DAMA-TDMA 的一种形式：卫星服务 N 个区域、接收 N 路 TDMA 上行流；任一时刻，星上开关按某种方式把这些上行波束路由到 N 个下行波束，每种配置称为一个模式，实现完全连接需要 N! 种模式。卫星周期性地在模式之间切换，最快每个时隙切换一次；模式序列与持续时间通常可由地面指令调整以适应业务量变化。

三种典型通信配置

① 在两个远距离地球站之间提供点对点链路；② 一个发射站对多个接收站提供业务；③ 一个中心枢纽站与众多远端客户站双向通信——多个客户站共享上行容量发往枢纽站，枢纽站与各客户交换消息，并在客户之间中继消息。

卫星网络的路由与切换

两种路由方案

有星间链路（ISL）

信息可在太空中直接从一颗卫星路由到另一颗，只需 1 条上行 + 1 条下行，所需的地面关口站也更少。

无星间链路

地球站把信息发给卫星 → 卫星转发给一个关口站 → 关口站经地面网络路由到目标卫星所属的关口站 → 再上行。共需 2 上行 + 2 下行。

四类切换

类型触发原因
星内切换 intra-satellite用户在同一颗卫星覆盖范围内的不同波束/扇区之间移动
星间切换 inter-satellite用户在两颗卫星覆盖之间移动，或卫星本身移出覆盖
关口站切换 gateway卫星移出当前关口站的服务范围
系统间切换 inter-system卫星系统与地面蜂窝系统之间的垂直切换，依据信号强度与 QoS 性能决定

在 MEO/LEO 系统中，即使用户完全静止，卫星的移动本身也会造成切换——这是与地面蜂窝系统最根本的区别。
