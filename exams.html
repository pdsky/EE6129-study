    考点：路径损耗 dB 形式 · 阴影衰落中断 · 平坦/慢衰落判别 · 衰落余量
    英文原题（逐字转录）

    1. (a) A wireless channel can be modelled using a simplified path loss model, or a model incorporating the effect of shadowing, or a more complex fading model, depending on the types of the channels assumed.

    (i) The path loss model that includes shadowing can be expressed as, Pr = PtK(d)−γψ where Pr and Pt are the received and transmitted signal power respectively, d is the distance between the transmitter and the receiver, K is a constant, γ is the path loss exponent, and ψ is a random variable due to shadowing. Convert this model into the dB form and use it to sketch a graph of path loss (in dB) versus distance (in dB) and indicate how KdB and γ fit in the graph.

    (ii) For the model described in part (a)(i) above, if the mean value of Pr,dB is 10 dB higher than the minimum received signal power needed for non-outage, determine the maximum value of the variance of ψdB that will result in an outage probability lower than 1%.

    (iii) A signal, s(t), with a symbol duration of 1 ms, is transmitted through a fading channel. The channel has a time invariant channel impulse response and a rms delay spread of 0.01ms. What is the fading type of this channel? Explain your answer.

    (iv) Consider the Rayleigh fading channel. At an outage probability of ε, the outage capacity per Hz of the channel can be expressed as Cε = log2[1 + γ̄R ln(1/(1 − ε))] where γ̄R is the average signal to noise ratio for the fading channel. Determine the fade margin at an outage probability of 0.1%.

    (12 Marks)

    看解答（建议先自己做一遍）
    1
    (i) 化成 dB。两边取 10 log₁₀：
    Pr,dB = Pt,dB + KdB − 10γ log₁₀ d + ψdB
    路径损耗定义为发射功率减接收功率：
    PL,dB = Pt,dB − Pr,dB = −KdB + γ·(10 log₁₀ d) − ψdB
    把横轴取成 10 log₁₀ d（"距离的 dB"），去掉随机项后就是一条直线：斜率是 γ，在 d = 1（横轴 0 dB）处的截距是 −KdB。ψdB 是零均值高斯随机变量，所以实测点散布在直线两侧。
    横轴用 10 log₁₀ d（单位 dB），纵轴是路径损耗（dB）。直线在 d = 1 处的截距是 −KdB，斜率是 γ。
    2
    (ii) 阴影衰落的中断概率。Pr,dB 服从均值 μ、标准差 σ（dB）的高斯分布，σ² 就是 ψdB 的方差。中断 = 接收功率低于门限 Pmin：
    Pout = P(Pr,dB < Pmin) = Q((μ − Pmin)/σ) = Q(10/σ)
    要求 Q(10/σ) < 0.01。查 Q 表：Q(2.33) ≈ 0.01，Q 是减函数，所以要 10/σ > 2.33：
    σ < 10/2.33 = 4.30 dB　→　σ² < 18.5 dB²
    3
    (iii) 衰落类型。两个维度分别判断：
    • 频率上：στ/Ts = 0.01 ms / 1 ms = 0.01 < 0.1，满足讲义的经验法则，所以是平坦衰落（时延扩展远小于符号时长，几乎没有 ISI）。
    • 时间上：信道冲激响应不随时间变化，相当于没有多普勒扩展、相干时间无穷大，符号时长远小于相干时间，所以是慢衰落。
    结论：平坦慢衰落（flat, slow fading）。
    4
    (iv) 衰落余量。要和 AWGN 信道达到同样容量，瑞利信道需要多出的平均 SNR（讲义 Ch2 p.51）：
    FM = 10 log₁₀[1 / ln(1/(1 − ε))]
    ε = 0.001：ln(1/0.999) = 0.0010005，
    FM = 10 log₁₀(1/0.0010005) ≈ 30.0 dB
    对照讲义例子：ε = 1% 时是 20 dB。中断概率要求严 10 倍，余量就多 10 dB。
    (ii) σ² < 18.5 dB²（σ < 4.3 dB）　(iii) 平坦、慢衰落　(iv) 衰落余量 ≈ 30 dB

    2023-24 S2Q1(b)(i)(b) 共 13 分
    考点：DPSK 两支路选择分集 · 离散 SNR 分布求平均
    英文原题（逐字转录）

    (b) Diversity techniques can be used to lower the outage probability of a wireless system operating in a fading channel.

    (i) A Differential Phase Shift Keying (DPSK) system uses a 2-branch Selection Diversity (SD) scheme to mitigate fading. The signal to noise ratio (SNR) of the received signal for each branch is assumed to be a discrete random variable with the following distribution: 10 dB with a probability of 0.2;　12 dB with a probability of 0.8 Determine the average SNR in dB of the received signals and the average symbol error probability of the SD scheme. Note: Symbol error probability of DPSK is ½e−SNR.

    看解答（建议先自己做一遍）
    1
    先把 dB 换成线性值（公式里的 SNR 一定要用线性值）：10 dB → 10，12 dB → 15.85。
    2
    每支路接收信号的平均 SNR：
    γ̄ = 0.2 × 10 + 0.8 × 15.85 = 14.68 → 11.67 dB
    注意要先在线性域平均再转 dB。直接平均 dB 值（0.2×10 + 0.8×12 = 11.6 dB）是错的做法。
    3
    选择分集取两支路中 SNR 较大的一个。两支路独立，只有两支都是 10 dB 时输出才是 10 dB：
    P(输出 = 10 dB) = 0.2 × 0.2 = 0.04；P(输出 = 12 dB) = 1 − 0.04 = 0.96
    SD 输出的平均 SNR = 0.04 × 10 + 0.96 × 15.85 = 15.61 → 11.94 dB。
    4
    平均误符号率：对每种输出情况算 ½e−SNR 再按概率加权：
    P̄s = 0.04 × ½e−10 + 0.96 × ½e−15.85 = 9.08×10⁻⁷ + 6.2×10⁻⁸ ≈ 9.7×10⁻⁷
    对比不用分集（单支路）：0.2 × ½e−10 + 0.8 × ½e−15.85 ≈ 4.6×10⁻⁶。分集让误码率降到约 1/5，主要是把"差的那种情况"出现的概率从 0.2 压到 0.04。
    接收信号平均 SNR ≈ 11.7 dB（SD 输出平均 ≈ 11.9 dB）；SD 平均误符号率 ≈ 9.7×10⁻⁷
    注：题目说的 "average SNR of the received signals" 指每支路的接收 SNR。为保险，SD 输出端的平均 SNR 也一并写出。

    考点：空间复用 · 复用增益 min(N,M) · Alamouti 正交性与分集增益
    英文原题（逐字转录）

    (ii) Briefly describe the basic principle of the spatial multiplexing scheme and the mathematical relationship between the number of transmit antennas and the number of receive antennas for the scheme. For a MIMO system with 3 transmit antennas and 5 receive antennas, find the maximum possible multiplexing gain.

    (iii) A Space-Time Block Coding system uses 2 transmit antennas and 2 time slots to transmit 2 complex symbols, s1 and s2. The code can be represented by the matrix X = ( s1　−s2* ; s2　s1* ) where s1 and s1 are the two transmitted symbols, and s1* and s2* are the complex conjugates of s1 and s1 respectively. Show that this is or is not an orthogonal space time block code.

    (iv) Does the Alamouti code have diversity gain? Explain your answer.

    (13 Marks)

    看解答（建议先自己做一遍）
    1
    (ii) 空间复用（讲义 Ch4 p.30）：把 N 个不同的数据符号同时从 N 根发射天线发出去，速率变成原来的 N 倍；代价是没有分集增益，衰落信道里误码性能可能较差。接收端要解出 N 路数据流，需要 M ≥ N 根接收天线。最大复用增益 rmax = min(N, M)：
    N = 3，M = 5 → rmax = min(3, 5) = 3
    2
    (iii) 正交性检验。正交 STBC 的定义（讲义 Ch5 p.22、p.27）是 X XH = (|s₁|² + |s₂|²) I。题中的 X 有两行：r₁ = (s₁, −s₂*)，r₂ = (s₂, s₁*)。
    r₁·r₁H = |s₁|² + |s₂|²；　r₂·r₂H = |s₂|² + |s₁|²
    r₁·r₂H = s₁s₂* + (−s₂*)(s₁*)* = s₁s₂* − s₂*s₁ = 0
    所以 X XH = (|s₁|² + |s₂|²) I，是正交 STBC。它其实就是讲义 Alamouti 矩阵的转置（讲义把行当时隙，这里把列当时隙），本质一样。
    3
    (iv) Alamouti 有分集增益。每个符号在两个时隙里分别从两根天线各发一次，经过两条独立衰落的路径到达接收端；接收端利用正交结构做线性合并，得到的检测量里有 (|h₁|² + |h₂|²)，两条路径同时深衰落的概率很小。2 发 1 收时分集阶数为 2，2 发 M 收时为 2M，即满分集 N × M。代价：它不需要发射端知道信道，但相比接收端 MRC 少了阵列增益（讲义 Ch5 p.30 "MRC has array gain over OSTBC & Alamouti code"）。
    (ii) 需 M ≥ N；最大复用增益 = 3　(iii) X XH = (|s₁|²+|s₂|²)I，是正交 STBC　(iv) 有，满分集 2M
    注：原题 (iii) 把 "s₁ and s₂" 印成了 "s₁ and s₁"，按 s₁、s₂ 理解即可。

    2023-24 S2Q2(a)13 分
    考点：ISI 离散模型 · 由 H(Z) 读冲激响应 · 线性均衡后的判决与误码率
    英文原题（逐字转录）

    2. (a) The discrete time representation of the received signal, {r[i], i = 1,2, …}, at the output of an Additive White Gaussian Noise (AWGN) Inter-Symbol-Interference (ISI) channel can be expressed as, r[i] = Σn=13 h[n] m[i − n + 1] + w[i] where m[k] is the kth transmitted symbol which is assumed to be equally likely to be −1 or 1, h[n] is the nth component of the sampled channel impulse response, and w[i] is the ith sample of the AWGN with zero mean and a variance of 0.3.

    (i) Explain how the discrete time representation above shows that ISI is present.

    (ii) If the Z-transform of the channel is, H(Z) = 1 + 0.6Z−2, determine all non-zero values of h[n].

    (iii) The received signal is processed by a linear filter which has a Z-transform of C(Z) = 1 − 0.6Z−2. The output of the filter is used as the decision variable for detecting m[i]. Derive the decision rule.

    (iv) Using the decision rule, determine the average probability of bit error of this system.

    (13 Marks)

    看解答（建议先自己做一遍）
    1
    (i) 把求和展开：r[i] = h[1]m[i] + h[2]m[i−1] + h[3]m[i−2] + w[i]。第 i 个采样里除了想要的 m[i]，还混进了前两个符号 m[i−1]、m[i−2]，这就是符号间干扰（ISI）。只要 h[2]、h[3] 不全为 0 就存在 ISI。
    2
    (ii) 按这个求和式，H(Z) = h[1] + h[2]Z⁻¹ + h[3]Z⁻²（h[n] 对应 Z−(n−1)）。对照 1 + 0.6Z⁻²：
    h[1] = 1，h[3] = 0.6（h[2] = 0）
    3
    (iii) 滤波后的信号。总响应 C(Z)H(Z) = (1 − 0.6Z⁻²)(1 + 0.6Z⁻²) = 1 − 0.36Z⁻⁴。噪声也经过滤波：w′[i] = w[i] − 0.6w[i−2]。所以
    y[i] = m[i] − 0.36 m[i−4] + w′[i]
    ISI 没有完全消掉，但从 0.6 降到了 0.36，而且被推到 4 个符号之外。m[i] 等概取 ±1，判决规则取符号：
    m̂[i] = +1，若 y[i] ≥ 0；m̂[i] = −1，若 y[i] < 0
    4
    (iv) 误码率。先算滤波后的噪声方差：
    σ′² = 0.3 × (1² + 0.6²) = 0.3 × 1.36 = 0.408，σ′ = 0.639
    设发 m[i] = +1，残余干扰 −0.36m[i−4] 等概为 −0.36 或 +0.36，有用信号到判决门限（0）的距离分别是 0.64 和 1.36：
