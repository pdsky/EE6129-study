例 1 · AMPS 系统的频谱效率

Original questionSlide 43

Consider an AMPS system with two operators sharing the 25 MHz bandwidth. Assume each cell uses 3 control channels. Calculate the spectral efficiency based on the following parameters.

  • Area of cell = 4 km2
  • Total coverage area = 2000 km2
  • Average number of calls per user per hour = 1.2
  • Average holding time of a call = 100 sec
  • Call blocking probability: GOS = 2%
  • Frequency reuse factor = 7
两家运营商共享 25MHz 的 AMPS 系统，每个小区用 3 条控制信道。求频谱效率、每小时呼叫数与用户数。
信道宽 30kHz小区面积 4km²总覆盖 2000km²1.2 次/用户/小时平均通话 100sGoS 2%N = 7
  1. 每家运营商分到 25 ÷ 2 = 12.5MHz，信道数 12.5×10⁶ ÷ 30×10³ = 416
  2. 扣掉控制信道：每个小区 3 条，一簇 7 个小区 → 416 − 3×7 = 395 条业务信道
  3. 每小区信道数 395 ÷ 7 ≈ 56
  4. 查 Erlang B 表（M = 56，GoS 2%）→ A = 45.9 Erlang/小区，折合 45.9 ÷ 4 = 11.5 Er/km²
  5. 频谱效率 ηm = 45.9 ÷ (12.5MHz × 4km²) = 0.92 Er/MHz/km²
  6. 每小时呼叫数 = A × 3600 ÷ h：45.9 × 3600/100 = 1652.4 次/小时/小区，除以面积得 413.1 次/小时/km²
  7. 用户数 = 呼叫数 ÷ 每人呼叫次数：1652.4 ÷ 1.2 = 1377 用户/小区
  8. （p.45 顺带）FDMA 多址效率 ηa = 395 × 30kHz ÷ 12.5MHz = 0.948
ηm = 0.92 Er/MHz/km²　·　1652 次/小时/小区　·　1377 用户/小区　·　ηa = 0.948
背数字链：25 → 12.5 → 416 → 395 → 56 → 45.9。通话 100 秒时，每小时呼叫数 = A × 36。
控制信道要减 3 × 7 = 21 条，不是 3 条。ηm 的分母用的是单个小区的面积 4km²，因为 A 是每个小区的话务量；题目给的总覆盖 2000km² 在计算中用不到。

北美 TDMA 系统的多址频谱效率

Original questionSlide 47

In the North American TDMA system, the parameters are as follows. Calculate the multiple access spectral efficiency.

  • Single operator bandwidth = 12.5 MHz with channel spacing = 30 kHz
  • Total data channels = 395
  • Frame duration = 40 ms with time slots per frame = 6
  • Speech rate = 13 kbps and gross data rate = 16.2 kbps
求北美 TDMA 系统的多址频谱效率 ηa。
单运营商 12.5MHz信道间隔 30kHz数据信道 395帧长 40ms每帧 6 时隙语音 13kbps总速率 16.2kbps
  1. 每个时隙长 40 ÷ 6 = 6.67ms，但其中只有 13/16.2 装的是语音，其余是开销
  2. 有效时隙 Ts = (13/16.2) × (40/6) = 5.35ms
  3. 时间利用率 TsMt/Tf = 5.35 × 6 ÷ 40 = 0.8025
  4. 这是窄带 TDMA（总带宽再分成 30kHz 子带），频率利用率 BuNu/Bw = 30 × 395 ÷ 12500 = 0.948
  5. 两者相乘 ηa = 0.8025 × 0.948 = 0.76
ηa ≈ 0.76
ηa = 时间利用率 × 频率利用率 = 0.80 × 0.95 ≈ 0.76。其中 0.948 就是例 1 里的 FDMA 效率，两题可以一起记。
Ts 不是 40/6 = 6.67ms，要乘 13/16.2 扣掉开销。窄带 TDMA 要乘频率因子，只算 TsMt/Tf 是宽带 TDMA 的公式。

用 CCIR 模型求接收功率

Original questionSlide 65

Find the received power using CCIR model for

  • PT = 5W, d = 2km
  • GT = 10dBd, GR = 0 dBd
  • hT = 25m, hR = 2m
用 CCIR 城区模型求接收功率 PR（f = 900MHz）。
PT = 5Wd = 2kmGT = 10dBdGR = 0dBdhT = 25mhR = 2m

思路：先按标准条件（PT = 10W、GT = 6dBd、GR = 0dBd、hT = 30m、hR = 3m）算出一条基准直线 PR = P0 + γ log d，再用 p.63 的修正表逐项修正。CCIR 城区：P0 = −71.04dBm，γ = −35.4。

  1. 基准线 −71.04 − 35.4 × log2 = −71.04 − 10.66 = −81.70 dBm
  2. 发射功率修正 10 log(5/10) = −3.01
  3. 基站高度修正（截距）14 log(25/30) = −1.11
  4. 基站高度修正（斜率）6.5 log(25/30) × log2 = −0.15
  5. 终端高度修正 2.25 × (2 − 3) = −2.25
  6. 天线增益修正 GT: 10 − 6 = +4；GR: 0 − 0 = 0
  7. 全部相加 −81.70 − 3.01 − 1.11 − 0.15 − 2.25 + 4 = −84.22 dBm
PR = −84.22 dBm

小区分裂的功率下降

Original questionSlide 136 · “Cell Splitting”

Subdivide congested cell into smaller cells (microcells), each with its own base station. These smaller cells have lower antenna height and smaller transmit power. Capacity is increased due to additional channels per unit area.

If microcells have half of the radius of original cell,

Pr[original cell] ∝ Pt1R−n
Pr[microcell] ∝ Pt2(R/2)−n

If path loss exponent n = 4, Pt2 = ?. Transmitted power for microcell has to be reduced by ? dB in order to maintain the same SIR.

讲解型例题，原文自带结果。下面照录原文，结果用 ? 代替。
微小区半径是原小区的一半，路径损耗指数 n = 4。为保持相同的 SIR，微小区的发射功率要降低多少？
  1. 小区边缘的接收功率要相等：Pt1 R⁻⁴ = Pt2 (R/2)⁻⁴
  2. 整理 Pt2 = Pt1 / 2⁴ = Pt1/16
  3. 换成 dB 10 log 16 = 12.04 dB

半径除以 k，功率除以 kⁿ。2⁴ = 16，每个 2 倍是 3dB，4 个就是 12dB。

Original questionSlide 148

A system has an average call duration of 2 minutes with the probability of blocking no more then 1%. Assume that this is a blocked system and each user makes 1 call per hour on average, if there are 395 traffic channels for a 7 cell reuse system, there will be 57 channels per cell.

Find the number of calls per hour if no sectoring is used.

Compute the number of calls per hour when 120 degree and 60 degree sectoring is used.

呼损制系统，平均通话 2 分钟，阻塞率不超过 1%，每用户每小时 1 次。7 小区复用共 395 条业务信道，即每小区 57 条。求：不分扇区、120° 扇区、60° 扇区时每小时的呼叫数。
  1. 通话 2 分钟，每小时呼叫数 = A × 60/2 = A × 30
  2. 不分扇区：M = 57，查表 A = 44.2 Er → 44.2 × 30 = 1326 次/小时
  3. 120° 扇区：每扇区 57/3 = 19 条，查表 A = 11.2 Er → 336 次/小时，3 个扇区共 1008 次/小时
  4. 下降 1 − 1008/1326 = 24%
  5. 60° 扇区：每扇区 9.5 条，干线效率进一步下降约 44%，切换次数增加，但 SIR 继续提升
不分扇区 1326　·　120° 1008（−24%）　·　60° 约 −44%

扇区化要同时写两个方向：SIR 升高，干线效率下降。只写其中一个，评述不完整。
