知识讲解 + 详细解析：WLAN 覆盖多大

知识讲解WLAN 的三个关键数

无线局域网（Wireless LAN, WLAN）就是把有线 LAN 的最后一段换成无线：笔记本等终端带天线，和接入点（Access Point, AP）之间走无线链路。讲义 Part B p.6 给了三个数：覆盖中等距离 50–500 m；每个小区只有一个物理信道，所有收发方、上行和下行共用一个频率；速率从 1 Mbps 到 54 Mbps。

逐项分析四个范围各是什么网

  • A. 5–50 m：错。这是个人 / 家庭网络的尺度：蓝牙 PAN 几米，ZigBee、BLE 的 HAN 几十米（p.95）。
  • B. 50–500 m：对，讲义 p.6 原话 "Radio coverage: medium 50-500 meters"。
  • C. 0.5–5 km：错。这是城域网 MAN（几公里）的量级（p.95）。
  • D. 5–50 km：错。这是广域网 WAN、蜂窝宏小区的量级，Wi-Fi 的发射功率到不了。

易错讲义里两个数不一样

  • IoT 部分 p.95 写 LAN（IEEE 802.11）"up to 100 m"。问 WLAN 覆盖按 p.6 答 50–500 m；只有在 IoT 按距离分类时才用 p.95 的分档。
一句话：选 B：WLAN 覆盖中等距离 50–500 m，一个小区共用一个频率，速率 1–54 Mbps（p.6）。
知识讲解 + 详细解析：BSS、ESS、AP、DS

知识讲解802.11 架构的四块积木（p.10）

名称是什么打个比方
BSS 基本服务集（Basic Service Set）一群竞争同一无线信道的站点，就是一个小区；可以孤立，也可以经 AP 接到 DS一间教室
AP 接入点一个设备，当网桥用，承担中心协调功能教室门口的老师
DS 分布系统（Distribution System）把 AP 连起来的交换机、有线或无线网走廊
ESS 扩展服务集（Extended Service Set）两个以上 BSS 经 DS 互联整栋教学楼

逐项分析

  • A. IBSS：错。（课外补充：讲义没出现这个缩写。）IBSS = 独立 BSS，就是 p.10 说的"孤立"BSS，不接 DS、没有 AP，站点直接对话，正好和"多个 BSS 经 DS 互联"相反。
  • B. ESS：对，p.10 定义。
  • C. AP：错。AP 是一个设备，不是一组 BSS。
  • D. DSSS：错。这是物理层的直接序列扩频，里面的 DS 是 direct sequence，不是 distribution system，是个字面陷阱。

记忆：Basic 小、Extended 大，ESS 由多个 BSS 拼成。

一句话：选 B：多个 BSS 通过 DS 连起来叫 ESS（p.10）。

  • A：错。"5 GHz、OFDM、54 Mbps"是 a 的参数，被安到了 b 身上。

一句话：选 C：802.11a = 5 GHz + OFDM + 6–54 Mbps；802.11b = 2.4 GHz + DSSS + 5.5/11 Mbps。
知识讲解 + 详细解析：WLAN 四类应用

知识讲解为什么要有 WLAN

有线 LAN 速度快、稳定，但要拉线：大空间布线贵，两栋楼之间不好挖沟，人走动时也没法带着网线。WLAN 的四类应用（讲义 Part B p.7–8）正好对应这四种"拉线不方便"的场景。记的时候按距离从近到远、从固定到移动排：扩展 → 楼间 → 游牧 → 自组。

详细解析四点逐条展开

  1. LAN 扩展（LAN Extension）：无线 LAN 接在同一场所的有线 LAN 上。有线部分做骨干，接服务器和固定工作站；无线部分覆盖大的开放空间，如厂房、证券交易大厅、仓库。为什么：这些地方面积大、布局常变，拉线不划算。
  2. 楼间互联（Cross-Building Interconnect）：用点对点无线链路把相邻建筑的 LAN 连起来，两头的设备通常是网桥或路由器。为什么：楼之间挖沟埋线成本高。
  3. 游牧接入（Nomadic Access）：在校园这种中等距离范围内，带着笔记本边走边上网、传数据。
  4. 自组网（Ad Hoc Networking）：为眼前的需要临时搭一个对等网络，没有 AP；例：员工开会时把笔记本连成临时网络，会开完就散。

易错

  • 楼间互联是"点对点链路 + 网桥/路由器"，不是普通用户接入，别和游牧接入混。
  • 题目要"各举一个例子"，每条都要有例子，只写名称会丢分。

考试英文写法

(1) LAN extension: a wireless LAN is linked into a wired LAN on the same premises. The wired backbone supports servers and stationary workstations, while the wireless part serves stations in large open areas, e.g. manufacturing plants, stock-exchange trading floors and warehouses.

(2) Cross-building interconnect: a point-to-point wireless link connects the LANs in nearby buildings; the connected devices are typically bridges or routers.

(3) Nomadic access: supports mobile computing within a medium distance, e.g. a student moving around the campus with a laptop.

(4) Ad hoc networking: a temporary peer-to-peer network set up to meet an immediate need, e.g. employees with laptops linking their computers for the duration of a meeting.

一句话：WLAN 四类应用：LAN 扩展、楼间互联、游牧接入、自组网，每类配一个例子（p.7–8）。
知识讲解 + 详细解析：两帧 / 四帧交换

知识讲解为什么要帧交换协议

无线信道误码多、还会冲突，发出去不等于收到了。802.11 用帧交换协议（frame exchange protocol）保证可靠传输（p.16）：接收方用 CRC（帧校验序列 FCS）检查，没错才回确认（ACK）；发送方等不到 ACK 就认为失败、重传。

隐藏节点（hidden node）：A 发给 B，C 在 B 的范围内、A 的范围外（p.48）。C 听不到 A，以为信道空，一发就在 B 处撞车。只靠 ACK 解决不了：撞了只能重传，还会反复撞。

课外补充：有线以太网可以边发边听、发现冲突就停（CSMA/CD）；无线发射时自己的信号太强，听不到别人，所以只能"先避让、后确认"。

详细解析两种流程和 NAV

两帧：源 → DATA；目的检查 CRC → ACK；没收到 ACK → 重传
四帧：源 → RTS；目的 → CTS；源 → DATA；目的 → ACK
  1. RTS（请求发送）和 CTS（允许发送）都带持续时间（后面的数据 + ACK 要占多久）（p.17）。
  2. 周围节点读到这个时长，设置自己的计时器 NAV（网络分配向量），在 NAV 归零前不发送。
  3. 关键：隐藏节点 C 听不到 A 的 RTS，但听得到 B 的 CTS，于是也设 NAV、闭嘴。老师课上强调的就是这一句。
  4. 代价：多了两个短帧的开销，所以四帧交换换来的是可靠性。

老师课上说 RTS/CTS 的时间线不会让画，理解过程即可。

考试英文写法

Two-frame exchange: the source transmits a data frame; the destination checks the frame check sequence (CRC) and replies with an ACK if the frame is received correctly; if the source does not receive the ACK, it retransmits the frame.

Four-frame exchange: RTS → CTS → DATA → ACK. Both RTS and CTS carry the duration of the coming data/ACK transmission, so all surrounding nodes set their NAV and defer. A hidden node, which cannot hear the RTS from the source, can still hear the CTS from the destination and defers, so collisions at the destination are avoided. The four-frame exchange improves robustness and solves the hidden node problem.

一句话：两帧 = DATA + ACK；四帧 = RTS + CTS + DATA + ACK，靠 CTS 让听不到发送方的隐藏节点也设 NAV 避让。
知识讲解 + 详细解析：SIFS、PIFS、DIFS 排序

知识讲解帧间间隔 = 优先级

帧间间隔（Interframe Space, IFS）是信道空闲后必须再等多久才能发（p.20）。大家看到信道空了都要等，谁要等的时间短，谁先抢到，所以间隔越短、优先级越高。

间隔长度谁用
SIFS（Short IFS）最短ACK、CTS、轮询应答这类立即响应
PIFS（PCF IFS）中间PCF 里 AP 发轮询，优先于普通竞争
DIFS（DCF IFS）最长普通异步数据帧竞争前的最短等待

逐项分析

  • A：错，整个顺序反了，DIFS 是最长的。
  • B：错，PIFS 必须比 DIFS 短，AP 才能压过普通竞争开始 CFP（p.29）。
  • C：对，SIFS < PIFS < DIFS（p.29 原文）。
  • D：错，SIFS 是最短的，ACK 必须最先发出。

记忆：S-P-D：Short 最短，Point 居中，Distributed 最长。优先级 ACK > 有时限分组 > 无时限数据（p.29）。课外补充：标准里 PIFS = SIFS + 1 个时隙，DIFS = SIFS + 2 个时隙。

一句话：选 C：SIFS < PIFS < DIFS，越短越优先。
知识讲解 + 详细解析：DCF 与 PCF 的关系

知识讲解802.11 MAC 的两个子层（p.18）

802.11 的 MAC 叫 DFWMAC，分两层：DCF（分布式协调功能）是基础，用 CSMA/CA 竞争，适合突发数据；PCF（点协调功能）是可选的，与 DCF 共存、建在 DCF 之上，由 AP 轮询，提供面向连接、无冲突、有时限的服务。老师课上强调 PCF 的关键词是"无竞争"（contention-free）。

逐项分析（本题选"错误"的一句）

  • A：正确描述。DCF 用 CSMA/CA，适合异步、突发业务。
  • B：正确描述。PCF 由 AP 轮询，无冲突、有时限。
  • C：错误描述，是答案。PCF 不能单独工作：超帧 = CFP + CP，CP 里大家还是用 DCF 竞争（p.28）；AP 开始 CFP 也是靠 DCF 的帧间间隔机制，用 PIFS 抢信道。
  • D：正确描述，p.18 原话 "Optional, coexist with DCF and built on DCF"。

记忆：DCF 是地基，PCF 是加盖的楼层，没有地基盖不了楼。

一句话：选 C：PCF 是可选的，建立在 DCF 之上，不能单独工作。
知识讲解 + 详细解析：二进制指数退避平均值

知识讲解二进制指数退避（p.22）

站点发送失败（没收到 ACK）说明信道太挤。二进制指数退避（Binary Exponential Backoff, BEB）的思路：每失败一次，把等待的范围翻倍，让大家的重发时间散开，减少再次碰撞。讲义规则：

  • 退避时间在 0 到 CW − 1 个时隙之间均匀随机选，CW 叫竞争窗口（contention window）。
  • 第 1 次尝试 CW = CWmin；每失败一次 CW 翻倍；到 CWmax 后不再增大。
  • 讲义推荐 CWmin = 32，CWmax = 256。

写成公式：第 k 次尝试 CWk = min(CWmin × 2k−1, CWmax)。0 到 N 的整数均匀分布，平均值 = (0 + N) / 2，所以平均退避 = (CW − 1) / 2。老师课上强调 DCF 流程图很重要，二进制指数退避就是用来应对重负载的。

详细解析一步步数

  1. 先把"失败次数"换成"第几次尝试"：失败 3 次后准备的是第 4 次尝试，CW 翻倍了 3 次。
  2. 逐次算 CW，并和上限比较：
第 1 次尝试：CW = 32
第 2 次尝试：CW = 32 × 2 = 64
第 3 次尝试：CW = 64 × 2 = 128
第 4 次尝试：CW = 128 × 2 = 256（= CWmax，刚好到顶）
可选值：0, 1, …, 255，共 256 个
平均 = (0 + 255) / 2 = 127.5 个时隙

验算：平均值应略小于 CW / 2 = 128，因为最大值是 255 不是 256；127.5 合理。

易错

  • 范围是 0 到 CW − 1，不是 0 到 CW；用 (0 + 256)/2 = 128 就错了。
  • 失败次数和尝试次数差 1。本题因为碰到上限，数错一次结果碰巧不变；但若只失败 2 次（第 3 次尝试），正确是 CW = 128、平均 (0 + 127)/2 = 63.5，数错就会得 127.5。
  • 课外补充：实际 802.11b（DSSS）用 CWmin = 31、CWmax = 1023；考试按讲义的 32 / 256 算。

考试英文写法

CW starts at CWmin = 32 and is doubled after each unsuccessful attempt, up to CWmax = 256. After 3 failures, the 4th attempt uses CW = 32 × 23 = 256 = CWmax. The backoff is uniformly chosen from 0 to CW − 1 = 255 slots, so the mean backoff = (0 + 255)/2 = 127.5 slots.

一句话：第 4 次尝试 CW = 256，退避在 0–255 均匀取，平均 127.5 个时隙。
知识讲解 + 详细解析：CW 到上限后不再增长

知识讲解CWmax 是天花板

讲义 p.22："CW stops increase when it reaches its maximum value CWmax"。翻倍规则只到 CWmax 为止：第 k 次尝试 CWk = min(32 × 2k−1, 256)。为什么要封顶：窗口无限翻倍，一个站失败几次后就要等非常久，时延不可接受，也不公平。

详细解析

  1. 上题第 4 次尝试已是 CW = 256。又失败 2 次 → 第 6 次尝试。
  2. 按公式不封顶会算到 1024，再取上限：
不封顶：32 × 25 = 1024
封顶：CW6 = min(1024, 256) = 256
平均退避仍是 (0 + 255) / 2 = 127.5 个时隙

易错

  • 直接写 1024 或 512 就是忘了上限。
  • 课外补充：标准里发送成功后 CW 重置回 CWmin，重传超过上限次数就丢弃该帧；讲义 p.22 没写，题目问到再提。

考试英文写法

CW is doubled after each failure but stops increasing at CWmax. For the 6th attempt, 32 × 25 = 1024 > 256, so CW = CWmax = 256.

一句话：CW 到 CWmax = 256 就封顶，第 6 次尝试仍是 256。
知识讲解 + 详细解析：RTS/CTS 三方动作

知识讲解信道预约（Channel Reservation，p.24–25）

RTS/CTS 就是"先订座、再上菜"：发送方先用短帧 RTS 订下信道，接收方用 CTS 确认，周围的人从这两个帧里读出要占用多久，自觉让开。用到两个间隔：DIFS（长，普通竞争前要等的）和 SIFS（短，同一次交换里的应答之间用）。同一次交换内部只隔 SIFS，别的站至少要等 DIFS，所以中途没人插得进来。

详细解析按时间顺序

发送方：侦听到信道空闲 DIFS → 发 RTS
接收方：等 SIFS → 回 CTS
发送方：收到 CTS，等 SIFS → 发数据
接收方：收完数据，等 SIFS → 回 ACK
其他站：读 RTS/CTS 的持续时间 → 设 NAV → 等 NAV + DIFS → 退避后再竞争
  1. 发送方先等 DIFS：确认信道真的空了，且让高优先级的帧（用 SIFS、PIFS 的）先走。
  2. 接收方只等 SIFS 就回 CTS、ACK：应答优先级最高，要最快回。
  3. 其他站点做虚拟载波侦听：读出帧里的 duration 字段设置 NAV，推迟"NAV + DIFS"，之后还要走一次退避（p.24 "Backoff after defer"），避免大家同时冲出来。

老师课上说时间线不会让画，但要能按顺序写出每一方的动作。

易错

  • 发送方开头等的是 DIFS 不是 SIFS；中间的应答才用 SIFS。
  • 其他站点推迟的是 NAV + DIFS，最后还有退避，别漏。

考试英文写法

Sender: senses the channel free for a DIFS interval, transmits an RTS to reserve the channel; once a CTS is received, waits for an SIFS and then sends the data packet.

Receiver: on receiving the RTS, waits for an SIFS and responds with a CTS; once the packet has been received, waits for an SIFS and responds with an ACK.

All other stations: listen to the channel, read the duration field and set their NAV, defer access for the NAV time plus DIFS, and then back off.

一句话：发送方 DIFS → RTS，接收方 SIFS → CTS，发送方 SIFS → 数据，接收方 SIFS → ACK；旁人设 NAV，等 NAV + DIFS 再退避。
知识讲解 + 详细解析：NAV 与虚拟载波侦听

知识讲解两种"听信道"的办法

物理载波侦听：真的去测信道上有没有信号。缺点：隐藏节点听不到发送方，测出来是"空"。虚拟载波侦听（virtual carrier sense，p.23）：每个帧带一个持续时间（duration）字段，说明这次传输（含后续分片和 ACK）要占多久；附近节点据此更新自己的计时器 NAV（Network Allocation Vector）。要发送前先看 NAV：不为零就当信道忙，等它数到零。

逐项分析

  • A. 物理载波侦听：错。那是测射频能量，NAV 是读帧里的数字。
  • B. 虚拟载波侦听：对，p.23 原话 "Collision Avoidance is achieved by a virtual carrier sense mechanism"。
  • C. 功率控制：错。NAV 不改发射功率。
  • D. 跳频同步：错。跳频（FHSS）是物理层的事，和 NAV 无关。

记忆：物理侦听是"竖起耳朵听"，虚拟侦听是"看别人贴出的占用时间表"。老师说帧格式里要记的就是地址字段和 duration 字段，后者正是 NAV 的来源。

一句话：选 B：NAV 根据帧里的 duration 字段计时，实现虚拟载波侦听。
知识讲解 + 详细解析：PCF 轮询与超帧

知识讲解PCF 就是 AP 点名

DCF 是大家抢着说，PCF（点协调功能）是 AP 当主持人、挨个点名，所以无冲突、有时限（p.26）。点名期间 AP 占住信道，异步业务全部锁住，DCF 暂停工作。

超帧（superframe，p.28）：两个 DTIM 信标（Delivery Traffic Indication Message，提供同步和定时）之间的时间 = CFP（无竞争期，AP 轮询）+ CP（竞争期，大家用 DCF）。CFP 的长度随业务量变，因为各站发的帧长不同。

详细解析三问逐个答

  1. 轮询过程（p.27）：AP 给某个节点发 CF-Poll；AP 自己有数据时，把数据和 CF-Poll 捎带（piggyback）在一帧里。被点到的节点回 Data+CF-ACK（有数据）或 CF-ACK（没数据）。和这个节点交换完，AP 点下一个。所有节点点完或 CFP 时间到，AP 广播 CF-End 宣布 CFP 结束。
  2. 超帧组成：CFP + CP，由 DTIM 信标开始。AP 在信标里广播实际 CFP 时长，各节点据此设 NAV；CFP 结束时所有节点把 NAV 清零，之后到下一个 DTIM 前都用 DCF 竞争（p.29）。
  3. 为什么 CFP 不会被 CP 打断：因为 SIFS < PIFS < DIFS。AP 用 PIFS 抢信道，普通站点要等更长的 DIFS，AP 一定先拿到；CFP 内部的应答只隔 SIFS，普通站点插不进来。优先级：ACK > 有时限分组 > 无时限数据（p.29）。

易错

  • CF-End 是 AP 广播的，不是最后一个被轮询的站发的。
  • "不被打断"的原因要落到 IFS 长短上，只写"PCF 优先级高"不够。

考试英文写法

Polling is started by the AP sending a CF-Poll frame to a node; if the AP has pending data, it piggybacks the CF-Poll on a data frame. The polled node responds with Data+CF-ACK or CF-ACK. The AP then polls the next node in its list. When all nodes have been polled or the CFP duration has expired, the AP broadcasts a CF-End frame.

A superframe consists of a contention-free period (CFP), in which the AP polls the nodes, followed by a contention period (CP), in which nodes contend using DCF; it starts with a DTIM beacon.

A CFP cannot be interrupted by a CP because SIFS < PIFS < DIFS: the AP seizes the channel with PIFS, which is shorter than the DIFS used by contending stations, so the CFP has higher priority.

一句话：AP 发 CF-Poll 挨个点名、最后广播 CF-End；超帧 = CFP + CP；PIFS 比 DIFS 短，所以 CFP 不会被打断。
知识讲解 + 详细解析：超帧被缩短

知识讲解CP 结束时 AP 要抢信道（p.29）

超帧的标称长度由 DTIM 信标的间隔定好。CP 末尾，AP 用 PIFS 竞争信道：信道空闲，AP 拿到信道，CP 结束、新的 CFP 开始；信道正忙（某站的帧还没发完），AP 只能等它变空，于是 CFP 晚开始，下一周期的超帧被压短，讲义叫 "foreshortened superframe"。

逐项分析

  • A：错。802.11 没有"打断别人"的机制，PIFS 只是让 AP 在信道空闲后先抢，正在发的帧要让它发完。
  • B：对，讲义原话 "resulting in a foreshortened superframe for the next cycle"。
  • C：错。讲义没有"取消 CFP"，只是晚一点开始。
  • D：错。NAV 清零发生在 CFP 结束时（p.29），和这里的情况无关。

记忆：上课铃响了，前一个人话还没说完，老师得等他说完再点名，这节课就短了一截。

一句话：选 B：AP 等信道空闲才能开始 CFP，下一周期的超帧被缩短。
知识讲解 + 详细解析：扫描、认证、关联

知识讲解新节点加入 BSS 的三步（p.31–32）

  1. 扫描（scanning）：先找到 AP、拿到同步信息。被动扫描：等 AP 发的信标帧（Beacon）；主动扫描：自己发 Probe Request，等 AP 回 Probe Response。
  2. 认证（authentication）：AP 和节点交换信息，双方证明自己知道约定的密码。
  3. 关联（association）：交换节点和 BSS 的能力信息，并告诉分布系统（所有 AP）这个节点现在在哪。关联完成后才能收发数据帧。

老师课上特别提到认证这一步，提醒大家一定要设密码；这一题 2025-26 S1 Q4(a) 考过。

逐项分析

  • A：错。还没找到 AP，跟谁认证？
  • B：错。认证必须在关联之前，没确认身份不能登记。
  • C：对。
  • D：错。关联是最后一步。

记忆：找门（扫描）→ 验身份（认证）→ 登记住址（关联）。

考试英文写法

Scanning: the node gets synchronization information from the AP, either passively by waiting for a beacon frame, or actively by sending probe request frames and waiting for a probe response. Authentication: the AP and the node exchange information to prove that each side knows a given password. Association: they exchange information about the node and BSS capabilities, and the distribution system is informed of the node's current position. Only after association can the node transmit and receive data frames.

一句话：选 C：扫描 → 认证 → 关联，关联完才能收发数据。

知识讲解 + 详细解析：802.11e 的 EDCA

知识讲解802.11e 给业务分优先级（p.39–40）

原始 DCF 对所有帧一视同仁，语音、视频得不到保证。802.11e 加了两种模式：EDCA（增强分布式信道接入）是带优先级的 DCF；HCCA 类似 PCF，由混合协调器 HC 按各业务类的负载调度无竞争发送机会。

EDCA 的做法（讲义原话 "eight traffic classes"）：8 个业务类，每类在节点内有自己的队列和独立的退避参数，再加一个仲裁帧间间隔 AIFS（Arbitration IFS）。各类先在节点内部竞争一个"虚拟信道"，胜出的帧再像原来的 DCF 一样竞争真正的信道。AIFS 短、竞争窗口小的类，等得少，就更优先，和 b6 里"间隔越短越优先"是同一个道理。

逐项分析

  • A. 4 个，靠不同信道：错。数量和讲义不符；而且各类共用同一个信道，靠的是参数不同，不是信道不同。
  • B. 8 个，靠各自的退避参数和 AIFS：对，按讲义。
  • C. 8 个，靠 AP 轮询：错。轮询是 HCCA（和 PCF）的做法，EDCA 是竞争式的。
  • D. 16 个，靠 QCI：错。QCI 是 LTE 承载的 QoS 标识（p.71），不是 WLAN 的。

课外补充标准里其实是 4 个接入类别

802.11e 标准中是 8 个用户优先级（0–7），映射成 4 个接入类别 AC：背景 AC_BK、尽力而为 AC_BE、视频 AC_VI、语音 AC_VO，每个 AC 一个队列、一套 AIFS 和 CW。讲义写的是 8 个业务类，考试按讲义选 8；简答题也照讲义写 "eight traffic classes"。

一句话：选 B：EDCA 有 8 个业务类（讲义说法），每类独立队列、独立退避参数和 AIFS。
知识讲解 + 详细解析：MANET 是什么

知识讲解没有基础设施的网

移动自组网（Mobile Ad Hoc Network, MANET）：一组无线移动节点，在没有基础设施（没有 AP、没有基站）的地方，自由、动态地自己组织成临时的、任意形状的网络（p.42）。它是对等（peer-to-peer）网络：不需要固定控制器，控制器由节点动态选举或分散在所有节点上；网络自建、自组织、自管理（self-creating, self-organizing, self-administering，p.43）。

有 AP 的 WLANMANET
基础设施AP + 分布系统没有
控制AP 集中协调动态选举或分布式
转发都经过 AP，单跳到 AP节点互相转发，可多跳

详细解析答题要点

  1. 定义：写出"无基础设施、自组织、临时拓扑"三个关键词。
  2. 最大区别：每个节点都必须能按需当路由器（p.45）。A 和 C 之间没有直接无线信道时，由中间节点 B 中继，这就是多跳（multi-hop）。选的路径必须无环（loop free），才叫路由。
  3. 可以补一句：802.11 很简单，适合做单跳自组网，也能搭几平方公里的多跳网；蓝牙可以组半径约 10 m 的体域网 / 个域网（p.43）。

易错

  • 只答"没有 AP"不够，要点出"每个节点都是路由器、多跳中继"。

考试英文写法

No fixed controller is required: a controller is dynamically elected or distributed among the nodes, and the network is self-creating, self-organizing and self-administering. The key difference from an infrastructure WLAN is that every node must be able to act as a router on demand: when two nodes have no direct radio channel, intermediate nodes relay the packets (multi-hop), instead of all traffic going through an AP.

一句话：MANET 是无基础设施、自组织的临时网络；和 WLAN 最大的区别是每个节点都要当路由器、多跳转发。
知识讲解 + 详细解析：隐藏节点在哪

知识讲解冲突发生在接收端

无线冲突要看接收端：只要 B 同时收到两路信号，B 就收不好。隐藏节点（hidden node，p.48）= 在目的端 B 范围内、在发送端 A 范围外的节点 C。C 听不到 A，侦听结果是"信道空"，一发就在 B 处和 A 的数据撞车，造成低利用率。解决：RTS/CTS，C 虽听不到 A 的 RTS，却能听到 B 的 CTS，于是设 NAV 推迟（p.17）。

逐项分析

  • A. 在 A 范围内、B 范围外：错。它听得到 A，会主动避让，不是隐藏节点。（课外补充：这种节点叫"暴露节点" exposed node，它想发给别人时会被 A 不必要地挡住。）
  • B. 在 B 范围内、A 范围外：对。
  • C. 同时在两人范围内：错。它能听到 A，载波侦听就够用了。
  • D. 不在任何人范围内：错。它的信号到不了 B，不会造成冲突。

记忆："藏"在发送方的视线外，却站在接收方身边。

一句话：选 B：隐藏节点在目的端范围内、发送端范围外。
知识讲解 + 详细解析：自组网的路由协议

知识讲解四类路由方式（p.51–53）

类别什么时候找路由代价
周期性（表驱动）一直周期交换，不管用不用随时有路，但耗带宽
按需（on-demand）有数据要发才做路由发现，通信期间维护省带宽，首包要等发现

老师课上说：按需路由只在需要时做路由发现，只激活相关节点，不浪费带宽。

逐项分析

  • A. 周期性：错，正好相反，平时一直在维护。
  • B. 按需：对，p.52 原话 "create routes only when necessary"。
  • C. 混合：错，它在本地区域仍周期维护。
  • D. 基于位置：错，它根本不建路由，靠位置逐跳转发。

课外补充：常见例子 AODV、DSR 是按需，DSDV、OLSR 是表驱动，ZRP 是混合。

一句话：选 B：按需协议平时不维护路由，有数据要发才发起路由发现。
知识讲解 + 详细解析：组合稳定性

知识讲解拓扑在变，更新跟得上吗

自组网里"谁能直接连到谁"（可达关系）会随时间变化，原因是：节点移动、电池耗尽、软件或硬件故障（p.47）。每次变化都要发拓扑更新，这些更新会吃掉本来给用户数据的带宽。

组合稳定性（combinatorial stability）：在给定的时间窗内，如果拓扑变化足够慢，慢到所有必要的拓扑更新都能成功传播出去，这个网络在这段时间内就是组合稳定的。"组合"指的是节点之间的连接关系（哪些边存在），稳定就是这张连接图的变化速度不超过网络消化更新的速度。

详细解析由哪些因素决定

  1. 网络的连通性：连接关系本身变得多快、多剧烈。
  2. 路由协议的复杂度：协议越复杂，一次更新要交换的消息越多、传播越慢。
  3. 节点的瞬时计算能力：节点算得慢，处理更新就慢。

讲义原话强调"不仅取决于连通性"，所以三个因素都要写，只写"移动速度"会丢分。

易错

  • "拓扑变化的原因"（移动、电池、故障）和"稳定性的决定因素"（连通性、协议复杂度、计算能力）是两组东西，别混在一起答。

考试英文写法

The reachability relations among nodes change with time because of node mobility, battery depletion and software or hardware failures, and the resulting topology updates consume bandwidth. Given a specific time window, an ad hoc network is combinatorially stable if and only if the topology changes occur sufficiently slowly to allow successful propagation of all necessary topology updates. Combinatorial stability is determined not only by the connectivity properties of the network, but also by the complexity of the routing protocol in use and the instantaneous computational capacity of the nodes.

一句话：拓扑变化慢到所有更新都能传播完就叫组合稳定，取决于连通性、路由协议复杂度和节点计算能力。
知识讲解 + 详细解析：WSN 与自组网四点不同

知识讲解传感器网络是什么

无线传感器网络（Wireless Sensor Network, WSN）：大量低成本、低功耗的小节点（感知 + 数据处理 + 通信），密集地部署在被测现象内部或附近，可以随机撒在难以到达的地方或灾区；协议必须能自组织，节点要相互协作（p.76）。它要用自组网技术实现，但自组网已有的协议不一定适合，因为有四点不同（p.56）。

方面一般自组网传感器网络
节点数量较少多几个数量级
部署与拓扑拓扑会变部署密集、易失效，拓扑变化非常频繁
通信方式点对点广播
资源笔记本、手机，较充足功率、计算能力、内存都很有限

详细解析每点为什么重要

  1. 数量大 → 协议要能扩展，不能每个节点都存全网路由表。
  2. 密集、易坏、拓扑常变 → 路由要能快速自愈。
  3. 广播 → MAC 要尽量减少和邻居广播的冲突（p.59）。
  4. 资源有限 → 一切以省电为先；老师课上说功耗是最关键的因素，因为节点大多靠电池。

结论：自组网的协议不能直接照搬到传感器网络。

(2) Sensor nodes are densely deployed and prone to failures, so the topology changes very frequently. (3) Sensor nodes use a broadcast communication paradigm, while ad hoc networks are based on point-to-point communications. (4) Sensor nodes are limited in power, computational capacity and memory. Therefore protocols designed for ad hoc networks may not fit sensor networks well.

知识讲解 + 详细解析：传感器协议栈三平面

知识讲解五层 + 三个平面（p.59）

五层自下而上：物理层（简单而稳健的调制、收发）、MAC 层（要省电、尽量减少与邻居广播的冲突）、网络层（给传输层交来的数据选路）、传输层（维持数据流）、应用层。另有三个管理平面纵向贯穿各层，监控节点之间的：

  • 功率管理：节点怎么用电，比如电量低时少转发。
  • 移动管理：节点的移动，记住邻居是谁。
  • 任务管理：在节点间分配感知任务。

老师课上说协议栈记住五层就行，功耗是最关键的因素。

逐项分析

  • A. 功率、移动、任务：对，p.59 原话 "power, mobility, and task management planes"。
  • B. 安全、QoS、计费：错，讲义的传感器协议栈没有这三项。
  • C. 时钟、路由、存储：错，路由是网络层的事，不是平面。
  • D. 频率、功率、编码：错，频率和编码属于物理层。

记忆：传感器最缺电、会挪动、要分工，所以是"电、动、活"三个平面。

一句话：选 A：三个管理平面是功率、移动、任务。

一句话：选 B：eNodeB 之间是 X2，到核心网是 S1（S1-MME 到 MME，S1-U 到 S-GW）。
知识讲解 + 详细解析：E-UTRAN 的功能

知识讲解无线的事都归 eNodeB

E-UTRAN 负责所有和无线有关的功能（p.64）。因为接入网只有 eNodeB 一种节点、没有集中控制器（p.63），这些功能全部集成在 eNodeB 里。课外补充：3G 里有集中的无线网络控制器 RNC，LTE 把它去掉、做成扁平结构，路径更短、时延更低。

详细解析四类功能，逐条说为什么

  1. 无线资源管理（Radio Resource Management）：与无线承载有关的全部功能：无线承载控制、无线接纳控制、无线移动性控制、上下行的调度和动态资源分配。为什么：空口资源（时间、频率）有限，要按需分给各 UE。
  2. 包头压缩（Header Compression）：压缩 IP 包头，减少开销。为什么：语音等小包的 IP 头占比大，压缩后空口效率更高。
  3. 安全（Security）：空中接口上发送的所有数据都加密。为什么：无线信号谁都能收到。
  4. 连接 EPC（Connectivity to the EPC）：到 MME 的信令和到 S-GW 的承载路径，也就是 S1-MME 和 S1-U。

易错

  • 无线资源管理下的四个小项（承载控制、接纳控制、移动控制、调度）要写全，这是得分细节。
  • 别把核心网的功能（如 MME 的移动性管理信令处理）写成 E-UTRAN 的。

考试英文写法

The E-UTRAN is responsible for all radio-related functions: (1) radio resource management, i.e. all functions related to radio bearers, including radio bearer control, radio admission control, radio mobility control, and scheduling and dynamic allocation of resources to UEs in both uplink and downlink; (2) header compression of IP packet headers to reduce overhead; (3) security: all data sent over the radio interface is encrypted; (4) connectivity to the EPC: the signalling towards the MME and the bearer path to the S-GW. All these functions reside in the eNodeBs; there is no centralized controller.

一句话：E-UTRAN 管无线资源管理、包头压缩、空口加密、连接 EPC，全部做在 eNodeB 里。

知识讲解 + 详细解析：LTE 帧里有几个时隙

知识讲解FDD 帧结构（p.66）

LTE 在时间上分三级：无线帧（radio frame）10 ms → 子帧（subframe）1 ms → 时隙（slot）0.5 ms。FDD（频分双工）模式下，一帧 10 个子帧，每个子帧 2 个时隙。TDD 模式帧长也是 10 ms，但分成两个 5 ms 半帧，里面可能有含 DwPTS、GP、UpPTS 的特殊子帧，本题问的是 FDD。

详细解析两种算法互相验算

按层级：10 个子帧 × 2 个时隙/子帧 = 20 个时隙
按时长：10 ms ÷ 0.5 ms = 20 个时隙

课外补充：1 ms 的子帧是 LTE 调度的基本时间单位（TTI）；一个时隙是资源块在时间上的长度（见 b28）。

易错

  • 别把子帧（10 个）当成时隙（20 个）。

考试英文写法

In FDD mode, each 10 ms radio frame consists of 10 subframes of 1 ms, and each subframe consists of 2 slots of 0.5 ms. Hence one radio frame contains 10 × 2 = 20 slots (check: 10 ms / 0.5 ms = 20).

一句话：10 ms 帧 = 10 个 1 ms 子帧 = 20 个 0.5 ms 时隙。
知识讲解 + 详细解析：资源块里的资源单元

知识讲解资源网格（p.67）

LTE 下行用 OFDMA，资源是一张"时间 × 频率"的网格。

  • 资源单元 RE（Resource Element）：1 个子载波 × 1 个 OFDM 符号，网格里最小的一格。
  • 资源块 RB（Resource Block）：频域 12 个子载波 × 时域 1 个时隙（0.5 ms）。
  • 一个时隙里有几个 OFDM 符号取决于循环前缀 CP：常规 CP 是 7 个，扩展 CP 是 6 个（大小区用，见 b29）。

老师课上也提到每个资源块 12 个子载波。

详细解析

常规 CP：RE = 12 子载波 × 7 符号 = 84 个
扩展 CP：RE = 12 子载波 × 6 符号 = 72 个

课外补充：LTE 子载波间隔 15 kHz，所以一个 RB 宽 12 × 15 = 180 kHz；一个 1 ms 子帧里两个时隙的 RB 对共 2 × 84 = 168 个 RE。

易错

  • RB 在时间上是 1 个时隙，不是 1 个子帧，别乘成 12 × 14。
  • 题目写"常规循环前缀"就用 7；没说明时按常规 CP 算，并注明假设。

考试英文写法

A resource block spans 12 subcarriers in the frequency domain and one slot in the time domain. With the normal cyclic prefix there are 7 OFDM symbols per slot, and a resource element is one subcarrier × one OFDM symbol, so one RB contains 12 × 7 = 84 REs (72 with the extended CP).

一句话：RB = 12 子载波 × 7 符号 = 84 个 RE（扩展 CP 为 72）。
知识讲解 + 详细解析：何时用扩展 CP

知识讲解循环前缀挡回波

循环前缀（Cyclic Prefix, CP）是把 OFDM 符号末尾的一小段复制到符号前面，当保护间隔。多径信号走不同的路，晚到的回波会拖进下一个符号造成干扰；只要保护间隔不短于最大时延扩展，回波就落在 CP 里，接收机丢掉 CP 即可。Part 2 第 7 章 p.17 的条件：保护间隔 TG ≥ 最大时延扩展 TD。

讲义 Part B p.67："The extended CP is used when the cell size is large."小区大 → 反射路径长、回波来得更晚 → 时延扩展大 → 要更长的 CP。代价：时隙长度固定 0.5 ms，CP 变长后只放得下 6 个符号（常规 7 个），开销变大。

逐项分析

  • A. 小区很小：错，小区小时延扩展小，常规 CP 就够。
  • B. 小区很大：对，p.67 原文。
  • C. 上行时：错，CP 长短看时延扩展，不看上下行。
  • D. TDD 模式：错，FDD 和 TDD 都有常规 / 扩展两种 CP。

课外补充：常规 CP 约 4.7 μs，对应路程差 4.7 μs × 3×10⁸ m/s ≈ 1.4 km；扩展 CP 约 16.7 μs，对应约 5 km，所以能容忍大小区里更远的回波。

一句话：选 B：大小区时延扩展大，用扩展 CP，代价是每时隙只剩 6 个符号。
知识讲解 + 详细解析：GBR 与 non-GBR 承载

知识讲解承载是什么

LTE 全 IP，用EPS 承载（bearer）把 IP 业务从 PDN 网关送到 UE：一个承载就是网关和 UE 之间一条有确定 QoS 的 IP 分组流，是一条逻辑连接（p.68）。每个承载都有一个 QCI 和一个 ARP（p.69）。按提供的 QoS 分两类，老师课上说记住这两类就行。

GBR 承载non-GBR 承载
速率保证有最低保证速率 GBR不保证任何速率
资源建立（或修改）时永久分配专用资源不永久分配
上限资源富余时可超过 GBR，上限是 MBR—
适合VoIP、语音网页浏览、FTP

详细解析答题要点

  1. 区别：按上表三行写：保证不保证、资源是否永久分配、典型业务。GBR 提一句 MBR 更完整。
  2. 默认承载（default bearer）：必须是 non-GBR，UE 一接入网络就建立，用于初始连接（p.70）。为什么：UE 刚开机还不知道要跑什么业务，不能一上来就永久占资源。
  3. 专用承载（dedicated bearer）：可以是 GBR 也可以是 non-GBR，有新业务、QoS 要求不同时才建立。

易错

  • GBR 不是"速率固定"：资源有富余时可以超过 GBR，最多到 MBR。

考试英文写法

A GBR bearer has a minimum guaranteed bit rate, for which dedicated transmission resources are permanently allocated at bearer establishment or modification; it is used for applications such as VoIP. A bit rate higher than the GBR may be allowed if resources are available, up to the maximum bit rate (MBR). A non-GBR bearer does not guarantee any particular bit rate and no bandwidth resources are allocated permanently; it is used for web browsing or FTP. The default bearer, created when the UE connects to the network, must be a non-GBR bearer; a dedicated bearer can be either GBR or non-GBR.

一句话：GBR 保证最低速率、永久占资源（VoIP），non-GBR 不保证（网页）；默认承载必须是 non-GBR。
知识讲解 + 详细解析：ARP 与 QCI 的分工

知识讲解每个承载两个 QoS 参数

ARP（Allocation and Retention Priority，分配与保持优先级，p.74）用于呼叫接纳控制和抢占：无线拥塞时决定新承载建不建；新承载请求来时决定能不能抢占别人；系统过载时决定先断哪些连接，保住高优先级连接。承载建立成功后，ARP 不再影响分组转发。

QCI（QoS Class Identifier，p.71–73）由优先级、分组时延预算、可接受丢包率刻画，决定 eNodeB 怎么处理分组：调度、队列管理、限速策略和 RLC 模式；丢包要求严的承载用 RLC 确认模式（AM）。转发处理由 QCI、GBR、MBR 决定。

逐项分析

  • A：错，正好是讲义说 ARP 不管的事，那是 QCI、GBR、MBR 的职责。
  • B：对，p.74 的三条：接纳、抢占、过载时断谁。
  • C：错，调制方式属于链路自适应（p.75 列为开放问题），与 ARP 无关。
  • D：错，RLC 模式由 QCI 决定（p.73）。

记忆：ARP 管"门口"（进不进、踢谁走），QCI 管"路上"（怎么排队、怎么送）。

一句话：选 B：ARP 决定拥塞时接不接纳、能否抢占、过载先断谁；建好后转发看 QCI。
知识讲解 + 详细解析：IoT 五大挑战

知识讲解IoT 难在哪

物联网（Internet of Things, IoT）就是把原来不联网的物体连起来，让它们能和人、和其他物体通信交互（p.78）。设备一多、数据一多、标准一多，就带来五个挑战（p.82–83）。这一题 2025-26 S1 Q4(b) 期末考过。

详细解析五点，每点"是什么 + 为什么难"

  1. 可扩展性（Scalability）：规模要扩到数以百万计的设备，整个系统怎么支撑是关键问题；网络层可以靠 IPv6 给设备分配海量地址。
  2. 安全（Security）：越来越多的"物"互相连接，攻击面大大扩大；一个设备被黑，它的连接就成了问题，被攻破的设备可以当跳板攻击其他设备和系统。
  3. 隐私（Privacy）：传感器越来越多，采到的数据很多和具体的人及其活动有关，可能含敏感信息和凭据；数据怎么保护、要不要共享、和谁共享是关键问题。
  4. 大数据与分析（Big data and analysis）：海量传感器带来数据洪流；难点是要及时处理来自不同来源、不同格式的海量数据，才能得到有价值的信息。
  5. 互操作性（Interoperability）：各种协议和架构争夺市场和标准，有的专有、有的开放；新标准能缓解，但实现方式仍然很多。

易错

  • "大数据与分析"算一点，不要拆成两点再漏掉互操作性。
  • 每点要写一句解释，只列五个名词拿不全分。

考试英文写法

(1) Scalability: the IoT may grow to millions of devices, and how the overall system supports such a huge number of devices is a critical issue; IPv6 can provide the addresses. (2) Security: the threat surface is greatly expanded, and a compromised device can serve as a launching point to attack other devices and systems. (3) Privacy: much of the sensed data is specific to individuals and their activities and may contain sensitive information; how it is protected and with whom it is shared is critical. (4) Big data and analysis: the deluge of data from many sources in various forms must be evaluated in a timely and efficient manner. (5) Interoperability: various proprietary and open protocols and architectures compete for market share and standardization.

一句话：IoT 五大挑战：可扩展性、安全、隐私、大数据与分析、互操作性。
知识讲解 + 详细解析：IoTWF 参考架构几层

知识讲解 + 详细解析：核心功能栈与四子层

知识讲解核心 IoT 功能栈（p.88–90）

简化框架有两个并行栈，这题问的是核心 IoT 功能栈（Core IoT Functional Stack），它描述"物"怎么把信息送到应用：

  1. "物"层（Things：传感器和执行器）：物理设备，既要适应部署环境的限制，又要提供所需信息。
  2. 通信网络层（Communications network layer）：智能物体不能自给自足时，要和外部系统通信，分四个子层。
  3. 应用与分析层（Application and analytics layer）：处理采集的数据，必要时控制智能物体，并据此做智能决策。

这一部分是期末高频题：2024-25 S2 Q4(b) 和 2025-26 S2 Q4(d) 两次考了通信网络层的四个子层，2023-24 S2 Q4(a) 要求描述两个并行栈。

详细解析通信网络层的四个子层，自下而上

子层做什么例子
接入网IoT 网络的"最后一公里"802.11ah、802.15.4g、LoRa

记忆："接入 → 汇聚回传 → 传输（IP）→ 管理（应用协议）"。

易错

  • 网络传输子层是 IP/UDP/TCP，网络管理子层是 HTTP/WebSocket，别放反。
  • "三层"问的是功能栈，不是数据管理与计算栈（边缘 / 雾 / 云）。

考试英文写法

The Core IoT Functional Stack has three layers: (1) the "things" layer of sensors and actuators; (2) the communications network layer; (3) the application and analytics layer. 知识讲解 + 详细解析：选接入技术看什么

  1. 通信距离：智能物体到信息采集器有多远，决定选哪一档（PAN、HAN……）。
  2. 单个采集小区里的目标设备数量：结合传输距离和所需吞吐量，这个参数决定小区大小。

  • C. 技术成本：包括，第三因素。
  • D. 屏幕分辨率：不包括，是答案。大多数传感器根本没有屏幕，这是终端显示属性，与接入网络无关。

知识讲解 + 详细解析：为什么需要雾计算

知识讲解全送云端的好处和问题

最自然的做法是把数据全送到云端集中处理，好处是简单：物体只要连上一个中心应用，它能看到所有节点、做所有分析（p.103）。但 IoT 数据量太大，带宽管理成问题：网络要扛得住流量，服务器要吞得下、存得下、算得动（p.104）。

详细解析第一问：五个问题（p.105）

  1. 最后一公里带宽很小：接入网多是低功耗无线，传不了海量原始数据。
  2. 时延大：来回一趟云端，做不到实时响应。
  3. 回程不可靠：网关的回程常靠 3G/LTE 甚至卫星。
  4. 回程上数据量太大，处理不过来。
  5. 大数据越来越大：实时分析和响应几乎不可能。

详细解析第二问：雾计算怎么解决（p.106–108）

  • 思路：把数据管理分布到整个 IoT 系统里，尽量靠近 IP 网络的边缘。任何有计算、存储和联网能力的设备都可以当雾节点（fog node），多了一个"雾层"。
  • 好处：在数据产生处附近分析 → 时延最小；把大量流量从核心网卸掉；敏感数据留在本地网络。
  • 还有：雾节点离传感器近，有上下文感知，能更快对事件作反应，形成分布式的边缘控制回路；上传前先做数据精简（p.108）。

老师课上强调雾计算的好处：分布式处理，不用等中心服务器，所以快；上传前先精简数据；能实时处理。

易错

  • 雾计算不取代云，二者互补（p.111）；别写成"不用云了"。

考试英文写法

Sending all IoT data to the cloud is a problem because: the bandwidth of last-mile IoT networks is very limited; latency can be very high, so real-time response is lost; the backhaul from the gateway can be unreliable, often depending on 3G/LTE or even satellite links; the volume of data on the backhaul is too high; and big data keeps growing, making real-time analysis almost impossible.

Fog computing distributes data management throughout the IoT system, as close to the network edge as possible. Any device with computing, storage and network connectivity can be a fog node. Analysing data close to where it is collected minimizes latency, offloads network traffic from the core network and keeps sensitive data inside the local network; the fog node is aware of the context of its sensors and can react to events quickly, and the data is reduced before being sent upstream.

一句话：全送云端会遇到带宽小、时延大、回程不可靠、数据太多；雾计算在边缘附近处理，降时延、减流量、数据留本地。
知识讲解 + 详细解析：雾计算五个特点

知识讲解雾节点在哪、干什么

雾节点是放在 IoT 终端附近的、有计算存储联网能力的设备（常见在网关、路由器里），在数据送到云之前先处理一遍（p.106）。讲义 p.109 把它的特点总结成五条。这一题 2025-26 S1 Q4(c) 期末考过。

详细解析五条，每条说清"为什么"

  1. 上下文位置感知、低时延（contextual location awareness and low latency）：雾节点尽量靠近 IoT 终端，知道自己管的是哪些传感器，就近处理所以快。
  2. 地理上分布（geographic distribution）：雾节点服务的业务和应用需要大范围分散部署。
  3. 部署在大量 IoT 终端附近（deployment near IoT endpoints）：通常有大量终端的地方才放雾节点。
  4. 雾与终端之间用无线通信（wireless communication）：一个雾节点要连大量终端，无线接入最容易扩展。
  5. 用于实时交互（use for real-time interactions）：在雾节点上先做预处理，上层应用只需对一部分数据做批处理。

老师课上强调的四个好处（快、先精简数据、实时、无线连接）都能对应到这五条里。

易错

  • "特点"和"雾计算要解决的问题"（b37）不是一回事，别答成带宽小、时延大那一组。

考试英文写法

(1) Contextual location awareness and low latency: the fog node sits as close to the IoT endpoints as possible to deliver distributed computing. (2) Geographic distribution: the services and applications targeted by fog nodes demand widely distributed deployments. (3) Deployment near IoT endpoints: fog nodes are typically deployed in the presence of a large number of IoT endpoints. (4) Wireless communication between the fog and the IoT endpoints: since a fog node deals with a large number of endpoints, wireless access is the easiest way to achieve scalability. (5) Use for real-time interactions: pre-processing at the fog nodes allows upper-layer applications to perform batch processing on only a subset of the data.

一句话：雾计算五特点：位置感知低时延、地理分布、靠近大量终端、与终端无线连接、用于实时交互。
知识讲解 + 详细解析：边缘、雾、云的分工

边缘（mist / edge）计算：把雾再往前推，直接放进 IoT 终端设备本身，有算力的终端自己做初步分析和过滤（p.110）。边缘、雾、云互补而不是互相取代（p.111）：边缘和雾是第一道防线，过滤和分析数据，免得每个事件都去问云。数据去哪处理，看它多急（p.113）：

可以等几秒到几分钟汇聚节点（aggregation node）

知识讲解 + 详细解析：三类轨道的高度

知识讲解高度决定一切

卫星按高度分三类（讲义 Part C p.10）：GEO（地球静止轨道，Geostationary Earth Orbit）35,863 km；MEO（中轨，Medium Earth Orbit）8,000–18,000 km；LEO（低轨，Low Earth Orbit）500–1,500 km。越高，看到的地面越大、绕一圈越慢，但信号越弱、时延越大。GPS 用的是 24 颗 MEO（p.9）。老师课上强调：GEO 离地约 36,000 km，所以地面站必须用高增益天线。

逐项分析四个选项

  • A 对：三个数字和 p.10 完全一致。
  • B 错：GEO 只有一个高度 35,863 km，20,000 km 属于 MEO 范围；100 km 太低，大气阻力会让卫星很快掉下来。
  • C 错：GEO 对，但 MEO、LEO 的范围都写低了；讲义 LEO 下限是 500 km。
  • D 错：42,000 km 是 GEO 到地心的轨道半径（6,370 + 35,863 = 42,233 km），不是离地高度。

记忆口诀

"低一千、中一万、静止三万六"：LEO 约 1,000 km 量级，MEO 约 10,000 km 量级，GEO 约 36,000 km。

一句话：GEO 35,863 km，MEO 8,000–18,000 km，LEO 500–1,500 km，选 A；42,000 km 是轨道半径，别混。
知识讲解 + 详细解析：轨道按形状和倾角分类

知识讲解描述一条轨道的三个维度

讲义 Part C p.10–11 用三个维度描述卫星轨道：高度（GEO / MEO / LEO，见 c1）、形状（shape）和倾角（inclination）。本题问后两个。

维度分类要点
形状圆轨道（circular）圆心在地心，高度不变
形状椭圆轨道（elliptical）地心在椭圆的一个焦点上，高度时高时低
倾角赤道轨道（equatorial）轨道面就是赤道面
倾角极轨道（polar）经过南北两极
倾角倾斜轨道（inclined）其他所有倾角

详细解析为什么这样分

  1. 形状决定卫星离地距离是否变化：圆轨道上信号损耗、时延都稳定；椭圆轨道在远地点走得慢，可以在某地区上空停留较久。
  2. 倾角决定卫星能飞过哪些纬度：赤道轨道永远只在赤道上空，高纬度地区仰角很低；极轨道每圈都经过两极，地球在下面自转，几圈下来可以扫过全球。
  3. GEO = 圆轨道 + 赤道轨道 + 35,863 km，三个条件缺一不可，否则卫星相对地面不会"静止"（p.15）。

课外补充（讲义没有）

极轨道常用于对地成像、气象卫星；高倾角椭圆轨道（如俄罗斯的 Molniya 轨道）用来照顾 GEO 覆盖不好的高纬度地区。

易错

  • 椭圆轨道是"一个焦点在地心"，不是"中心在地心"。
  • 倾斜轨道是"除赤道、极轨道以外的其他轨道"，不要只答两类。

考试英文写法

By shape: (1) circular orbit, with the centre of the circle at the earth's centre; (2) elliptical orbit, with one focus at the earth's centre. By inclination: (1) equatorial orbit, directly above the earth's equator; (2) polar orbit, passing over both poles; (3) all other orbits are called inclined orbits. (A GEO satellite uses a circular equatorial orbit at 35,863 km.)

一句话：形状分圆（圆心在地心）和椭圆（一个焦点在地心）；倾角分赤道、极轨道和倾斜轨道。
知识讲解 + 详细解析：仰角与覆盖角

知识讲解两个角度定位卫星

讲义 Part C p.12–13：卫星在天空中的位置用两个角度描述。

  • 仰角 θ（elevation angle）：站在地面站，从水平线（地表在天线处的切线）抬头到天线主瓣中心（天线正对卫星）的夹角。θ = 90° 是正头顶，θ = 0° 是贴着地平线。
  • 覆盖角 β（coverage angle）：在最小仰角下，卫星能看到的那部分地球表面有多大，用地心处张开的角度表示。

两者的关系（由 p.13 的几何图推出，讲义没写公式）：cos(θ + β) = R·cos θ / (R + h)，R 是地球半径，h 是卫星高度。最小仰角 θ 越小，β 越大。

详细解析答题要点逐条展开

  1. 仰角：要说清"从哪里量到哪里"——从地面站处的地表切线量到天线指向卫星的主瓣中心。只写"天线抬起的角度"会丢分。
  2. 覆盖角：关键词是"在最小仰角下卫星可见的地表部分"。
  3. 理想最小仰角 = 0°：仰角下限放到 0°，离星下点很远的地面站也能看到卫星，覆盖一直延伸到卫星的光学地平线（optical horizon），覆盖最大（p.12）。
  4. 实际不用 0°：仰角越低，信号穿过的大气越厚，雨、雾、大气吸收都大增（p.21、p.23），所以实际取 5°–10°。
GEO，θ = 0°：cos β = 6370 / 42233 = 0.1508 → β = 81.3°
GEO，θ = 10°：cos(θ + β) = 6370 × 0.9848 / 42233 = 0.1485 → θ + β = 81.46° → β = 71.46°
覆盖直径 ≈ 2βR：0° 时约 18,000 km，10° 时约 15,900 km（≈ 讲义 p.14 表里的 16,000 km）

易错

  • 仰角在地面站处量，覆盖角在地心处量，别画错位置。
  • "理想 0°"是为了覆盖最大，不代表实际最好；两句都要写，体现权衡。

考试英文写法

Elevation angle θ is the angle from the horizontal (the line tangent to the earth's surface at the antenna's location) to the centre of the antenna's main beam when the antenna points directly at the satellite. Coverage angle β is the measure of the portion of the earth's surface visible to the satellite with the minimum elevation angle. To obtain maximum coverage, a minimum elevation angle of 0° is preferred, so that the coverage extends to the satellite's optical horizon in all directions. In practice a few degrees (e.g. 5°–10°) is used, because at low elevation the signal passes through more atmosphere and suffers larger attenuation.

一句话：仰角在地面站量（切线到卫星方向），覆盖角在地心量（最小仰角下可见的地表）；理想最小仰角 0°，覆盖到光学地平线。
知识讲解 + 详细解析：GEO 传播时延

知识讲解时延 = 路程 ÷ 光速

无线电波在真空中以光速 c = 3×10⁸ m/s = 300,000 km/s 传播。传播时延 t = d / c。卫星通信里，信号从一个地面站上行到卫星，卫星转发后再下行到另一个地面站，所以路程是"上 + 下"两段。讲义 Part C p.16：两地都在卫星正下方时，"round-trip propagation delay"是 0.24 s；p.14 表里 GEO 往返时延约 250 ms。这里的"往返"指经卫星走一趟（地 → 星 → 地）。

详细解析一步一步算

  1. 做什么：求路程。为什么：两站都在卫星正下方附近，斜距 ≈ 高度 h。
  2. 做什么：除以光速。注意单位统一用 km 和 km/s。
d = 2 × 35,863 km = 71,726 km
t = 71,726 km ÷ 300,000 km/s = 0.239 s ≈ 0.24 s

合理性检查：和讲义 p.16 的 0.24 s 一致。如果地面站在覆盖边缘（仰角 10°），斜距约 40,660 km，一趟约 0.27 s，所以表里写"约 250 ms"是个典型值。打电话"一问一答"要经过卫星两趟，约 0.48 s，能明显感觉到停顿。

易错

  • 只算单程 35,863 km 得 0.12 s：漏了下行那一段。
  • 把 "round trip" 理解成对话一来一回再乘 2 得 0.48 s：讲义的 0.24 s 指地 → 星 → 地一趟。
  • km 和 m 混用，差 1000 倍。

考试英文写法

Path length = uplink + downlink = 2 × 35,863 km = 71,726 km. Propagation delay t = d / c = 71,726 km / (3 × 10⁵ km/s) ≈ 0.239 s ≈ 0.24 s.

一句话：上行 + 下行共 71,726 km，除以 3×10⁵ km/s，约 0.239 s。
知识讲解 + 详细解析：GEO 覆盖角

知识讲解从 p.13 的几何图出发（课外补充）

讲义 Part C p.13 只画了图，公式是本题补充的。画三角形 O–E–S：O 是地心，E 是地面站，S 是卫星。OE = R（地球半径），OS = R + h。仰角 θ = 0° 时，地面站看卫星的视线正好贴着地表，和半径 OE 垂直，所以三角形在 E 处是直角。直角三角形里，β 的邻边是 R，斜边是 R + h：

cos β = R / (R + h)

一般仰角时公式是 cos(θ + β) = R·cos θ / (R + h)，θ = 0° 时就退化成上式。

详细解析一步一步算

  1. 求 R + h：卫星到地心的距离。
  2. 求 cos β，再用计算器 cos⁻¹（注意计算器在 DEG 模式）。
  3. 换成地面直径：弧长 = 半径 × 角度（弧度），覆盖区直径 = 2βR。
R + h = 6,370 + 35,863 = 42,233 km
cos β = 6,370 / 42,233 = 0.1508
β = cos⁻¹ 0.1508 = 81.3°
直径 ≈ 2 × (81.3° × π/180) × 6,370 = 2 × 1.419 × 6,370 ≈ 18,000 km

合理性检查：β 必须小于 90°（卫星不可能看到半个地球以上），81.3° 合理。讲义 p.14 表里 GEO 覆盖直径约 16,000 km，是按最小仰角 10° 算的（β = 71.46°，直径约 15,900 km），两个数不矛盾。

课外补充"1/4 个地球"从哪来

讲义 p.15 说一颗 GEO 覆盖 "¼ of the earth"。按几何，可见的球冠面积占地球表面 (1 − cos β)/2：仰角 0° 时约 42%，仰角 10° 时约 34%（这就是常说的"约 1/3"）。讲义的 1/4 是偏保守的说法，考试照讲义写即可。三颗相隔 120° 的 GEO 拼起来覆盖除两极外的几乎全球（p.15）。

易错

  • 用 cos β = R / h（忘了加 R）：得到 cos β = 0.178，β 偏小。
  • 计算器在 RAD 模式，cos⁻¹ 得 1.419 却当成度。
  • 直径用 β 的度数直接乘 R，没换成弧度。

考试英文写法

At 0° elevation the line of sight is tangent to the earth, so it is perpendicular to the earth radius at the earth station. Hence cos β = R / (R + h) = 6,370 / (6,370 + 35,863) = 0.1508, giving β ≈ 81.3°. The coverage diameter on the ground is about 2βR ≈ 18,000 km.

一句话：仰角 0° 时视线垂直于半径，cos β = 6370/42233 = 0.1508，β ≈ 81.3°，覆盖直径约 18,000 km。
知识讲解 + 详细解析：GEO 的优缺点

知识讲解GEO 为什么"静止"

GEO 在赤道上空 35,863 km 的圆轨道上，转速和地球自转一样，看上去始终停在赤道某点正上方（讲义 Part C p.15）。优点（p.15）：相对地面几乎不动，多普勒频移（Doppler shift）影响小；地面站跟踪简单；覆盖大，3 颗相隔 120° 就几乎覆盖全球。缺点（p.16）：信号走 35,000 多公里后很弱；极地和高纬度地区服务差；时延大（往返 0.24 s）；大波束做点对点通信浪费频谱。

逐项分析找"不是特点"的那项

  • A 是特点：卫星相对地面不动，天线对准后基本不用动。
  • B 是特点：没有相对运动，就几乎没有多普勒频移。
  • C 是特点：p.14 表里 GEO 往返时延约 250 ms（p.16 写 0.24 s）。
  • D 不是特点，选它：GEO 在赤道上空，越往两极，地面站看卫星的仰角越低，信号穿过的大气越厚，甚至看不到卫星。所以高纬度覆盖差，是缺点。

记忆

"赤道上的灯泡"：照赤道附近亮，照两极几乎贴着地平线，照不到。

一句话：GEO 在赤道上空，极地和高纬度仰角太低、覆盖差，所以 D 不是它的特点。
知识讲解 + 详细解析：LEO 的问题、优点与分类

知识讲解LEO 为什么又好又麻烦

LEO 只有 500–1,500 km 高，离地近，所以信号强、时延小；但离地近也意味着飞得快（约 7 km/s，1.5–2 小时绕一圈）、一颗只能看到 15–20 分钟（讲义 Part C p.14），所以要一大群卫星接力。讲义 p.17 讲问题，p.18 讲优点，p.19 讲 Little / Big LEO。

详细解析答案要点逐条展开

问题（p.17）

  1. 多普勒频移大：卫星相对地面高速运动，收到的频率会偏移，接收机必须跟踪。课外估算：1,000 km 高的 LEO 速度约 7.35 km/s，2 GHz 载频最大偏移 f·v/c ≈ 49 kHz，远大于地面手机的几百 Hz。
  2. 大气阻力（atmospheric drag）明显，轨道逐渐衰退，卫星寿命有限。
  3. 要多个轨道面、每面多颗卫星才能连续覆盖。
  4. 两地通信常要把信号从一颗卫星切换到另一颗。

优点（p.18）

  1. 同样发射功率下，收到的信号比 GEO 强得多。课外估算：自由空间损耗只差距离项 20 log(35,863 / 1,000) ≈ 31 dB。
  2. 覆盖更局部，频谱可以在不同地区复用，更省频谱。
  3. 适合需要强信号的手持 / 移动终端。
  4. 代价：要 24 小时全覆盖需要很多颗卫星。
Little LEOBig LEO
频率1 GHz 以下1 GHz 以上
带宽 / 速率小于 5 MHz，最高 10 kbps可达几 Mbps
业务寻呼、跟踪、低速消息Little LEO 全部业务 + 话音、定位

易错

  • Little / Big 的分界是频率 1 GHz，不是卫星大小或高度。
  • Big LEO 是"在 Little LEO 的基础上加上话音和定位"，不是另一套业务。

考试英文写法

Problems: (1) the satellite moves fast relative to the ground, so the system must cope with large Doppler shifts; (2) atmospheric drag is significant, causing gradual orbital deterioration; (3) multiple orbital planes, each with multiple satellites, are needed; (4) communication between two earth stations usually involves handing off from one satellite to another. Advantages: the received signal is much stronger than a GEO signal for the same transmit power; coverage is more localised so spectrum is better conserved; suitable for mobile and personal terminals. Little LEOs operate below 1 GHz with less than 5 MHz bandwidth and up to 10 kbps, for paging, tracking and low-rate messaging. 知识讲解 + 详细解析：MEO 与 LEO 对比

一句话：MEO 比 LEO 切换少得多，但时延和所需功率更大，选 B。

知识讲解 + 详细解析：链路质量三大因素

知识讲解信号在路上损失在哪

讲义 Part C p.21–23 列出影响卫星链路性能的三大因素。老师课上强调：这三个因素非常重要，他"必须强调"。思路就是从卫星天线到地面站天线，信号沿路被"削弱"的三个原因：距离、偏离波束中心、大气。

详细解析三个因素逐条展开

  1. 卫星天线和地面站天线之间的距离：自由空间损耗 L(dB) = 32.44 + 20 log f(MHz) + 20 log d(km)。所以频率越高、卫星越高，损耗越大（p.21，p.22 的图）。课外举例：同一颗 GEO，Ku 12 GHz 比 C 4 GHz 多损耗 20 log 3 ≈ 9.5 dB；GEO 比 1,000 km 的 LEO 多损耗约 31 dB。
  2. 下行时地面站离卫星"瞄准点"（aim point）的地面距离：卫星波束对准地面某一点，覆盖区中心功率最高，越往边缘越弱。所以同一颗卫星，覆盖边缘的用户需要更大的天线。
  3. 大气衰减：受氧气、水汽、仰角和频率影响。仰角越小，信号穿过的大气越厚，衰减越大；频率越高越严重（p.21、p.23）。课外：仰角 5° 时穿过大气的路程约为 30° 时的 5.7 倍（按 1/sin θ 估算）。
频率项：20 log(12/4) = 9.5 dB
距离项：20 log(35,863 / 1,000) = 31.1 dB
大气路程比（平地近似）：sin 30° / sin 5° = 0.5 / 0.0872 ≈ 5.7

易错

  • 第二个因素只在下行时讲，答题时把"For downlink"写上。
  • 第一个因素要同时写"频率越高"和"卫星越高"两个方向。

考试英文写法

(1) Distance between the satellite antenna and the earth-station antenna: the higher the signal frequency and the higher the satellite, the greater the signal power loss. (2) For the downlink, the terrestrial distance between the earth-station antenna and the "aim point" of the satellite: the centre of the coverage area receives the highest power, and the power drops off away from the centre. (3) Atmospheric attenuation: affected by oxygen, water, the elevation angle and frequency; the smaller the elevation angle, the more atmosphere the signal must travel through, and higher frequencies suffer more.

一句话：距离（频率高、卫星高损耗大）、下行时离瞄准点的距离（中心最强）、大气衰减（仰角低、频率高衰减大）。
知识讲解 + 详细解析：GEO 自由空间损耗

知识讲解自由空间损耗公式

自由空间损耗（free-space path loss）来自 Friis 公式：L = (4πd/λ)²。换成 dB，并把 f 用 MHz、d 用 km 表示，常数合在一起就是：

L(dB) = 32.44 + 20 log₁₀ f(MHz) + 20 log₁₀ d(km)

每个符号：f 是载波频率（MHz），d 是收发距离（km）。规律：f 或 d 每增加 10 倍，损耗多 20 dB。Part A 讲义 p.51 写的常数是 32（取整），本题用 32.44。讲义 Part C p.22 的图就是这条公式画出来的（1、4、10、40 GHz 四条平行线）。

详细解析一步一步算

  1. 换单位：4 GHz = 4,000 MHz（公式要求 MHz，填 4 会差 60 dB）。
  2. 算两个对数项。计算器提示：log 4000 = log 4 + 3 = 0.602 + 3 = 3.602。
  3. 三项相加。
20 log 4,000 = 20 × 3.602 = 72.04 dB
20 log 35,863 = 20 × 4.555 = 91.09 dB
L = 32.44 + 72.04 + 91.09 = 195.6 dB
（常数用 32：L = 195.1 dB，也算对）

合理性检查：p.22 图上 4 GHz、GEO 高度处约 196 dB，吻合。对比：同样 4 GHz、1,000 km 的 LEO 只有 164.5 dB，差约 31 dB；同一颗 GEO 用 1 GHz 是 183.5 dB。

易错

  • f 用 GHz 代入：20 log 4 = 12.04，少了 60 dB。
  • d 用 m 代入：多了 60 dB。
  • 用 10 log 代替 20 log：功率与距离平方、频率平方成正比，所以是 20 log。

考试英文写法

L(dB) = 32.44 + 20 log₁₀(4000) + 20 log₁₀(35,863) = 32.44 + 72.04 + 91.09 ≈ 195.6 dB.

一句话：32.44 + 72.04 + 91.09 ≈ 195.6 dB，f 用 MHz、d 用 km。
知识讲解 + 详细解析：仰角与雨雾衰减

知识讲解仰角越低，穿过的大气越厚

大气层大约只有十几公里厚。卫星在头顶（仰角 90°）时，信号笔直穿过大气，路程最短；仰角越低，信号斜着穿过大气，路程越长，氧气、水汽、雨、雾对它的吸收和散射也越多（讲义 Part C p.21）。p.23 的图画了大气吸收、雾、雨三种衰减随仰角的变化：都随仰角升高而迅速下降，仰角低于 10° 时急剧增大，雨的影响最大。

课外补充（平地近似）：穿过大气的路程 ∝ 1/sin θ。sin 30° / sin 5° = 0.5 / 0.0872 ≈ 5.7，仰角从 30° 降到 5°，路程约长 5.7 倍。

逐项分析

  • A 错：仰角变化对大气路程影响很大，不会不变。
  • B 对：路程变长，雨衰、雾衰都明显增大。
  • C 错：方向反了。
  • D 错：雨和雾都随路程增大，不会只有一种增大；而且雨的影响更大。
一句话：仰角越低，信号穿过的大气越厚，雨衰和雾衰都明显增大，选 B。
知识讲解 + 详细解析：三种通信配置

知识讲解按"谁和谁通信"来分

讲义 Part C p.24–25 把卫星通信分成三种常见配置。区分的方法是看发射站和接收站的数量关系：一对一、一对多、中心对多（双向）。

配置关系例子
点对点（point-to-point）一对一，双向跨洋干线
广播（broadcast）一个发射站 → 多个接收站卫星电视
双向星形（VSAT 网）一个 hub ↔ 多个远端站银行网点、加油站

详细解析每种配置的关键点

  1. 点对点：卫星给两个相距很远的地面站提供一条链路，替代跨洋电缆，这正是卫星最初的用途（p.4）。
  2. 广播：一个带发射机的地面站，对许多只有接收机的地面站。GEO 一个波束覆盖很大，最适合广播（p.16）。
  3. 双向星形：一个中心站（hub）和许多远端客户站。远端站共享卫星容量发给 hub；hub 和各站交换消息，并在远端站之间中转。远端站通常是天线很小的 VSAT（0.3–0.9 m，p.26），因为 hub 天线大，链路预算主要靠 hub 撑起来。

易错

  • 星形网里远端站之间不直接通信，要经 hub 中转（卫星 → hub → 卫星）。
  • 广播是单向的；点对点和星形都是双向。

考试英文写法

(1) Point-to-point: the satellite provides a link between two distant earth stations. (2) Broadcast: the satellite provides service between one earth station with a transmitter and a number of earth stations with receivers. (3) Two-way star (VSAT network): one central hub and many remote client stations; the clients share the satellite capacity to transmit to the hub, and the hub exchanges messages with each client and relays messages between clients.

一句话：点对点（两站）、广播（一发多收）、双向星形（hub 加许多 VSAT，远端经 hub 中转）。

知识讲解 + 详细解析：信道可用带宽

知识讲解FDMA 先切信道，保护带要扣掉

卫星的总容量先用 FDMA（频分多址）切成若干物理信道，信道里面再进一步分配（讲义 Part C p.28）。相邻信道之间必须留保护带（guard band）：滤波器不是理想的，信号频谱会"漏"到旁边，保护带就是一段空着不用的频率，防止相邻信道互相干扰。所以：

可用带宽 = 信道带宽 − 保护带

详细解析一步一步算

  1. 每个信道 40 MHz，其中 4 MHz 是保护带，不能传数据。
  2. 相减得到可用带宽；顺便算保护带占比。
  3. 检查总量：24 个信道共 960 MHz，大于总带宽 500 MHz，说明用了频率复用（讲义原话 "by frequency reuse technique"）。
可用 = 40 − 4 = 36 MHz
保护带占比 = 4 / 40 = 10%
24 × 40 = 960 MHz ≈ 1.9 × 500 MHz

课外补充复用怎么做到

常见做法是两种正交极化：500 MHz 里放 12 个 40 MHz 信道（480 MHz），水平、垂直极化各用一遍，就是 24 个。

易错

  • 用 500 / 24 = 20.8 MHz：题目已说每信道 40 MHz，靠复用，不是平分。
  • 用 40 − 2 × 4：保护带 4 MHz 已经包含在40 MHz 里，只扣一次。

考试英文写法

Each 40-MHz channel includes a 4-MHz guard band, so the usable bandwidth per channel = 40 − 4 = 36 MHz. (24 × 40 = 960 MHz exceeds 500 MHz, which is possible by frequency reuse.)

一句话：40 − 4 = 36 MHz，保护带占 10%；24 个信道靠频率复用装进 500 MHz。
知识讲解 + 详细解析：FAMA、DAMA 与 CSC

知识讲解容量"固定分"还是"按需分"

讲义 Part C p.29–30。FAMA（Fixed-Assignment Multiple Access，固定分配多址）：容量预先固定分给各站。DAMA（Demand-Assignment Multiple Access，按需分配多址）：根据各站需求的变化随时调整分配。老师课上强调：FAMA 预先分好、不能改；DAMA 把一部分链路当公共池，按需分配，更灵活。

FAMADAMA
分配方式固定按需动态
缺点需求波动时容量大量闲置需要信令和调度
FDMA 版本各站频带预先分好子信道组成池，按需分一对

详细解析CSC 的工作过程

  1. 资源池：一个信道里的子信道（subchannel）当作可用链路池。两个地面站要全双工通信时，动态分给它们一对子信道（一去一回）。
  2. 分布式分配：没有中心站逐个审批，由各地面站自己通过公共信令信道 CSC（Common Signalling Channel）协调。
  3. CSC 帧结构：CSC 反复发送一个 TDMA 帧，50 个时隙；第 1 个用于同步，其余 49 个永久分给 49 个站。
  4. 占用广播：某站选好子信道后，在自己的时隙里广播所选子信道的编号；其他站都听得到，就不会再选这些子信道，避免冲突。
  5. 公平：要公平使用子信道，还需要一个集中调度器（p.30 最后一点）。

为什么 DAMA 好：某站空闲时，FAMA 下它那份容量别人用不上；DAMA 下空闲的子信道回到池里给忙的站用。

易错

  • CSC 本身是 TDMA 帧，而它分配的是 FDMA 子信道，两层别混。
  • 能支持的站数是 49，不是 50（见 c18）。

考试英文写法

FAMA assigns capacity to the stations in a fixed manner; since demand fluctuates, capacity is significantly under-used. DAMA changes the assignment as needed to respond to demand. In DAMA-FDMA, the subchannels in a channel form a pool; a pair of subchannels is dynamically assigned for a full-duplex link between two earth stations. The assignment is done in a distributed way using a common signalling channel (CSC), which carries a repetitive TDMA frame of 50 slots: the first slot is for synchronisation and the other 49 are permanently assigned to 49 stations. A station that selects subchannels transmits their identifiers in its own slot, so other stations will not select them. A centralised scheduler is needed for fair use.

一句话：FAMA 固定分、浪费；DAMA 按需分；DAMA-FDMA 靠 CSC（50 时隙 TDMA 帧，1 同步 + 49 站）广播自己占用的子信道。
知识讲解 + 详细解析：CSC 支持的站数

知识讲解CSC 的 50 个时隙怎么用

DAMA-FDMA 的公共信令信道 CSC 反复发送一个 TDMA 帧，共 50 个时隙（讲义 Part C p.30）。第 1 个时隙用于同步：所有站靠它对齐帧的起点，才知道"现在是第几个时隙"，否则各站会在别人的时隙里发送。其余 49 个时隙永久分给 49 个站，每站一个，用来广播自己选了哪些子信道。

详细解析

  1. 做什么：从总时隙里扣掉同步时隙。为什么：同步时隙不属于任何站。
  2. 每站固定占一个时隙，所以站数 = 剩下的时隙数。
支持站数 = 50 − 1 = 49 个

合理性检查：讲义原话 "Others are permanently assigned to 49 stations"，一致。

易错

  • 答 50：忘了第 1 个时隙是同步用的。
  • 答 24 或 25（以为全双工要两个时隙一对）：时隙用来发信令，每站一个；成对的是 FDMA 子信道，不是 CSC 时隙。

考试英文写法

The CSC frame has 50 slots; the first slot is used for synchronisation and the remaining 49 slots are permanently assigned to stations, so at most 50 − 1 = 49 earth stations are supported.

一句话：50 个时隙减去 1 个同步时隙，最多 49 个站。
知识讲解 + 详细解析：TDMA 为何比 FDMA 高效

知识讲解比的是"开销"占多少容量

两种多址都有开销：FDMA 相邻信道之间要留保护带（guard band，一段不用的频率）；TDMA 相邻突发之间要留保护时间（guard time），每帧还有参考突发和前导等控制比特。讲义 Part C p.35 原话：TDMA 的保护时间和控制比特占用的容量，比 FDMA 的保护带少，所以 TDMA 通常更高效。在 Ku、K 高频段还能用窄波束做多波束复用，效率更高。

课外举例：TDMA 帧 2 ms，参考突发 20 µs，10 站各 10 µs 前导 + 2 µs 保护：开销 140 µs → 效率 93%
FDMA：40 MHz 信道含 4 MHz 保护带 → 效率 90%

逐项分析

  • A 错：恰恰相反，TDMA 需要严格的时间同步，各站才能准确落在自己的时隙里。
  • B 对：讲义 p.35 的原因。
  • C 错：两者共用同一个转发器带宽，效率差别来自开销，不是带宽大小。
  • D 错：卫星通信当然需要地面站。
一句话：TDMA 的保护时间和控制比特比 FDMA 的保护带占用更少容量，选 B。
知识讲解 + 详细解析：SS/TDMA 模式数

知识讲解卫星在天上当交换机

Ku、K 频段可以用多个窄波束分别照 N 个区域（讲义 Part C p.35）。同一区域内的站用普通 FAMA-TDMA；不同区域之间通信，卫星要把某个上行波束的时隙交换到另一个下行波束上，这叫卫星交换 TDMA（SS/TDMA），是 DAMA-TDMA 的一种（p.36）。任一时刻，星上开关把 N 个上行波束一一对应地接到 N 个下行波束，每一种接法叫一个模式（mode）。讲义：全连通需要 N! 种模式；卫星周期性换模式，最多每个时隙换一次，模式和时长可由地面指令调整。

详细解析为什么是 N!

  1. 一种模式 = 把 N 个上行波束排到 N 个下行位置上，每个下行只接一个上行，这正是 N 个元素的一个排列。
  2. 第 1 个上行有 N 种选择，第 2 个剩 N − 1 种……所以排列数 = N × (N − 1) × … × 1 = N!。
  3. 代入 N = 5。
N = 3：3! = 6（ABC、ACB、BAC、BCA、CAB、CBA）
N = 4：4! = 24
N = 5：5! = 5 × 4 × 3 × 2 × 1 = 120 种

课外补充（讲义没有）

严格说，N! 是所有可能的开关模式总数。如果只要求"任意两个区域之间某个时刻能连通"，N 个循环移位模式就能覆盖全部 N² 个上下行组合。考试按讲义写 N!。

易错

  • 答 N² = 25 或 N(N − 1) = 20：那是"上下行对"的个数，不是模式数。
  • 答 5 × 2 = 10 等：模式是整体排列，不是单条连接。

考试英文写法

Each mode is a one-to-one connection of the N uplink beams to the N downlink beams, i.e. a permutation, so N! modes are required for full connectivity: 5! = 120 modes.

一句话：每种模式是一个排列，全连通需要 N! 种，5! = 120。
知识讲解 + 详细解析：TDMA 帧结构

知识讲解为什么 TDMA 帧要这样设计

卫星 TDMA（讲义 Part C p.31）：传输是重复的帧，每帧分成若干时隙，每个站分到一个或多个时隙；各站轮流在自己的时隙发上行，卫星把收到的内容广播给所有站，每个站要知道哪个时隙发、哪个时隙收。难点在于：各站离卫星距离不同，时钟也不完全一样，所以帧里必须有"定时基准"和"自我介绍"。p.32 的图就是答案。

部分内容作用
参考突发（reference burst）载波与比特定时恢复、协调数据给全网一个时间基准，告诉各站帧从哪里开始
保护时间（guard time）突发之间的空隙吸收各站的定时误差，防止突发重叠
各站数据突发前导 + 信息每站在自己的时隙发送

详细解析前导（preamble）的四个字段

  1. 载波与比特定时恢复（carrier and bit timing recovery）：接收机先锁定这个突发的载波相位和比特时钟，才能正确解调。每个站的突发来自不同发射机，所以每个突发都要重新恢复。
  2. 唯一字（unique word）：一段固定的比特图样，用来准确找到突发里信息开始的位置（突发定位）。
  3. 站识别（station identification）：说明这个突发是哪个站发的。
  4. 网络控制与请求（network control and request）：传网络管理信息，或请求更多容量。

前导后面才是真正的信息（information）。p.33–34：上行时各站在不同时隙发送；下行时卫星把整帧广播回去，各站挑出发给自己的部分。

易错

  • 参考突发在帧开头，每帧一个；前导在每个站的突发开头，每站一个。
  • 保护时间、参考突发、前导都是开销，这就是 c19 说的"保护时间和控制比特"。

考试英文写法

A TDMA frame starts with a reference burst (carrier and bit timing recovery, coordination data), followed by the data bursts of the individual stations, separated by guard times. Each station's burst consists of a preamble and information. The preamble contains carrier and bit timing recovery, a unique word, station identification, and network control and request; the information field carries the user data.

一句话：参考突发 + 各站数据突发（中间隔保护时间）；每个突发 = 前导（定时恢复、唯一字、站识别、网络控制与请求）+ 信息。
知识讲解 + 详细解析：星间链路的路由

知识讲解两种路由方案

讲义 Part C p.39：两个用户分别在两颗卫星下面。有星间链路（ISL，Inter-Satellite Link）时，信息在太空中直接从一颗卫星转到另一颗；没有时，卫星先下传到地面网关，经地面网络路由到负责另一颗卫星的网关，再上传。

有 ISL无 ISL
路径用户 A ↑ 卫星 1 → 卫星 2 ↓ 用户 BA ↑ 卫星 1 ↓ 网关 1 → 地面网 → 网关 2 ↑ 卫星 2 ↓ B
链路数1 上 + 1 下2 上 + 2 下
地面网关少多

逐项分析

  • A 对：上行一次进入太空，星间转发，下行一次到达对方。
  • B 错：这是没有星间链路的情况。
  • C 错：用户在地面，至少要一上一下。
  • D 错：上下行数应相等，单向路径进出太空各一次。

记忆

数"进出太空"的次数：有 ISL 进出各一次；无 ISL 中途要回地面一趟，进出各两次。

一句话：有星间链路时 1 上 1 下，还能少建网关；没有时 2 上 2 下，选 A。
知识讲解 + 详细解析：卫星系统四种切换

知识讲解为什么 MEO/LEO 系统要切换

地面蜂窝里，切换（handover）几乎都是用户在动引起的。MEO、LEO 卫星相对地面在动（LEO 每颗只可见 15–20 分钟），如果卫星本身带着"基站"，即使用户不动，卫星一飞走也要切换（讲义 Part C p.40）。GEO 相对地面静止，几乎不用切换。这一题是 2025-26 S2 期末 Q4(b)，8 分；老师课上强调卫星是未来很重要的方向，并提到期末考过这一题，属于必背。

详细解析四种切换，看"谁变了"

切换原因例子
星内切换（intra-satellite）用户在同一颗卫星覆盖区内，从一个扇区（点波束）移到另一个开车穿过两个点波束交界
星间切换（inter-satellite）用户移到另一颗卫星的覆盖区，或卫星自己飞走头顶 LEO 落下地平线，转到下一颗
网关切换（gateway）卫星离开当前地面网关卫星改连另一个网关
系统间切换（inter-system）卫星系统与地面蜂窝系统之间，因信号强度和 QoS 发生的垂直切换从野外进城，从卫星转到 4G
  1. 星内：波束变，卫星不变。
  2. 星间：卫星变。原因有两个，都要写，"卫星飞走"是卫星系统特有的。
  3. 网关：地面网关变，和用户无关，是卫星和地面之间那条链路在换。
  4. 系统间：网络类型变，所以叫垂直切换（vertical handover），判断依据是信号强度和 QoS。

易错

  • 星间切换只写"用户移动"，漏了"卫星移走"。
  • 系统间切换要写出 "vertical handover" 和 "signal strength and QoS"。
  • 8 分题四点各约 2 分：每种写"名称 + 原因"一句，不要只列名字。

考试英文写法

(1) Intra-satellite handover: caused by the movement of a mobile user within the coverage of one satellite, from one sector (spot beam) to another. (2) Inter-satellite handover: caused by the movement of a mobile user from the coverage of one satellite to that of another, or because the satellite moves away. (3) Gateway handover: caused by the movement of the satellite away from its current gateway, so the satellite must connect to another gateway. (4) Inter-system handover: between the satellite system and a terrestrial cellular system; it is a vertical handover triggered by signal strength and QoS performance.

一句话：波束变 → 星内；卫星变 → 星间；网关变 → 网关；系统变 → 系统间（垂直切换）。
