5对数正态阴影的中断概率与覆盖 · Log-normal shadowing: outage and coverage

背考试给定义·必会 出现：期末 1/4 套（2023-24 S2 Q1(a)(ii)）· Practice 1 Q1(b)、Q2 · Practice 2 Q2 · 模拟 A · Q2 · 模拟 C · Q1 · 讲义第 2 章 p.16 例题

阴影让接收功率的 dB 值变成高斯 \(\mathcal N(\bar P_r,\sigma^2)\)，"中断"就是它掉到门限以下的那块左尾面积，所有题都归结为一个式子 \(P_{\text{out}}=Q(M/\sigma)\)。Quiz 可能正着问（给距离或平均功率，求 \(P_{\text{out}}\)），也可能倒着问（给 \(P_{\text{out}}\) 目标，求允许的 σ²、所需余量或最大距离；2023-24 S2 期末 Q1(a)(ii) 就是求方差上限）。Practice 2 Q2 再加一层：两个基站都低于门限才算中断。老师说 Q 函数表一定会考到，正查、反查都要会（第 8、9 周录音）。

公式 · Formulas

dBm 与 W 互换 · dBm ↔ W 定义·必会
\[ P_{\mathrm{dBm}}=10\log_{10}\frac{P}{1\ \mathrm{mW}},\qquad P=10^{P_{\mathrm{dBm}}/10}\ \mathrm{mW},\qquad 1\ \mathrm{W}=30\ \mathrm{dBm} \]
100 mW = 20 dBm；2 W = 2000 mW = 33.01 dBm。dBm 是绝对功率，dB 是倍数：dBm + dB = dBm（路径损耗式），dBm − dBm = dB（余量），所以余量和 σ 都是 dB。老师说 mW 没换成 dBm 会扣分（第 8、9 周录音）。
简化路径损耗 + 阴影（讲义第 2 章 p.8、p.12）· Path loss with shadowing 背
\[ P_r=P_tK\Big(\frac{d_0}{d}\Big)^{\gamma}\psi\;\Longrightarrow\;P_{r,\mathrm{dB}}=\underbrace{P_{t,\mathrm{dBm}}+K_{\mathrm{dB}}-10\gamma\log_{10}\frac{d}{d_0}}_{\bar P_r\ (\text{确定的数})}+\underbrace{\psi_{\mathrm{dB}}}_{\sim\mathcal N(0,\,\sigma^2)} \]
线性和 dB 两种形式都要背，考试不给（第 8、9 周录音）。加了阴影以后 \(P_{r,\mathrm{dB}}\sim\mathcal N(\bar P_r,\sigma^2)\)：均值 = 不含阴影的路径损耗结果，方差 = 阴影方差（第 9 周录音）。题目直接给"平均功率"或"path loss alone 时比门限高几 dB"，这一步就省了。
中断概率（讲义第 2 章 p.14–15）· Outage probability 背
\[ P_{\text{out}}=P\big(P_{r,\mathrm{dB}}\lt P_{\min}\big)=P\big(\psi_{\mathrm{dB}}\lt -M\big)=Q\Big(\frac{M}{\sigma}\Big),\qquad M=\bar P_r-P_{\min} \]
老师要求的写法（第 9 周录音）：把"\(P_r\lt P_{\min}\)"整理成"随机变量 \(\lt -M\)"（随机变量留在左边），再由高斯的对称性写成 Q(M/σ)。M 和 σ 都是 dB，直接相除，不换线性；σ 是标准差，给的是方差或 MSE 就先开根号。讲义 p.16：典型目标 \(P_{\text{out}}\lt 1\%\)，对应 \(M\ge 2.33\sigma\)。
Q 函数、Φ 与对称性 · Q-function, Φ and symmetry 考试给定义·必会
\[ Q(x)=P(Z\gt x)=\int_x^{\infty}\frac{1}{\sqrt{2\pi}}e^{-u^2/2}\,du,\qquad \Phi(x)=P(Z\le x)=1-Q(x),\qquad Q(-x)=1-Q(x) \]
考卷附的是 Q 表（右尾面积），数值不用背。习惯 Z 表 / Φ 表（左尾，也就是 CDF）的话，用 \(Q(x)=1-\Phi(x)\) 换算，所以也有 \(P_{\text{out}}=\Phi(-M/\sigma)\)。Q(0) = 0.5，x 越大 Q 越小。常用值：Q(1) = 0.1587，Q(1.282) ≈ 0.1，Q(1.645) = 0.05，Q(2) = 0.0228，Q(2.326) = 0.01，Q(3.09) = 0.001。
倒着用：所需余量、允许的 σ、最大距离 · Inverse use 定义·必会
\[ P_{\text{out}}\le p\iff\frac{M}{\sigma}\ge x_p=Q^{-1}(p)\;\Longrightarrow\;M\ge x_p\,\sigma,\qquad \sigma\le\frac{M}{x_p} \]\[ \bar P_r(d)\ge P_{\min}+x_p\sigma\;\Longrightarrow\;d_{\max}=d_0\cdot10^{\,(P_{t,\mathrm{dBm}}+K_{\mathrm{dB}}-P_{\min}-x_p\sigma)/(10\gamma)} \]
就是上面必背的式子倒过来用，不用另背。Q 是减函数，"概率 ≤ p"要翻成"参数 ≥ \(x_p\)"。所需余量加门限就是平均功率的下限，再代回路径损耗式解 d（或解 \(P_t\)）。常用：\(x_{0.1}=1.282\)，\(x_{0.05}=1.645\)，\(x_{0.01}=2.326\)，\(x_{0.001}=3.09\)。
宏分集，两路阴影独立（Practice 2 Q2(b)）· Macro-diversity, independent shadowing 定义·必会
\[ P_{\text{out}}=P\big(\{Z_1\lt-\Delta\}\cap\{Z_2\lt-\Delta\}\big)=P(Z_1\lt-\Delta)\,P(Z_2\lt-\Delta)=\Big[Q\Big(\frac{\Delta}{\sigma}\Big)\Big]^2 \]\[ M_{\text{eq}}=\sigma\,Q^{-1}\big(P_{\text{out}}\big),\qquad G=M_{\text{eq}}-\Delta\ \ (\mathrm{dB}) \]
两个都低于门限才中断；两路独立 → 概率相乘（第 1b 章的乘法规则），一步就能推出来，不用死背。第二行是模拟 C · Q1(c) 的问法：单基站要多大余量才能一样可靠，多出来的 dB 就是宏分集白送的增益。原理见讲义第 4 章 p.3–4：基站相隔很远，两条路被同一个障碍物同时挡住的机会小。
宏分集，两路阴影相关（Practice 2 Q2(c)）· Correlated shadowing 考试给
\[ Z_i=aY_i+bY:\qquad P_{\text{out}}=\int_{-\infty}^{\infty}\frac{1}{\sqrt{2\pi}}\Big[Q\Big(\frac{\Delta+b\sigma y}{|a|\sigma}\Big)\Big]^2e^{-y^2/2}\,dy \]
这是 Practice 2 Q2(c) 印在题目里、让你"证明"的式子；式里的积分变量 y 其实是换元后的 u = Y/σ（题目原样照印）。老师说不会考积分（第 8–10 周录音）；他讲这题的方法（第 10 周录音）：先把共同阴影 Y 当成常数 → 两条链路条件独立，相乘 → 再对 Y 的 PDF 积分 → 换元 u = y/σ。结论：相关时不能直接平方；b = 0 退回 \([Q(\Delta/\sigma)]^2\)，a = 0（完全相关）就等于单基站的 \(Q(\Delta/\sigma)\)。

中文例子 · 怎么用

例 1 · 功率给 W、方差给 MSE、余量为负（正查）

某基站发射功率 2 W，传播服从简化路径损耗模型：KdB = −38 dB，γ = 3.2，d₀ = 1 m。手机接收功率低于 −100 dBm 就中断。实测拟合得到阴影的均方误差 MSE = 30.25 dB²。求 (a) d = 400 m，(b) d = 1 km 处的中断概率。

  1. 换单位：2 W = 2000 mW，\(P_t\) = 10 log₁₀2000 = 33.01 dBm。MSE 就是方差：σ = √30.25 = 5.5 dB。
  2. (a) \(\bar P_r\) = 33.01 − 38 − 32 log₁₀400 = 33.01 − 38 − 83.27 = −88.26 dBm；余量 M = −88.26 − (−100) = 11.74 dB。
  3. M/σ = 11.74 / 5.5 = 2.1345 ≈ 2.13，\(P_{\text{out}}\) = Q(2.13) = 0.0166（不舍入算是 0.0164）。
  4. (b) \(\bar P_r\) = 33.01 − 38 − 32 × 3 = −100.99 dBm，M = −100.99 − (−100) = −0.99 dB：平均已经比门限低，余量为负。
  5. M/σ = −0.99 / 5.5 = −0.18。表里只有正数，用 Q(−x) = 1 − Q(x)：\(P_{\text{out}}\) = 1 − Q(0.18) = 1 − 0.4286 = 0.571。用 Φ 表结果一样：\(P_{\text{out}}=\Phi(0.18)\) = 0.571。

答案：(a) 0.0166 ≈ 1.7%；(b) ≈ 57%（平均功率低于门限，一半以上的时间中断）

例 2 · 反查三问：5% 目标求最大距离、求发射功率、0.1% 目标求 σ²

微蜂窝：\(P_t\) = 100 mW，KdB = −40 dB，γ = 3，d₀ = 1 m，门限 −95 dBm，阴影 σ = 6 dB。(a) 要求 \(P_{\text{out}}\le 5\%\)，最大覆盖距离是多少？(b) 要覆盖到 200 m（仍要求 \(P_{\text{out}}\le 5\%\)），发射功率至少多少？(c) 发射功率仍是 100 mW，要求 100 m 处 \(P_{\text{out}}\le 0.1\%\)，阴影方差最大允许多少？

  1. \(P_t\) = 10 log₁₀100 = 20 dBm。(a) 反查：Q(1.64) = 0.0505、Q(1.65) = 0.0495 → x = 1.645。所需余量 M ≥ 1.645 × 6 = 9.87 dB，平均功率下限 = −95 + 9.87 = −85.13 dBm。
  2. 代回模型：20 − 40 − 30 log₁₀d ≥ −85.13 → 30 log₁₀d ≤ 65.13 → log₁₀d ≤ 2.171 → d ≤ 102.171 = 148.3 m。
  3. (b) 30 log₁₀200 = 69.03 dB。要求 \(P_t\) − 40 − 69.03 ≥ −85.13 → \(P_t\) ≥ 23.90 dBm = 102.390 mW = 245.5 mW（比 100 mW 多 3.90 dB，即 100.390 ≈ 2.45 倍）。
  4. (c) \(\bar P_r\) = 20 − 40 − 30 × 2 = −80 dBm，M = −80 − (−95) = 15 dB。反查 Q(3.09) = 0.001 → x = 3.09。σ ≤ 15 / 3.09 = 4.854 dB，σ² ≤ 4.854² = 23.56 dB²。

答案：(a) dmax ≈ 148 m；(b) \(P_t\) ≥ 23.90 dBm ≈ 245.5 mW；(c) σ² ≤ 23.6 dB²（σ ≤ 4.85 dB）

例 3 · 宏分集：两站概率、等效余量、反求每站余量、完全相关

手机在两个基站正中间。只考虑路径损耗时，每个基站送来的平均功率都是 −92 dBm；门限 −104 dBm；两条链路的阴影独立，σ = 8 dB。(a) 只用一个基站时 \(P_{\text{out}}\) 是多少？(b) 宏分集（两个都低于门限才中断）时 \(P_{\text{out}}\) 是多少？单基站要多大余量才一样可靠？(c) 要求宏分集后 \(P_{\text{out}}\le 1\%\)，每条链路的余量至少多少？单基站要多少？(d) 若两条链路总被同一栋楼一起挡住（完全相关），(b) 的答案变成多少？

  1. (a) Δ = −92 − (−104) = 12 dB，Δ/σ = 12 / 8 = 1.5，\(P_{\text{out},1}\) = Q(1.5) = 0.0668。
  2. (b) 独立 → 相乘：\(P_{\text{out},2}\) = 0.0668² = 4.46 × 10⁻³。反查：Q(2.61) = 0.00453、Q(2.62) = 0.00440 → x ≈ 2.615，\(M_{\text{eq}}\) = 2.615 × 8 = 20.92 dB，宏分集增益 G = 20.92 − 12 = 8.92 dB。
  3. (c) 两路相同且独立：\([Q(\Delta/\sigma)]^2\le 0.01\) → \(Q(\Delta/\sigma)\le\sqrt{0.01}=0.1\)。Q(1.28) = 0.1003、Q(1.29) = 0.0985 → x = 1.282，Δ ≥ 1.282 × 8 = 10.26 dB。单基站要 Δ ≥ 2.326 × 8 = 18.61 dB，宏分集少要 8.35 dB。
  4. (d) 完全相关时 \(Z_1=Z_2\)，"两个都低于"就等于"一个低于"：\(P_{\text{out}}\) = Q(1.5) = 0.0668，和单基站一样，宏分集没有用。部分相关时结果介于两者之间，例如 \(b^2=0.5\) 时数值积分约 0.0183（Quiz 不会让你算这个积分）。

答案：(a) 0.0668；(b) 4.46 × 10⁻³，相当于单站余量 20.9 dB，增益约 8.9 dB；(c) 每站 ≥ 10.26 dB（单站要 18.61 dB）；(d) 0.0668

易错 · Traps

  • σ 和 σ² 混用：Q 里除的是标准差。给 MSE 或方差要先开根号：讲义 p.16 例题 σ = √3.36 = 1.833 dB，Q(4.94/1.833) ≈ Q(2.69) ≈ 0.0036；错除 3.36 得 Q(1.47) ≈ 0.071，大了约 20 倍。反过来，2023-24 期末问的是方差最大值，要平方成 σ² < 18.5 dB²，只写 σ < 4.30 dB 没答完。
  • 单位：W、mW 先换 dBm（2 W = 33.01 dBm，不是 3.01，3.01 是 dBW）；距离项是 10γ log₁₀d（γ = 3.6 时系数是 36）；dBm − dBm 得到的余量是 dB。老师说没写 dB ↔ 线性换算会扣分（第 8–10 周录音）。
  • 把余量换成线性：Q(M/σ) 是在 dB 上推出来的，M 和 σ 都用 dB 直接相除。老师讲 Practice 1 Q1 时专门提醒，"10 dB above"的 10 就是 dB，不要换成线性（第 10 周录音）。瑞利中断 \(1-e^{-\gamma_0/\bar\gamma}\) 才要线性值，两者别混。
  • 表查反了：Q 是右尾、递减，反查时不等号要翻（\(P_{\text{out}}\lt 1\%\iff M/\sigma\gt 2.326\)）。余量为负时 \(Q(-x)=1-Q(x)\)，答案大于 50%；手上是 Φ 表（左尾）时 \(Q(x)=1-\Phi(x)\)。用计算器核对的话，Casio 统计菜单里的 Q( 是 0 到 t 的面积，不是本课的 Q 函数，右尾对应的是 R(。
  • 宏分集写成"任意一个"：两个都低于门限才中断，所以是 p²；写成 \(1-(1-p)^2\) 是"任意一个断就算中断"，意思反了。只有独立才能平方；求等效余量时反查的是 p²，不是 p。
  • 舍入：Q 的参数一般先舍到 2 位小数再查表（0.625 这种正好在两行中间就插值）；中间结果多留一位小数，最后再舍入，别对已经舍过的数再舍一次（2.1345 舍到 2 位是 2.13，不是先变 2.135 再变 2.14）。上下限答案要带不等号（d ≤ 223 m、σ² < 18.5 dB²）；想保守可以上限往小取、下限往大取（148.3 m 写 148 m），本页其余数字按四舍五入写。
英文答题模板 · Exam English

With log-normal shadowing, \(P_{r,\mathrm{dB}}=\bar P_r+\psi_{\mathrm{dB}}\) with \(\psi_{\mathrm{dB}}\sim\mathcal N(0,\sigma_\psi^2)\), so outage occurs when \(\psi_{\mathrm{dB}}\lt-M\), where \(M=\bar P_r-P_{\min}\) is the margin in dB; by the symmetry of the Gaussian, \(P_{\text{out}}=P(\psi_{\mathrm{dB}}\lt-M)=Q(M/\sigma_\psi)\).

Here \(P_t=10\log_{10}100=20\) dBm, \(\bar P_r=20-31.5-36\log_{10}300=-100.68\) dBm and \(M=-100.68-(-110)=9.32\) dB, hence \(P_{\text{out}}=Q(9.32/6)=Q(1.55)=0.0606\).

Since Q is decreasing, \(P_{\text{out}}\lt 1\%\) requires \(M/\sigma_\psi\gt Q^{-1}(0.01)=2.326\); with M = 10 dB this gives \(\sigma_\psi\lt 4.30\) dB, so the variance of \(\psi_{\mathrm{dB}}\) must be below \(18.5\ \mathrm{dB}^2\).

With macro-diversity, outage requires both links to be below the threshold; if the shadowing on the two links is independent, \(P_{\text{out}}=P(Z_1\lt-\Delta)\,P(Z_2\lt-\Delta)=[Q(\Delta/\sigma)]^2\). The base stations are far apart, so both links are rarely blocked at the same time.
