8时延扩展与平坦/频率选择性 · Delay spread, flat vs frequency-selective fading

考试给背定义·必会 出现：期末 2/4 套（2023-24 Q1(a)(iii)、2025-26 S2 Q1(a)(i)）· 期末 OFDM 题用 BC（2023-24 Q2(b)(i)、2025-26 S1 Q2(b)(i)）· Practice 1 Q3 · 模拟 A·Q3 · 模拟 C·Q2 · 专项·Q3(e)

考"回声拖多长"：把功率时延谱当成概率分布，求时延的加权均值 μ 和标准差 σ（公式考试给），再拿 σ 和符号时长 Ts 比（σ/Ts < 0.1 要背），或拿信号带宽 Bs 和相干带宽 BC 比，判断平坦还是频率选择性。Quiz 可能像 Practice 1 Q3、模拟 A·Q3 那样出：给几条回波（功率用 dB）求 μ、σ，再问"符号速率最高多少才平坦"或"现在是不是平坦"。

公式 · Formulas

平均时延 Mean delay 考试给
\[ \mu_{T_m}=\frac{\sum_k \tau_k\,P_r(\tau_k)}{\sum_k P_r(\tau_k)} \]
讲义第 2 章 p.30。Pr 必须是线性功率（它是权重）；分母是总功率，不是 1。连续谱把求和换成积分；Quiz 不考积分，遇到连续均匀谱（Practice 1 Q3）用下一张卡的捷径。
rms 时延扩展 RMS delay spread 考试给
\[ \sigma_{T_m}=\sqrt{\frac{\sum_k(\tau_k-\mu_{T_m})^2P_r(\tau_k)}{\sum_kP_r(\tau_k)}}=\sqrt{E[\tau^2]-\mu_{T_m}^2} \]\[ E[\tau^2]=\frac{\sum_k\tau_k^2\,P_r(\tau_k)}{\sum_kP_r(\tau_k)} \]
讲义给的是左边的定义式；右边"平方的均值 − 均值的平方"就是第 1b 章的方差公式，列表算更快。[0, a] 上的均匀谱：μ = a/2，E[τ²] = a²/3，σ = a/√12 = a/3.464。
dB → 线性 dB to linear 定义·必会
\[ P_{\text{lin}}=10^{P_{\text{dB}}/10},\qquad P_{\text{mW}}=10^{P_{\text{dBm}}/10} \]
0、−3、−6、−10 dB → 1、0.5012、0.2512、0.1。给 dBm（绝对功率）时同样换；也可以先都减去最强那条，变成相对 dB，比例不变。老师说没写 dB ↔ 线性换算会扣分。
平坦衰落判据 Flat-fading rule of thumb 背
\[ \frac{\sigma_{T_m}}{T_s}\lt 0.1\ \Rightarrow\ \text{flat};\qquad \frac{\sigma_{T_m}}{T_s}\gg 1\ \Rightarrow\ \text{frequency-selective} \]
讲义 p.33；老师说这是蓝框公式，要背（发布的讲义 PDF 这一页看不到框，以课上录音为准）。反过来用：\(T_s\gt 10\,\sigma_{T_m}\)，即 \(R_s\lt 0.1/\sigma_{T_m}\)，求出来是上限。0.1 到 ≫ 1 之间是灰区：老师课上说比值只稍大于 0.1（如 0.15）时不能下结论，要远大于 0.1 才能说是频率选择性。比的是 rms 时延扩展，不是最大时延扩展。
相干带宽与信号带宽 Coherence bandwidth vs signal bandwidth 定义·必会
\[ B_s\approx R_s=\frac{1}{T_s},\qquad B_C\approx\frac{1}{\sigma_{T_m}}\ \ (\text{order of magnitude}) \]\[ B_s\lt B_C\ \Rightarrow\ \text{flat},\qquad B_s\gt B_C\ \Rightarrow\ \text{frequency-selective} \]
讲义 p.31–32：Bs < BC 平坦，Bs > BC 频率选择性；老师的简单记法：信号带宽在相干带宽以内就是平坦。p.31 用时延谱的傅里叶变换定义 BC，没给 1/σ 前面的系数，所以 BC ≈ 1/σ 只是数量级：只用来估 BC、说明"σ 越大 BC 越小"，不要拿它把 Bs/BC 换算成 σ/Ts 再去套 0.1。题目给 σ 就用 σ/Ts < 0.1；题目给了 BC 就直接比 Bs 和 BC：2025-26 S1 Q2(b) 同时给了 BC = 30 kHz 和最大时延扩展 10 µs，(i) 直接按子载波带宽 500/N < 30 kHz 得 N > 16.67 → Nmin = 17（此时 500/17 = 29.4 kHz，只比 30 kHz 小一点，按 Bs < BC 就算平坦；OFDM 题，判平坦的方法一样）；10 µs 是最大时延，不是 σ，留给 (ii) 定保护间隔，不拿来判平坦。题目常写 assume T = 1/B。

中文例子 · 怎么用

例 1 · 功率给 dBm（绝对值）+ 比值卡在灰区

某信道有三条可分辨路径：时延 0、2、5 µs，接收功率分别为 −80、−84、−90 dBm。(a) 求平均时延和 rms 时延扩展；(b) 要平坦衰落，符号速率最高多少？(c) 系统用 100 k 符号/s，衰落是平坦的吗？

  1. dBm → mW：−80 dBm = 1.000×10⁻⁸ mW，−84 dBm = 3.981×10⁻⁹ mW，−90 dBm = 1.000×10⁻⁹ mW。都除以最强那条（等于先换成相对 0、−4、−10 dB）：权重 1、0.3981、0.1，总和 1.498。
  2. (a) μ = (0×1 + 2×0.3981 + 5×0.1)/1.498 = 1.296/1.498 = 0.8652 ≈ 0.865 µs（下一步要平方，先多留一位）。
  3. E[τ²] = (0 + 4×0.3981 + 25×0.1)/1.498 = 4.092/1.498 = 2.732 µs²；σ² = 2.732 − 0.8652² = 2.732 − 0.7486 = 1.983，σ = 1.41 µs。
  4. (b) σ/Ts < 0.1 → Ts > 10σ = 14.1 µs → Rs < 1/14.08 µs = 71.0 ksps。
  5. (c) Ts = 1/100 k = 10 µs，σ/Ts = 1.41/10 = 0.141：大于 0.1，不满足平坦判据；又远没到 ≫ 1。老师说稍大于 0.1 时不能下结论，所以写"不能认为是平坦衰落，属于边界情况，可能有轻微 ISI"。

答案：μ ≈ 0.865 µs，σ ≈ 1.41 µs；Rs < 71.0 ksps；100 ksps 时 σ/Ts = 0.141 > 0.1，不能算平坦（边界情况）

例 2 · 连续均匀谱，高度不是 1，再估一下 BC

功率时延谱 Pr(τ) = 2（0 ≤ τ ≤ 4 µs），其他为 0。(a) 求 μ、σ；(b) 符号速率 50 k 符号/s 时是不是平坦衰落？(c) 估计相干带宽。

  1. 高度 2 在分子、分母里同时出现，约掉：和高度 1 一样，就是 [0, 4] µs 上的均匀分布（分母 = 面积 = 2×4 = 8，不是 1）。
  2. (a) μ = a/2 = 2 µs；E[τ²] = a²/3 = 16/3 = 5.333 µs²；σ² = 5.333 − 2² = 1.333，σ = 1.155 µs（= 4/√12 = 4/3.464）。
  3. (b) Ts = 1/50 k = 20 µs，σ/Ts = 1.155/20 = 0.0577 < 0.1 → 平坦（Rs 上限 0.1/σ = 86.6 ksps）。
  4. (c) BC ≈ 1/σ = 1/1.155 µs ≈ 866 kHz（只是数量级估计）。Bs ≈ 50 kHz < 866 kHz，频域看也是平坦（按这个估法 Bs/BC 恰好等于 σ/Ts = 0.0577，两种说法结论相同）。

答案：μ = 2 µs，σ ≈ 1.155 µs；50 ksps 时 σ/Ts = 0.0577 < 0.1，平坦；BC 约 866 kHz（数量级）

例 3 · 题目直接给 BC：频域判断 + 反求速率

测得信道相干带宽 BC = 150 kHz，取 Bs ≈ Rs。(a) Rs = 10 k 符号/s；(b) Rs = 1 M 符号/s，频率维度上各是什么衰落？(c) 要平坦，Rs 最高多少？

  1. (a) Bs ≈ 10 kHz < BC = 150 kHz（Bs/BC = 10/150 = 0.0667，小 15 倍）→ 平坦：整个信号带宽一起衰落。
  2. (b) Bs ≈ 1 MHz > 150 kHz（大 6.67 倍）→ 频率选择性衰落：不同频率衰落不同，时域上有 ISI，要靠均衡或 OFDM。
  3. (c) 按讲义 p.31 直接用 Bs < BC：Rs ≈ Bs < 150 kHz → Rs < 150 ksps，是上限（2025-26 S1 Q2(b)(i) 求 N 也是这样直接比的）。题目给的是 BC，不要再用 BC ≈ 1/σ 换算成 σ/Ts 去套 0.1。

答案：(a) 平坦；(b) 频率选择性；(c) Rs < 150 ksps（上限）

易错 · Traps

  • 拿 dB 值当权重：0、−3、−6 dB 是负数，必须先换线性（1、0.5012、0.2512）；dBm 也要换。老师说没写 dB ↔ 线性换算会扣分。
  • 忘了除总功率：模拟 A·Q3 要除 1.752；连续谱除面积（Practice 1 Q3 的分母是 10，不是 1）。
  • σ ≠ √E[τ²]，要减 μ²；σ 也不是"最大时延 − 最小时延"：模拟 A·Q3 时延差 3 µs，σ 只有 1.03 µs。题目给"最大时延扩展"（如 2025-26 S1 Q2(b) 的 10 µs）时它不是 σ，别拿去套 0.1。
  • 不等号方向：平坦要符号长、速率低，算出来是上限（Rs < 34.6 ksps），不是"Rs = 34.6 ksps"。Rs 是符号速率：给比特率先除以 log₂M（4-QAM、200 kbit/s → 100 ksps）。
  • 把 0.1 当成严格分界：σ/Ts 稍大于 0.1（例 1 的 0.141）不能直接写"频率选择性"，讲义 p.33 选择性要 ≫ 1，老师也说要远大于 0.1。这个灰区只针对 σ/Ts；题目给 BC 时按讲义直接比，Bs < BC 就写 flat（模拟 C·Q2：50 kHz < 200 kHz → 平坦），不要自己再加"borderline"。
  • 把 BC ≈ 1/σ 当精确公式，或拿最大时延去估 BC：题目给了 BC 就直接和 Bs 比（2025-26 S1 Q2(b)：BC = 30 kHz 是测出来给你的；10 µs 是最大时延扩展，不是 σ）。
英文答题模板 · Exam English

Converting the powers to linear values (0, −3, −6 dB → 1, 0.5012, 0.2512), the mean delay is μ = ΣPkτk/ΣPk = 1.255/1.752 = 0.716 µs and the rms delay spread is σ = √(E[τ²] − μ²) = √(1.576 − 0.716²) = 1.03 µs. With Ts = 1/(50 ksps) = 20 µs, σ/Ts = 0.052 < 0.1, so the rule of thumb for flat fading is satisfied: the delay spread is much smaller than the symbol duration and ISI is negligible. If only bandwidths are given, compare them directly: Bs ≈ 50 kHz < BC = 200 kHz, so the whole signal bandwidth fades together and the fading is flat.

公式 · Formulas

多普勒频移 Doppler shift 定义·必会
\[ f_d=\frac{v}{\lambda}\cos\theta=\frac{v}{c}\,f_c\cos\theta \]
讲义 p.34。θ < 90°（迎着电波走）为正，θ > 90° 为负，θ = 90°（横着走）为 0。老师说多普勒频移本身不算失真，多普勒扩展才是（频率色散）。
最大多普勒频移、多普勒扩展 Maximum Doppler shift, Doppler spread 定义·必会
\[ f_m=\frac{v\,f_c}{c}=\frac{v}{\lambda},\qquad B_D=f_m \]
讲义 p.34–35。v 用 m/s（km/h ÷ 3.6），fc 用 Hz。fm 也出现在 LCR/AFD 公式里（考试给），老师要求会说出它是最大多普勒频移。
相干时间 Coherence time 定义·必会
\[ T_C\approx\frac{1}{B_D}=\frac{1}{f_m} \]
讲义 p.36：信道冲激响应基本不变的时长。动得越快，fm 越大，TC 越短；不动（时不变信道）时 fm = 0，TC → ∞。
快/慢衰落判据 Slow vs fast fading 定义·必会
\[ T_s\ll T_C\ \Longleftrightarrow\ B_s\gg B_D\ \Rightarrow\ \text{slow fading} \]\[ T_s\ \text{comparable to or longer than}\ T_C\ \Rightarrow\ \text{fast fading} \]
讲义 p.37：符号时长比相干时间短、或信号带宽远大于多普勒扩展 → 一个符号内幅度和相位近似不变，慢衰落；相干时间比符号时长小 → 快衰落。因为 Bs ≈ 1/Ts、BD ≈ 1/TC，时域和频域两种说法等价。老师的简单记法：符号时长在相干时间以内就是慢衰落。
两个维度合起来 Combined classification 定义·必会
\[ \sigma_{T_m}\ll T_s\ll T_C\ \ (\text{time}),\qquad B_D\ll B_s\lt B_C\ \ (\text{frequency})\quad\Rightarrow\quad\text{flat, slow fading} \]
时域里的 σ ≪ Ts 就是要背的 σ/Ts < 0.1（t8）；频域按讲义 p.31 只要 Bs < BC。老师说时延扩展（时间色散）和多普勒扩展（频率色散）分开判断：σ（或 BC）只管平坦/选择性，TC（或 BD）只管快/慢，组合出四种：平坦慢、平坦快、选择性慢、选择性快（讲义 p.38–39 两张图）。提高符号速率 → Ts 变短：更容易频率选择性，更不容易快衰落；"平坦"不等于"慢"。

中文例子 · 怎么用

例 1 · 只给波长；高铁 + 低符号速率 → 快衰落

高铁时速 360 km/h，载波波长 λ = 5 cm，车上传感器以 1 k 符号/s 发数据，rms 时延扩展 1 µs。判断衰落类型。

  1. v = 360/3.6 = 100 m/s。给的是波长，直接 fm = v/λ = 100/0.05 = 2000 Hz（等价于 fc = c/λ = 6 GHz，v fc/c 也是 2000 Hz）。
  2. TC ≈ 1/fm = 0.5 ms；Ts = 1/1 k = 1 ms。Ts/TC = 2：符号比相干时间还长，一个符号内信道就在变 → 快衰落（频域：Bs ≈ 1 kHz < BD = 2 kHz）。
  3. σ/Ts = 1 µs/1 ms = 0.001 < 0.1 → 平坦。

答案：fm = 2000 Hz，TC ≈ 0.5 ms；平坦快衰落（flat, fast fading）

例 2 · 反求：由相干时间求车速

在 900 MHz 测得信道相干时间约 5 ms。(a) 估计移动台速度（km/h）；(b) 系统用 100 k 符号/s，是快衰落还是慢衰落？

  1. (a) fm ≈ 1/TC = 1/5 ms = 200 Hz。
  2. v = fmc/fc = 200 × 3×10⁸ / (9×10⁸) = 66.67 m/s（也可以先算 λ = c/fc = 0.3333 m，v = fmλ）；× 3.6 = 240 km/h。
  3. (b) Ts = 1/100 k = 10 µs，TC/Ts = 500，Ts ≪ TC → 慢衰落。

答案：v ≈ 66.67 m/s ≈ 240 km/h；100 ksps 时是慢衰落

例 3 · 同一个信道换符号速率：Rs 怎样改变两个维度

信道 rms 时延扩展 σ = 2 µs，最大多普勒频移 fm = 500 Hz。符号速率分别为 250 符号/s、20 k 符号/s、5 M 符号/s 时，各是什么衰落？

  1. 先算信道本身：TC ≈ 1/500 = 2 ms。σ 和 TC 不随 Rs 变，变的只有 Ts。
  2. 250 sps：Ts = 4 ms。σ/Ts = 0.0005 → 平坦；Ts/TC = 2，符号比 TC 长 → 快。平坦快衰落。
  3. 20 ksps：Ts = 50 µs。σ/Ts = 0.04 → 平坦；TC/Ts = 40 → 慢。平坦慢衰落。
  4. 5 Msps：Ts = 0.2 µs。σ/Ts = 10 ≫ 1 → 频率选择性；TC/Ts = 10000 → 慢。选择性慢衰落。
  5. 规律：Rs 越高（Ts 越短），越容易频率选择性、越不容易快衰落。这个信道怎么调 Rs 都得不到"选择性快"：那要 Ts 远小于 σ = 2 µs，同时又不短于 TC = 2 ms，做不到。

答案：250 sps 平坦快；20 ksps 平坦慢；5 Msps 频率选择性慢

易错 · Traps

  • km/h 忘了 ÷ 3.6：54 km/h 当成 54 m/s，fm 会算成 360 Hz（正确是 100 Hz，大了 3.6 倍）；72 km/h = 20 m/s。GHz、MHz 换成 Hz，比较 Ts 和 TC 前把 ms、µs 统一。计算器上除以 3×10⁸ 要加括号（或用 EXP 键输入 3E8），直接按 "÷ 3 × 10⁸" 会变成先除 3 再乘 10⁸。
  • 衰落类型只答一个维度：老师说只给一半分。平坦/选择性写一句（σ/Ts，或 Bs 和 BC 比），快/慢写一句（Ts 和 TC 比，或 Bs 和 BD 比），合起来写 "flat, slow fading"。
  • "车快 = 快衰落"：快/慢看 Ts 和 TC 的相对大小。例 1 同样 360 km/h，只要符号时长远小于 0.5 ms 就是慢衰落；"平坦"也不等于"慢"（例 3）。
  • 两个不等号方向相反：平坦要 Bs 小于 BC，慢要 Bs 远大于 BD；时域里平坦要 Ts 远大于 σ，慢要 Ts 远小于 TC。
  • 把多普勒频移当扩展：带 cos θ 的 fd 是单条回波的频移；判快/慢用 BD = fm（θ = 0 时的最大值）。
  • 没给速度也能判：题目说 time-invariant channel，就是没有多普勒，TC → ∞，一定是慢衰落（2023-24 Q1(a)(iii)）。
英文答题模板 · Exam English

The coherence bandwidth BC, set by the multipath delay spread, is compared with the signal bandwidth Bs: if Bs < BC the fading is flat, and if Bs > BC it is frequency-selective and causes ISI. The Doppler spread BD = fm, set by the motion, is also compared with Bs: if Bs ≫ BD, i.e. Ts ≪ TC ≈ 1/BD, the fading is slow, otherwise it is fast; the two comparisons are independent and give four types (flat-slow, flat-fast, selective-slow, selective-fast).

Worked line: v = 54/3.6 = 15 m/s, fm = vfc/c = 15 × 2×10⁹/(3×10⁸) = 100 Hz and TC ≈ 1/fm = 10 ms ≫ Ts = 100 µs, so the fading is slow; σTm/Ts = 2/100 = 0.02 < 0.1, so it is flat. Hence the signal experiences flat, slow fading.
