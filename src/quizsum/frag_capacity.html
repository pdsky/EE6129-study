11香农容量与 SNR / SIR / SINR · Shannon capacity and SINR

背定义·必会出现：Practice 2 Q3 · 模拟 B·Q3 (a)(b) · 模拟 C·Q3 (a)(b) · 期末没单独考 AWGN 容量，但 4 套都出现 log₂(1 + ·)（2023-24、2025-26 S2 的中断容量；2024-25、2025-26 S1 的 MIMO 容量）

香农公式是蓝框，必背，老师说这是通信工程师最基本的公式。Quiz 可能给接收功率、噪声功率（或噪声谱密度 N0）和带宽求容量；也可能有两个用户或同频干扰，考你分母里放什么（SINR），再问干扰消掉以后、带宽翻倍以后容量变成多少。

公式 · Formulas

香农容量 · Shannon capacity（讲义第 2 章 p.48）背
\[ C=B\log_2(1+\mathrm{SNR}),\qquad \mathrm{SNR}=\frac{S}{N}=\frac{S}{N_0B} \]\[ R\le C\quad\Longleftrightarrow\quad \mathrm{SNR}\ge 2^{R/B}-1 \]
SNR 必须是线性值（17.01 dB 先换成 50.2 再代）。B 用 Hz，结果是 bit/s；题目问 per Hz（bit/s/Hz）就不乘 B。第二行是反着用：要可靠地传 R bit/s，SNR 至少 2R/B − 1。
三个比值 · SNR, SIR, SINR（Practice 2 Q3；讲义第 1a 章 p.16 多用户检测）定义·必会
\[ \mathrm{SNR}=\frac{S}{N},\qquad \mathrm{SIR}=\frac{S}{I},\qquad \mathrm{SINR}=\frac{S}{I+N} \]\[ C=B\log_2(1+\mathrm{SINR}) \]
分母 = 所有不是你想要、又被当成噪声的功率。题目说 treat the interference as (Gaussian) noise 或 assume it is AWGN，就用 SINR 代香农；MUD 或干扰消除器把干扰完全去掉后 I = 0，回到 SNR。I ≫ N 时 SINR ≈ SIR，叫“干扰受限”。
噪声功率 · noise power（p.48）定义·必会
\[ N=N_0B\qquad\Longleftrightarrow\qquad N_{\mathrm{dBm}}=N_{0,\,\mathrm{dBm/Hz}}+10\log_{10}B \]
乘法在 dB 里变加法：−174 dBm/Hz、B = 5 MHz → −174 + 66.99 = −107.01 dBm。B 翻倍 → N 多 10 log₁₀2 = 3.01 dB → 功率不变时 SNR 减半。
dB ↔ 线性 · dB conversion定义·必会
\[ x_{\mathrm{dB}}=10\log_{10}x,\qquad x=10^{x_{\mathrm{dB}}/10} \]\[ P_{\mathrm{dBm}}=10\log_{10}\frac{P}{1\ \mathrm{mW}},\qquad \mathrm{SNR}_{\mathrm{dB}}=S_{\mathrm{dBm}}-N_{\mathrm{dBm}} \]
dBm − dBm = dB（比值）；mW 和 dBm 不能直接相加。老师说没写 dB ↔ 线性换算会扣分，每次都写出来，例如“17.01 dB → 101.701 = 50.2”。

中文例子 · 怎么用

例 1 · 功率用 mW、N0 用 W/Hz（先统一单位）+ 带宽翻倍

接收信号功率 S = 10 mW，噪声功率谱密度 N0 = 10−9 W/Hz，带宽 B = 1 MHz。(a) 求 SNR（线性和 dB）和香农容量。(b) 功率不变，带宽加到 2 MHz，容量多少？翻倍了吗？

  1. 统一成 W：S = 10 mW = 0.01 W；噪声 N = N0B = 10−9 × 106 = 10−3 W（= 1 mW = 0 dBm）。
  2. SNR = 0.01 / 0.001 = 10 → 10 log₁₀10 = 10 dB。
  3. C = 106 × log₂(1 + 10) = 106 × 3.459 = 3.46 Mbps。
  4. (b) N = 10−9 × 2×106 = 2×10−3 W（3.01 dBm），SNR = 0.01/0.002 = 5（6.99 dB），C = 2×106 × log₂6 = 2 × 2.585 = 5.17 Mbps。
  5. 5.17 / 3.46 = 1.49 倍，不到 2 倍：带宽翻倍，噪声 N0B 也翻倍，SNR 从 10 掉到 5。只有 SNR 不变（比如功率也加到 20 mW）时才正好翻倍：2 MHz × log₂11 = 6.92 Mbps。

答案：(a) SNR = 10（10 dB），C ≈ 3.46 Mbps；(b) C ≈ 5.17 Mbps，约 1.49 倍，没有翻倍

例 2 · 反着问：给速率，求最小 SNR 和最小接收功率

带宽 5 MHz，要可靠地传 20 Mbps。(a) 所需最小 SNR（线性和 dB）？(b) 噪声功率为 −100 dBm，接收功率至少多少 dBm？(c) 如果 SNR 只有 10 dB，最多能传多快？

  1. R ≤ C = B log₂(1 + SNR) → log₂(1 + SNR) ≥ R/B = 20/5 = 4。
  2. SNR ≥ 24 − 1 = 15 → 10 log₁₀15 = 11.76 dB。
  3. (b) 在 dB 里相加：S ≥ −100 + 11.76 = −88.24 dBm。
  4. (c) 10 dB → 101 = 10，C = 5 MHz × log₂11 = 5 × 3.459 = 17.3 Mbps < 20 Mbps，传不了。

答案：(a) 15（11.76 dB）；(b) −88.24 dBm；(c) 17.3 Mbps，不够 20 Mbps

例 3 · 两个用户功率不同：先解谁，分母就不同

两个用户同时同频向基站发送，接收功率 P₁ = 8 mW、P₂ = 2 mW，噪声 0.2 mW，每个用户带宽 10 MHz。(a) 先解用户 1（用户 2 当 AWGN），再用 MUD 减掉用户 1 解用户 2，求两个容量。(b) 顺序反过来呢？(c) 不用 MUD（两个都把对方当噪声），总容量多少？

  1. (a) 解用户 1：SINR₁ = 8/(2 + 0.2) = 3.64（5.61 dB），C₁ = 10 × log₂4.636 = 10 × 2.213 = 22.1 Mbps。
  2. 减掉用户 1 后只剩噪声：SNR₂ = 2/0.2 = 10（10 dB），C₂ = 10 × log₂11 = 10 × 3.459 = 34.6 Mbps。总和 56.7 Mbps。
  3. (b) 先解用户 2：SINR₂ = 2/(8 + 0.2) = 0.244（−6.13 dB），C₂ = 10 × log₂1.244 = 10 × 0.315 = 3.15 Mbps；再解用户 1：SNR₁ = 8/0.2 = 40（16.02 dB），C₁ = 10 × log₂41 = 53.6 Mbps。总和还是 56.7 Mbps。
  4. 自检：和容量 = 10 × log₂(1 + (8 + 2)/0.2) = 10 × log₂51 = 56.7 Mbps，和解码顺序无关。
  5. (c) 都不消除：22.1 + 3.15 = 25.3 Mbps，不到 MUD 的一半。

答案：(a) C₁ ≈ 22.1 Mbps，C₂ ≈ 34.6 Mbps；(b) C₂ ≈ 3.15 Mbps，C₁ ≈ 53.6 Mbps，两种顺序总和都是 56.7 Mbps；(c) 25.3 Mbps

易错 · Traps

  • SNR 用 dB 直接代进 log₂：模拟 B·Q3 的 17.01 dB 要先换成 50.2，log₂(1 + 50.2) = 5.68；写成 log₂(1 + 17.01) = 4.17 就错了。
  • 带宽翻倍忘了噪声 N = N0B 也翻倍：功率不变时 SNR 减半，容量不到 2 倍（例 1 是 1.49 倍，模拟 B·Q3 是 1.66 倍）。只有 SNR 保持不变时才正好翻倍。
  • 有干扰时分母要写 I + N。Practice 2 Q3 (a) 写成 10/0.1 = 100 等于假装用户 2 不存在；只有 MUD 把对方减掉以后，后解的用户分母才只剩 N。
  • 单位混用：mW 和 W 要统一；dBm 和 mW 不能直接相加减；dBm − dBm 得到的是 dB（比值）。
  • SINR 0.990 是线性值（约 −0.04 dB），不要把它当成 dB 再换一次。
  • 问容量要乘 B 并写单位 bit/s（Mbps）；问 per Hz 才不乘 B。
英文答题模板 · Exam English

When user 1 is decoded, user 2's signal is treated as AWGN, so the denominator contains both interference and noise: SINR₁ = P₁/(P₂ + N) = 10/(10 + 0.1) = 0.990 (linear). By Shannon's formula, C₁ = B log₂(1 + SINR₁) = 20×10⁶ × log₂(1.990) = 19.86 Mbps.

After multi-user detection removes user 1, user 2 sees only noise: SNR₂ = P₂/N = 10/0.1 = 100 (20 dB), so C₂ = 20×10⁶ × log₂(101) = 133.16 Mbps.

With the signal power fixed, doubling the bandwidth also doubles the noise power N = N₀B, so the SNR halves (17.01 dB → 14.00 dB, i.e. 50.2 → 25.1) and the capacity rises only from 28.4 to 47.1 Mbps, about 1.66 times, not double.

12瑞利信道的中断容量与衰落余量 · Outage capacity and fade margin

背考试给尽量记出现：期末 2/4 套（2023-24 Q1(a)(iv)、2025-26 S2 Q1(a)(iii)）· 模拟 B·Q1 (b) · 模拟 C·Q3 (c)

瑞利衰落下 SNR 时高时低，想让 1 − ε 的时间都能通信，只能按很低的最小 SNR γmin 设计速率；和没有衰落的 AWGN 信道比，平均 SNR 要多给的那部分就是衰落余量。期末两次都把 Cε 公式印在题里：2025-26 S2 给 γ̄ = 25 dB 和 ε = 0.005，问最小 SNR 和衰落余量；2023-24 只给 ε = 0.1%，只问衰落余量。也可以反过来问需要多大的平均 SNR（模拟 B·Q1 (b)）。遍历容量要对 SNR 分布积分，Quiz 不考积分，Jensen 不等式老师说只要求懂概念。

公式 · Formulas

瑞利中断 · Rayleigh outage（讲义第 2 章 p.25–26）背
\[ P_{out}=P(\gamma\lt\gamma_0)=1-e^{-\gamma_0/\bar\gamma} \]
老师说这个公式“经常出现”。γ0、γ̄ 都用线性值。令它等于 ε，两步就能反解出下面的 γmin：\(e^{-\gamma_{\min}/\bar\gamma}=1-\varepsilon\)，两边取 ln。
中断容量与最小 SNR · outage capacity（p.50）考试给
\[ C_\varepsilon=B\log_2\!\Big(1+\bar\gamma\ln\frac{1}{1-\varepsilon}\Big),\qquad \gamma_{\min}=\bar\gamma\ln\frac{1}{1-\varepsilon} \]
2023-24 和 2025-26 S2 期末都把 Cε 印在题里。括号里 γ̄ ln(1/(1 − ε)) 这一项就是最小 SNR，所以 Cε 等于 SNR 为 γmin 的 AWGN 信道的容量。没印公式时，从背的瑞利中断反解即可。平均无错速率 = (1 − ε)Cε。
衰落余量 · fade margin（p.51）尽量记
\[ \mathrm{FM}=\bar\gamma_{\mathrm{dB}}-\gamma_{\min,\mathrm{dB}}=10\log_{10}\frac{\bar\gamma}{\gamma_{\min}} \]\[ \mathrm{FM}=10\log_{10}\frac{1}{\ln\frac{1}{1-\varepsilon}}\ \mathrm{dB}\ \approx\ 10\log_{10}\frac{1}{\varepsilon} \]
老师说瑞利的衰落余量公式“有点难记，但要尽量记”。记不住就从第一行的比值推：γ̄/γmin = 1/ln(1/(1 − ε))，γ̄ 约掉了，所以 FM 只和 ε 有关。速记：ε = 1% → 19.98 ≈ 20 dB，0.5% → 23.00 dB，0.1% → 30.00 dB；中断要求每严 10 倍，余量多约 10 dB。

例 1 · ε = 2%、带宽 1 MHz：最小 SNR、Cε、平均无错速率，和 AWGN 比

瑞利信道平均 SNR 为 30 dB，带宽 1 MHz，允许中断概率 2%。已知 Cε = B log₂[1 + γ̄ ln(1/(1 − ε))]。(a) 求最小 SNR（线性和 dB）和衰落余量。(b) 求 Cε 和平均无错速率 (1 − ε)Cε。(c) 和 SNR 同为 30 dB 的 AWGN 信道比较。

  2. γmin = 1000 × 0.02020 = 20.20 → 10 log₁₀20.20 = 13.05 dB。
  3. FM = 30 − 13.05 = 16.95 dB（用公式检查：10 log₁₀(1/0.02020) = 16.95 dB ✓）。
  4. (b) Cε = 106 × log₂(1 + 20.20) = 106 × log₂21.20 = 4.41 Mbps；平均无错速率 = 0.98 × 4.406 = 4.32 Mbps。
  5. (c) AWGN：106 × log₂(1 + 1000) = 9.97 Mbps。瑞利信道能保证的速率不到它的一半。
  6. 自检：1 − e−20.20/1000 = 1 − e−0.02020 = 0.0200 = ε ✓。

答案：γmin ≈ 20.2（13.05 dB），FM ≈ 16.95 dB；Cε ≈ 4.41 Mbps，平均无错速率 ≈ 4.32 Mbps；AWGN 为 9.97 Mbps

例 2 · 反着问：要保证 2 bit/s/Hz，平均 SNR 至少多少

瑞利信道，允许中断概率 1%，要求能保证 Cε/B = 2 bit/s/Hz。平均 SNR 至少要多少 dB？对应的衰落余量是多少？

  1. 先由速率求最小 SNR：log₂(1 + γmin) = 2 → γmin = 22 − 1 = 3 → 10 log₁₀3 = 4.77 dB。
  2. 由 γmin = γ̄ ln(1/(1 − ε)) 反求：γ̄ = 3 / ln(1/0.99) = 3 / 0.01005 = 298.5。
  3. 换 dB：10 log₁₀298.5 = 24.75 dB。
  4. FM = 24.75 − 4.77 = 19.98 dB ≈ 20 dB，正是 ε = 1% 的余量：要求的速率变了，余量不变。

答案：γ̄ ≥ 298.5（24.75 dB）；FM ≈ 19.98 dB

例 3 · 只问余量：γ̄ 换了余量不变；ε 从 5% 收紧到 0.5%

(a) 允许中断概率 5%，瑞利信道的衰落余量是多少？分别取 γ̄ = 15 dB 和 25 dB 求最小 SNR，验证余量相同。(b) 用近似式 10 log₁₀(1/ε) 算，差多少？(c) 中断要求收紧到 0.5%，平均 SNR 要再多给多少 dB？

  1. ln(1/0.95) = 0.05129，FM = 10 log₁₀(1/0.05129) = 12.90 dB。
  2. γ̄ = 15 dB → 101.5 = 31.62：γmin = 31.62 × 0.05129 = 1.622（2.10 dB），FM = 15 − 2.10 = 12.90 dB。
  3. γ̄ = 25 dB → 102.5 = 316.2：γmin = 316.2 × 0.05129 = 16.22（12.10 dB），FM = 25 − 12.10 = 12.90 dB。两次一样，因为 γ̄ 在 γ̄/γmin 里约掉了。
  4. (b) 近似：10 log₁₀(1/0.05) = 13.01 dB，比精确值大 0.11 dB；ε 越小，近似越准。
  5. (c) ε = 0.5%：FM = 23.00 dB，要多给 23.00 − 12.90 = 10.10 dB。中断要求严 10 倍，余量多约 10 dB。

答案：FM ≈ 12.90 dB（与 γ̄ 无关）；近似值 13.01 dB；收紧到 0.5% 要多给 10.10 dB

易错 · Traps

  • ln 不是 log₁₀：2025-26 S2 那题如果用 log₁₀(1/0.995) = 0.002177，会得到 γmin = 0.688（−1.62 dB）、FM = 26.6 dB，全错。
  • γ̄ 要先换成线性再乘：25 dB → 316.2，不能写成 25 × 0.005013。
  • ε 用小数代：0.5% = 0.005，0.1% = 0.001，不能代 0.5 或 0.1。
  • FM 是两个 dB 值相减（等于线性相除），只取决于 ε，与 γ̄、B 都无关；不要用 316.2 − 1.585 这种线性差。
  • 问 minimum SNR 时线性和 dB 都写（1.585 → 2.00 dB），老师说漏写 dB ↔ 线性换算会扣分。
  • 近似 10 log₁₀(1/ε) 只在 ε 小时准：ε = 10% 时精确值 9.77 dB，近似 10.00 dB；有时间就用精确式。Cε 是能保证的速率，平均无错速率还要乘 (1 − ε)。
英文答题模板 · Exam English

In Rayleigh fading the SNR is exponentially distributed, so P(γ < γmin) = 1 − e−γmin/γ̄ = ε, which gives γmin = γ̄ ln[1/(1 − ε)].

With γ̄R = 25 dB = 316.2 and ε = 0.005: γmin = 316.2 × ln(1/0.995) = 316.2 × 0.005013 = 1.585, i.e. 2.0 dB. This is the minimum SNR, and Cε equals the capacity of an AWGN channel with this SNR.

The fade margin compared with the AWGN channel is FM = γ̄dB − γmin,dB = 25 − 2.0 = 23.0 dB = 10 log₁₀[1/ln(1/(1 − ε))]; it depends only on ε, not on γ̄.

13注水法功率分配 · Water-filling power allocation

尽量记出现：期末 1/4 套（2024-25 Q1(a)(iii)）· 模拟 B·Q3 (c) · 讲义第 2 章 p.56–57 例题 · 第 5、7 章也用（Practice 5 Q1、Practice 7 Q1(d)，属期末范围）

频率选择性信道切成几个子带（子信道），好坏不同，总功率固定：好的多给、差的少给、太差的干脆不给。老师说注水“很重要，要会算”。Quiz 可能给 2–3 个子带的 SNR（dB）和总功率 P，求每个子带分多少瓦（和总容量）。关键是先假设全开解 γ0，检查，不满足就去掉最差的重算。时变信道的注水老师说只要求概念，不会让算。

符号与含义 · Symbols

符号中文English含义（大白话）单位
\(\gamma_i\)第 i 个子信道的 SNRSNR of sub-channel i把全部功率 P 都给它时的 SNR；越大信道越好线性（dB 先换）
\(\gamma_0\)截止 SNR（门限）cutoff SNR (threshold)γi 低于它的子信道一点功率都不给；由总功率约束解出来线性
\(1/\gamma_0\)水位water level倒进去的水最后的平面高度，所有开着的子信道都到这个高度—
\(1/\gamma_i\)池底高度floor of sub-channel i信道越好池底越低，能装的水（功率）越多；池底高过水位的就没水—
\(P\)总发射功率total transmit power各子信道功率之和必须等于它W
\(P_i\)分给第 i 个子信道的功率power allocated to sub-channel i（水位 − 池底）× PW
\(n\)分到功率的子信道个数number of active sub-channels去掉一个就减 1，重算时一定要改—

公式 · Formulas

功率分配 · power allocation（讲义第 2 章 p.54）尽量记
\[ \frac{P_i}{P}=\begin{cases}\dfrac{1}{\gamma_0}-\dfrac{1}{\gamma_i}, & \gamma_i\ge\gamma_0\\[6pt] 0, & \gamma_i\lt\gamma_0\end{cases} \]
老师说这个分配式尽量记，注水要会算。2024-25 期末把它印在题里（写成 Pi = P(1/γ0 − 1/γi)），但只给了这一式，γ0 要自己用 ΣPi = P 解；Quiz 不保证会印。P 不是 1 W 时别忘了乘 P。
求水位 · solving for γ0（由 ΣPi = P 推出）尽量记
\[ \sum_{\text{on}}\Big(\frac{1}{\gamma_0}-\frac{1}{\gamma_i}\Big)=1\qquad\Longrightarrow\qquad \frac{1}{\gamma_0}=\frac{1}{n}\Big(1+\sum_{\text{on}}\frac{1}{\gamma_i}\Big) \]
只对“开着”的 n 个子信道求和。第一次假设全部都开；解出 γ0 后检查每个 γi ≥ γ0，有不满足的就去掉最差的那个，n 减 1 再解，直到剩下的全部满足。
总容量 · total capacity（p.54）尽量记
\[ C=\sum_{\gamma_i\ge\gamma_0}B_i\log_2\frac{\gamma_i}{\gamma_0}\qquad\Big(=\sum B_i\log_2\Big(1+\gamma_i\frac{P_i}{P}\Big)\Big) \]
括号里的写法说明它就是香农公式：子信道 i 拿到 Pi，SNR 变成 γiPi/P，而 1 + γi(1/γ0 − 1/γi) = γi/γ0。记不住就用香农现算。γi/γ0 = γi × (1/γ0)，直接乘水位更快。

中文例子 · 怎么用

例 1 · 两个子带都开，总功率 2 W（P 不是 1 W）

两个子带各 1 MHz，把全部功率 P = 2 W 给其中一个时 SNR 分别为 12 dB、6 dB。用注水法求每个子带分多少瓦、总容量，并和平分功率比较。

  1. 换线性：12 dB → 101.2 = 15.85，6 dB → 100.6 = 3.981；1/γ = 0.0631、0.2512。
  2. 假设都开：1/γ0 = (1 + 0.0631 + 0.2512)/2 = 1.3143/2 = 0.6571 → γ0 = 1.522（1.82 dB）。
  3. 检查：3.981 ≥ 1.522 ✓，两个都开。
  4. 功率要乘 P = 2 W：P₁ = 2 × (0.6571 − 0.0631) = 1.188 W；P₂ = 2 × (0.6571 − 0.2512) = 0.812 W；和 = 2 W ✓。
  5. 容量：C = 1 MHz × [log₂(15.85 × 0.6571) + log₂(3.981 × 0.6571)] = log₂10.42 + log₂2.616 = 3.381 + 1.387 = 4.77 Mbps。
  6. 平分：每个 1 W，SNR 减半为 7.924 和 1.991：log₂8.924 + log₂2.991 = 3.158 + 1.581 = 4.74 Mbps。两个子带都不差时注水只多一点；子带差距大时（模拟 B·Q3：4.39 对 3.78 Mbps）差别才明显。

答案：P₁ ≈ 1.188 W，P₂ ≈ 0.812 W；C ≈ 4.77 Mbps（平分为 4.74 Mbps）

例 2 · 三个子带：最差的要关掉，再重算

频率选择性信道分成三个子带，各 1 MHz。把全部功率 P = 1 W 给某个子带时，SNR 分别为 15 dB、6 dB、−3 dB。用注水法求各子带的功率和总容量。

  1. 换线性：15 dB → 101.5 = 31.62，6 dB → 100.6 = 3.981，−3 dB → 10−0.3 = 0.5012；1/γ = 0.03162、0.2512、1.995。
  2. 假设三个都开：1/γ0 = (1 + 0.03162 + 0.2512 + 1.995)/3 = 3.278/3 = 1.093 → γ0 = 0.915。
  3. 检查：γ₃ = 0.5012 < 0.915 ✗。如果硬算，P₃ = 1.0927 − 1.9953 = −0.9026 W，功率是负的，说明第 3 个子带该关掉。
  4. 去掉第 3 个，n = 2 重算：1/γ0 = (1 + 0.03162 + 0.2512)/2 = 1.283/2 = 0.6414 → γ0 = 1.559（1.93 dB）。再检查：γ₂ = 3.981 ≥ 1.559 ✓。
  5. 功率：P₁ = 0.6414 − 0.03162 = 0.610 W，P₂ = 0.6414 − 0.2512 = 0.390 W，P₃ = 0；0.610 + 0.390 = 1 W ✓。
  6. 容量：C = 1 MHz × [log₂(31.62 × 0.6414) + log₂(3.981 × 0.6414)] = log₂20.28 + log₂2.553 = 4.342 + 1.352 = 5.69 Mbps。

答案：P₁ ≈ 0.610 W，P₂ ≈ 0.390 W，P₃ = 0；C ≈ 5.69 Mbps

例 3 · 四个子带：要去掉两次，每次重算后全部重新检查

四个子带各 1 MHz，全部功率给它时 SNR 为 20、10、0、−5 dB，总功率 P = 1 W。求功率分配和总容量。

  1. 换线性：100、10、1、10−0.5 = 0.3162；1/γ = 0.01、0.1、1、3.162。
  2. 第 1 轮（4 个都开）：1/γ0 = (1 + 0.01 + 0.1 + 1 + 3.162)/4 = 5.272/4 = 1.318 → γ0 = 0.759。γ₄ = 0.3162 < 0.759 ✗，去掉第 4 个。此时 γ₃ = 1 ≥ 0.759，看起来没问题。
  3. 第 2 轮（3 个）：1/γ0 = (1 + 0.01 + 0.1 + 1)/3 = 2.11/3 = 0.7033 → γ0 = 1.422。重新检查：γ₃ = 1 < 1.422 ✗，第 3 个也要去掉。
  4. 第 3 轮（2 个）：1/γ0 = (1 + 0.01 + 0.1)/2 = 1.11/2 = 0.555 → γ0 = 1.802。γ₂ = 10 ≥ 1.802 ✓，结束。
  5. 功率：P₁ = 0.555 − 0.01 = 0.545 W，P₂ = 0.555 − 0.1 = 0.455 W，P₃ = P₄ = 0；和 = 1 W ✓。
  6. 容量：C = log₂(100 × 0.555) + log₂(10 × 0.555) = log₂55.5 + log₂5.55 = 5.794 + 2.472 = 8.27 Mbps。

答案：P = 0.545 / 0.455 / 0 / 0 W；C ≈ 8.27 Mbps

易错 · Traps

  • γi 一定用线性值：18 dB 是 63.1，不是 18。
  • 不检查 γi ≥ γ0 就会算出负功率（例 2 硬算得 P₃ = −0.9026 W）；负功率就说明这个子带该关掉。
  • 去掉子带后 n 要跟着改（3 → 2），括号里的“1”（代表总功率 P/P）别漏。
  • 每次重算后要把剩下的全部重新检查：例 3 第一轮第 3 个子带过关（1 ≥ 0.759），去掉第 4 个后水位从 1.318 降到 0.7033，它就不过关了（1 < 1.422）。
  • 容量是 log₂(γi/γ0)，不是 log₂(1 + γi)；只对开着的子带求和。
  • P 不是 1 W 时 Pi = P × (1/γ0 − 1/γi)；最后自检 ΣPi = P。
英文答题模板 · Exam English

Converting the SNRs to linear values gives γ₁ = 63.1, γ₂ = 10.0 and γ₃ = 1.995. Assuming all three sub-bands receive power, Σ(1/γ₀ − 1/γᵢ) = 1 gives 1/γ₀ = (1 + 1/63.1 + 1/10 + 1/1.995)/3 = 0.539, so γ₀ = 1.855 (2.68 dB).

Since every γᵢ ≥ γ₀, the assumption holds, and Pᵢ = P(1/γ₀ − 1/γᵢ) gives P₁ = 0.523 W, P₂ = 0.439 W and P₃ = 0.038 W, which add up to P = 1 W.

If a sub-band had γᵢ < γ₀, it would receive no power; it is removed and γ₀ is recomputed with the remaining sub-bands until all of them satisfy γᵢ ≥ γ₀. The capacity is then C = Σ Bᵢ log₂(γᵢ/γ₀) over the active sub-bands.
