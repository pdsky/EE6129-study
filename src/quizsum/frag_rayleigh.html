6瑞利衰落：中断概率与衰落余量 · Rayleigh fading: outage and fade margin

背尽量记出现：期末 2/4 套考衰落余量（2023-24 Q1(a)(iv)、2025-26 S2 Q1(a)(iii)）；正着算中断只在第 4 章题 2024-25 Q1(b)(i) 的第一步出现过 · 模拟 B · Q1 · 专项 · Q3(c) · 模拟 C · Q3(c)

瑞利衰落 = 没有直射径、只有大量散射回波，瞬时 SNR γ 是随机变量（指数分布）。Quiz 可能：① 已知平均 SNR 和门限，求中断概率；② 已知中断要求 ε，倒推所需平均 SNR、最小 SNR 或衰落余量（期末 2023-24、2025-26 S2 都考了衰落余量）；③ 同样余量下和阴影比谁中断多。老师说瑞利中断公式"经常出现"。

公式 · Formulas

SNR 的指数分布 · Exponential PDF of the SNR 背
\[ p(\gamma)=\frac{1}{\bar\gamma}\,e^{-\gamma/\bar\gamma},\qquad \gamma\ge 0 \]
讲义第 2 章 p.25–26。瑞利衰落时包络 z 服从瑞利分布，功率 z² 和 SNR γ 服从指数分布。老师说要背的是这一个，不是包络的瑞利 PDF \(\frac{z}{\sigma^2}e^{-z^2/(2\sigma^2)}\)；推导不会让推。
瑞利中断概率 · Rayleigh outage probability 背
\[ P_{out}=P(\gamma\lt\gamma_0)=1-e^{-\gamma_0/\bar\gamma}\;\approx\;\frac{\gamma_0}{\bar\gamma}\quad(\gamma_0\ll\bar\gamma) \]
γ0、γ̄ 先换成线性值再相除（是比值，单位一致即可）。近似只在比值小时用：x ≈ 0.05 时偏高 2.5%，x = 0.1 时偏高 5.1%，x = 0.5 时偏高 27%，答题写精确值。口诀：门限比平均低 10 dB → 9.52%，低 20 dB → 0.995%，低 30 dB → 0.100%。反面：高于某个值 γ1 的概率 \(P(\gamma\gt\gamma_1)=e^{-\gamma_1/\bar\gamma}\)，取 γ1 = γ̄ 得高于平均值的概率只有 e−1 = 0.368。门限按幅度给（信号强度是 rms 值的 ρ 倍）时 γ0/γ̄ = ρ²：Practice 2 Q1 的 ρ = 0.1 → 1 − e−0.01 = 0.00995（该题本身求 AFD；0.00995 是练习页解答里顺带算的"低于门限的时间比例"）。
倒着解：所需平均 SNR / 最小 SNR · Solving backwards 会反解
\[ \bar\gamma=\frac{\gamma_0}{\ln\frac{1}{1-\varepsilon}},\qquad \gamma_{\min}=\bar\gamma\,\ln\frac{1}{1-\varepsilon} \]
不用另背：令 ε = 1 − e−γ0/γ̄，两边整理后取 ln 就得到。ε 小时 ln(1/(1−ε)) ≈ ε，所以 γ̄ ≈ γ0/ε。真题印的中断容量公式 \(C_\varepsilon=B\log_2\!\big[1+\bar\gamma_R\ln\frac{1}{1-\varepsilon}\big]\)（考试给）里，\(\bar\gamma_R\ln\frac{1}{1-\varepsilon}\) 就是 γmin；中断容量本身见第 12 类。
衰落余量（瑞利）· Fade margin (Rayleigh) 尽量记
\[ \mathrm{FM}=\bar\gamma_{\mathrm{dB}}-\gamma_{0,\mathrm{dB}}=10\log_{10}\frac{\bar\gamma}{\gamma_0}=10\log_{10}\frac{1}{\ln\frac{1}{1-\varepsilon}}\ \mathrm{dB}\;\approx\;10\log_{10}\frac{1}{\varepsilon} \]
讲义 p.51，老师说"有点难记，但要尽量记"；记不住就用上一条现推。讲义写成 γ̄dB − γAWGN,dB：不衰落的 AWGN 信道只要 SNR = γ0，瑞利信道要多给 FM。只和 ε 有关、和 γ̄ 无关：ε = 10% → 9.77 dB，5% → 12.90 dB，1% → 19.98 dB，0.5% → 23.00 dB，0.1% → 30.00 dB。中断要求每严 10 倍，余量多 10 dB。

中文例子 · 怎么用

例 1 · 给的是 dBm 功率；再问"高于"的概率

手机平均接收功率 −92 dBm，噪声功率 −110 dBm，信道是瑞利衰落。(a) 接收机要求瞬时 SNR 至少 6 dB，求中断概率。(b) 瞬时 SNR 比平均值高 3 dB 以上的概率是多少？

  1. 平均 SNR：γ̄ = −92 − (−110) = 18 dB（dBm − dBm = dB）→ γ̄ = 101.8 = 63.10。
  2. 门限：γ0 = 6 dB → 100.6 = 3.981。
  3. 比值：x = 3.981 / 63.10 = 0.06310（也可以直接 10(6−18)/10 = 10−1.2：门限比平均低 12 dB）。
  4. (a) Pout = 1 − e−0.06310 = 0.0611；估算 ≈ 0.0631，接近 ✓。
  5. (b) "高于"用反面：\(P(\gamma\gt\gamma_1)=e^{-\gamma_1/\bar\gamma}\)。γ1 = 18 + 3 = 21 dB → 125.9，125.9 / 63.10 = 1.995（= 100.3），P = e−1.995 = 0.136。

答案：(a) Pout ≈ 0.0611（6.11%）；(b) ≈ 0.136

例 2 · 倒着求平均 SNR 和余量，再求最远距离

瑞利信道，接收机门限 SNR 8 dB，要求中断概率不超过 2%。(a) 平均 SNR 至少要多少？衰落余量多少？(b) 发射功率 1 W，简化路径损耗模型 KdB = −40 dB、路径损耗指数 γ = 3.5（这个 γ 不是 SNR）、d0 = 1 m，噪声功率 −115 dBm。满足 (a) 的最远距离是多少？

  1. γ0 = 8 dB → 100.8 = 6.310；ln(1/(1 − 0.02)) = ln(1/0.98) = 0.020203。
  2. γ̄ = 6.310 / 0.020203 = 312.3 → 10 log10312.3 = 24.95 dB。
  3. FM = 24.95 − 8 = 16.95 dB；核对 10 log10(1/0.020203) = 16.95 dB（近似 10 log1050 = 16.99 dB）。
  4. (b) 所需平均接收功率 = 噪声 + 平均 SNR = −115 + 24.95 = −90.05 dBm；Pt = 1 W = 1000 mW → 30 dBm。
  5. 30 + (−40) − 35 log10d ≥ −90.05 → 35 log10d ≤ 80.05 → log10d ≤ 2.2873 → d ≤ 193.8 m。

答案：(a) γ̄ ≥ 24.95 dB，FM ≈ 16.95 dB；(b) d ≤ 193.8 m（"最远"往小取，约 193 m）

例 3 · 同样余量：阴影和瑞利谁中断多？

两条链路的平均接收功率都比门限高 15 dB。链路 A 只有阴影衰落（σ = 6 dB），链路 B 是瑞利衰落（没有阴影）。哪条的中断概率大？

  1. A 是阴影，在 dB 上相减、用 Q：Pout = Q(15/6) = Q(2.50) = 0.00621（查 Q 表）。
  2. B 是瑞利，在线性上相除、用指数：γ0/γ̄ = 10−15/10 = 10−1.5 = 0.03162，Pout = 1 − e−0.03162 = 0.0311。
  3. 比较：B 约是 A 的 5 倍，瑞利的深坑更深。
  4. 但这不是定律：专项 · Q3 余量 10 dB、σ = 8 dB 时，阴影 Q(1.25) = 0.106，瑞利 1 − e−0.1 = 0.0952，反而阴影大。同样 σ = 8 dB，余量 15 dB 时两者差不多（阴影 0.0304 对瑞利 0.0311），20 dB 时瑞利大（阴影 0.00621 对瑞利 0.00995）。原因：瑞利余量每多 10 dB，中断只降 10 倍；阴影的 Q(余量/σ) 在余量/σ 大时降得快得多。

答案：本题 B（瑞利）大：B 3.11% 对 A 0.621%。考试两个都算出来再比，别凭感觉。

易错 · Traps

  • 把 dB 直接代进指数：1 − e−7/20 = 0.295 ✗，正确是 1 − e−5.012/100 = 0.0489。老师讲第 3 章用这个公式的例题时说：8.5 dB 要先换成 100.85，每年都强调还是有人不换；没写 dB ↔ 线性换算会扣分。
  • ln 按成 log：ε = 1% 时 log10(1/0.99) = 0.004365 → 算出 23.60 dB ✗，用 ln 才是 19.98 dB。
  • 衰落余量用线性相减：498.7 − 5.012 = 493.7 没有意义 ✗。FM 是 dB 相减，等于线性相除再取 10 log。
  • 阴影、瑞利公式用反：给了 σ（dB）→ Q(余量/σ)；只给平均 SNR、没有 σ → 1 − e−γ0/γ̄。
  • 以为 SNR 一半时间高于平均：指数分布不对称，P(γ > γ̄) = e−1 = 0.368，有 63.2% 的时间低于平均值。
  • 门限按幅度给（rms 的 ρ 倍）忘了平方：ρ = 0.1 时写 1 − e−0.1 = 0.0952 ✗，应为 1 − e−0.01 = 0.00995。
英文答题模板 · Exam English

In Rayleigh fading the instantaneous SNR γ is exponentially distributed, \(p(\gamma)=\frac{1}{\bar\gamma}e^{-\gamma/\bar\gamma}\), so the outage probability is \(P_{out}=P(\gamma\lt\gamma_0)=1-e^{-\gamma_0/\bar\gamma}\). In linear terms \(\bar\gamma\) = 20 dB = 100 and \(\gamma_0\) = 7 dB = 5.012, so \(P_{out}=1-e^{-5.012/100}=0.0489\).

With \(\bar\gamma_R\) = 25 dB = 316.2 and ε = 0.005, setting \(1-e^{-\gamma_{\min}/\bar\gamma}=\varepsilon\) gives \(\gamma_{\min}=\bar\gamma\ln\frac{1}{1-\varepsilon}\) = 316.2 × 0.005013 = 1.585, i.e. 10 log101.585 = 2.00 dB, so the fade margin relative to an AWGN channel is 25 − 2.00 = 23.0 dB \(=10\log_{10}\big[1/\ln\frac{1}{1-\varepsilon}\big]\), which depends only on ε.

7莱斯衰落与 K 因子 · Rician fading and the K-factor

考试给定义·必会出现：期末 0/4 套 · 专项 · Q3(d) · 讲义第 2 章 p.27–28

莱斯 = 多径散射 + 一条直射径（LOS）。Quiz 若考，多半是由功率比求 K 并换成 dB，再定性说深衰落、中断比瑞利多还是少（专项 · Q3(d) 就是这种问法）。莱斯分布考试给，懂 K 的含义即可；老师说只要知道直射分量越强，越接近没有衰落的 AWGN。

公式 · Formulas

莱斯因子 · Rician K-factor 考试给
\[ K=\frac{s^2}{2\sigma^2}=\frac{\text{LOS power}}{\text{total scattered power}} \]
讲义 p.27–28。式子考试给，但含义自己要会说：直射功率 ÷ 散射总功率（功率比）。K = 0 → 没有直射 → 瑞利（最差）；K → ∞ → 只剩直射 → 不衰落（AWGN）。同一平均 SNR、同一门限下（门限低于平均 SNR，也就是正常留了余量的情况），K 越大，深衰落越少，中断越小。
K 的 dB 与功率拆分 · K in dB and the power split 定义·必会
\[ K_{\mathrm{dB}}=10\log_{10}K,\qquad \frac{s^2}{s^2+2\sigma^2}=\frac{K}{K+1},\qquad \frac{2\sigma^2}{s^2+2\sigma^2}=\frac{1}{K+1} \]
K 是功率比，用 10 log（不是 20 log）。K = 0 dB 的意思是 K = 1（直射、散射各 50%），不是瑞利；瑞利是 K = 0，即 −∞ dB。讲义 p.28 的图画了 K = −∞ dB（瑞利）、6 dB、∞ dB 三条曲线。
莱斯分布（包络）· Rician envelope PDF 考试给
\[ p_z(z)=\frac{z}{\sigma^2}\,e^{-\frac{z^2+s^2}{2\sigma^2}}\,I_0\!\left(\frac{zs}{\sigma^2}\right),\qquad z\ge 0 \]
不用背，I0 不用会算。看到它要认出 s² 是直射功率、2σ² 是散射功率。令 s = 0：I0(0) = 1，就变回瑞利 PDF \(\frac{z}{\sigma^2}e^{-z^2/(2\sigma^2)}\)，所以瑞利是莱斯 K = 0 的特例。

例 2 · 倒着读 KdB；直射被挡住会怎样

(a) 某信道 KdB = −3 dB，直射功率占总功率多少？它更像瑞利还是 AWGN？(b) 用户从开阔地（K = 10 dB）走进楼群，直射径被完全挡住。假设平均 SNR 仍是 20 dB、门限仍是 10 dB，衰落分布和中断概率怎么变？

  1. (a) K = 10−3/10 = 10−0.3 = 0.5012；直射占 0.5012 / 1.5012 = 33.4%，散射占 66.6%。
  2. 散射为主，更接近瑞利；但 K = −3 dB 不是瑞利（瑞利是 K = 0，即 −∞ dB）。
  3. (b) 直射被挡 → s² = 0 → K = 0 → 包络从莱斯变成瑞利 → 深衰落变多 → 中断概率变大。
  4. 瑞利那一端能算：1 − e−10/100 = 0.0952。课外数值（莱斯要数值计算，只为建立感觉）：K = 10 dB（K = 10）约 0.074%，K = 4（6.02 dB，就是专项 · Q3 (d)）约 1.63%，K = 0 dB（K = 1）约 7.33%，到瑞利（K = 0）9.52%，比 K = 10 dB 时大约 129 倍。

答案：(a) 直射约 33.4%，偏瑞利但不是瑞利；(b) 变成瑞利衰落，中断概率变大（升到 9.52%）

易错 · Traps

  • KdB 用 20 log：K = 4 → 20 log104 = 12.04 dB ✗，应为 10 log104 = 6.02 dB（K 是功率比）。
  • 给的是幅度比忘了平方：直射幅度是散射 rms 幅度 √(2σ²) 的 2 倍 → K = 2² = 4（6.02 dB），不是 2（3.01 dB）。
  • 把 K = 0 dB 当成瑞利 ✗：0 dB 是 K = 1（直射、散射各 50%）；瑞利是 K = 0 = −∞ dB。
  • 散射总功率用 dBm 直接相加，或只取最强的一条 ✗（例 1 只取 −90 dBm 那条会得 KdB = −80 − (−90) = 10 dB，正确是 7.11 dB）：先换 mW 全部加起来，再求 K。
  • 把"瑞利 / 莱斯"和"平坦 / 选择性、快 / 慢"混为一谈：前者说幅度服从什么分布，后者说衰落和信号的关系；一个信道可以同时是"平坦、慢、莱斯"。
  • 说"有直射径就不会中断" ✗：只是比瑞利小；K → ∞ 才接近 AWGN。比较时要说明是同一平均 SNR、同一门限。
英文答题模板 · Exam English

The Rician K-factor is the ratio of the power in the line-of-sight component to the total power in the scattered components, \(K=s^2/(2\sigma^2)\). Here K = 4, i.e. \(K_{\mathrm{dB}}=10\log_{10}4=6.02\) dB. Because of the direct path the envelope is Rician rather than Rayleigh, so deep fades are less likely and, for the same average SNR (20 dB) and threshold (10 dB), the outage probability is lower than the Rayleigh value of 0.0952. K = 0 reduces to Rayleigh fading and K → ∞ to an AWGN channel with no fading.
