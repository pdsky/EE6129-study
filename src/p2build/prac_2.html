P2 · Q1

平均衰落时长

Original question · 中英对照Practice 2

For Rayleigh fading channels, the average fade duration can be expressed as,

对于瑞利衰落信道，平均衰落持续时间（AFD）可以表示为：

\(AFD=\dfrac{e^{\rho^2}-1}{\sqrt{2\pi}f_D\rho}\)

The maximum Doppler shift is 50 Hz. The minimum signal strength, for acceptable performance is 0.1 of the rms value of the signal strength. Determine the average time duration when the signal strength is below the acceptable value.

最大多普勒频移为 50 Hz。保证可接受性能所需的最小信号强度是信号强度 rms 值的 0.1 倍。求信号强度低于这个可接受值的平均持续时间。

AFDρ = Z_min / Z_rms讲义第 2 章 p.42–43
  1. ρ = 0.1，\(e^{\rho^2}-1=e^{0.01}-1=0.01005\)。
  2. 分母：\(\sqrt{2\pi}\times50\times0.1=2.5066\times5=12.53\)。
  3. \(AFD=0.01005/12.53=8.0\times10^{-4}\) s。
AFD ≈ 0.8 ms
官方答案：0.8 ms ✓
顺便算 LCR：\(\sqrt{2\pi}\times50\times0.1\times e^{-0.01}=12.4\) 次/秒。两者相乘 = 0.00995 ≈ 1%，就是信号低于 rms 值 20 dB 的时间比例。
◆ 本题知识点
考什么
瑞利衰落的平均衰落持续时间 AFD（第 2 章 p.42–43）。
前置知识
ρ = Zmin/Zrms 是幅度比；瑞利 P(z < Zmin) = 1 − e−ρ²；多普勒 fD = v fc/c。
解题套路
算 ρ → eρ² − 1 → 分母 √(2π) fD ρ → 相除。
关键公式
AFD = (eρ² − 1)/(√(2π) fD ρ)；LCR = √(2π) fD ρ e−ρ²；AFD × LCR = 1 − e−ρ²（低于门限的时间比例）。
易错
"rms 值的 0.1"是幅度，ρ = 0.1（功率低 20 dB）；若题目说"功率的 0.1"，则 ρ = √0.1 = 0.316。
举一反三
已知车速和载频，先求 fD。一次衰落连错几个符号 = AFD × 符号速率：1 Msps 时 0.8 ms ≈ 800 个符号（讲解页 2.6 节例题）。
直觉
ρ 很小时 AFD ≈ ρ/(√(2π) fD)：门限越低，跌到门限以下的时间越短；车越快（fD 越大），衰落越短但越频繁。

两个基站的宏分集：独立与相关阴影

Original question · 中英对照Practice 2

Consider a mobile station located between two base stations in a cellular network. The received signal powers (in dBm) from the base stations are given by

考虑蜂窝网络中一个位于两个基站之间的移动台。它从两个基站收到的信号功率（dBm）为

\(P_{r,1}=W+Z_1;\quad P_{r,2}=W+Z_2\)

where \(Z_1\) and \(Z_2\) are random variables \(\sim\mathcal N(0,\sigma^2)\). Outage is defined to have occurred when both \(P_{r,1}\) and \(P_{r,2}\) fall below a threshold T, where T is smaller than W by Δ.

其中 \(Z_1\) 和 \(Z_2\) 是随机变量，\(\sim\mathcal N(0,\sigma^2)\)。当 \(P_{r,1}\) 和 \(P_{r,2}\) 都低于门限 T 时，定义为发生中断；T 比 W 小 Δ。

(a) Interpret the terms W, \(Z_1\), \(Z_2\).

(a) 解释 W、\(Z_1\)、\(Z_2\) 这几项的含义。

(b) If \(Z_1\) and \(Z_2\) are statistically independent, show that the outage probability is, \(P_{out}=[Q(\Delta/\sigma)]^2\)

(b) 若 \(Z_1\) 与 \(Z_2\) 统计独立，证明中断概率为 \(P_{out}=[Q(\Delta/\sigma)]^2\)。

(c) Now suppose \(Z_1\) and \(Z_2\) are correlated in the following way: \(Z_1=aY_1+bY\), \(Z_2=aY_2+bY\), where Y, \(Y_1\), \(Y_2\) are independent random variables \(\sim\mathcal N(0,\sigma^2)\). Show that

(c) 现在假设 \(Z_1\) 与 \(Z_2\) 按如下方式相关：\(Z_1=aY_1+bY\)，\(Z_2=aY_2+bY\)，其中 Y、\(Y_1\)、\(Y_2\) 是相互独立的随机变量，\(\sim\mathcal N(0,\sigma^2)\)。证明

\(P_{out}=\displaystyle\int_{-\infty}^{\infty}\frac{1}{\sqrt{2\pi}}Q\!\left[\frac{\Delta+by\sigma}{|a|\sigma}\right]^2e^{-y^2/2}dy\)

宏分集独立 → 概率相乘条件概率 + 全概率讲义第 2 章 p.12–15；第 4 章 p.4
  1. (a) W：只考虑路径损耗时的平均接收功率（两个基站到手机的平均值相同）；\(Z_1,Z_2\)：两条链路各自的阴影衰落分量（dB）。
  2. (b) 中断 = 两条都低于 T = W − Δ，即 \(Z_1<-\Delta\) 且 \(Z_2<-\Delta\)。每个的概率 \(P(Z_i<-\Delta)=Q(\Delta/\sigma)\)（对称性）。独立 → 相乘：\(P_{out}=[Q(\Delta/\sigma)]^2\)。
  3. (c) 两条链路共享 bY，所以相关。技巧：先固定 Y，此时 \(Z_1,Z_2\) 只剩独立的 \(aY_1,aY_2\)。
  4. 为了和答案的形式一致，令 \(Y=\sigma u\)，\(u\sim\mathcal N(0,1)\)。给定 u：\(Z_i\sim\mathcal N(b\sigma u,\ a^2\sigma^2)\)，
    P(Z_i < −Δ | u) = Q( (Δ + bσu) / (|a|σ) )
  5. 给定 u 时两者独立：\(P(\text{中断}\mid u)=Q\big(\tfrac{\Delta+b\sigma u}{|a|\sigma}\big)^2\)。
  6. 再按 u 的标准正态密度 \(\tfrac{1}{\sqrt{2\pi}}e^{-u^2/2}\) 求平均（全概率定理），即得结果。
(b) [Q(Δ/σ)]²；(c) ∫ (1/√(2π)) Q[(Δ + bσu)/(|a|σ)]² e^{−u²/2} du
官方答案：与上面一致 ✓（题目里写成 byσ，积分变量 y 指的是归一化后的 u）
直觉：b = 0 时退化成 (b) 的独立情况；a = 0 时两条链路完全一样，Pout = Q(Δ/σ)，分集完全没用。相关性越强，宏分集效果越差。
◆ 本题知识点
考什么
宏分集的中断概率：独立阴影和相关阴影两种情况；条件概率 + 全概率（第 2 章 p.12–15；第 4 章 p.3–4、p.21）。
前置知识
独立事件概率相乘；独立高斯的线性组合仍是高斯，aY₁ + bY ~ N(0, (a² + b²)σ²)；全概率的连续形式 P(A) = ∫P(A | y)p(y)dy。
解题套路
(b) 每个基站单独中断 P(Zi < −Δ) = Q(Δ/σ)，独立 → 平方。(c) 先固定两条链路共享的 Y（"条件化"），这时两条链路独立 → 条件中断概率相乘 → 再按 Y 的 PDF 积分。
关键一步
令 Y = σu，u ~ N(0, 1)。给定 u：Zi ~ N(bσu, a²σ²)，P(Zi < −Δ | u) = Q((Δ + bσu)/(|a|σ))。
隐含条件
要和"Zi ~ N(0, σ²)"一致，需要 a² + b² = 1。此时 Z₁、Z₂ 的相关系数等于 b²：b 越大，两条链路越像。
自检
b = 0 时退化成 (b) 的 [Q(Δ/σ)]²；a = 0（完全相关）时两条链路一模一样，Pout = Q(Δ/σ)，分集完全没用。
联系
Practice 4 第 1 题用文字解释同一件事；第 4 章 p.21"相关削弱分集"；Practice 4 第 2(c) 题是离散版本的共享阴影。
P2 · Q3

两个用户：干扰当噪声 vs 多用户检测

Original question · 中英对照Practice 2

Two users transmit simultaneously to a single receiver over an AWGN channel. The power received from each transmitter is 10mW. The total received noise power is 0.1mW. The channel bandwidth for each user is 20MHz.

两个用户通过 AWGN 信道同时向同一个接收机发送信号。来自每个发射机的接收功率都是 10 mW，总接收噪声功率为 0.1 mW，每个用户的信道带宽为 20 MHz。

(a) The receiver decodes user 1's signal first. In this decoding, user 2's signal behaves like noise (assume it is AWGN). What is the capacity of user 1's channel?

(a) 接收机先解码用户 1 的信号。解码时，用户 2 的信号相当于噪声（假设它是 AWGN）。用户 1 信道的容量是多少？

(b) After applying MUD, the decoder removes user 1's signal completely from the received signal. What is the capacity of user 2's channel?

(b) 采用多用户检测（MUD）后，解码器把用户 1 的信号从接收信号中完全去掉。用户 2 信道的容量是多少？

香农容量SINRMUD讲义第 1a 章 p.16；第 2 章 p.48
  1. (a) 用户 2 当噪声：SINR = 10 / (10 + 0.1) = 0.990。
    C₁ = 20×10⁶ × log₂(1 + 0.990) = 20×10⁶ × 0.993 = 19.86 Mbps
  2. (b) 用户 1 被完全减掉，只剩噪声：SNR = 10 / 0.1 = 100。
    C₂ = 20×10⁶ × log₂(101) = 20×10⁶ × 6.658 = 133.16 Mbps
(a) 19.86 Mbps；(b) 133.16 Mbps
官方答案：19.86 Mbps；133.16 Mbps ✓
◆ 本题知识点
考什么
香农容量、SINR（把干扰当噪声）、多用户检测 MUD / 连续干扰消除（第 1a 章 p.16；第 2 章 p.48）。
前置知识
C = B log₂(1 + SNR)，SNR 用线性值；log₂x = ln x / ln 2 = log₁₀x / 0.301。
解题套路
(a) SINR₁ = P₁/(P₂ + N)；(b) 用户 1 已被减掉，SNR₂ = P₂/N；分别代入香农公式。
检验
C₁ + C₂ = 19.86 + 133.16 = 153.02 Mbps = 20 log₂(1 + (10 + 10)/0.1)：连续消除的总容量等于两个用户功率合起来的单用户容量，和解码顺序无关。
易错
SINR 0.990 是线性值，不是 dB；log₂1.99 = 0.993；别忘了乘带宽 20 MHz；两个功率的单位要一致（都用 mW）。
举一反三
反过来先解用户 2，两个结果对调，总和不变。如果不用 MUD，两个用户都把对方当噪声，总容量只有 2 × 19.86 = 39.7 Mbps，不到 MUD 的 1/3，这就是多用户检测的价值。
