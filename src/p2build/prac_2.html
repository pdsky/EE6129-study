平均衰落时长

Original question · 中英对照Practice 2

For Rayleigh fading channels, the average fade duration can be expressed as,

对于瑞利衰落信道，平均衰落持续时间（AFD）可以表示为：

\(AFD=\dfrac{e^{\rho^2}-1}{\sqrt{2\pi}f_D\rho}\)

The maximum Doppler shift is 50 Hz. The minimum signal strength, for acceptable performance is 0.1 of the rms value of the signal strength. Determine the average time duration when the signal strength is below the acceptable value.

最大多普勒频移为 50 Hz。保证可接受性能所需的最小信号强度是信号强度 rms 值的 0.1 倍。求信号强度低于这个可接受值的平均持续时间。

AFDρ = Z_min / Z_rms讲义第 2 章 p.42–43
题意讲解：这道题到底要干嘛

场景题目在讲一件什么事

手机在移动时，多径信号时而同相相加、时而反相抵消，接收信号的幅度快速起伏，这就是瑞利衰落（Rayleigh fading）。

信号偶尔会掉进很深的"坑"（深衰落），在坑里的这段时间通信质量很差。题目问：每次掉进坑里，平均要多久才爬出来。这就是平均衰落时长（AFD, average fade duration）。

符号题目里每个量是什么

\(f_D\)最大多普勒频移 50 Hz，表示信道变化有多快：车越快 f_D 越大，坑来得越频繁、也越短
ρ门限和信号 rms 值之比：ρ = Z_min / Z_rms
AFD 公式题目直接给出，代数即可

要求每一问在问什么

  • 唯一一问 "可接受的最低信号强度是 rms 值的 0.1 倍"：求 ρ，代进公式算信号低于门限时平均持续多久。

注意读题容易误会的地方

  • "signal strength" 指幅度，所以 ρ = 0.1 直接代；如果说的是功率的 0.1 倍，ρ 才是 √0.1。
  • 幅度 0.1 倍 = 功率低 20 dB，是很深的坑，所以 AFD 很短。

目的这道题想让你明白什么

AFD 告诉你一次深衰落会吞掉多少个符号，交织和编码要按它来设计。

一句话：瑞利衰落时信号会掉进深坑，题目问"低于 rms 值 0.1 倍"的坑平均持续多久，求出 ρ 代入公式即可。
  1. ρ = 0.1，\(e^{\rho^2}-1=e^{0.01}-1=0.01005\)。
  2. 分母：\(\sqrt{2\pi}\times50\times0.1=2.5066\times5=12.53\)。
  3. \(AFD=0.01005/12.53=8.0\times10^{-4}\) s。
AFD ≈ 0.8 ms
官方答案：0.8 ms ✓
顺便算 LCR：\(\sqrt{2\pi}\times50\times0.1\times e^{-0.01}=12.4\) 次/秒。两者相乘 = 0.00995 ≈ 1%，就是信号低于 rms 值 20 dB 的时间比例。
◆ 本题知识点
考什么
瑞利衰落的平均衰落持续时间 AFD（第 2 章 p.42–43）。
前置知识
ρ = Zmin/Zrms 是幅度比；瑞利 P(z < Zmin) = 1 − e−ρ²；多普勒 fD = v fc/c。
解题套路
算 ρ → eρ² − 1 → 分母 √(2π) fD ρ → 相除。
关键公式
AFD = (eρ² − 1)/(√(2π) fD ρ)；LCR = √(2π) fD ρ e−ρ²；AFD × LCR = 1 − e−ρ²（低于门限的时间比例）。
易错
"rms 值的 0.1"是幅度，ρ = 0.1（功率低 20 dB）；若题目说"功率的 0.1"，则 ρ = √0.1 = 0.316。
举一反三
已知车速和载频，先求 fD。一次衰落连错几个符号 = AFD × 符号速率：1 Msps 时 0.8 ms ≈ 800 个符号（讲解页 2.6 节例题）。
直觉
ρ 很小时 AFD ≈ ρ/(√(2π) fD)：门限越低，跌到门限以下的时间越短；车越快（fD 越大），衰落越短但越频繁。
  1. ρ = 0.1, \(e^{\rho^2}-1=e^{0.01}-1=0.01005\).
  2. Denominator: \(\sqrt{2\pi}\times50\times0.1=2.5066\times5=12.53\).
  3. \(AFD=0.01005/12.53=8.0\times10^{-4}\) s.
AFD ≈ 0.8 ms
Official answer: 0.8 ms ✓
By-product, the level crossing rate: \(\sqrt{2\pi}\times50\times0.1\times e^{-0.01}=12.4\) crossings/s. AFD × LCR = 0.00995 ≈ 1%, the fraction of time the signal is more than 20 dB below its rms value.
◆ Key points
What it tests
Average fade duration (AFD) in Rayleigh fading (Ch 2 p.42–43).
Background
ρ = Zmin/Zrms is an amplitude ratio; Rayleigh P(z < Zmin) = 1 − e−ρ²; Doppler fD = v fc/c.
Method
Find ρ → eρ² − 1 → denominator √(2π) fD ρ → divide.
Key formulas
AFD = (eρ² − 1)/(√(2π) fD ρ); LCR = √(2π) fD ρ e−ρ²; AFD × LCR = 1 − e−ρ² (fraction of time below the threshold).
Common mistakes
"0.1 of the rms value" is an amplitude, so ρ = 0.1 (power 20 dB down). If a question says "0.1 of the power", then ρ = √0.1 = 0.316.
Variations
Given vehicle speed and carrier frequency, compute fD first. Number of symbols lost per fade = AFD × symbol rate: at 1 Msps, 0.8 ms ≈ 800 symbols (Section 2.6 example on the learning page).
Intuition
For small ρ, AFD ≈ ρ/(√(2π) fD): the lower the threshold, the shorter the time spent below it; the faster the vehicle (larger fD), the shorter but more frequent the fades.

两个基站的宏分集：独立与相关阴影

Original question · 中英对照Practice 2

Consider a mobile station located between two base stations in a cellular network. The received signal powers (in dBm) from the base stations are given by

考虑蜂窝网络中一个位于两个基站之间的移动台。它从两个基站收到的信号功率（dBm）为

\(P_{r,1}=W+Z_1;\quad P_{r,2}=W+Z_2\)

where \(Z_1\) and \(Z_2\) are random variables \(\sim\mathcal N(0,\sigma^2)\). Outage is defined to have occurred when both \(P_{r,1}\) and \(P_{r,2}\) fall below a threshold T, where T is smaller than W by Δ.

其中 \(Z_1\) 和 \(Z_2\) 是随机变量，\(\sim\mathcal N(0,\sigma^2)\)。当 \(P_{r,1}\) 和 \(P_{r,2}\) 都低于门限 T 时，定义为发生中断；T 比 W 小 Δ。

(a) Interpret the terms W, \(Z_1\), \(Z_2\).

(a) 解释 W、\(Z_1\)、\(Z_2\) 这几项的含义。

(b) If \(Z_1\) and \(Z_2\) are statistically independent, show that the outage probability is, \(P_{out}=[Q(\Delta/\sigma)]^2\)

(b) 若 \(Z_1\) 与 \(Z_2\) 统计独立，证明中断概率为 \(P_{out}=[Q(\Delta/\sigma)]^2\)。

(c) Now suppose \(Z_1\) and \(Z_2\) are correlated in the following way: \(Z_1=aY_1+bY\), \(Z_2=aY_2+bY\), where Y, \(Y_1\), \(Y_2\) are independent random variables \(\sim\mathcal N(0,\sigma^2)\). Show that

(c) 现在假设 \(Z_1\) 与 \(Z_2\) 按如下方式相关：\(Z_1=aY_1+bY\)，\(Z_2=aY_2+bY\)，其中 Y、\(Y_1\)、\(Y_2\) 是相互独立的随机变量，\(\sim\mathcal N(0,\sigma^2)\)。证明

\(P_{out}=\displaystyle\int_{-\infty}^{\infty}\frac{1}{\sqrt{2\pi}}Q\!\left[\frac{\Delta+by\sigma}{|a|\sigma}\right]^2e^{-y^2/2}dy\)

宏分集独立 → 概率相乘条件概率 + 全概率讲义第 2 章 p.12–15；第 4 章 p.4
题意讲解：这道题到底要干嘛

场景题目在讲一件什么事

手机站在两个基站中间，能同时收到两个基站的信号：基站 1 ))) 📱 ((( 基站 2。这种安排叫宏分集（macro-diversity）："分集"是准备多条路，"宏"是说这两条路来自相隔很远的两个基站。

目的：只要有一个基站的信号够强，通话就不断；两个都不行才真的断线。

举例：W = −90 dBm，门限 T = −100 dBm（所以 Δ = 10 dB）。某一时刻 Z₁ = −12 dB、Z₂ = +3 dB，则 P_r,1 = −102 dBm（基站 1 被楼挡住），P_r,2 = −87 dBm（畅通）。手机改用基站 2，不算中断。

符号题目里每个量是什么

\(P_{r,1},P_{r,2}\)手机从两个基站收到的功率（dBm）
W平均接收功率，只由距离决定（路径损耗）。手机在正中间，两边一样
\(Z_1,Z_2\sim\mathcal N(0,\sigma^2)\)阴影衰落（dB）：被楼、树挡住造成的随机起伏，平均为 0，σ 是起伏大小，典型 6–10 dB
T门限：接收功率低于它就听不清
Δ余量（margin）：T 比 W 小 Δ，即 T = W − Δ

要求每一问在问什么

  • (a) 解释 W、Z₁、Z₂ 的含义，就是上面表里那几句。
  • (b) 假设两边的阴影互不相关（独立）：基站 1 那边挡不挡，和基站 2 那边无关。求两个同时低于门限的概率。
  • (c) 更真实的情况：有些障碍物会同时挡住两条路（手机进了地下室、车里、站到大楼背后）。题目用 \(Z_1=aY_1+bY\)、\(Z_2=aY_2+bY\) 描述：Y 是两条链路共有的阴影（手机周围的墙、车身），Y₁、Y₂ 是各自独有的阴影。b 越大，两条链路越像（相关系数 ρ = b²）；b = 0 就是 (b)，a = 0 就是两条完全一样。要证明这时的中断概率等于题目给的积分式。

注意读题容易误会的地方

  • 中断要求两个都低于门限，不是任意一个。
  • "功率低于门限"和"阴影低于 −Δ"是同一件事：\(P_{r,i}\lt T\iff W+Z_i\lt W-\Delta\iff Z_i\lt-\Delta\)。−Δ 不是门限，而是门限在阴影这个尺度上的对应位置：平均功率本来比门限高 Δ，阴影要把信号压低超过 Δ 才会中断。改写成 Z 的形式，是因为题目只给了 Z 的分布。
  • 所以整道题都在求同一个东西：\(P_{out}=P(Z_1\lt-\Delta\ \text{and}\ Z_2\lt-\Delta)\)，一个 0 到 1 之间的数。

目的这道题想让你明白什么

相关性会削弱宏分集。取 Δ = σ：一个基站中断 15.9%；两个独立基站 2.5%；相关 ρ = 0.5 时 6.3%；完全相关又回到 15.9%，等于没多一个基站。宏分集的好处来自"一个坏了还有另一个"，两个经常一起坏，备用的就帮不上忙。

一句话：手机同时连两个基站，两个都低于门限才算断线。(b) 算两边阴影独立时的断线概率，(c) 算两边有共同阴影时的断线概率，说明相关会让"多一个基站"的好处变小。
  1. (a) W：只考虑路径损耗时的平均接收功率（两个基站到手机的平均值相同）；\(Z_1,Z_2\)：两条链路各自的阴影衰落分量（dB）。
  2. (b) 中断 = 两条都低于 T = W − Δ，即 \(Z_1<-\Delta\) 且 \(Z_2<-\Delta\)。每个的概率 \(P(Z_i<-\Delta)=Q(\Delta/\sigma)\)（对称性）。独立 → 相乘：\(P_{out}=[Q(\Delta/\sigma)]^2\)。
  3. (c) 两条链路共享 bY，所以相关。技巧：先固定 Y，此时 \(Z_1,Z_2\) 只剩独立的 \(aY_1,aY_2\)。
  4. 为了和答案的形式一致，令 \(Y=\sigma u\)，\(u\sim\mathcal N(0,1)\)。给定 u：\(Z_i\sim\mathcal N(b\sigma u,\ a^2\sigma^2)\)，
    P(Z_i < −Δ | u) = Q( (Δ + bσu) / (|a|σ) )
  5. 给定 u 时两者独立：\(P(\text{中断}\mid u)=Q\big(\tfrac{\Delta+b\sigma u}{|a|\sigma}\big)^2\)。
  6. 再按 u 的标准正态密度 \(\tfrac{1}{\sqrt{2\pi}}e^{-u^2/2}\) 求平均（全概率定理），即得结果。
(b) [Q(Δ/σ)]²；(c) ∫ (1/√(2π)) Q[(Δ + bσu)/(|a|σ)]² e^{−u²/2} du
官方答案：与上面一致 ✓（题目里写成 byσ，积分变量 y 指的是归一化后的 u）
直觉：b = 0 时退化成 (b) 的独立情况；a = 0 时两条链路完全一样，Pout = Q(Δ/σ)，分集完全没用。相关性越强，宏分集效果越差。
(c) 逐步详解：先固定 Y → 相乘 → 对 Y 积分 → 换元

第 0 步把"中断"写成 Z 的条件

\(P_{r,i}=W+Z_i\)，门限 \(T=W-\Delta\)，所以

\[P_{r,i}\lt T\iff W+Z_i\lt W-\Delta\iff Z_i\lt-\Delta,\qquad P_{out}=P\big(Z_1\lt-\Delta\ \text{and}\ Z_2\lt-\Delta\big)\]

(b) 和 (c) 的中断条件完全一样，区别只在 Z₁、Z₂ 之间是什么关系。

第 1 步为什么不能像 (b) 那样直接平方

\(Z_1=aY_1+bY\)，\(Z_2=aY_2+bY\)：两条链路含有同一个 \(bY\)。Y 很负时两条链路一起变差，所以 Z₁、Z₂ 不独立，\(P(A\cap B)\neq P(A)P(B)\)，不能直接相乘。

直观理解（课外补充）：\(bY\) 像两条链路共有的阴影，比如手机站在大楼背后、在车里，信号从哪个基站来都要穿过它；\(aY_1\)、\(aY_2\) 是各条路径独有的阴影，互相独立。

相关程度：交叉项因为独立且均值为 0，全部消掉，

\[\operatorname{Cov}(Z_1,Z_2)=E\big[(aY_1+bY)(aY_2+bY)\big]=b^2E[Y^2]=b^2\sigma^2,\qquad \operatorname{Var}(Z_i)=(a^2+b^2)\sigma^2\]

题目说 \(Z_i\sim\mathcal N(0,\sigma^2)\)，隐含 \(a^2+b^2=1\)，相关系数 \(\rho=b^2\)：b 越大，两条链路越像。

第 2 步老师的方法①：先把 Y 当成常数

假设 Y = y 已经确定。\(Z_1=aY_1+by\) 里的 \(by\) 只是常数平移，唯一随机的是 \(aY_1\sim\mathcal N(0,a^2\sigma^2)\)（常数乘高斯，标准差是 \(|a|\sigma\)），所以

\[Z_i\mid y\ \sim\ \mathcal N\big(by,\ a^2\sigma^2\big)\]

关键：给定 y 以后，Z₁ 只和 Y₁ 有关，Z₂ 只和 Y₂ 有关，而 Y₁、Y₂ 独立，所以 Z₁、Z₂ 条件独立。共享的那部分被"冻结"了，相关性就没有了。

第 3 步一条链路的条件中断概率

\[P(Z_1\lt-\Delta\mid y)=P\big(aY_1\lt-(\Delta+by)\big)=P\Big(N\lt-\frac{\Delta+by}{|a|\sigma}\Big)=P\Big(N\gt\frac{\Delta+by}{|a|\sigma}\Big)=Q\Big(\frac{\Delta+by}{|a|\sigma}\Big)\]

N ~ N(0, 1) 是 aY₁ 除以它的标准差 |a|σ 得到的；第三个等号用高斯关于 0 对称；最后一步就是 Q 的定义 Q(x) = P(N > x)。写 |a| 是因为标准差必须为正，a 为负时分布不变。y 越负（共同阴影越深），Δ + by 越小，Q 越大，越容易中断。

第 4 步两条链路相乘

\[P(\text{outage}\mid y)=P(Z_1\lt-\Delta\mid y)\,P(Z_2\lt-\Delta\mid y)=\Big[Q\Big(\frac{\Delta+by}{|a|\sigma}\Big)\Big]^2\]

这一步就是 (b) 的"独立 → 相乘"，只是放在"Y 已知"这个条件下做。

第 5 步老师的方法②：把 Y 变回随机变量，对它的 PDF 积分

全概率定理的连续形式 \(P(A)=\int P(A\mid Y=y)\,f_Y(y)\,dy\)，离散版是 \(\sum_k P(A\mid B_k)P(B_k)\)，意思就是按每种情况出现的概率加权平均。代入 \(f_Y(y)=\frac{1}{\sqrt{2\pi}\,\sigma}e^{-y^2/(2\sigma^2)}\)：

\[P_{out}=\int_{-\infty}^{\infty}\Big[Q\Big(\frac{\Delta+by}{|a|\sigma}\Big)\Big]^2\,\frac{1}{\sqrt{2\pi}\,\sigma}\,e^{-y^2/(2\sigma^2)}\,dy\]

这个式子已经是对的，只是和题目给的形式还不一样。

第 6 步老师的方法③：换元 u = y/σ

\(y=\sigma u\)，\(dy=\sigma\,du\)，上下限仍是 ±∞。PDF 前面的 1/σ 和 dy 里的 σ 抵消；\(e^{-y^2/(2\sigma^2)}=e^{-u^2/2}\)；Q 的参数变成 \((\Delta+b\sigma u)/(|a|\sigma)\)：

\[P_{out}=\int_{-\infty}^{\infty}\frac{1}{\sqrt{2\pi}}\Big[Q\Big(\frac{\Delta+b\sigma u}{|a|\sigma}\Big)\Big]^2e^{-u^2/2}\,du\]

积分变量叫什么都可以（哑变量）。把 u 改名成 y，就是题目里的 \((\Delta+by\sigma)/(|a|\sigma)\)，所以题目里的 y 其实是归一化后的 u，不是原来的 Y。题目写的 \(Q[\cdot]^2\) 指 \([Q(\cdot)]^2\)，不是把 Q 里面的东西平方。

自检两个极端

  • b = 0（没有共同阴影，a = 1）：Q 里不含 u，可以提到积分外面，剩下 \(\int\frac{1}{\sqrt{2\pi}}e^{-u^2/2}du=1\)，结果是 \([Q(\Delta/\sigma)]^2\)，回到 (b) ✓
  • a → 0（完全共享，b = 1）：Q 的参数趋向 ±∞。u > −Δ/σ 时 Q → 0，u < −Δ/σ 时 Q → 1，所以 \(P_{out}=P(u\lt-\Delta/\sigma)=Q(\Delta/\sigma)\)，和只有一个基站时一样，分集完全没用 ✓

考试英文写法（照这个结构写）

Outage ⇔ \(Z_1\lt-\Delta\) and \(Z_2\lt-\Delta\). \(Z_1\) and \(Z_2\) share the term \(bY\), so they are correlated; condition on \(Y=y\).

Given y, \(Z_i=aY_i+by\sim\mathcal N(by,\,a^2\sigma^2)\), and \(Z_1,Z_2\) are independent since \(Y_1,Y_2\) are independent.

\(P(Z_i\lt-\Delta\mid y)=P\big(aY_i\lt-(\Delta+by)\big)=Q\big(\tfrac{\Delta+by}{|a|\sigma}\big)\), so \(P(\text{out}\mid y)=Q^2\big(\tfrac{\Delta+by}{|a|\sigma}\big)\).

By the total probability theorem, \(P_{out}=\int P(\text{out}\mid y)f_Y(y)\,dy=\int Q^2\big(\tfrac{\Delta+by}{|a|\sigma}\big)\tfrac{1}{\sqrt{2\pi}\,\sigma}e^{-y^2/2\sigma^2}dy\).

Let \(u=y/\sigma\) (\(dy=\sigma\,du\)): \(P_{out}=\int\tfrac{1}{\sqrt{2\pi}}Q^2\big(\tfrac{\Delta+b\sigma u}{|a|\sigma}\big)e^{-u^2/2}du\), which is the required result.

一句话记住：先固定共享变量 → 条件独立，相乘 → 按它的 PDF 积分 → 换元 u = y/σ。Practice 4 第 2(c) 题是同一套路的离散版。

Sanity check: b = 0 reduces to the independent case (b); a = 0 makes the two links identical, Pout = Q(Δ/σ), and diversity is useless. The stronger the correlation, the weaker the macro-diversity gain.
(c) Step by step: fix Y → multiply → integrate over Y → substitute

Step 0Write outage as a condition on Z

\(P_{r,i}=W+Z_i\) and the threshold is \(T=W-\Delta\), so

\[P_{r,i}\lt T\iff W+Z_i\lt W-\Delta\iff Z_i\lt-\Delta,\qquad P_{out}=P\big(Z_1\lt-\Delta\ \text{and}\ Z_2\lt-\Delta\big)\]

The outage condition is the same in (b) and (c); only the relation between Z₁ and Z₂ changes.

Step 1Why we cannot just square, as in (b)

\(Z_1=aY_1+bY\), \(Z_2=aY_2+bY\): both links contain the same \(bY\). When Y is very negative, both links get worse together, so Z₁ and Z₂ are not independent: \(P(A\cap B)\neq P(A)P(B)\), and we cannot simply multiply.

Intuition (not in the slides): \(bY\) is shadowing common to both links, e.g. the phone is behind a building or inside a car, so the signal from either base station must pass through it; \(aY_1\), \(aY_2\) are the shadowing specific to each path, independent of each other.

How strong the correlation is: the cross terms vanish because the variables are independent with zero mean,

\[\operatorname{Cov}(Z_1,Z_2)=E\big[(aY_1+bY)(aY_2+bY)\big]=b^2E[Y^2]=b^2\sigma^2,\qquad \operatorname{Var}(Z_i)=(a^2+b^2)\sigma^2\]

The question says \(Z_i\sim\mathcal N(0,\sigma^2)\), which implies \(a^2+b^2=1\); the correlation coefficient is \(\rho=b^2\). The larger b, the more alike the two links.

Step 2Lecturer's method ①: treat Y as a constant

Suppose Y = y is known. In \(Z_1=aY_1+by\) the term \(by\) is just a constant shift; the only random part is \(aY_1\sim\mathcal N(0,a^2\sigma^2)\) (a constant times a Gaussian, standard deviation \(|a|\sigma\)), so

\[Z_i\mid y\ \sim\ \mathcal N\big(by,\ a^2\sigma^2\big)\]

Key point: given y, Z₁ depends only on Y₁ and Z₂ only on Y₂, and Y₁, Y₂ are independent, so Z₁ and Z₂ are conditionally independent. The shared part is "frozen" and the correlation disappears.

Step 3Conditional outage of one link

\[P(Z_1\lt-\Delta\mid y)=P\big(aY_1\lt-(\Delta+by)\big)=P\Big(N\lt-\frac{\Delta+by}{|a|\sigma}\Big)=P\Big(N\gt\frac{\Delta+by}{|a|\sigma}\Big)=Q\Big(\frac{\Delta+by}{|a|\sigma}\Big)\]

N ~ N(0, 1) is aY₁ divided by its standard deviation |a|σ; the third equality uses the symmetry of the Gaussian about 0; the last step is the definition Q(x) = P(N > x). We write |a| because a standard deviation must be positive; a negative a leaves the distribution unchanged. The more negative y (deeper common shadow), the smaller Δ + by and the larger Q: outage becomes more likely.

Step 4Multiply the two links

\[P(\text{outage}\mid y)=P(Z_1\lt-\Delta\mid y)\,P(Z_2\lt-\Delta\mid y)=\Big[Q\Big(\frac{\Delta+by}{|a|\sigma}\Big)\Big]^2\]

This is the "independent → multiply" of part (b), done under the condition that Y is known.

Step 5Lecturer's method ②: make Y random again and integrate over its PDF

Total probability theorem, continuous form: \(P(A)=\int P(A\mid Y=y)\,f_Y(y)\,dy\) (discrete form \(\sum_k P(A\mid B_k)P(B_k)\)): a weighted average over every case, weighted by how likely it is. With \(f_Y(y)=\frac{1}{\sqrt{2\pi}\,\sigma}e^{-y^2/(2\sigma^2)}\):

\[P_{out}=\int_{-\infty}^{\infty}\Big[Q\Big(\frac{\Delta+by}{|a|\sigma}\Big)\Big]^2\,\frac{1}{\sqrt{2\pi}\,\sigma}\,e^{-y^2/(2\sigma^2)}\,dy\]

This is already correct; it just does not look like the required form yet.

Step 6Lecturer's method ③: substitute u = y/σ

\(y=\sigma u\), \(dy=\sigma\,du\), limits still ±∞. The 1/σ in front of the PDF cancels the σ in dy; \(e^{-y^2/(2\sigma^2)}=e^{-u^2/2}\); the argument of Q becomes \((\Delta+b\sigma u)/(|a|\sigma)\):

\[P_{out}=\int_{-\infty}^{\infty}\frac{1}{\sqrt{2\pi}}\Big[Q\Big(\frac{\Delta+b\sigma u}{|a|\sigma}\Big)\Big]^2e^{-u^2/2}\,du\]

The integration variable is a dummy variable. Renaming u to y gives the question's \((\Delta+by\sigma)/(|a|\sigma)\), so the y in the question is the normalised u, not the original Y. The question's \(Q[\cdot]^2\) means \([Q(\cdot)]^2\), not Q of a squared argument.

CheckTwo extreme cases

  • b = 0 (no common shadowing, a = 1): Q no longer depends on u and comes out of the integral, leaving \(\int\frac{1}{\sqrt{2\pi}}e^{-u^2/2}du=1\). The result is \([Q(\Delta/\sigma)]^2\), part (b) ✓
  • a → 0 (fully shared, b = 1): the argument of Q goes to ±∞. For u > −Δ/σ, Q → 0; for u < −Δ/σ, Q → 1. So \(P_{out}=P(u\lt-\Delta/\sigma)=Q(\Delta/\sigma)\), the same as a single base station: no diversity at all ✓

ExamCompact answer (write it in this order)

Outage ⇔ \(Z_1\lt-\Delta\) and \(Z_2\lt-\Delta\). \(Z_1\) and \(Z_2\) share the term \(bY\), so they are correlated; condition on \(Y=y\).

Given y, \(Z_i=aY_i+by\sim\mathcal N(by,\,a^2\sigma^2)\), and \(Z_1,Z_2\) are independent since \(Y_1,Y_2\) are independent.

\(P(Z_i\lt-\Delta\mid y)=P\big(aY_i\lt-(\Delta+by)\big)=Q\big(\tfrac{\Delta+by}{|a|\sigma}\big)\), so \(P(\text{out}\mid y)=Q^2\big(\tfrac{\Delta+by}{|a|\sigma}\big)\).

By the total probability theorem, \(P_{out}=\int P(\text{out}\mid y)f_Y(y)\,dy=\int Q^2\big(\tfrac{\Delta+by}{|a|\sigma}\big)\tfrac{1}{\sqrt{2\pi}\,\sigma}e^{-y^2/2\sigma^2}dy\).

Let \(u=y/\sigma\) (\(dy=\sigma\,du\)): \(P_{out}=\int\tfrac{1}{\sqrt{2\pi}}Q^2\big(\tfrac{\Delta+b\sigma u}{|a|\sigma}\big)e^{-u^2/2}du\), which is the required result.

In one line: fix the shared variable → conditionally independent, multiply → integrate over its PDF → substitute u = y/σ. Practice 4 Q2(c) is the discrete version of the same method.

两个用户：干扰当噪声 vs 多用户检测

Original question · 中英对照Practice 2

Two users transmit simultaneously to a single receiver over an AWGN channel. The power received from each transmitter is 10mW. The total received noise power is 0.1mW. The channel bandwidth for each user is 20MHz.

两个用户通过 AWGN 信道同时向同一个接收机发送信号。来自每个发射机的接收功率都是 10 mW，总接收噪声功率为 0.1 mW，每个用户的信道带宽为 20 MHz。

(a) The receiver decodes user 1's signal first. In this decoding, user 2's signal behaves like noise (assume it is AWGN). What is the capacity of user 1's channel?

(a) 接收机先解码用户 1 的信号。解码时，用户 2 的信号相当于噪声（假设它是 AWGN）。用户 1 信道的容量是多少？

(b) After applying MUD, the decoder removes user 1's signal completely from the received signal. What is the capacity of user 2's channel?

(b) 采用多用户检测（MUD）后，解码器把用户 1 的信号从接收信号中完全去掉。用户 2 信道的容量是多少？

香农容量SINRMUD讲义第 1a 章 p.16；第 2 章 p.48
题意讲解：这道题到底要干嘛

场景题目在讲一件什么事

两个用户在同一时间、同一频段，向同一个接收机（比如基站）发信号。接收机收到的是"用户 1 的信号 + 用户 2 的信号 + 噪声"混在一起。

信道是 AWGN 信道（Additive White Gaussian Noise，加性高斯白噪声）：噪声直接加在信号上（加性），所有频率上功率一样、不同时刻互不相关（白），幅度服从均值 0 的高斯分布；除了这种噪声没有别的损伤（没有衰落、没有多径）。香农公式 C = B log₂(1 + SNR) 就是在这种信道下成立的。

符号题目里每个量是什么

10 mW接收机收到的每个用户的功率
0.1 mW总噪声功率
20 MHz每个用户的带宽
SINR信号 /（干扰 + 噪声）：把别的用户也当成噪声时的信噪比
MUD多用户检测（multi-user detection）：先解出一个用户，把它从接收信号里减掉，再解下一个（连续干扰消除 SIC）

要求每一问在问什么

  • (a) 先解用户 1。这时用户 2 的信号还在，只能把它当噪声。用户 1 的容量是多少？关键是 SINR = P₁ /(P₂ + N)。
  • (b) 用户 1 解出来并完全减掉以后，再解用户 2，它只剩噪声。用户 2 的容量是多少？SNR = P₂ / N。

注意读题容易误会的地方

  • 香农公式里的 SNR 用线性值，不是 dB。
  • 两个功率单位要一致（都用 mW）。

目的这道题想让你明白什么

把干扰当噪声代价很大（同样 10 mW，容量差了好几倍）；先解一个再减掉，后解的那个用户就像独占信道一样。

一句话：两个用户同时发，(a) 先解用户 1、把用户 2 当噪声，(b) 减掉用户 1 后再解用户 2，分别用香农公式求容量。
  1. (a) 用户 2 当噪声：SINR = 10 / (10 + 0.1) = 0.990。
    C₁ = 20×10⁶ × log₂(1 + 0.990) = 20×10⁶ × 0.993 = 19.86 Mbps
  2. (b) 用户 1 被完全减掉，只剩噪声：SNR = 10 / 0.1 = 100。
    C₂ = 20×10⁶ × log₂(101) = 20×10⁶ × 6.658 = 133.16 Mbps
(a) 19.86 Mbps；(b) 133.16 Mbps
官方答案：19.86 Mbps；133.16 Mbps ✓
◆ 本题知识点
考什么
香农容量、SINR（把干扰当噪声）、多用户检测 MUD / 连续干扰消除（第 1a 章 p.16；第 2 章 p.48）。
前置知识
C = B log₂(1 + SNR)，SNR 用线性值；log₂x = ln x / ln 2 = log₁₀x / 0.301。
解题套路
(a) SINR₁ = P₁/(P₂ + N)；(b) 用户 1 已被减掉，SNR₂ = P₂/N；分别代入香农公式。
检验
C₁ + C₂ = 19.86 + 133.16 = 153.02 Mbps = 20 log₂(1 + (10 + 10)/0.1)：连续消除的总容量等于两个用户功率合起来的单用户容量，和解码顺序无关。
易错
SINR 0.990 是线性值，不是 dB；log₂1.99 = 0.993；别忘了乘带宽 20 MHz；两个功率的单位要一致（都用 mW）。
举一反三
反过来先解用户 2，两个结果对调，总和不变。如果不用 MUD，两个用户都把对方当噪声，总容量只有 2 × 19.86 = 39.7 Mbps，不到 MUD 的 1/3，这就是多用户检测的价值。

    C₁ = 20×10⁶ × log₂(1 + 0.990) = 20×10⁶ × 0.993 = 19.86 Mbps
  2. (b) User 1 completely removed, only noise remains: SNR = 10 / 0.1 = 100.
    C₂ = 20×10⁶ × log₂(101) = 20×10⁶ × 6.658 = 133.16 Mbps
(a) 19.86 Mbps; (b) 133.16 Mbps

◆ Key points
What it tests
Shannon capacity, SINR (interference treated as noise) and multi-user detection / successive interference cancellation (Ch 1a p.16; Ch 2 p.48).
Background
C = B log₂(1 + SNR) with SNR as a linear value; log₂x = ln x / ln 2 = log₁₀x / 0.301.
Method
(a) SINR₁ = P₁/(P₂ + N); (b) user 1 already subtracted, SNR₂ = P₂/N; substitute each into Shannon's formula.
Check
C₁ + C₂ = 19.86 + 133.16 = 153.02 Mbps = 20 log₂(1 + (10 + 10)/0.1): the sum capacity with successive cancellation equals the single-user capacity with the two powers combined, independent of the decoding order.
Common mistakes
SINR 0.990 is linear, not dB; log₂1.99 = 0.993; remember to multiply by the 20 MHz bandwidth; use the same unit (mW) for both powers.
Variations
Decoding user 2 first swaps the two results; the sum stays the same. Without MUD, each user treats the other as noise and the total is only 2 × 19.86 = 39.7 Mbps, less than a third of the MUD total. That is the value of multi-user detection.
