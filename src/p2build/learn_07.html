第七章

OFDM：把一条坑洼的宽路，改成很多条平整的窄路

单载波系统速率越高，符号越短，ISI 拖的符号越多，时域均衡器越复杂（p.3）。OFDM 换个思路：不把一条高速数据流塞进一个宽带信道，而是拆成 N 条低速子流，每条用一个窄带子载波发（p.2、p.4）。

类比

一辆卡车在坑洼的宽马路上飞驰，颠得厉害（频率选择性衰落、ISI）；把货分给 N 辆小推车，每辆走一条很窄、很平整的小道，每辆都慢慢走，但加起来运量一样。每条小道窄到"路面平整"（平坦衰落），每辆车慢到"颠簸的回声来不及影响下一趟"（无 ISI）。

7.1两条设计原则★★★ 必考

OFDM 设计（p.5）
\(\dfrac1T\lt B_C\)（每个子载波上平坦衰落）　　\(T_G>T_D\)（保护间隔长于最大时延扩展）
T 是 OFDM 符号时长，1/T 约等于子载波宽度，要小于相干带宽，每个子信道才是平坦的。再在每个 OFDM 符号前加一段保护间隔 \(T_G\)，长度超过最大时延扩展 \(T_D\)，上一个符号的回声就全落在保护间隔里，不影响下一个符号。
子载波数与速率（p.8）
\(\Delta f=\dfrac BN\)　　\(T=NT_S\)　　每个子载波的符号速率 \(R=\dfrac1T=\dfrac{R_S}{N}\)
总带宽 B 分成 N 份，每份 Δf。原来单载波的符号时长是 \(T_S\)，现在每个子载波上的符号拉长 N 倍。N 越大，子信道越窄越平坦、符号越长，越不怕 ISI。
例题N 该怎么选（Practice 7 第 1(a) 题）

已知条件：总带宽 B，多普勒扩展 \(B_d\)，相干带宽 \(B_C\)；要求每个子信道都是慢平坦衰落。

1
平坦：子信道宽度远小于相干带宽：\(B/N\ll B_C\) → \(N\gg B/B_C\)。
2
慢衰落：子载波符号时长 \(N/B\) 远小于相干时长 \(1/B_d\) → \(N\ll B/B_d\)。
B/B_C ≪ N ≪ B/B_d：N 太小，子信道不平坦；N 太大，符号太长，一个符号内信道就变了
◆ 本题知识点
考什么
子载波数的选取原则（p.5、p.8、p.14，Practice 7 第 1(a) 题）。
用到的知识
平坦衰落：子载波带宽 < 相干带宽；慢衰落：符号时长 < 相干时间 ≈ 1/Bd。
关键一步
Δf = B/N 和 T = N/B 都由 N 决定：N 大 → 子信道更平坦，但符号更长，信道在一个符号内来不及保持不变。所以 N 有上下两个界。
期末计算
N > B/BC，往上取整：B = 500 kHz、BC = 30 kHz → N = 17（2025-26 S1）。
易错
平坦比较的是"子载波带宽 vs 相干带宽"，慢衰落比较的是"符号时长 vs 相干时间"，别交叉。
★ 考试重点 · 子载波数和速率（期末每年都有一问）
  • 平坦条件：每个子载波带宽 B/N 要小于相干带宽：N > B/BC，取整往上（2025-26 S1：500/30 = 16.7 → 17；2023-24：子载波带宽取 BC/2 → N = 1 MHz / 250 kHz = 4）。
  • 时间关系：原始符号时长 Ts = 1/B；一个 OFDM 块 T = N Ts（N 个符号并行，每个拉长 N 倍）。
  • 速率：每个 OFDM 块传 N log₂M 比特。不加保护间隔速率 = N log₂M / T；加了 TG 后有效速率 = N log₂M / (T + TG)（2025-26 S1：100 bit / 110 µs ≈ 909 kbit/s）。每个子载波的速率 = 总速率 / N（2024-25：10 Mbit/s → 每个 2.5 Mbit/s）。

7.2子载波为什么能挤在一起而不干扰：正交★★★ 必考

子载波正交（p.7）与 OFDM 信号（p.9）
\(\dfrac1T\displaystyle\int_0^Te^{j2\pi(f_j-f_k)t}dt=\begin{cases}1&j=k\\0&j\ne k\end{cases}\)　　\(x(t)=\dfrac{1}{\sqrt T}\sum_{k=0}^{N-1}s_ke^{j2\pi kt/T}\)
子载波间隔正好是 1/T，任意两个子载波在一个符号周期内都相差整数个周期，相乘积分为 0。所以虽然各子载波的频谱（sinc 形状）互相重叠，在每个子载波的中心频率处，其他子载波正好过零（p.10–11）。接收端在 \(f=k/T\) 处采样频谱，就能把 \(s_k\) 单独取出来。
推导子载波为什么正交、频谱为什么是 sinc（p.7、p.9–11）
1
\(\dfrac1T\int_0^Te^{j2\pi(j-k)t/T}dt\)。j = k 时被积函数恒为 1，结果 1。
2
j ≠ k 时记 m = j − k（非零整数）：
(1/T) · [ e^(j2πmt/T) / (j2πm/T) ]₀^T = (e^(j2πm) − 1) / (j2πm) = 0
因为 \(e^{j2\pi m}=1\)。物理意义：两个子载波的差频在 T 秒内正好转整数圈，正负面积抵消。子载波间隔必须正好是 1/T 的整数倍。
3
频谱：每个子载波只持续 T 秒，相当于乘了一个宽 T 的矩形窗。矩形窗的傅里叶变换是 sinc，所以第 k 个子载波的频谱幅度 ∝ \(\mathrm{sinc}(fT-k)\)，主瓣中心在 f = k/T（p.9）。
4
\(\mathrm{sinc}(x)=\dfrac{\sin\pi x}{\pi x}\) 在所有非零整数 x 处为 0。在 f = k/T 处，其他子载波的值 \(\mathrm{sinc}(k-m)=0\)，只剩 \(s_k\)：频谱重叠但在采样点上互不干扰（p.10 的图）。
5
N 个子载波的主瓣铺满约 N/T 的宽度，N 很大时总带宽 \(B\approx N/T=1/T_s\)（p.11）。
间隔 1/T → 差频整数圈 → 积分为 0；频域里每个 sinc 的峰正好落在其他 sinc 的零点上

频谱互相重叠，所以 OFDM 比传统频分复用（各子载波之间要留保护带）省带宽（p.27）。功率谱 \(\sum_n\mathrm{sinc}^2(fT-n)\)，N 很大时总带宽趋于 N/T（p.11）。

实现：发射端的"N 个子载波相加"在离散时间就是 IDFT，接收端的"N 个相关器"就是 DFT（p.19–20），都用 FFT 快速计算。

推导发端是 IDFT、收端是 DFT（p.19–20）
1
一个块内 \(x(t)=\frac{1}{\sqrt T}\sum_ks_ke^{j2\pi kt/T}\)。每 \(T_s=T/N\) 采样一次，\(t=iT/N\)：\(x_i=\frac{1}{\sqrt T}\sum_{k=0}^{N-1}s_ke^{j2\pi ki/N}\)，i = 0 … N − 1。和 N 点 IDFT \(x_i=\frac1N\sum_ks_ke^{j2\pi ki/N}\) 只差一个常数（讲义 p.19 写的是 1/N 版本）。
2
收端对 N 个采样做 DFT：
Σi xi e^(−j2πik/N) = (1/N) Σm sm Σi e^(j2π(m−k)i/N)
3
里面的和是等比数列，公比 \(q=e^{j2\pi(m-k)/N}\)。m = k 时 q = 1，和为 N；m ≠ k 时 \(\sum_{i=0}^{N-1}q^i=\dfrac{1-q^N}{1-q}=\dfrac{1-e^{j2\pi(m-k)}}{1-q}=0\)。所以结果正好是 \(s_k\)：这是上面积分正交的离散版本。
4
p.20 的相关器 \(\frac1T\int_0^Tx(t)e^{-j2\pi kt/T}dt\) 用 N 个采样求和近似，就是 DFT。N 个相关器 = 一次 FFT，运算量 N log N，而不是 N² 次乘法。
x = IDFT{s}，s = DFT{x}；离散正交 Σi ej2π(m−k)i/N = Nδ[m − k]
★ 两个证明题的答题要点
  • 相关器输出 = sn（2025-26 S1 Q2(b)(iii)）：乘 (1/√T)e−j2πnt/T 在 [0, T] 积分，得 (1/T)Σk sk∫ej2π(k−n)t/Tdt。k = n 时被积函数为 1，积分 = T；k ≠ n 时是整数个周期的复指数，积分 = 0。所以只剩 sn。
  • 为什么是 IDFT（2025-26 S2 Q2(b)(ii)）：在一个块内按 t = iT/N 采样，xi = (1/√T)Σ skej2πki/N，和 N 点 IDFT 的式子只差一个常数。频域的 N 个符号变成时域的 N 个采样，发端用 IFFT、收端用 FFT。

7.3多径信道下：子信道增益 H_k★★★ 必考

子信道增益（p.15）
\(H_k=\displaystyle\sum_{i=0}^{L-1}h_i\,e^{-j2\pi ik/N}\)
\(h_i\) 是信道冲激响应的第 i 个抽头。\(H_k\) 就是冲激响应的 DFT 在第 k 个子载波上的值。不同子载波的增益不同，这就是"频率选择性"；但每个子载波内部增益是一个常数，所以是平坦的。
例题4 个子载波的信道增益（Practice 7 第 1(b) 题）

已知条件：\(y(t)=h_0x(t)+h_1x(t-\tau)+w(t)\)，\(h_0=0.8\)，\(h_1=0.6\)，N = 4，延迟正好一个采样。

1
\(H_k=0.8+0.6e^{-j2\pi k/4}=0.8+0.6e^{-j\pi k/2}\)。
2
逐个代入：\(e^{-j\pi k/2}\) 依次是 1、−j、−1、j：
H₀ = 0.8 + 0.6 = 1.4；H₁ = 0.8 − 0.6j；H₂ = 0.8 − 0.6 = 0.2；H₃ = 0.8 + 0.6j；H₄ = H₀ = 1.4
|H|²：H₁、H₃ 为 1，H₂ 只有 0.04（深衰落），H₄ 为 1.96

直观看：子载波 2 上，直射和延迟两路正好反相相减，只剩 0.2；子载波 0（= 4）上同相相加，有 1.4。

◆ 本题知识点
考什么
子信道增益 Hk = Σhie−j2πik/N（p.15），期末每年 Q2(b)。
用到的知识
欧拉公式：e−jπ/2 = −j，e−jπ = −1，e−j3π/2 = j；|a + jb|² = a² + b²。
关键一步
每个 k 只是把第二个抽头转 k × 90°，再和第一个抽头相加。
自检
HN = H₀ = 所有抽头之和；实系数时 H₁ 和 H₃ 共轭；Σ|Hk|² = N Σhi²：1 + 0.04 + 1 + 1.96 = 4 = 4 × (0.64 + 0.36)。
为什么是 DFT
加了循环前缀后，线性卷积变成循环卷积，DFT 后变成乘法（7.4 节的推导框）。
★ 考试重点 · 手算 Hk（N = 4 的速算表）

Hk = Σi hi e−j2πik/N，k = 1…N，HN = H0。N = 4 时 e−j2πk/4 依次是：

k1234（= 0）
e−j2πk/4（乘 h₁）−j−1j1
e−j2π·2k/4（乘 h₂）−11−11

例：h = {1, 0.3}（2025-26 S2）→ H₁ = 1 − 0.3j，H₂ = 0.7，H₃ = 1 + 0.3j，H₄ = 1.3。h = {1, −0.6, 0.2}（2023-24）→ 0.8 + 0.6j、1.8、0.8 − 0.6j、0.6。自检：H₄ = 所有抽头之和；H₁ 和 H₃ 互为共轭（抽头是实数时）。

7.4保护间隔与循环前缀★★★ 必考

多径会带来两种干扰（p.16）：上一个 OFDM 符号的回声（时延扩展），和子载波之间失去正交（子载波间干扰 ICI）。

  • 保护间隔（p.17–18）：每个 OFDM 块前面延长 \(T_G\ge T_D\)，接收端把这段丢掉，只看后面的 N 个采样，上一块的回声就进不来。代价是多花了时间和功率，功率损失 \(=10\log_{10}\dfrac{NT_S+T_G}{NT_S}\) dB。
  • 循环前缀 CP（p.21–22）：保护间隔里放的不是空白，而是把这个块最后 G 个采样复制到最前面。这样信道的线性卷积在接收窗口里等价于循环卷积，DFT 以后正好变成相乘：\(r_k=H_ks_k+w_k\)。子载波之间保持正交，没有 ICI。
推导为什么加了循环前缀以后 rk = Hksk + wk（p.15–22）
1
采样后的多径信道是离散卷积：\(r_i=\sum_{l=0}^{L-1}h_lx_{i-l}+w_i\)，L 个抽头，最长的回波晚 L − 1 个采样。
2
没有 CP：块内前几个采样（i < L − 1）里，\(x_{i-l}\) 的下标是负的，取到的是上一个块的数据 → 块间干扰（p.16 的 Delay Spread 项）；接收窗口里看到的也不是完整的周期信号，子载波失去正交 → ICI。
3
有 CP：发送 \(x_{-G},\dots,x_{-1},x_0,\dots,x_{N-1}\)，其中 \(x_{-m}=x_{N-m}\)（块尾复制到块头，p.21）。只要 G ≥ L − 1，接收端保留的 i = 0 … N − 1 用到的 \(x_{i-l}\) 下标都 ≥ −G，全在本块里，而且 \(x_{i-l}=x_{(i-l)\bmod N}\)：
ri = Σl hl x(i−l) mod N + wi　← 循环卷积
4
代入 \(x_n=\frac1N\sum_ks_ke^{j2\pi kn/N}\)。\(e^{j2\pi kn/N}\) 以 N 为周期，mod N 不影响它：
ri = (1/N) Σk sk e^(j2πki/N) · Σl hl e^(−j2πkl/N) + wi = (1/N) Σk (Hksk) e^(j2πki/N) + wi
中间那个求和正是 \(H_k=\sum_lh_le^{-j2\pi lk/N}\)（p.15）。
5
上式说明 \(\{r_i\}\) 是 \(\{H_ks_k\}\) 的 IDFT。收端做 DFT：\(R_k=H_ks_k+W_k\)（p.22）。每个子载波只乘一个复数，频域均衡就是除以 \(H_k\)（p.25）。
6
代价：每块多发 G 个采样，效率 N/(N + G)，功率损失 \(10\log_{10}\frac{N+G}{N}=10\log_{10}\frac{NT_s+T_G}{NT_s}\) dB（p.18）。
CP ≥ L − 1 → 线性卷积变循环卷积 → DFT 后变乘法：rk = Hksk + wk（用 h = {0.8, 0.6}、N = 4、G = 1 数值验证过）
例题最短需要多长的循环前缀（Practice 7 第 3 题）

已知条件：信道 \(H(z)=1+0.9z^{-1}\)。

1
冲激响应只有两个抽头：当前采样，加上晚一个采样的回声（系数 0.9）。最大时延扩展 = 1 个采样。
2
CP 长度要 ≥ 信道长度 − 1 = 2 − 1 = 1，才能把上一个块的回声挡住。
最短 CP = 1 个采样（符号）长度
◆ 本题知识点
考什么
循环前缀的长度要求（p.17–22，Practice 7 第 3 题）。
用到的知识
Z⁻¹ = 延迟一个采样；L 个抽头的信道，最长延迟 L − 1 个采样。
关键一步
CP ≥ L − 1 = 1 个采样：接收窗口里的 N 个采样都只含本块的数据，线性卷积变成循环卷积。
换成时间
连续时间里就是 TG ≥ 最大时延扩展 TD（p.5、p.17）。
易错
是 L − 1 个（1 个），不是 L 个（2 个）；CP 太长浪费时间和功率，损失 10 log((N + G)/N) dB。
例题设计一个 OFDM 系统（Practice 7 第 2 题）

已知条件：速率 2 Mbps，16-QAM，可用带宽 600 kHz，最大时延扩展 20 µs，CP 等于最大时延扩展。求子载波数和 OFDM 符号时长。

1
16-QAM 每符号 4 bit，需要的总符号速率：2 Mbps ÷ 4 = 500 k 符号/秒。
2
N 个子载波，每个宽 600k/N Hz，有用符号时长 \(T=N/600\text{k}\)；加上 CP，一个 OFDM 符号总长 \(T+20\) µs，期间发出 N 个符号：
N / (N/600k + 20 µs) = 500k
3
解方程：N = 500k × (N/600k + 2×10⁻⁵) = 0.8333N + 10 → 0.1667N = 10 → N = 60。
4
有用部分 T = 60/600k = 100 µs，加 CP 20 µs，总长 120 µs。
N = 60 个子载波，OFDM 符号时长 0.12 ms（其中 0.1 ms 有用 + 0.02 ms CP）

检验：每秒 1/120 µs = 8333 个 OFDM 符号 × 60 个子载波 × 4 bit = 2 Mbps ✓。CP 占 1/6 的时间，功率损失 10 log(120/100) = 0.79 dB。

◆ 本题知识点
考什么
OFDM 参数设计：子载波数、符号时长、CP 开销（Practice 7 第 2 题；期末每年一问）。
用到的知识
有用符号时长 T = N/B = 1/Δf；块时长 T + TG；速率 = N log₂M / (T + TG)。
关键一步
列方程 4N / (N/600k + 20 µs) = 2 M，解出 N = 60。
检验
60 × 4 bit / 120 µs = 2 Mbps；CP 功率损失 10 log(120/100) = 0.79 dB。
易错
题目给的是比特速率，要除以 log₂M = 4 得符号速率；CP 不传数据但占时间。
★ 考试重点 · 循环前缀
  • 表达式（2024-25 Q2(b)(ii)）：式子不变，只把时间范围往前延长 TG：x(t) = (1/√T)Σ skej2πkt/T，nT − TG ≤ t < (n+1)T。ej2πkt/T 以 T 为周期，所以前面多出来的一段正好是块尾的复制。
  • 功率损失：10 log₁₀[(NTs + TG)/(NTs)] dB（2023-24：4 µs + 1 µs → 0.97 dB；2025-26 S2：8 µs + 20 µs → 5.44 dB）。
  • 长度：TG ≥ 最大时延扩展；离散时 CP ≥ 信道长度 − 1 个采样（Practice 7 第 3 题）。

7.5OFDM 的容量和均衡★★ 常考

OFDM 容量（p.24）
\(C(\mathbf P)=\displaystyle\sum_{k=1}^{N}\log_2\!\left(1+\frac{|H_k|^2P_k}{N_k}\right)\)
N 个独立的平行高斯信道，最优功率分配还是第 2 章的注水法。
例题等容量分配 vs 注水（Practice 7 第 1(c)(d) 题）

已知条件：沿用上面的 \(|H_k|^2=\{1,\ 0.04,\ 1,\ 1.96\}\)，噪声 1，总功率 10。

1
(c) 要每个子信道容量相等，就要 \(|H_k|^2P_k\) 都相等，记为 c：\(P_k=c/|H_k|^2\)。
c(1 + 25 + 1 + 0.510) = 10 → c = 0.3635
P₁ = 0.36，P₂ = 9.09，P₃ = 0.36，P₄ = 0.19
为了"拉平"，最差的子信道吃掉了 91% 的功率。
2
(d) 求最大总容量用注水。把"噪声/增益" \(1/|H_k|^2=\{1,25,1,0.51\}\) 当池底，水面 μ 满足 \(\sum(\mu-1/|H_k|^2)=10\)。
3
四个都放水：μ = (10 + 27.51)/4 = 9.38 < 25，子信道 2 的池底高过水面，去掉。
4
剩三个：μ = (10 + 1 + 1 + 0.51)/3 = 4.17，功率 3.17、3.17、3.66。
C = log₂(4.17) + log₂(4.17) + log₂(4.17 × 1.96) = 2.06 + 2.06 + 3.03 = 7.15 bit/OFDM 符号
每个子载波占 B/N 的带宽，所以按 bit/s/Hz 算要除以 N = 4：C ≈ 1.79 ≈ 1.8 bit/s/Hz
◆ 本题知识点
考什么
OFDM 的功率分配：等容量 vs 注水（p.24，Practice 7 第 1(c)(d) 题；期末 2024-25 Q2(b)(iii)）。
用到的知识
子载波容量 log₂(1 + |Hk|²Pk/Nk)；注水 Pk = μ − Nk/|Hk|²（不能为负）。
关键一步
等容量 ⇔ |Hk|²Pk 都相同 → Pk ∝ 1/|Hk|²，越差的子载波给越多功率；注水正好相反，越差的给越少，太差的不给。
单位
4 个子载波各占 B/4：总共 7.15 bit 对应每 Hz 7.15/4 = 1.79 bit/s/Hz。
易错
题目给 |Hk| 时要先平方；池底是 Nk/|Hk|²（噪声 ÷ 增益），不是 |Hk|²。
频域均衡（p.25–26）
\(R_k=s_kH_k+W_k\ \Longrightarrow\ \hat s_k=\dfrac{R_k}{H_k}\)
每个子载波只要除以一个复数（估计出的信道增益），比第 6 章的时域均衡器简单得多。这是 OFDM 能做高速率的根本原因（p.27）：把频率选择性信道变成 N 条平行的平坦信道，不需要复杂的时域均衡。
⚠ 易错 · 等容量分配（2024-25 Q2(b)(iii)）
  • Ck = ¼log₂(1 + Pk|Hk|²) = 0.9 → 1 + Pk|Hk|² = 23.6，别忘了先乘回 4。
  • 给的是 |Hk|，公式里要平方：|H₂| = 0.2 → |H₂|² = 0.04。
★ 第七章考试重点
  • N > B/BC；T = NTs；速率 N log₂M/(T + TG)。
  • 子载波正交 → 相关器输出 sn；发端是 IDFT。
  • Hk = Σ hie−j2πik/N，N = 4 速算。
  • CP 表达式（nT − TG ≤ t）和功率损失 10 log((NTs + TG)/NTs)。
  • OFDM 容量 = Σ log₂(1 + |Hk|²Pk/Nk)，最优是注水；频域均衡 ŝk = Rk/Hk。
自测

(1) 为什么 OFDM 的子载波频谱重叠也不会互相干扰？(2) CP 为什么要复制块尾，而不是放一段空白？(3) 带宽 1 MHz、64 个子载波，子载波间隔和有用符号时长各是多少？

点击看答案
(1) 间隔正好 1/T，在每个子载波的采样频率上其他子载波都过零（正交）。(2) 复制块尾让线性卷积在接收窗口内等价于循环卷积，DFT 后正好是 H_k s_k，子载波保持正交、没有 ICI；空白只能挡住上一块的回声。(3) Δf = 1 MHz/64 = 15.625 kHz，T = 1/Δf = 64 µs。
