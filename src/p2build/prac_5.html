三个子信道的注水容量

Original question · 中英对照Practice 5

Consider a 3-channel MIMO system. The SNRs for the three channels are 80, 40, and 40. The channel bandwidth is 10MHz. Assume informed transmitter and find the channel capacity using the Water-filling method.

考虑一个 3 信道 MIMO 系统，三个信道的 SNR 分别为 80、40、40，信道带宽为 10 MHz。假设发射端已知信道（informed transmitter），用注水法（Water-filling）求信道容量。

注水法informed transmitter讲义第 2 章 p.54–57；第 5 章 p.40
题意讲解：这道题到底要干嘛

场景题目在讲一件什么事

MIMO 系统可以分解成 3 条互不干扰的并行子信道，它们的 SNR 分别是 80、40、40（总功率全给它一条时的 SNR）。

发射端知道信道（informed transmitter），所以可以把总功率聪明地分给 3 条子信道，让总容量最大。方法就是注水（water-filling）。

符号题目里每个量是什么

\(\gamma_i\)第 i 条子信道的 SNR：80、40、40
\(\gamma_0\)截止值：SNR 低于它的子信道一点功率都不给
\(P_i/P=1/\gamma_0-1/\gamma_i\)注水的功率分配公式，加起来等于 1
10 MHz带宽

要求每一问在问什么

  • 唯一一问 先假设 3 条都分到功率，由"功率加起来 = 1"解出 γ₀；检查每条的 γ_i 是否都大于 γ₀；最后容量 C = B Σ log₂(γ_i/γ₀)。

注意读题容易误会的地方

  • 如果某条 γ_i 小于 γ₀，要把它去掉、重新算 γ₀，不能直接用。

目的这道题想让你明白什么

发射端知道信道时，可以多给好信道、少给差信道，太差的直接放弃，这样总容量最大。

一句话：3 条并行子信道 SNR 为 80、40、40，发射端知道信道，用注水法分配功率，求总容量。
  1. 先假设三个都分到功率：\(\sum_{i=1}^{3}\big(\tfrac1{\gamma_0}-\tfrac1{\gamma_i}\big)=1\Rightarrow\dfrac3{\gamma_0}=1+\dfrac1{80}+\dfrac1{40}+\dfrac1{40}=1.0625\)。
  2. \(\gamma_0=3/1.0625=2.82\)。三个 SNR（80、40、40）都大于 2.82，假设成立，不用去掉任何子信道。
  3. 功率：\(P_1/P=1/2.82-1/80=0.342\)，\(P_2/P=P_3/P=1/2.82-1/40=0.329\)。
  4. 容量：\(C=B\sum\log_2(\gamma_i/\gamma_0)=10\text{ MHz}\times[\log_2(28.33)+2\log_2(14.17)]=10\times(4.82+7.65)\)。
C ≈ 124.7 Mbps ≈ 125 Mbps
官方答案：125 Mbps ✓
◆ 本题知识点
考什么
发射端知道信道（informed）时的 MIMO 容量：特征子信道 + 注水（第 5 章 p.19、p.40；第 2 章 p.54–57）。
前置知识
SVD 把 MIMO 信道拆成互不干扰的并行子信道；注水公式。
解题套路
① 假设全部子信道都分功率，由 Σ(1/γ₀ − 1/γi) = 1 求 γ₀；② 检查最差的 γi ≥ γ₀，不满足就去掉重算；③ Pi/P = 1/γ₀ − 1/γi；④ C = B Σ log₂(γi/γ₀)。
关键数字
γ₀ = 3/1.0625 = 2.82；功率 0.342、0.329、0.329（和为 1）；C = 10 MHz × (4.82 + 7.65) = 124.7 Mbps。
对比 1
功率平分（发射端不知道信道）：每路 SNR 变为 80/3、40/3、40/3，C = 122.1 Mbps，只少 2%。高 SNR 时知不知道信道差别很小（p.41–42）。
对比 2
低 SNR 时差别就大了：三个 SNR 都除以 100（0.8、0.4、0.4），注水只用第一个子信道，0.85 bit/s/Hz；平分只有 0.70 bit/s/Hz，差 21%。
易错
注水公式里的 γi 是"全部功率都给这个子信道"时的 SNR；平分时每个只分到 P/3；B 最后再乘。
  1. Assume all three sub-channels get power: \(\sum_{i=1}^{3}\big(\tfrac1{\gamma_0}-\tfrac1{\gamma_i}\big)=1\Rightarrow\dfrac3{\gamma_0}=1+\dfrac1{80}+\dfrac1{40}+\dfrac1{40}=1.0625\).
  2. \(\gamma_0=3/1.0625=2.82\). All three SNRs (80, 40, 40) exceed 2.82, so the assumption holds and no sub-channel is dropped.
  3. Powers: \(P_1/P=1/2.82-1/80=0.342\), \(P_2/P=P_3/P=1/2.82-1/40=0.329\).
  4. Capacity: \(C=B\sum\log_2(\gamma_i/\gamma_0)=10\text{ MHz}\times[\log_2(28.33)+2\log_2(14.17)]=10\times(4.82+7.65)\).
C ≈ 124.7 Mbps ≈ 125 Mbps
Official answer: 125 Mbps ✓
◆ Key points
What it tests
MIMO capacity with an informed transmitter: eigen-sub-channels plus water-filling (Ch 5 p.19, p.40; Ch 2 p.54–57).
Background
The SVD splits a MIMO channel into non-interfering parallel sub-channels; the water-filling formulas.
Method
① Assume every sub-channel gets power and find γ₀ from Σ(1/γ₀ − 1/γi) = 1; ② check that the weakest γi ≥ γ₀, otherwise drop it and repeat; ③ Pi/P = 1/γ₀ − 1/γi; ④ C = B Σ log₂(γi/γ₀).
Key numbers
γ₀ = 3/1.0625 = 2.82; powers 0.342, 0.329, 0.329 (sum 1); C = 10 MHz × (4.82 + 7.65) = 124.7 Mbps.
Comparison 1
Equal power (uninformed transmitter): the SNRs become 80/3, 40/3, 40/3 and C = 122.1 Mbps, only 2% less. At high SNR channel knowledge at the transmitter matters little (p.41–42).
Comparison 2
At low SNR the difference is large: dividing all three SNRs by 100 (0.8, 0.4, 0.4), water-filling uses only the first sub-channel and gives 0.85 bit/s/Hz, while equal power gives 0.70 bit/s/Hz, 21% less.
Common mistakes
The γi in water-filling is the SNR if all the power went to that sub-channel; with equal power each gets only P/3; multiply by B at the end.

推导 Alamouti 码的判决变量

Original question · 中英对照Practice 5

An Alamouti scheme transmits two complex-value symbols, \(u_1\) and \(u_2\), over 2 symbol duration using 2 antennas A and B. The transmitted symbols for the first symbol duration are \(x_A(1)=u_1\) and \(x_B(1)=u_2\), and for the second symbol duration are \(x_A(2)=-u_2^*\) and \(x_B(2)=u_1^*\). Let the channel gains be, \(h_A(1)=h_A(2)=h_A\) and \(h_B(1)=h_B(2)=h_B\), \(h_A,h_B\sim\mathcal N(0,1)\). Assume channel noise \(\sim\mathcal N(0,N_0)\). Derive the decision variable.

Alamouti 方案用 A、B 两根天线，在 2 个符号周期内发送两个复值符号 \(u_1\) 和 \(u_2\)：第一个符号周期发送 \(x_A(1)=u_1\)、\(x_B(1)=u_2\)，第二个符号周期发送 \(x_A(2)=-u_2^*\)、\(x_B(2)=u_1^*\)。设信道增益 \(h_A(1)=h_A(2)=h_A\)、\(h_B(1)=h_B(2)=h_B\)，\(h_A,h_B\sim\mathcal N(0,1)\)，信道噪声 \(\sim\mathcal N(0,N_0)\)。推导判决变量。

Alamouti STBC共轭技巧正交矩阵 F讲义第 5 章 p.21–26
题意讲解：这道题到底要干嘛

场景题目在讲一件什么事

两根发射天线 A、B，一根接收天线。Alamouti 码用两个时隙发两个符号 u₁、u₂：第 1 个时隙 A 发 u₁、B 发 u₂；第 2 个时隙 A 发 −u₂*、B 发 u₁*（* 是共轭）。

信道在两个时隙里不变。接收端在两个时隙各收到一个值 y₁、y₂，每个都是 u₁ 和 u₂ 混在一起的。

符号题目里每个量是什么

\(h_A,h_B\)两根天线到接收机的信道增益，复高斯
*复共轭
\(N_0\)噪声方差
判决变量（decision variable）接收端算出来、拿去判决的量

要求每一问在问什么

  • 唯一一问 推导判决变量：怎样把 y₁、y₂ 线性组合，得到只含 u₁（加噪声）的 z₁ 和只含 u₂ 的 z₂。提示：先对 y₂ 取共轭，写成矩阵，这个矩阵有正交性。

注意读题容易误会的地方

  • 先把 y₂ 取共轭，让 u₁、u₂ 都以不带共轭的形式出现，才能写成矩阵。

目的这道题想让你明白什么

发射端不需要知道信道，只靠这种编码排列，接收端用简单的线性运算就能把两个符号分开，而且每个符号都得到 |h_A|² + |h_B|² 的二阶分集。

一句话：Alamouti 码两个时隙发两个符号，接收端收到的 y₁、y₂ 是混在一起的；要找出线性组合把它们分开，得到各自的判决变量。
  1. 两个时隙收到：\(y_1=h_Au_1+h_Bu_2+w_1\)，\(y_2=-h_Au_2^*+h_Bu_1^*+w_2\)。
  2. 对 \(y_2\) 取共轭，让未知量都以 \(u_1,u_2\)（不带共轭）出现：\(y_2^*=h_B^*u_1-h_A^*u_2+w_2^*\)。
  3. 写成矩阵：\(\begin{bmatrix}y_1\\y_2^*\end{bmatrix}=\underbrace{\begin{bmatrix}h_A&h_B\\h_B^*&-h_A^*\end{bmatrix}}_{\mathbf F}\begin{bmatrix}u_1\\u_2\end{bmatrix}+\begin{bmatrix}w_1\\w_2^*\end{bmatrix}\)，且 \(\mathbf F^H\mathbf F=(|h_A|^2+|h_B|^2)\mathbf I\)。
  4. 左乘 \(\mathbf F^H\)，两个符号完全分开：
    z₁ = h_A* y₁ + h_B y₂* = (|h_A|² + |h_B|²)u₁ + h_A* w₁ + h_B w₂*
    z₂ = h_B* y₁ − h_A y₂* = (|h_A|² + |h_B|²)u₂ + h_B* w₁ − h_A w₂*
  5. 噪声项方差 \((|h_A|^2+|h_B|^2)N_0\)。除以 \(\|\mathbf h\|=\sqrt{|h_A|^2+|h_B|^2}\) 归一化，噪声方差回到 \(N_0\)。
z₁ = ‖h‖u₁ + w̃₁，z₂ = ‖h‖u₂ + w̃₂，‖h‖² = |h_A|² + |h_B|²，w̃₁, w̃₂ ~ N(0, N₀)
官方答案：z₁ = ‖h₁‖u₁ + w̃₁，z₂ = ‖h₂‖u₂ + w̃₂（两个范数其实是同一个 ‖h‖）✓
每个符号的有效 SNR ∝ |h_A|² + |h_B|²，两路衰落同时很小的概率很低，所以有二阶分集；发射端完全不需要知道信道。
◆ 本题知识点
考什么
Alamouti 空时块码的接收、判决变量和分集阶数（第 5 章 p.21–26）。
前置知识
复数共轭 (ab)* = a*b*；2 × 2 矩阵乘法；噪声乘以复数 c 后方差变成 |c|²N₀。
解题套路
① 写出两个时隙的 y₁、y₂；② 对 y₂ 取共轭，让 u₁、u₂ 都不带共轭；③ 写成 ỹ = Fu + ṽ；④ 左乘 FH；⑤ 除以 ‖h‖ 归一化。
关键性质
X XH = ‖s‖²I（编码正交）→ FHF = (|hA|² + |hB|²)I（接收端能把两个符号完全分开）。
易错
第二时隙天线 A 发的是 −u₂*（负号和共轭都要有）；z₁ 的噪声项是 hA*w₁ + hBw₂*，方差 (|hA|² + |hB|²)N₀。
为什么是 2 阶分集
有效增益 |hA|² + |hB|² 是两个独立衰落之和，两个同时很小的概率远小于一个很小的概率；而且发射端不需要知道信道。
举一反三
2 发 M 收：增益是 2M 个 |h|² 之和，分集 2M（满分集）。2025-26 S2 问 ŝ 的统计量：无偏，方差 σ²/‖h‖²。和 1 发 2 收 MRC 比，分集相同，但少 3 dB（功率分给两根天线，p.30）。
  1. Received in the two slots: \(y_1=h_Au_1+h_Bu_2+w_1\), \(y_2=-h_Au_2^*+h_Bu_1^*+w_2\).
  2. Conjugate \(y_2\) so that the unknowns appear as \(u_1,u_2\) without conjugates: \(y_2^*=h_B^*u_1-h_A^*u_2+w_2^*\).
  3. In matrix form: \(\begin{bmatrix}y_1\\y_2^*\end{bmatrix}=\underbrace{\begin{bmatrix}h_A&h_B\\h_B^*&-h_A^*\end{bmatrix}}_{\mathbf F}\begin{bmatrix}u_1\\u_2\end{bmatrix}+\begin{bmatrix}w_1\\w_2^*\end{bmatrix}\), with \(\mathbf F^H\mathbf F=(|h_A|^2+|h_B|^2)\mathbf I\).
  4. Pre-multiply by \(\mathbf F^H\); the two symbols separate completely:
    z₁ = hA* y₁ + hB y₂* = (|hA|² + |hB|²)u₁ + hA* w₁ + hB w₂*
    z₂ = hB* y₁ − hA y₂* = (|hA|² + |hB|²)u₂ + hB* w₁ − hA w₂*
  5. The noise variance is \((|h_A|^2+|h_B|^2)N_0\). Dividing by \(\|\mathbf h\|=\sqrt{|h_A|^2+|h_B|^2}\) brings it back to \(N_0\).
z₁ = ‖h‖u₁ + w̃₁, z₂ = ‖h‖u₂ + w̃₂, ‖h‖² = |hA|² + |hB|², w̃₁, w̃₂ ~ N(0, N₀)
Official answer: z₁ = ‖h₁‖u₁ + w̃₁, z₂ = ‖h₂‖u₂ + w̃₂ (the two norms are in fact the same ‖h‖) ✓
The effective SNR of each symbol is proportional to |hA|² + |hB|². Both paths fading at the same time is unlikely, which gives second-order diversity, and the transmitter needs no channel knowledge.
◆ Key points
What it tests
Reception, decision variables and diversity order of the Alamouti space-time block code (Ch 5 p.21–26).
Background
Complex conjugate (ab)* = a*b*; 2 × 2 matrix multiplication; multiplying noise by a complex c scales its variance by |c|².
Method
① Write y₁ and y₂ for the two slots; ② conjugate y₂ so u₁ and u₂ appear without conjugates; ③ write ỹ = Fu + ṽ; ④ pre-multiply by FH; ⑤ divide by ‖h‖ to normalise.
Key properties
X XH = ‖s‖²I (orthogonal code) → FHF = (|hA|² + |hB|²)I (the receiver can separate the two symbols completely).
Common mistakes
In slot 2 antenna A sends −u₂* (both the minus sign and the conjugate); the noise in z₁ is hA*w₁ + hBw₂*, variance (|hA|² + |hB|²)N₀.
Why order 2
The effective gain |hA|² + |hB|² is a sum of two independently fading terms; both being small at once is much less likely than one being small. And the transmitter does not need the channel.
Variations
2 transmit, M receive antennas: the gain is a sum of 2M terms |h|², diversity 2M (full diversity). 2025-26 S2 asks for the statistics of ŝ: unbiased, variance σ²/‖h‖². Compared with 1 × 2 MRC the diversity is the same but 3 dB is lost (power split between two antennas, p.30).

分集-复用折中：8 × 4 MIMO 最高速率

Original question · 中英对照Practice 5

Consider an 8 x 4 MIMO system. The diversity-multiplexing trade-off formula is given as, \(d(r)=(N-r)(M-r)\), where r and d are integers.

考虑一个 8 × 4 MIMO 系统。分集–复用折中公式为 \(d(r)=(N-r)(M-r)\)，其中 r 和 d 都是整数。

a) What is the maximum transmission rate per Hz for this channel if \(P_e=\gamma^{-d}\le10^{-3}\), where the SNR, γ = 10dB?

a) 若要求 \(P_e=\gamma^{-d}\le10^{-3}\)，SNR γ = 10 dB，该信道每 Hz 的最大传输速率是多少？

b) Given the r in part (a), what is the resulting \(P_e\)?

b) 在 (a) 求出的 r 下，得到的 \(P_e\) 是多少？

分集增益 d复用增益 rR = r·log₂SNR讲义第 4 章 p.31–34
题意讲解：这道题到底要干嘛

场景题目在讲一件什么事

8 × 4 的 MIMO 系统。多根天线可以用来提高可靠性（分集），也可以用来同时传多路数据提高速率（复用），两者不能同时拉满。

题目给了它们之间的折中关系 d(r) = (N − r)(M − r)：复用多一点，分集就少一点。

符号题目里每个量是什么

r复用增益（multiplexing gain）：速率 R = r·log₂SNR，相当于同时传几路
d分集增益（diversity gain）：误码率 \(P_e=\gamma^{-d}\)
N, M8 和 4，两端的天线数
γ = 10 dBSNR，线性值是 10

要求每一问在问什么

  • a) 要求 \(P_e\le10^{-3}\)，即需要 d 至少多大；在满足这个 d 的前提下，r 最大取多少；速率 R = r·log₂γ。
  • b) 用 (a) 选定的 r 算出实际的 d，再求 P_e。

注意读题容易误会的地方

  • 10 dB 先换成线性值 10。
  • r、d 都是整数，逐个试 r = 0、1、2、3、4。

目的这道题想让你明白什么

可靠性和速率要折中：先用可靠性要求定下最小的 d，再在这个限制下把 r 取到最大。

一句话：8 × 4 MIMO 在分集和复用之间折中：由误码率要求定出 d ≥ 3，找满足条件的最大 r，再算速率和实际误码率。
  1. γ = 10 dB = 10。\(10^{-d}\le10^{-3}\) → d ≥ 3。
  2. N = 8、M = 4，逐个试 r：
    r01234
    d = (8−r)(4−r)32211250
    满足 d ≥ 3 的最大 r 是 3。
  3. 复用增益的定义 \(r=R/\log_2\mathrm{SNR}\)，所以 \(R=r\log_2\gamma=3\times\log_210=3\times3.32=9.97\) bit/s/Hz。
  4. (b) r = 3 → d = 5 → \(P_e=10^{-5}\)。
(a) ≈ 9.96 bit/s/Hz；(b) Pe = 10⁻⁵
官方答案：9.96 bits/s/Hz；10⁻⁵ ✓
◆ 本题知识点
考什么
分集-复用折中：d(r) = (N − r)(M − r)，速率 R = r log₂SNR（第 4 章 p.31–34）。
前置知识
分集增益 d：SNR 翻倍时误码率降多快，最大 N × M；复用增益 r：SNR 翻倍时速率多几 bit/s/Hz，最大 min(N, M)。
解题套路
① 由 Pe = γ−d ≤ 目标求 d 的下限；② 列 r = 0 … min(N, M) 对应的 d；③ 找满足条件的最大 r；④ R = r log₂γ，Pe = γ−d(r)。
关键数字
γ = 10 → d ≥ 3；d(3) = 5 ≥ 3，d(4) = 0 < 3 → r = 3；R = 3 × 3.32 = 9.97 bit/s/Hz，Pe = 10⁻⁵。
易错
SNR 用线性值（10 dB → 10，20 dB → 100）；d 必须是整数，向上取；r 不能超过 min(N, M) = 4。
举一反三
SNR = 20 dB（100）时：100−d ≤ 10⁻³ → d ≥ 1.5 → 取 2；r = 3 的 d = 5 仍满足，r = 4 不行 → R = 3 log₂100 = 19.9 bit/s/Hz。已知 Pe 和 d 求 SNR：SNR = Pe−1/d。
物理意义
r 是同时传输的独立数据流个数，d 是抗衰落能力；天线资源要么用来"多传"，要么用来"传得稳"。
  1. γ = 10 dB = 10. \(10^{-d}\le10^{-3}\) → d ≥ 3.
  2. N = 8, M = 4, try each r:
    r01234
    d = (8−r)(4−r)32211250
    The largest r with d ≥ 3 is 3.
  3. By definition of the multiplexing gain \(r=R/\log_2\mathrm{SNR}\), so \(R=r\log_2\gamma=3\times\log_210=3\times3.32=9.97\) bit/s/Hz.
  4. (b) r = 3 → d = 5 → \(P_e=10^{-5}\).
(a) ≈ 9.96 bit/s/Hz; (b) Pe = 10⁻⁵
Official answer: 9.96 bits/s/Hz; 10⁻⁵ ✓
◆ Key points
What it tests
The diversity-multiplexing trade-off d(r) = (N − r)(M − r) and the rate R = r log₂SNR (Ch 4 p.31–34).
Background
Diversity gain d: how fast the error rate falls when the SNR doubles, at most N × M. Multiplexing gain r: how many extra bit/s/Hz per doubling of SNR, at most min(N, M).
Method
① From Pe = γ−d ≤ target find the minimum d; ② list d for r = 0 … min(N, M); ③ take the largest r that meets it; ④ R = r log₂γ, Pe = γ−d(r).
Key numbers
γ = 10 → d ≥ 3; d(3) = 5 ≥ 3, d(4) = 0 < 3 → r = 3; R = 3 × 3.32 = 9.97 bit/s/Hz, Pe = 10⁻⁵.
Common mistakes
Use the linear SNR (10 dB → 10, 20 dB → 100); d must be an integer, round up; r cannot exceed min(N, M) = 4.
Variations
At SNR = 20 dB (100): 100−d ≤ 10⁻³ → d ≥ 1.5 → 2; r = 3 (d = 5) still works, r = 4 does not → R = 3 log₂100 = 19.9 bit/s/Hz. Given Pe and d, the SNR is Pe−1/d.
Physical meaning
r is the number of independent data streams sent at once, d is the robustness against fading: the antennas can be used either to send more or to send more reliably.
