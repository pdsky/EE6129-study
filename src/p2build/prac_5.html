场景题目在讲一件什么事

MIMO 系统可以分解成 3 条互不干扰的并行子信道，它们的 SNR 分别是 80、40、40（总功率全给它一条时的 SNR）。

发射端知道信道（informed transmitter），所以可以把总功率聪明地分给 3 条子信道，让总容量最大。方法就是注水（water-filling）。

符号题目里每个量是什么

\(\gamma_i\)第 i 条子信道的 SNR：80、40、40
\(\gamma_0\)截止值：SNR 低于它的子信道一点功率都不给
\(P_i/P=1/\gamma_0-1/\gamma_i\)注水的功率分配公式，加起来等于 1

要求每一问在问什么

  • 唯一一问 先假设 3 条都分到功率，由"功率加起来 = 1"解出 γ₀；检查每条的 γ_i 是否都大于 γ₀；最后容量 C = B Σ log₂(γ_i/γ₀)。

注意读题容易误会的地方

  • 如果某条 γ_i 小于 γ₀，要把它去掉、重新算 γ₀，不能直接用。

目的这道题想让你明白什么

发射端知道信道时，可以多给好信道、少给差信道，太差的直接放弃，这样总容量最大。

一句话：3 条并行子信道 SNR 为 80、40、40，发射端知道信道，用注水法分配功率，求总容量。
  1. 先假设三个都分到功率：\(\sum_{i=1}^{3}\big(\tfrac1{\gamma_0}-\tfrac1{\gamma_i}\big)=1\Rightarrow\dfrac3{\gamma_0}=1+\dfrac1{80}+\dfrac1{40}+\dfrac1{40}=1.0625\)。
  2. \(\gamma_0=3/1.0625=2.82\)。三个 SNR（80、40、40）都大于 2.82，假设成立，不用去掉任何子信道。
  3. 功率：\(P_1/P=1/2.82-1/80=0.342\)，\(P_2/P=P_3/P=1/2.82-1/40=0.329\)。
  4. 容量：\(C=B\sum\log_2(\gamma_i/\gamma_0)=10\text{ MHz}\times[\log_2(28.33)+2\log_2(14.17)]=10\times(4.82+7.65)\)。

知识讲解 + 详细解析：注水法分配功率求容量

知识讲解为什么要"注水"

MIMO 信道做奇异值分解（SVD）以后，等价于几条互不干扰的并行子信道（特征子信道，eigen-sub-channel，讲义第 5 章 p.19）。本题直接给出 3 条子信道。问题是：总功率 P 固定，怎么分给这 3 条，总容量最大？

每条子信道的容量都是香农公式 log₂(1 + SNR)。log 曲线"先陡后平"：SNR 小时多给一点功率，容量涨得快；SNR 已经很大时再加功率，涨得慢。所以最优分法不是平分，而是好信道多给、差信道少给、太差的干脆不给，这就是注水（water-filling，第 2 章 p.54–57；第 5 章 p.40 说发射端知道信道（informed transmitter）时就用它）。

三个公式（老师课上强调：求 γ₀ 的那个式子是他框起来要背的，考试不给，今年 Quiz 第 3 题就考了注水）：

Pj/P = 1/γ₀ − 1/γj（γj ≥ γ₀ 时），否则 Pj = 0
Σj (1/γ₀ − 1/γj) = 1（各子信道功率加起来等于 P）
C = B Σj log₂(γj/γ₀)（只对分到功率的子信道求和）

符号：γj 是"把全部功率 P 都给第 j 条子信道"时它的 SNR（题目里的 80、40、40）；γ₀ 是截止值（cut-off），γj 低于它的子信道一点功率都不给。形象地看：1/γj 是"池底"，1/γ₀ 是"水面"，每条子信道分到的功率就是水面到池底的那段"水深"。

容量公式里为什么没有"1 +"：第 j 条分到 Pj 后，SNR = γj·Pj/P = γj(1/γ₀ − 1/γj) = γj/γ₀ − 1。代进香农公式：log₂(1 + γj/γ₀ − 1) = log₂(γj/γ₀)，"1 +"被抵消了。

详细解析四步算出 124.7 Mbps

  1. 先假设三条都分到功率。为什么：事先不知道哪条会被放弃，先全算，再检查。怎么算：Σ(1/γ₀ − 1/γj) = 1 → 3/γ₀ = 1 + 1/80 + 1/40 + 1/40 = 1 + 0.0125 + 0.025 + 0.025 = 1.0625。
  2. 求 γ₀ 并检查。γ₀ = 3/1.0625 = 2.82。最小的 γj = 40 远大于 2.82，三条都保留，假设成立。如果有 γj < γ₀，就把它去掉，"3"改成"2"重算（第 2 章 p.56–57 的例题就去掉了 γ₃ = 0.087）。
  3. 分功率（题目没问，用来自检）。1/γ₀ = 0.354；P₁/P = 0.354 − 0.0125 = 0.342，P₂/P = P₃/P = 0.354 − 0.025 = 0.329；加起来 0.342 + 0.329 + 0.329 = 1 ✓。
  4. 算容量。γ₁/γ₀ = 80/2.82 = 28.33，γ₂/γ₀ = γ₃/γ₀ = 40/2.82 = 14.17。计算器没有 log₂ 时用 log₂x = log₁₀x / 0.301：log₂28.33 = 1.452/0.301 ≈ 4.82，log₂14.17 = 1.151/0.301 ≈ 3.82。
C = 10 MHz × (4.82 + 3.82 + 3.82) = 10 MHz × 12.47 bit/s/Hz ≈ 124.7 Mbps ≈ 125 Mbps

自检和功率平分比一比

发射端不知道信道（uninformed）时只能平分：每条子信道分到 P/3，SNR 变成 80/3 = 26.7、40/3 = 13.3、13.3。

C = 10 MHz × [log₂(1 + 26.7) + 2 log₂(1 + 13.3)] = 10 × (4.79 + 2 × 3.84) ≈ 124.7 Mbps

只比注水少约 0.006 Mbps。原因：三条子信道 SNR 都很高，都在 log 曲线"平"的那一段，怎么分差别都很小。讲义第 5 章 p.42 也说：高 SNR 时 informed 和 uninformed 几乎没有差别。注水的好处在低 SNR 才明显（本题知识点框"对比 2"：SNR 都除以 100 后，注水 0.85 bit/s/Hz，平分 0.70 bit/s/Hz，注水高约 21%）。

易错常见丢分点

  • 把 γj 当成"分到功率以后"的 SNR。题目给的 80、40、40 是全部功率都给它时的 SNR。
  • 平分时漏了"1 +"：写成 log₂(80/3) 会算出 122.1 Mbps（错）。注水公式没有"1 +"是因为被抵消了，平分公式必须有。
  • 忘了检查 γj ≥ γ₀；去掉一条子信道后忘了把 3/γ₀ 改成 2/γ₀。
  • 最后忘了乘带宽 B = 10 MHz，或者单位写成 bit/s/Hz。

Concept + walkthrough: water-filling capacity

ConceptWhy "water-filling"

After a singular value decomposition (SVD), a MIMO channel is equivalent to a few non-interfering parallel sub-channels (eigen-sub-channels, Ch 5 p.19). This question gives the 3 sub-channels directly. The problem: with a fixed total power P, how should it be split among the 3 to maximise the total capacity?

Each sub-channel's capacity is Shannon's log₂(1 + SNR). The log curve is "steep first, flat later": a little extra power on a low-SNR channel raises capacity quickly; on a channel whose SNR is already high it adds little. So the optimum is not an equal split: give more to good channels, less to poor ones, and nothing to very poor ones. This is water-filling (Ch 2 p.54–57; Ch 5 p.40 says it is used when the transmitter knows the channel, i.e. an informed transmitter).

Three formulas (lecturer's emphasis: the equation for γ₀ is boxed for memorising and will not be given in the exam; this year's Quiz Q3 was water-filling):

Pj/P = 1/γ₀ − 1/γj (if γj ≥ γ₀), otherwise Pj = 0
Σj (1/γ₀ − 1/γj) = 1 (the sub-channel powers add up to P)
C = B Σj log₂(γj/γ₀) (sum only over sub-channels that receive power)

Symbols: γj is the SNR of sub-channel j if all the power P went to it (80, 40, 40 here); γ₀ is the cut-off: a sub-channel with γj below it gets no power. Picture it: 1/γj is the "floor" of a pool, 1/γ₀ is the "water level", and the power of each sub-channel is the "water depth" between the level and its floor.

Why there is no "1 +" in the capacity formula: after receiving Pj, sub-channel j has SNR = γj·Pj/P = γj(1/γ₀ − 1/γj) = γj/γ₀ − 1. In Shannon's formula: log₂(1 + γj/γ₀ − 1) = log₂(γj/γ₀); the "1 +" cancels.

Step by stepFour steps to 124.7 Mbps

  1. Assume all three get power. Why: we do not know in advance which one might be dropped, so compute with all, then check. How: Σ(1/γ₀ − 1/γj) = 1 → 3/γ₀ = 1 + 1/80 + 1/40 + 1/40 = 1 + 0.0125 + 0.025 + 0.025 = 1.0625.
  2. Find γ₀ and check. γ₀ = 3/1.0625 = 2.82. The smallest γj = 40 is far above 2.82, so all three stay and the assumption holds. If some γj < γ₀, drop it, change "3" to "2" and recompute (the example on Ch 2 p.56–57 drops γ₃ = 0.087).
  3. Allocate power (not asked, used as a check). 1/γ₀ = 0.354; P₁/P = 0.354 − 0.0125 = 0.342, P₂/P = P₃/P = 0.354 − 0.025 = 0.329; sum 0.342 + 0.329 + 0.329 = 1 ✓.
  4. Compute the capacity. γ₁/γ₀ = 80/2.82 = 28.33, γ₂/γ₀ = γ₃/γ₀ = 40/2.82 = 14.17. Without a log₂ key use log₂x = log₁₀x / 0.301: log₂28.33 = 1.452/0.301 ≈ 4.82, log₂14.17 = 1.151/0.301 ≈ 3.82.
C = 10 MHz × (4.82 + 3.82 + 3.82) = 10 MHz × 12.47 bit/s/Hz ≈ 124.7 Mbps ≈ 125 Mbps

CheckCompare with an equal split

An uninformed transmitter can only split equally: each sub-channel gets P/3, so the SNRs become 80/3 = 26.7, 40/3 = 13.3, 13.3.

C = 10 MHz × [log₂(1 + 26.7) + 2 log₂(1 + 13.3)] = 10 × (4.79 + 2 × 3.84) ≈ 124.7 Mbps

Only about 0.006 Mbps below water-filling. Reason: all three SNRs are high, on the flat part of the log curve, so the split hardly matters. Ch 5 p.42 says the same: at high SNR informed and uninformed transmitters are virtually identical. Water-filling pays off at low SNR (comparison 2 in the key-points box: with every SNR divided by 100, water-filling gives 0.85 bit/s/Hz and the equal split 0.70 bit/s/Hz, about 21% more for water-filling).

PitfallsWhere marks are lost

  • Treating γj as the SNR after allocation. The given 80, 40, 40 are the SNRs if all the power went to that sub-channel.
  • Dropping the "1 +" in the equal split: log₂(80/3) gives a wrong 122.1 Mbps. Water-filling has no "1 +" only because it cancels; the equal-split formula must keep it.
  • Forgetting to check γj ≥ γ₀; after dropping a sub-channel, forgetting to change 3/γ₀ into 2/γ₀.
  • Forgetting to multiply by B = 10 MHz at the end, or giving the unit as bit/s/Hz.

推导 Alamouti 码的判决变量

Original question · 中英对照Practice 5

An Alamouti scheme transmits two complex-value symbols, \(u_1\) and \(u_2\), over 2 symbol duration using 2 antennas A and B. The transmitted symbols for the first symbol duration are \(x_A(1)=u_1\) and \(x_B(1)=u_2\), and for the second symbol duration are \(x_A(2)=-u_2^*\) and \(x_B(2)=u_1^*\). Let the channel gains be, \(h_A(1)=h_A(2)=h_A\) and \(h_B(1)=h_B(2)=h_B\), \(h_A,h_B\sim\mathcal N(0,1)\). Assume channel noise \(\sim\mathcal N(0,N_0)\). Derive the decision variable.

Alamouti 方案用 A、B 两根天线，在 2 个符号周期内发送两个复值符号 \(u_1\) 和 \(u_2\)：第一个符号周期发送 \(x_A(1)=u_1\)、\(x_B(1)=u_2\)，第二个符号周期发送 \(x_A(2)=-u_2^*\)、\(x_B(2)=u_1^*\)。设信道增益 \(h_A(1)=h_A(2)=h_A\)、\(h_B(1)=h_B(2)=h_B\)，\(h_A,h_B\sim\mathcal N(0,1)\)，信道噪声 \(\sim\mathcal N(0,N_0)\)。推导判决变量。

Alamouti STBC共轭技巧正交矩阵 F讲义第 5 章 p.21–26
题意讲解：这道题到底要干嘛

场景题目在讲一件什么事

两根发射天线 A、B，一根接收天线。Alamouti 码用两个时隙发两个符号 u₁、u₂：第 1 个时隙 A 发 u₁、B 发 u₂；第 2 个时隙 A 发 −u₂*、B 发 u₁*（* 是共轭）。

信道在两个时隙里不变。接收端在两个时隙各收到一个值 y₁、y₂，每个都是 u₁ 和 u₂ 混在一起的。

符号题目里每个量是什么

\(h_A,h_B\)两根天线到接收机的信道增益，复高斯
*复共轭
\(N_0\)噪声方差
判决变量（decision variable）接收端算出来、拿去判决的量

要求每一问在问什么

  • 唯一一问 推导判决变量：怎样把 y₁、y₂ 线性组合，得到只含 u₁（加噪声）的 z₁ 和只含 u₂ 的 z₂。提示：先对 y₂ 取共轭，写成矩阵，这个矩阵有正交性。

注意读题容易误会的地方

  • 先把 y₂ 取共轭，让 u₁、u₂ 都以不带共轭的形式出现，才能写成矩阵。

目的这道题想让你明白什么

发射端不需要知道信道，只靠这种编码排列，接收端用简单的线性运算就能把两个符号分开，而且每个符号都得到 |h_A|² + |h_B|² 的二阶分集。

一句话：Alamouti 码两个时隙发两个符号，接收端收到的 y₁、y₂ 是混在一起的；要找出线性组合把它们分开，得到各自的判决变量。
  1. 两个时隙收到：\(y_1=h_Au_1+h_Bu_2+w_1\)，\(y_2=-h_Au_2^*+h_Bu_1^*+w_2\)。
  2. 对 \(y_2\) 取共轭，让未知量都以 \(u_1,u_2\)（不带共轭）出现：\(y_2^*=h_B^*u_1-h_A^*u_2+w_2^*\)。
  3. 写成矩阵：\(\begin{bmatrix}y_1\\y_2^*\end{bmatrix}=\underbrace{\begin{bmatrix}h_A&h_B\\h_B^*&-h_A^*\end{bmatrix}}_{\mathbf F}\begin{bmatrix}u_1\\u_2\end{bmatrix}+\begin{bmatrix}w_1\\w_2^*\end{bmatrix}\)，且 \(\mathbf F^H\mathbf F=(|h_A|^2+|h_B|^2)\mathbf I\)。
  4. 左乘 \(\mathbf F^H\)，两个符号完全分开：
    z₁ = h_A* y₁ + h_B y₂* = (|h_A|² + |h_B|²)u₁ + h_A* w₁ + h_B w₂*
    z₂ = h_B* y₁ − h_A y₂* = (|h_A|² + |h_B|²)u₂ + h_B* w₁ − h_A w₂*
  5. 噪声项方差 \((|h_A|^2+|h_B|^2)N_0\)。除以 \(\|\mathbf h\|=\sqrt{|h_A|^2+|h_B|^2}\) 归一化，噪声方差回到 \(N_0\)。

官方答案：z₁ = ‖h₁‖u₁ + w̃₁，z₂ = ‖h₂‖u₂ + w̃₂（两个范数其实是同一个 ‖h‖）✓

知识讲解 + 详细解析：Alamouti 码的判决变量

知识讲解Alamouti 码在解决什么问题

发射分集（transmit diversity）：发射端 2 根天线、接收端 1 根，而且发射端不知道信道。如果两根天线同时发同一个符号，收到的是 (hA + hB)u，而 hA + hB 只是另一个高斯随机变量，照样会深衰落，没有分集（第 5 章 p.18）。Alamouti 的办法是把两个符号在"空间（两根天线）× 时间（两个时隙）"上交错排列，叫空时块码（STBC，第 5 章 p.20–21）：

时隙天线 A天线 B
1u₁u₂
2−u₂*u₁*

老师课上强调：这个编码矩阵是蓝框，要背。它的关键性质是正交：X XH = (|u₁|² + |u₂|²) I（第 5 章 p.22、p.29）。正交性到了接收端，就变成下面矩阵 F 的性质 FHF = ‖h‖² I：两个符号可以用简单的线性运算完全分开。

要用到的工具：共轭规则 (ab)* = a*b*、(a*)* = a；|h|² = h·h*；FH 是共轭转置（先转置，再每个元素取共轭）；噪声乘上复数 c 后方差变成 |c|²N₀；两个独立噪声相加，方差相加。

判决变量（decision variable）：接收端最后拿去判决的那个量。老师说它要满足两点：只含要检测的那一个符号，而且符号前面乘的是标量，不是向量。

详细解析六步推出 z₁、z₂

  1. 写出两个时隙的接收信号。为什么：先把发送方案翻译成方程。
    y₁ = hAu₁ + hBu₂ + w₁
    y₂ = hA(−u₂*) + hBu₁* + w₂ = −hAu₂* + hBu₁* + w₂
  2. 对 y₂ 取共轭。为什么：y₂ 里出现的是 u₁*、u₂*，和 y₁ 里的 u₁、u₂ 不是同一组未知数，没法联立（老师说：两个方程四个未知数，解不出来）。共轭以后两个式子都只含 u₁、u₂：
    y₂* = hB*u₁ − hA*u₂ + w₂*
  3. 写成矩阵并检查正交。\(\tilde{\mathbf y}=\begin{bmatrix}y_1\\y_2^*\end{bmatrix}=\mathbf F\begin{bmatrix}u_1\\u_2\end{bmatrix}+\begin{bmatrix}w_1\\w_2^*\end{bmatrix}\)，\(\mathbf F=\begin{bmatrix}h_A&h_B\\h_B^*&-h_A^*\end{bmatrix}\)（第 5 章 p.23）。FHF 的对角元 = |hA|² + |hB|²；非对角元 = hA*hB − hBhA* = 0。所以 FHF = ‖h‖² I。
  4. 左乘 FH。为什么：交叉项是 0，每个输出只剩一个符号。
    z₁ = hA*y₁ + hBy₂*，z₂ = hB*y₁ − hAy₂*
    展开 z₁ 验证：hA*(hAu₁ + hBu₂ + w₁) + hB(hB*u₁ − hA*u₂ + w₂*) = (|hA|² + |hB|²)u₁ + (hA*hB − hBhA*)u₂ + hA*w₁ + hBw₂*。u₂ 的两项正好抵消，这就是 −u₂* 里负号和共轭的作用。z₂ 同理。
  5. 算噪声方差。hA*w₁ 的方差是 |hA|²N₀，hBw₂* 的方差是 |hB|²N₀，两者独立，相加得 (|hA|² + |hB|²)N₀ = ‖h‖²N₀。
  6. 归一化。两边除以 ‖h‖ = √(|hA|² + |hB|²)，信号项变成 ‖h‖u₁，噪声方差回到 ‖h‖²N₀/‖h‖² = N₀：
    z₁ = ‖h‖u₁ + w̃₁，z₂ = ‖h‖u₂ + w̃₂，w̃₁, w̃₂ ~ N(0, N₀)
    这就是官方答案的形式。如果改为除以 ‖h‖²，就得到讲义 p.25 的 û = u + 噪声，噪声方差 N₀/‖h‖²。

数字验证（不含噪声）：取 hA = 1、hB = j、u₁ = 1、u₂ = −1。y₁ = 1 − j，y₂ = −1·(−1) + j·1 = 1 + j，y₂* = 1 − j。z₁ = 1·(1 − j) + j(1 − j) = 2 = ‖h‖²u₁ ✓（‖h‖² = 2）；z₂ = (−j)(1 − j) − (1 − j) = −2 = ‖h‖²u₂ ✓。

为什么是二阶分集：每个符号的有效 SNR ∝ |hA|² + |hB|²，两条独立衰落路径同时很弱的概率远小于一条很弱的概率（讲义 p.26）。而且发射端完全不需要知道信道，只有接收端要知道 hA、hB（用来算 FH）。

易错常见丢分点

  • 第二时隙天线 A 发的是 −u₂*：负号和共轭缺一不可，少了负号 u₂ 的交叉项就消不掉。
  • 只对 y₂ 取共轭，y₁ 不动；z₁ 里乘的是 hB（不带共轭）乘 y₂*。
  • 左乘 FH 后噪声方差是 ‖h‖²N₀，不是 N₀；除以 ‖h‖ 以后才回到 N₀。
  • 官方答案写成 ‖h₁‖、‖h₂‖ 两个符号，其实是同一个 √(|hA|² + |hB|²)。
  • 如果总发射功率固定，两根天线各分一半，Alamouti 的 SNR 比 1 发 2 收的 MRC 低 3 dB（第 5 章 p.30），但分集阶数一样是 2。

Concept + walkthrough: Alamouti decision variables

ConceptWhat problem the Alamouti code solves

Transmit diversity: 2 antennas at the transmitter, 1 at the receiver, and the transmitter does not know the channel. If both antennas sent the same symbol at the same time, the receiver would get (hA + hB)u; but hA + hB is just another Gaussian random variable that fades just as deeply, so there is no diversity (Ch 5 p.18). Alamouti's idea is to arrange the two symbols across "space (two antennas) × time (two slots)", a space-time block code (STBC, Ch 5 p.20–21):

SlotAntenna AAntenna B
1u₁u₂
2−u₂*u₁*

Lecturer's emphasis: this code matrix is in a blue box and must be memorised. Its key property is orthogonality: X XH = (|u₁|² + |u₂|²) I (Ch 5 p.22, p.29). At the receiver orthogonality becomes the property FHF = ‖h‖² I of the matrix F below: the two symbols can be separated completely by simple linear operations.

Tools needed: conjugate rules (ab)* = a*b*, (a*)* = a; |h|² = h·h*; FH is the conjugate transpose (transpose, then conjugate every element); multiplying noise by a complex c scales its variance by |c|²; the variances of two independent noises add.

Decision variable: the quantity the receiver finally feeds to the decision. The lecturer says it must satisfy two things: it contains only the one symbol being detected, and that symbol is multiplied by a scalar, not a vector.

Step by stepSix steps to z₁ and z₂

  1. Write the received signals in the two slots. Why: translate the transmission scheme into equations.
    y₁ = hAu₁ + hBu₂ + w₁
    y₂ = hA(−u₂*) + hBu₁* + w₂ = −hAu₂* + hBu₁* + w₂
  2. Conjugate y₂. Why: y₂ contains u₁* and u₂*, not the same unknowns as u₁ and u₂ in y₁, so the two equations cannot be solved together (lecturer: two equations, four unknowns). After conjugating, both equations contain only u₁ and u₂:
    y₂* = hB*u₁ − hA*u₂ + w₂*
  3. Write it as a matrix and check orthogonality. \(\tilde{\mathbf y}=\begin{bmatrix}y_1\\y_2^*\end{bmatrix}=\mathbf F\begin{bmatrix}u_1\\u_2\end{bmatrix}+\begin{bmatrix}w_1\\w_2^*\end{bmatrix}\), \(\mathbf F=\begin{bmatrix}h_A&h_B\\h_B^*&-h_A^*\end{bmatrix}\) (Ch 5 p.23). The diagonal elements of FHF are |hA|² + |hB|²; the off-diagonal ones are hA*hB − hBhA* = 0. Hence FHF = ‖h‖² I.
  4. Pre-multiply by FH. Why: the cross terms are 0, so each output keeps only one symbol.
    z₁ = hA*y₁ + hBy₂*, z₂ = hB*y₁ − hAy₂*
    Expand z₁ to verify: hA*(hAu₁ + hBu₂ + w₁) + hB(hB*u₁ − hA*u₂ + w₂*) = (|hA|² + |hB|²)u₁ + (hA*hB − hBhA*)u₂ + hA*w₁ + hBw₂*. The two u₂ terms cancel exactly; that is what the minus sign and the conjugate in −u₂* are for. z₂ works the same way.
  5. Noise variance. hA*w₁ has variance |hA|²N₀, hBw₂* has variance |hB|²N₀; they are independent, so the total is (|hA|² + |hB|²)N₀ = ‖h‖²N₀.
  6. Normalise. Divide by ‖h‖ = √(|hA|² + |hB|²): the signal term becomes ‖h‖u₁ and the noise variance returns to ‖h‖²N₀/‖h‖² = N₀:
    z₁ = ‖h‖u₁ + w̃₁, z₂ = ‖h‖u₂ + w̃₂, w̃₁, w̃₂ ~ N(0, N₀)
    This is the form of the official answer. Dividing by ‖h‖² instead gives û = u + noise with variance N₀/‖h‖², as on slide p.25.

Numerical check (no noise): take hA = 1, hB = j, u₁ = 1, u₂ = −1. y₁ = 1 − j, y₂ = −1·(−1) + j·1 = 1 + j, y₂* = 1 − j. z₁ = 1·(1 − j) + j(1 − j) = 2 = ‖h‖²u₁ ✓ (‖h‖² = 2); z₂ = (−j)(1 − j) − (1 − j) = −2 = ‖h‖²u₂ ✓.

Why diversity order 2: the effective SNR of each symbol is proportional to |hA|² + |hB|²; two independently fading paths being weak at the same time is far less likely than one being weak (slide p.26). And the transmitter needs no channel knowledge at all; only the receiver must know hA, hB (to form FH).

PitfallsWhere marks are lost

  • In slot 2 antenna A sends −u₂*: both the minus sign and the conjugate are needed; without the minus sign the u₂ cross terms do not cancel.
  • Only y₂ is conjugated, y₁ is left alone; in z₁, hB (no conjugate) multiplies y₂*.
  • After pre-multiplying by FH the noise variance is ‖h‖²N₀, not N₀; it returns to N₀ only after dividing by ‖h‖.
  • The official answer writes ‖h₁‖ and ‖h₂‖, but both are the same √(|hA|² + |hB|²).
  • With a fixed total transmit power, each antenna gets half, so Alamouti's SNR is 3 dB below 1 × 2 MRC (Ch 5 p.30), but the diversity order is the same, 2.

知识讲解分集增益 d 和复用增益 r

N 发 M 收的 MIMO 有两种用法（第 4 章 p.31–33）：

  • 分集（diversity）：同一份数据走很多条独立路径，求"稳"。用分集增益 d 衡量：高 SNR 时 Pe ≈ SNR−d，d 越大，SNR 每提高一点误码率降得越快。最大 d = N × M。
  • 复用（multiplexing）：同时发几路不同的数据，求"快"。用复用增益 r 衡量：速率 R = r·log₂SNR（bit/s/Hz），相当于同时有 r 路数据，每路 log₂SNR。最大 r = min(N, M)，因为高 SNR 时容量 C ≈ min(N, M)·log₂SNR（p.31）。

两者不能同时拉满：天线资源用来"多传"就不能全用来"传得稳"。题目给的折中曲线 d(r) = (N − r)(M − r)（p.33）：r = 0 时 d = N × M（全分集），r = min(N, M) 时 d = 0（全复用）。老师课上强调：这只是其中一种折中关系，r、d 都取整数，画出来是离散的点。

本题的解题思路就是"把题目给的符号连起来"（老师讲 p.34 例题时的说法）：Pe 的要求 → 最小 d → 最大 r → 速率 R。

Concept + walkthrough: DMT, rate and P_e

ConceptDiversity gain d and multiplexing gain r

An N × M MIMO system can be used in two ways (Ch 4 p.31–33):

  • Diversity: the same data travels over many independent paths, for "reliability". Measured by the diversity gain d: at high SNR Pe ≈ SNR−d; the larger d, the faster the error rate falls as the SNR rises. Maximum d = N × M.
  • Multiplexing: several different data streams are sent at once, for "speed". Measured by the multiplexing gain r: the rate R = r·log₂SNR (bit/s/Hz), as if r streams each carried log₂SNR. Maximum r = min(N, M), because at high SNR the capacity C ≈ min(N, M)·log₂SNR (p.31).

Both cannot be maxed out at once: antennas used to "send more" cannot all be used to "send reliably". The trade-off curve given here, d(r) = (N − r)(M − r) (p.33): r = 0 gives d = N × M (full diversity), r = min(N, M) gives d = 0 (full multiplexing). Lecturer's emphasis: this is only one possible trade-off; r and d are integers, so the curve is a set of discrete points.

The method is to "connect the symbols the question gives you" (the lecturer's words on the p.34 example): Pe requirement → minimum d → maximum r → rate R.

Step by step(a) Find r from the error-rate requirement

  1. dB to linear. Why: the γ in Pe = γ−d is a linear value. γ = 1010/10 = 10.
  2. Lower bound on d. 10−d ≤ 10−3 ⇔ −d ≤ −3 ⇔ d ≥ 3. In general: d ≥ log(1/Pe,target) / log γ = 3/1 = 3.
  3. Largest r with d ≥ 3. Two ways:
    r01234
    d = (8 − r)(4 − r)32211250
    By the table: r = 3 gives d = 5 ≥ 3, r = 4 gives d = 0, which fails. The lecturer's way: solve (8 − r)(4 − r) = 3, i.e. r² − 12r + 29 = 0, r = 6 ± √7 ≈ 3.35 or 8.65. 8.65 exceeds min(N, M) = 4 and is discarded; for 0 ≤ r ≤ 4, d falls as r grows, so we need r ≤ 3.35, and the integer is r = 3.
  4. Rate. From the definition r = R/log₂SNR:
    R = r·log₂γ = 3 × log₂10 = 3 × 3.32 = 9.97 bit/s/Hz
    log₂10 = 1/0.301 = 3.32. Exactly, 3 × 3.3219 = 9.966; the official answer writes 9.96 (truncated); 9.97 or 9.96 are both fine.

Step by step(b) Substitute back for the actual error rate

r = 3 → d = (8 − 3)(4 − 3) = 5 → Pe = γ−d = 10−5. Better than the required 10−3: r must be an integer, so it drops from 3.35 to 3, and the spare diversity shows up as a lower error rate.

CheckIs it reasonable?

  • r = 3 ≤ min(8, 4) = 4 ✓; d = 5 ≤ N × M = 32 ✓.
  • With r = 4: R = 4 × 3.32 = 13.3 bit/s/Hz is faster, but d = 0, the error rate does not fall with SNR, so the requirement fails.
  • With r = 2: d = 12, Pe = 10−12 is very reliable, but R = 6.64 bit/s/Hz wastes rate.

PitfallsWhere marks are lost

  • Not converting the SNR to linear (10 dB → 10).
  • d must be an integer: for d ≥ 3, r is rounded down to 3, not 3.35.
  • The other root of the quadratic, 8.65, exceeds min(N, M) and is meaningless.
  • R uses log₂, not log₁₀ or ln.
  • (b) asks for the Pe actually obtained with r = 3 (10−5), not the required 10−3.

◆ Key points
What it tests
The diversity-multiplexing trade-off d(r) = (N − r)(M − r) and the rate R = r log₂SNR (Ch 4 p.31–34).
Background
Diversity gain d: how fast the error rate falls when the SNR doubles, at most N × M. Multiplexing gain r: how many extra bit/s/Hz per doubling of SNR, at most min(N, M).
Method
① From Pe = γ−d ≤ target find the minimum d; ② list d for r = 0 … min(N, M); ③ take the largest r that meets it; ④ R = r log₂γ, Pe = γ−d(r).
Key numbers
γ = 10 → d ≥ 3; d(3) = 5 ≥ 3, d(4) = 0 < 3 → r = 3; R = 3 × 3.32 = 9.97 bit/s/Hz, Pe = 10⁻⁵.
Common mistakes
Use the linear SNR (10 dB → 10, 20 dB → 100); d must be an integer, round up; r cannot exceed min(N, M) = 4.
Variations
At SNR = 20 dB (100): 100−d ≤ 10⁻³ → d ≥ 1.5 → 2; r = 3 (d = 5) still works, r = 4 does not → R = 3 log₂100 = 19.9 bit/s/Hz. Given Pe and d, the SNR is Pe−1/d.
Physical meaning
r is the number of independent data streams sent at once, d is the robustness against fading: the antennas can be used either to send more or to send more reliably.
