正交基与信号空间维数

Original question · 中英对照Practice 3

Consider the following modulated signal, where the message signals are modulated in \(A_i\) and \(\phi_j\).

考虑如下调制信号，消息信号被调制在幅度 \(A_i\) 和相位 \(\phi_j\) 上。

\(A_i\cos\!\left(\dfrac{2\pi t}{T}+\phi_j\right),\quad 0

(a) Find an orthonormal basis for the signal.

(a) 求该信号的一组标准正交基。

(b) Find the dimension of the space spanned by the signal.

(b) 求该信号所张成的信号空间的维数。

正交归一基和角公式讲义第 3 章 p.4–11
  1. 拆开：\(A_i\cos(2\pi t/T+\phi_j)=(A_i\cos\phi_j)\cos(2\pi t/T)+(-A_i\sin\phi_j)\sin(2\pi t/T)\)。所有信号都在 cos 和 sin 这两个方向上。
  2. 正交：\(\int_0^T\cos(2\pi t/T)\sin(2\pi t/T)dt=\tfrac12\int_0^T\sin(4\pi t/T)dt=0\)。
  3. 归一：\(\int_0^T\cos^2(2\pi t/T)dt=T/2\)，所以乘 \(\sqrt{2/T}\) 使能量为 1。
(a) { √(2/T)·cos(2πt/T), √(2/T)·sin(2πt/T) }；(b) 维数 2
官方答案：同上 ✓
◆ 本题知识点
考什么
信号空间：正交归一基和维数（第 3 章 p.4–11）。
前置知识
和角公式 cos(a + b) = cos a cos b − sin a sin b；∫₀T cos²(2πt/T) dt = T/2；内积 = 相乘再积分。
解题套路
① 把信号展开成几个固定波形的线性组合；② 验证这些波形两两正交；③ 每个除以 √能量做归一化；④ 基函数的个数就是维数。
关键结果
ψ₁ = √(2/T) cos(2πt/T)，ψ₂ = √(2/T) sin(2πt/T)。坐标 (Aicosφj√(T/2), −Aisinφj√(T/2))，到原点的距离 Ai√(T/2) = √E。
易错
忘了归一化系数 √(2/T)；以为 Ai、φj 取值多维数就多：维数只看需要几个基函数，与信号个数无关（D ≤ M）；sin 前面的负号放进坐标里。
举一反三
只调幅度（φ 固定）→ 1 维（PAM）；只调相位 → 2 维（PSK）；幅度、相位都调 → 2 维（QAM，本题就是）。期末 2025-26 S1 Q1(a)(i)：画 ±1 的星座，维数 1、距离 2。
  1. Expand: \(A_i\cos(2\pi t/T+\phi_j)=(A_i\cos\phi_j)\cos(2\pi t/T)+(-A_i\sin\phi_j)\sin(2\pi t/T)\). Every signal lies along the cos and sin directions.
  2. Orthogonal: \(\int_0^T\cos(2\pi t/T)\sin(2\pi t/T)dt=\tfrac12\int_0^T\sin(4\pi t/T)dt=0\).
  3. Normalise: \(\int_0^T\cos^2(2\pi t/T)dt=T/2\), so multiply by \(\sqrt{2/T}\) to get unit energy.
(a) { √(2/T)·cos(2πt/T), √(2/T)·sin(2πt/T) }; (b) dimension 2
Official answer: same as above ✓
◆ Key points
What it tests
Signal space: orthonormal basis and dimension (Ch 3 p.4–11).
Background
Angle-sum identity cos(a + b) = cos a cos b − sin a sin b; ∫₀T cos²(2πt/T) dt = T/2; inner product = multiply and integrate.
Method
① Write the signal as a linear combination of a few fixed waveforms; ② check they are mutually orthogonal; ③ divide each by √energy to normalise; ④ the number of basis functions is the dimension.
Key result
ψ₁ = √(2/T) cos(2πt/T), ψ₂ = √(2/T) sin(2πt/T). Coordinates (Aicosφj√(T/2), −Aisinφj√(T/2)); distance from the origin Ai√(T/2) = √E.
Common mistakes
Forgetting the normalising factor √(2/T); thinking many values of Ai, φj mean many dimensions (the dimension only counts basis functions, D ≤ M); the minus sign of the sin term belongs in the coordinate.
Variations
Amplitude only (φ fixed) → 1-D (PAM); phase only → 2-D (PSK); both → 2-D (QAM, as here). 2025-26 S1 Q1(a)(i): sketch the ±1 constellation, dimension 1, distance 2.

噪声方差不相等时的 ML 判决

Original question · 中英对照Practice 3

A particular binary disc storage channel can be approximated as a discrete-time AWGN channel with inputs \(x_n\in\{0,1\}\) and output \(y_n=x_n+w_n\), where \(y_n\) is also the decision variable in the disc reading device at time n. The noise variance depends on the value of \(x_n\) in that \(w_n\) has the conditional Gaussian pdf given below, where \(\sigma_1^2>\sigma_0^2\).

某二进制磁盘存储信道可以近似为离散时间 AWGN 信道：输入 \(x_n\in\{0,1\}\)，输出 \(y_n=x_n+w_n\)，\(y_n\) 也是读盘设备在时刻 n 的判决变量。噪声方差与 \(x_n\) 的取值有关：\(w_n\) 的条件高斯概率密度如下，其中 \(\sigma_1^2>\sigma_0^2\)。

\(f(w_n\mid x_n)=\begin{cases}\dfrac{1}{\sqrt{2\pi\sigma_0^2}}e^{-w_n^2/2\sigma_0^2} & x_n=0\\[2mm] \dfrac{1}{\sqrt{2\pi\sigma_1^2}}e^{-w_n^2/2\sigma_1^2} & x_n=1\end{cases}\)

Assume \(P(x_n=0)=P(x_n=1)=\tfrac12\) for all n.

对所有 n，假设 \(P(x_n=0)=P(x_n=1)=\tfrac12\)。

(a) Find a decision rule for a ML detector that will decide \(\hat x_n\in\{0,1\}\) based on the value of \(y_n\), and formulate it in terms of \(\sigma_0^2\) and \(\sigma_1^2\).

(a) 求 ML 检测器根据 \(y_n\) 的值判决 \(\hat x_n\in\{0,1\}\) 的判决规则，并用 \(\sigma_0^2\) 和 \(\sigma_1^2\) 表示。

(b) Find the corresponding bit error probability \(P_e\).

(b) 求相应的误比特概率 \(P_e\)。

ML 检测似然比判决门限讲义第 3 章 p.18–20
  1. 发 0 时 \(y\sim\mathcal N(0,\sigma_0^2)\)，发 1 时 \(y\sim\mathcal N(1,\sigma_1^2)\)。ML：哪个似然大判哪个。
  2. 判 1 当 \(\dfrac{1}{\sigma_1}e^{-(y-1)^2/2\sigma_1^2}>\dfrac{1}{\sigma_0}e^{-y^2/2\sigma_0^2}\)，取对数：
    g(y) = y²/(2σ₀²) − (y − 1)²/(2σ₁²) + ln(σ₀/σ₁) > 0
  3. g(y) = 0 是关于 y 的二次方程，取在 0 与 1 之间的根作为门限 ỹ：y > ỹ 判 1，y < ỹ 判 0。方差相等时 ỹ = 0.5；σ₁ > σ₀ 时 ỹ 往 0 那边移。
  4. (b) 两种错误：发 0、噪声把 y 推过 ỹ，概率 \(Q(\tilde y/\sigma_0)\)；发 1、y 掉到 ỹ 以下，概率 \(Q((1-\tilde y)/\sigma_1)\)。等概各乘 ½。
x̂ₙ = 1 当 yₙ > ỹ，否则 0；Pe = ½[Q((1 − ỹ)/σ₁) + Q(ỹ/σ₀)]
官方答案：同上 ✓
数字感受：σ₀² = 0.1、σ₁² = 0.4 时，g(y) = 3.75y² + 2.5y − 1.943，ỹ ≈ 0.46。严格说二次方程在很负的 y 处还有第二个根（那里也会判 1），概率极小，答案忽略。
◆ 本题知识点
考什么
非标准情况下的 ML 检测：两种假设的噪声方差不同（第 3 章 p.18–20）。
前置知识
高斯 PDF（前面的系数 1/(√(2π)σ) 不能丢）；ln 是增函数，比大小时可以取对数；二次方程求根；Q 函数。
解题套路
① 写出两个条件 PDF；② 比较似然并取对数，整理成 g(y) > 0；③ 解 g(ỹ) = 0 得门限；④ 两种错误分别算；⑤ 按先验概率（各 ½）加权。
关键公式
g(y) = y²/(2σ₀²) − (y − 1)²/(2σ₁²) + ln(σ₀/σ₁)；Pe = ½[Q((1 − ỹ)/σ₁) + Q(ỹ/σ₀)]。
数值例
σ₀² = 0.1、σ₁² = 0.4：ỹ ≈ 0.46，Pe = ½[Q(0.54/0.632) + Q(0.46/0.316)] = ½[Q(0.85) + Q(1.46)] ≈ 0.135。
易错
只比较指数、忘了系数 1/σ，会得到错误的门限；两种错误要用各自的 σ；二次方程有两个根，取 0 和 1 之间的那个。
举一反三
方差相等 → ỹ = 0.5，Pe = Q(0.5/σ)；先验不等 → 用 MAP，对数里再加 ln P(x)，门限往先验小的一边移。
  1. Sending 0: \(y\sim\mathcal N(0,\sigma_0^2)\); sending 1: \(y\sim\mathcal N(1,\sigma_1^2)\). ML: choose the hypothesis with the larger likelihood.
  2. Decide 1 when \(\dfrac{1}{\sigma_1}e^{-(y-1)^2/2\sigma_1^2}>\dfrac{1}{\sigma_0}e^{-y^2/2\sigma_0^2}\); taking logarithms:
    g(y) = y²/(2σ₀²) − (y − 1)²/(2σ₁²) + ln(σ₀/σ₁) > 0
  3. g(y) = 0 is a quadratic in y; the root between 0 and 1 is the threshold ỹ: decide 1 if y > ỹ, 0 if y < ỹ. With equal variances ỹ = 0.5; with σ₁ > σ₀ the threshold moves towards 0.
  4. (b) Two error events: sending 0 and the noise pushes y above ỹ, probability \(Q(\tilde y/\sigma_0)\); sending 1 and y falls below ỹ, probability \(Q((1-\tilde y)/\sigma_1)\). Equal priors, weight ½ each.
x̂n = 1 if yn > ỹ, otherwise 0; Pe = ½[Q((1 − ỹ)/σ₁) + Q(ỹ/σ₀)]
Official answer: same as above ✓
A numerical feel: with σ₀² = 0.1 and σ₁² = 0.4, g(y) = 3.75y² + 2.5y − 1.943 and ỹ ≈ 0.46. Strictly, the quadratic has a second root at a very negative y (where the rule decides 1 again); its probability is negligible and the answer ignores it.
◆ Key points
What it tests
Non-standard ML detection: the two hypotheses have different noise variances (Ch 3 p.18–20).
Background
Gaussian PDF (keep the factor 1/(√(2π)σ)); ln is increasing, so likelihoods can be compared after taking logs; roots of a quadratic; the Q function.
Method
① Write both conditional PDFs; ② compare likelihoods, take logs, rearrange to g(y) > 0; ③ solve g(ỹ) = 0 for the threshold; ④ compute the two error events separately; ⑤ weight by the priors (½ each).
Key formulas
g(y) = y²/(2σ₀²) − (y − 1)²/(2σ₁²) + ln(σ₀/σ₁); Pe = ½[Q((1 − ỹ)/σ₁) + Q(ỹ/σ₀)].
Numerical example
σ₀² = 0.1, σ₁² = 0.4: ỹ ≈ 0.46, Pe = ½[Q(0.54/0.632) + Q(0.46/0.316)] = ½[Q(0.85) + Q(1.46)] ≈ 0.135.
Common mistakes
Comparing only the exponents and dropping 1/σ gives the wrong threshold; each error event uses its own σ; the quadratic has two roots, take the one between 0 and 1.
Variations
Equal variances → ỹ = 0.5, Pe = Q(0.5/σ). Unequal priors → MAP, add ln P(x) inside the log; the threshold moves towards the less likely symbol.

时延扩展造成的误码平台与最高速率

Original question · 中英对照Practice 3

Using the approximation \(P_{floor}\approx\left(\dfrac{\sigma_{T_m}}{T_b}\right)^2\) for a BPSK system, determine the data rate of a QPSK system that can be transmitted through a channel with delay spread \(\sigma_{T_m}\) = 3 µs, such that the irreducible error floor is \(10^{-3}\).

利用 BPSK 系统的近似式 \(P_{floor}\approx\left(\dfrac{\sigma_{T_m}}{T_b}\right)^2\)，求 QPSK 系统在时延扩展 \(\sigma_{T_m}\) = 3 µs 的信道上、不可约误码平台（irreducible error floor）为 \(10^{-3}\) 时能传输的数据速率。

误码平台符号时长 vs 比特时长讲义第 3 章 p.35–36
  1. 平台公式里起作用的是"回声长度 / 符号长度"。BPSK 一个符号就是一个比特，所以公式写 \(T_b\)；换成 QPSK 要用符号时长 \(T_s\)。
  2. \((3\,\mu s/T_s)^2=10^{-3}\) → \(3/T_s=0.0316\) → \(T_s=94.9\) µs。
  3. QPSK 每符号 2 bit：\(R_b=2/T_s=2/94.9\,\mu s=21.08\) kbps。（同样条件下 BPSK 只有 10.54 kbps。）
R ≈ 21.08 kbps
官方答案：21.08 kbps ✓
◆ 本题知识点
考什么
时延扩展造成的不可消除误码平台；比特时长和符号时长的换算（第 3 章 p.35）。
前置知识
M 进制每符号 log₂M bit：Rb = log₂M / Ts；QPSK 的 M = 4。
解题套路
由平台要求求最短符号时长 T = σTm/√Pfloor，再换成比特速率。
关键公式
(σTm/T)² = Pfloor → T = 3 µs / √10⁻³ = 3/0.0316 = 94.9 µs → Rb = 2/94.9 µs = 21.08 kbps。
易错
公式里的 T 是符号时长（ISI 取决于回声相对一个符号多长）；直接当成比特时长会得到 10.54 kbps；σTm 是 rms 时延扩展，不是最大时延。
对比
多普勒平台 ½(πfDTb)² 要求符号短（速率下限），时延扩展平台要求符号长（速率上限），两者同时存在时速率要落在两者之间。
物理意义
"平台"是指 SNR 再高误码率也降不下去：误码来自信号自己的回声，不是噪声。解决办法是均衡（第 6 章）或 OFDM（第 7 章）。
  1. What matters in the floor formula is "echo length / symbol length". For BPSK a symbol is one bit, so the formula uses \(T_b\); for QPSK use the symbol duration \(T_s\).
  2. \((3\,\mu s/T_s)^2=10^{-3}\) → \(3/T_s=0.0316\) → \(T_s=94.9\) µs.
  3. QPSK carries 2 bits per symbol: \(R_b=2/T_s=2/94.9\,\mu s=21.08\) kbps. (Under the same conditions BPSK gives only 10.54 kbps.)
R ≈ 21.08 kbps
Official answer: 21.08 kbps ✓
◆ Key points
What it tests
The irreducible error floor caused by delay spread; converting between bit and symbol durations (Ch 3 p.35).
Background
M-ary signalling carries log₂M bits per symbol: Rb = log₂M / Ts; QPSK has M = 4.
Method
From the floor requirement find the shortest symbol duration T = σTm/√Pfloor, then convert to a bit rate.
Key formula
(σTm/T)² = Pfloor → T = 3 µs / √10⁻³ = 3/0.0316 = 94.9 µs → Rb = 2/94.9 µs = 21.08 kbps.
Common mistakes
T in the formula is the symbol duration (ISI depends on how long the echo is compared with one symbol); treating it as a bit duration gives 10.54 kbps. σTm is the rms delay spread, not the maximum delay.
Contrast
The Doppler floor ½(πfDTb)² needs short symbols (a minimum rate); the delay-spread floor needs long symbols (a maximum rate). With both present, the rate must lie between the two limits.
Physical meaning
A "floor" means the error rate stops falling however high the SNR: the errors come from the signal's own echoes, not from noise. The remedies are equalisation (Ch 6) or OFDM (Ch 7).
