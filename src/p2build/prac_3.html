知识讲解把波形当成向量：信号空间

讲义第 3 章 p.4–8 的核心思想：M 个有限能量的信号 si(t) 都可以写成 D 个基函数（basis function）的线性组合 \(s_i(t)=\sum_{j=1}^{D}s_{ij}\psi_j(t)\)，D ≤ M。这和平面上的向量一模一样：ψj 是坐标轴，sij 是坐标。

平面向量信号空间
单位向量 x̂、ŷ基函数 ψ₁(t)、ψ₂(t)
点积 a·b内积 \(\langle a,b\rangle=\int_0^Ta(t)b(t)dt\)（相乘再积分）
x̂·ŷ = 0，x̂·x̂ = 1正交归一（orthonormal）：\(\int_0^T\psi_i\psi_j\,dt=1\)（i = j），0（i ≠ j）
坐标 = 向量在轴上的投影\(s_{ij}=\int_0^Ts_i(t)\psi_j(t)dt\)
向量长度²信号能量 E = Σjsij²

维数 D = 需要几个坐标轴，和信号有多少个无关。把所有信号画成点就是星座图（signal constellation，p.8）：PAM 是 1 维（p.9），PSK、QAM 是 2 维（p.10–11）。老师课上强调：基函数是正交归一的，不只是正交；还要会判断一个调制方式是几维。

详细解析(a) 找基：拆开 → 验正交 → 归一化

  1. 做什么：用和角公式拆开 \(A_i\cos(2\pi t/T+\phi_j)=A_i\cos\phi_j\cdot\cos(2\pi t/T)-A_i\sin\phi_j\cdot\sin(2\pi t/T)\)。为什么：把"携带信息、不随 t 变的数"（Aicosφj、Aisinφj）和"随 t 变的波形"分开。不随 t 变的数就是坐标，随 t 变的波形就是坐标轴的候选。
  2. 候选方向：所有信号都只用到 cos(2πt/T) 和 sin(2πt/T) 两个波形。
  3. 验正交：用 sin 2a = 2 sin a cos a，\(\int_0^T\cos(2\pi t/T)\sin(2\pi t/T)dt=\tfrac12\int_0^T\sin(4\pi t/T)dt=0\)，因为 sin(4πt/T) 在 0 到 T 上正好两个完整周期，正负面积抵消。
  4. 求能量：用 cos²a = (1 + cos 2a)/2，\(\int_0^T\cos^2(2\pi t/T)dt=\tfrac T2+\tfrac12\int_0^T\cos(4\pi t/T)dt=T/2\)；sin² 同样是 T/2。
  5. 归一化：能量是 T/2，要变成 1，就除以 √(T/2)，即乘 √(2/T)。
∫₀T cos·sin dt = 0（正交）
∫₀T cos² dt = ∫₀T sin² dt = T/2
ψ₁(t) = √(2/T) cos(2πt/T)，ψ₂(t) = √(2/T) sin(2πt/T)，0 ≤ t ≤ T

顺便得到每个信号的坐标：si = (Aicosφj√(T/2), −Aisinφj√(T/2))，到原点的距离 Ai√(T/2) = √E，正好是信号能量的平方根，可以用来自检。

详细解析(b) 维数

  1. (a) 用了两个基函数，所以 D = 2。
  2. 为什么不是更多：不管 Ai、φj 取多少个值，所有信号都在这个平面里。
  3. 为什么不是 1：φ 在变，cos 和 sin 两个分量都会出现，而且 sin 不能由 cos 表示（两者正交）。如果 φ 固定（只调幅度），就只剩一个方向，D = 1（PAM）。

老师说这类题可以直接出成考题，并会追问"还能怎么问"，比如"这是什么调制"：幅度和相位都调 → QAM。

易错常见丢分点

  • 归一化系数写成 1/√T 或 √T：cos² 在一个周期上积分是 T/2，不是 T，系数是 √(2/T)。
  • 只验了正交没归一化（或反过来），两个条件都要写。
  • 以为 Ai、φj 取值越多维数越大：维数只看基函数个数。
  • sin 前面的负号放进坐标里，基函数本身取 +sin 或 −sin 都对（基不唯一，旋转一下仍正交归一），写最自然的那组即可。

考试英文写法

(a) Using cos(a + b) = cos a cos b − sin a sin b: \(A_i\cos(2\pi t/T+\phi_j)=A_i\cos\phi_j\cos(2\pi t/T)-A_i\sin\phi_j\sin(2\pi t/T)\), so every signal is a linear combination of cos(2πt/T) and sin(2πt/T).

They are orthogonal: \(\int_0^T\cos(2\pi t/T)\sin(2\pi t/T)dt=\tfrac12\int_0^T\sin(4\pi t/T)dt=0\). Each has energy \(\int_0^T\cos^2(2\pi t/T)dt=T/2\), so dividing by √(T/2) gives the orthonormal basis \(\psi_1(t)=\sqrt{2/T}\cos(2\pi t/T)\), \(\psi_2(t)=\sqrt{2/T}\sin(2\pi t/T)\), 0 ≤ t ≤ T.

(b) Two basis functions are needed, so the dimension is D = 2. Each signal is the point (Aicosφj√(T/2), −Aisinφj√(T/2)) in this plane (a QAM constellation).

一句话：用和角公式把信号拆成 cos 和 sin 两个方向，它们正交、能量各为 T/2，乘 √(2/T) 归一化就是基；两个基函数，维数是 2。

场景题目在讲一件什么事

从光盘（磁盘）读数据：每个位置存的是 0 或 1，读出来的值 y = x + 噪声。

特别之处：噪声大小和存的是什么有关。存 1 时噪声更大（σ₁ > σ₀）。读到一个 y，要判断原来存的是 0 还是 1。

符号题目里每个量是什么

\(x_n\in\{0,1\}\)存的比特，0 和 1 各占一半
\(w_n\)噪声，高斯；x = 0 时方差 σ₀²，x = 1 时方差 σ₁²
\(y_n\)读出来的值，也就是判决用的变量
ML 检测最大似然（maximum likelihood）：比较"存 0 时读到这个 y 的可能性"和"存 1 时读到这个 y 的可能性"，选大的

要求每一问在问什么

  • (a) 写出 ML 判决规则：y 大于某个门限 ỹ 判 1，否则判 0。要求把门限用 σ₀²、σ₁² 表示出来。
  • (b) 求误码率：存 0 被误判成 1，和存 1 被误判成 0，两种错误各占一半。

注意读题容易误会的地方

  • 噪声方差相等时门限就是中点 0.5；这里不相等，门限会偏，不能直接用 0.5。
  • 0、1 等概，所以 ML 和 MAP（最大后验）结果一样。

目的这道题想让你明白什么

ML 门限是两条似然曲线（两个 PDF）的交点，不一定在中点：哪一边噪声大，门限就往另一边让。

一句话：读到 y，比较"存 0 时出现 y"和"存 1 时出现 y"的概率密度，哪个大判哪个；两边噪声不一样大，所以门限不在 0.5。
  1. 发 0 时 \(y\sim\mathcal N(0,\sigma_0^2)\)，发 1 时 \(y\sim\mathcal N(1,\sigma_1^2)\)。ML：哪个似然大判哪个。
  2. 判 1 当 \(\dfrac{1}{\sigma_1}e^{-(y-1)^2/2\sigma_1^2}>\dfrac{1}{\sigma_0}e^{-y^2/2\sigma_0^2}\)，取对数：
    g(y) = y²/(2σ₀²) − (y − 1)²/(2σ₁²) + ln(σ₀/σ₁) > 0
  3. g(y) = 0 是关于 y 的二次方程，取在 0 与 1 之间的根作为门限 ỹ：y > ỹ 判 1，y < ỹ 判 0。方差相等时 ỹ = 0.5；σ₁ > σ₀ 时 ỹ 往 0 那边移。
  4. (b) 两种错误：发 0、噪声把 y 推过 ỹ，概率 \(Q(\tilde y/\sigma_0)\)；发 1、y 掉到 ỹ 以下，概率 \(Q((1-\tilde y)/\sigma_1)\)。等概各乘 ½。
x̂ₙ = 1 当 yₙ > ỹ，否则 0；Pe = ½[Q((1 − ỹ)/σ₁) + Q(ỹ/σ₀)]
官方答案：同上 ✓
数字感受：σ₀² = 0.1、σ₁² = 0.4 时，g(y) = 3.75y² + 2.5y − 1.943，ỹ ≈ 0.46。严格说二次方程在很负的 y 处还有第二个根（那里也会判 1），概率极小，答案忽略。
知识讲解 + 详细解析：方差不等时的 ML 门限与误码率

知识讲解ML 检测：比较两条似然曲线

最大似然（maximum likelihood, ML）检测（讲义第 3 章 p.18–20）：收到 y 以后，对每个可能发送的 x 算似然 f(y | x)，"如果发的是 x，收到这个 y 的可能性有多大"，选最大的那个。由贝叶斯公式（p.20），后验 P(x | y) ∝ f(y | x)P(x)；0、1 等概时 P(x) 相同，所以 ML = MAP（最大后验），也就是误码率最小的检测器。

本题的似然：y = x + w，所以 y 的 PDF 就是噪声的 PDF 平移到 x（老师课上的说法）：发 0 时 \(y\sim\mathcal N(0,\sigma_0^2)\)，发 1 时 \(y\sim\mathcal N(1,\sigma_1^2)\)。

情况门限在哪原因
σ₀ = σ₁（讲义的标准情况）中点 0.5ML = 最小距离，选离 y 最近的点
σ₁ > σ₀（本题）两条 PDF 的交点，比 0.5 靠近 0发 1 的 PDF 又矮又宽，在中点处反而更高

例：σ₀² = 0.1、σ₁² = 0.4 时，在 y = 0.5 处 f(0.5 | 0) = 0.361，f(0.5 | 1) = 0.461，判 1 的似然更大，所以门限要往 0 那边移。

详细解析(a) 推导判决门限

  1. 写两个似然（系数不能丢）：判 1 当 \(\frac{1}{\sqrt{2\pi}\sigma_1}e^{-(y-1)^2/2\sigma_1^2}\gt\frac{1}{\sqrt{2\pi}\sigma_0}e^{-y^2/2\sigma_0^2}\)。√(2π) 两边约掉，1/σ 约不掉。
  2. 取 ln：ln 是增函数，不改变不等号方向，指数变成多项式：\(g(y)=\frac{y^2}{2\sigma_0^2}-\frac{(y-1)^2}{2\sigma_1^2}+\ln\frac{\sigma_0}{\sigma_1}\gt0\)。
  3. 整理成二次式：两边乘 2σ₀²σ₁²（正数，不等号不变）：\((\sigma_1^2-\sigma_0^2)y^2+2\sigma_0^2y-\sigma_0^2-\sigma_0^2\sigma_1^2\ln(\sigma_1^2/\sigma_0^2)\gt0\)。
  4. 求门限：二次项系数 σ₁² − σ₀² > 0，抛物线开口向上，两根之外 g > 0。取 0 和 1 之间的那个根作门限 ỹ（老师说门限只取正根）：
    \(\tilde y=\dfrac{-\sigma_0^2+\sqrt{\sigma_0^4+(\sigma_1^2-\sigma_0^2)\big(\sigma_0^2+\sigma_0^2\sigma_1^2\ln(\sigma_1^2/\sigma_0^2)\big)}}{\sigma_1^2-\sigma_0^2}\)
  5. 判决规则：y > ỹ 判 1，y < ỹ 判 0。
数值例 σ₀² = 0.1，σ₁² = 0.4：
g(y) = 3.75y² + 2.5y − 1.943
两根：ỹ = 0.46（门限），另一根 −1.13
若忘了系数 1/σ：门限变成 0.33（错）

负根 −1.13 是什么：y 极负时，宽的 N(1, σ₁²) 尾巴比窄的 N(0, σ₀²) 厚，所以那里也判 1。但发 0 时 y 落到那里的概率只有约 2 × 10⁻⁴，标准答案忽略它，误码率只差约 10⁻⁴。

自检：σ₀ = σ₁ 时二次项消失，剩 2σ₀²y − σ₀² = 0，ỹ = 0.5，回到中点 ✓。

详细解析(b) 误码率：两种错误分别算

  1. 全概率：\(P_e=P(x=0)P(\text{判 1}\mid0)+P(x=1)P(\text{判 0}\mid1)\)，两个先验都是 ½。
  2. 发 0 判成 1：积分区间是 ỹ 到 ∞（老师强调要写对区间）。换元 u = y/σ₀：\(P(y\gt\tilde y\mid0)=Q(\tilde y/\sigma_0)\)。
  3. 发 1 判成 0：区间 −∞ 到 ỹ。换元 u = (y − 1)/σ₁，再用对称性：\(P(y\lt\tilde y\mid1)=P(u\lt(\tilde y-1)/\sigma_1)=Q\big((1-\tilde y)/\sigma_1\big)\)。
  4. 合起来：\(P_e=\tfrac12\big[Q(\tilde y/\sigma_0)+Q\big((1-\tilde y)/\sigma_1\big)\big]\)。注意两项用各自的 σ。
数值例：ỹ/σ₀ = 0.460/0.3162 = 1.455，(1 − ỹ)/σ₁ = 0.540/0.6325 = 0.854
Pe = ½[Q(1.455) + Q(0.854)] = ½[0.0728 + 0.1966] = 0.135
对比用中点 0.5：½[Q(1.581) + Q(0.791)] = 0.136，ML 门限更好一点 ✓

老师说 (b) 这种"写积分区间 → 换元成 Q 函数"的步骤后面 Practice 还会反复出现，期末经常以不同形式考到。

易错常见丢分点

  • 只比较指数、丢掉系数 1/σ₀、1/σ₁：门限会错（数值例里 0.33 对 0.46）。
  • 两种错误用同一个 σ：发 0 用 σ₀，发 1 用 σ₁。
  • 二次方程有两个根，取 0 和 1 之间的那个；ln(σ₀/σ₁) 是负数，别丢符号。
  • 直接写门限 0.5：那只在方差相等时成立。

ConceptML detection: compare two likelihood curves

Maximum likelihood (ML) detection (lecture Ch 3 p.18–20): after receiving y, compute for each possible x the likelihood f(y | x), "how likely is this y if x was sent", and choose the largest. By Bayes' rule (p.20) the posterior P(x | y) ∝ f(y | x)P(x); with 0 and 1 equally likely, P(x) is the same for both, so ML = MAP (maximum a posteriori), the detector with the smallest error probability.最大似然（maximum likelihood, ML）检测（讲义第 3 章 p.18–20）：收到 y 以后，对每个可能发送的 x 算似然 f(y | x)，"如果发的是 x，收到这个 y 的可能性有多大"，选最大的那个。由贝叶斯公式（p.20），后验 P(x | y) ∝ f(y | x)P(x)；0、1 等概时 P(x) 相同，所以 ML = MAP（最大后验），也就是误码率最小的检测器。
