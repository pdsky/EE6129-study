P6 · Q1

二进制 PAM：加不加这个均衡器

Original question · 中英对照Practice 6

Figure 1 shows a discrete-time model of a binary PAM communication system: \(a(n)\sqrt{E_b}\to H(z)\to(+w(n))\to U(z)\to z(n)\to\) Detector \(\to\hat a(n)\).

图 1 是二进制 PAM 通信系统的离散时间模型：\(a(n)\sqrt{E_b}\to H(z)\to(+w(n))\to U(z)\to z(n)\to\) 检测器 \(\to\hat a(n)\)。

In the Figure, w(n) is a white Gaussian noise with the autocorrelation function, \(R_w(k)=\dfrac{N_0}{2}\delta(k)\).

图中 w(n) 是高斯白噪声，自相关函数为 \(R_w(k)=\dfrac{N_0}{2}\delta(k)\)。

The channel, H(Z), introduces Inter-Symbol Interference (ISI) and is modelled as, \(H(Z)=1+\alpha Z^{-1},\ 0<\alpha<\tfrac12\).

信道 H(Z) 会引入符号间干扰（ISI），模型为 \(H(Z)=1+\alpha Z^{-1},\ 0\lt\alpha\lt\tfrac12\)。

The transmitted data is modelled as a sequence of independent and identically distributed symbols, \(\{a_n\}\), where \(a_n\) is equally likely to be ±1. The detector detects the transmitted data according to the following rule, \(\hat a(n)=1\) if \(z(n)\ge0\), −1 if \(z(n)<0\).

发送数据建模为独立同分布的符号序列 \(\{a_n\}\)，\(a_n\) 等概取 ±1。检测器按如下规则判决：\(z(n)\ge0\) 时 \(\hat a(n)=1\)，\(z(n)\lt0\) 时 \(\hat a(n)=-1\)。

Consider an equalizer design, where \(U(z)=1-\alpha z^{-1}\).

考虑一种均衡器设计：\(U(z)=1-\alpha z^{-1}\)。

(a) Derive the expressions for the average bit error probability when no equalizer is used and when the above equalizer is used.

(a) 分别推导不用均衡器和使用上述均衡器时平均误比特概率的表达式。

(b) The system is to operate at high signal-to-noise ratio. Will it be better for the system to operate with or without the above equalizer? Explain your answer.

(b) 系统将工作在高信噪比下。用还是不用上述均衡器更好？说明理由。

ISI 条件误码率滤波后噪声方差高 SNR 看最坏项讲义第 6 章 p.22–28
  1. 记 \(A=\sqrt{2E_b/N_0}\)。没有 ISI 时 \(P_e=Q(A)\)：信号幅度 \(\sqrt{E_b}\)，噪声标准差 \(\sqrt{N_0/2}\)。
  2. (a) 不均衡：\(z(n)=\sqrt{E_b}(a_n+\alpha a_{n-1})+w(n)\)。前一个符号同号时幅度 \((1+\alpha)\sqrt{E_b}\)，异号时 \((1-\alpha)\sqrt{E_b}\)，各一半：
    Pe = ½Q((1 − α)A) + ½Q((1 + α)A)
  3. 加均衡：总响应 \(H(z)U(z)=(1+\alpha z^{-1})(1-\alpha z^{-1})=1-\alpha^2z^{-2}\)，ISI 从 α 降到 α²，但噪声也经过 U(z)：方差变成 \(\tfrac{N_0}{2}(1+\alpha^2)\)（系数平方和）。
  4. \(z(n)=\sqrt{E_b}(a_n-\alpha^2a_{n-2})+w'(n)\)，幅度 \((1\pm\alpha^2)\sqrt{E_b}\)，标准差放大 \(\sqrt{1+\alpha^2}\)：
    Pe = ½Q( (1 − α²)/√(1 + α²) · A ) + ½Q( (1 + α²)/√(1 + α²) · A )
  5. (b) 高 SNR 时误码率由 Q 参数最小的那一项决定。比较：不均衡 \(1-\alpha\)；均衡 \((1-\alpha^2)/\sqrt{1+\alpha^2}\)。
  6. \(\dfrac{1-\alpha^2}{\sqrt{1+\alpha^2}}>1-\alpha\ \Leftrightarrow\ \dfrac{1+\alpha}{\sqrt{1+\alpha^2}}>1\ \Leftrightarrow\ (1+\alpha)^2>1+\alpha^2\ \Leftrightarrow\ 2\alpha>0\)，对 α > 0 总成立。
(b) 加均衡器更好：最坏情况的"有效距离"更大。例 α = 0.4：不均衡 0.6，均衡 0.78
官方答案：表达式同上；(b) Better to operate with the proposed equalizer ✓
◆ 本题知识点
考什么
ISI 信道的误码率；均衡器的权衡：ISI 减小 vs 噪声放大；高 SNR 下的比较（第 6 章 p.22–28）。
前置知识
Z 变换相乘 = 滤波器串联；白噪声过 FIR 后方差 σ²Σc²；条件误码率再平均；高 SNR 时误码率由 Q 参数最小的那一项决定。
解题套路
不均衡：ISI 前一个符号同号 / 异号两种情况，各 ½。加均衡：信号经过 H(z)U(z) = 1 − α²z⁻²，噪声只经过 U(z)，方差变成 (N₀/2)(1 + α²)，再分两种情况。
关键比较
(1 − α²)/√(1 + α²) > 1 − α ⇔ (1 + α)/√(1 + α²) > 1 ⇔ (1 + α)² > 1 + α² ⇔ 2α > 0，对 α > 0 总成立。
易错
噪声只经过 U(z)，不经过 H(z)；均衡后残余 ISI 是 −α²，位置在 n − 2，不是 0；Q 里除的是 √(1 + α²) 倍的标准差。
数值例
α = 0.4：最坏项参数不均衡 0.6，均衡 0.84/1.077 = 0.78，所以加均衡器更好。
联系
期末 Q2(a) 四年考了四次，都是"残余 ISI a + 放大后的噪声 σ′"，公式 ½[Q((1 − a)/σ′) + Q((1 + a)/σ′)]。
  1. Let \(A=\sqrt{2E_b/N_0}\). Without ISI \(P_e=Q(A)\): signal amplitude \(\sqrt{E_b}\), noise standard deviation \(\sqrt{N_0/2}\).
  2. (a) No equaliser: \(z(n)=\sqrt{E_b}(a_n+\alpha a_{n-1})+w(n)\). If the previous symbol has the same sign the amplitude is \((1+\alpha)\sqrt{E_b}\), otherwise \((1-\alpha)\sqrt{E_b}\), each half the time:
    Pe = ½Q((1 − α)A) + ½Q((1 + α)A)
  3. With the equaliser: overall response \(H(z)U(z)=(1+\alpha z^{-1})(1-\alpha z^{-1})=1-\alpha^2z^{-2}\), so the ISI drops from α to α²; but the noise also passes through U(z) and its variance becomes \(\tfrac{N_0}{2}(1+\alpha^2)\) (sum of squared coefficients).
  4. \(z(n)=\sqrt{E_b}(a_n-\alpha^2a_{n-2})+w^{\prime}(n)\): amplitudes \((1\pm\alpha^2)\sqrt{E_b}\), standard deviation scaled by \(\sqrt{1+\alpha^2}\):
    Pe = ½Q( (1 − α²)/√(1 + α²) · A ) + ½Q( (1 + α²)/√(1 + α²) · A )
  5. (b) At high SNR the error rate is dominated by the term with the smallest Q argument. Compare: without equaliser \(1-\alpha\); with equaliser \((1-\alpha^2)/\sqrt{1+\alpha^2}\).
  6. \(\dfrac{1-\alpha^2}{\sqrt{1+\alpha^2}}>1-\alpha\ \Leftrightarrow\ \dfrac{1+\alpha}{\sqrt{1+\alpha^2}}>1\ \Leftrightarrow\ (1+\alpha)^2>1+\alpha^2\ \Leftrightarrow\ 2\alpha>0\), which always holds for α > 0.
(b) Better with the equaliser: the worst-case effective distance is larger. E.g. α = 0.4: 0.6 without, 0.78 with
Official answer: expressions as above; (b) Better to operate with the proposed equalizer ✓
◆ Key points
What it tests
Error rate of an ISI channel; the equaliser trade-off between less ISI and more noise; comparison at high SNR (Ch 6 p.22–28).
Background
Multiplying Z-transforms = cascading filters; white noise through an FIR filter has variance σ²Σc²; average the conditional error rates; at high SNR the smallest Q argument dominates.
Method
Without equaliser: the previous symbol has the same or opposite sign, ½ each. With equaliser: the signal sees H(z)U(z) = 1 − α²z⁻², the noise sees only U(z) and its variance becomes (N₀/2)(1 + α²); again two cases.
Key comparison
(1 − α²)/√(1 + α²) > 1 − α ⇔ (1 + α)/√(1 + α²) > 1 ⇔ (1 + α)² > 1 + α² ⇔ 2α > 0, always true for α > 0.
Common mistakes
The noise goes through U(z) only, not H(z); after equalisation the residual ISI is −α² at position n − 2, not zero; divide by √(1 + α²) times the standard deviation inside Q.
Numbers
α = 0.4: worst-case argument 0.6 without the equaliser, 0.84/1.077 = 0.78 with it, so the equaliser is better.

P6 · Q2

ISI 信道：直接判决 vs 理想迫零

Original question · 中英对照Practice 6

Consider the following discrete time model for binary transmission over an ISI channel. \(y_n=b_n+a\cdot b_{n-1}+w_n\), where \(b_n\in\{\pm1\}\) is the nth transmitted bit, a is a fixed real coefficient, 0 < a < 1 and \(w_n\) is i.i.d. zero-mean Gaussian with variance 0.1. \(\{b_n\}\) are equally likely and independent in n.

考虑如下 ISI 信道上二进制传输的离散时间模型：\(y_n=b_n+a\cdot b_{n-1}+w_n\)，其中 \(b_n\in\{\pm1\}\) 是第 n 个发送比特，a 是固定的实系数，0 < a < 1，\(w_n\) 是 i.i.d. 零均值高斯噪声，方差为 0.1。\(\{b_n\}\) 等概，且对不同 n 相互独立。

(a) Find the bit error probability \(P(\hat b_n\ne b_n)\) if \(\hat b_n=\mathrm{sgn}(y_n)\).

(a) 若判决 \(\hat b_n=\mathrm{sgn}(y_n)\)，求误比特概率 \(P(\hat b_n\ne b_n)\)。

(b) Find the resulting BER if an ideal zero-forcing equalizer is used and the decision is made based on the sign of the equalizer output.

(b) 若使用理想迫零（zero-forcing）均衡器，并根据均衡器输出的正负号判决，求所得的 BER。

条件误码率求平均迫零噪声放大等比级数讲义第 6 章 p.23–28
  1. (a) 设 \(b_n=+1\)：\(b_{n-1}=+1\) 时幅度 1 + a，\(b_{n-1}=-1\) 时幅度 1 − a，噪声标准差 √0.1：
    Pe = ½Q((1 + a)/√0.1) + ½Q((1 − a)/√0.1)
  2. (b) 理想迫零：\(C(z)=\dfrac{1}{1+az^{-1}}=\sum_{k\ge0}(-a)^kz^{-k}\)（|a| < 1 收敛），输出 \(b_n\) + 滤波后的噪声。
  3. 噪声方差 = 0.1 × 系数平方和 = \(0.1\sum_k a^{2k}=\dfrac{0.1}{1-a^2}\)。
  4. \(P_e=Q\!\left(\dfrac{1}{\sqrt{0.1/(1-a^2)}}\right)=Q\!\left(\sqrt{\dfrac{1-a^2}{0.1}}\right)\)。
(a) ½Q((1+a)/√0.1) + ½Q((1−a)/√0.1)；(b) Q(√((1−a²)/0.1))
官方答案：同上 ✓
比较：ZF 的 Q 参数是 √(1−a²)/√0.1，不均衡最坏项是 (1−a)/√0.1。√(1−a²) = √((1−a)(1+a)) > 1−a，所以高 SNR 时 ZF 更好；但 a 接近 1 时 ZF 把噪声放大很多。
◆ 本题知识点
考什么
直接判决（不均衡）和理想迫零均衡下的误码率（第 6 章 p.23–28）。
前置知识
条件误码率再平均；ZF：C(z) = 1/H(z)；等比级数 Σa2k = 1/(1 − a²)；滤波后噪声方差 σ²Σc²。
解题套路
(a) bn−1 = ±1 两种情况，信号离门限 1 ± a，标准差 √0.1；(b) 1/(1 + az⁻¹) = Σ(−a)kz−k，ISI 消失，噪声方差 0.1/(1 − a²)，只剩一项 Q。
数值例
a = 0.5：(a) ½[Q(4.74) + Q(1.58)] ≈ 0.028；(b) Q(√7.5) = Q(2.74) ≈ 0.0031，ZF 好约 9 倍。
比较
高 SNR 时比较最坏的 Q 参数：ZF 是 √(1 − a²)，不均衡是 1 − a；√(1 − a²) = √((1 − a)(1 + a)) > 1 − a，所以 ZF 更好。但 a → 1 时噪声放大 1/(1 − a²) 趋于无穷。
易错
√0.1 是标准差，0.1 是方差；ZF 后没有 ISI，不要再分情况；不均衡时别只算 Q((1 − a)/σ) 一项。
  1. (a) Take \(b_n=+1\): if \(b_{n-1}=+1\) the amplitude is 1 + a, if \(b_{n-1}=-1\) it is 1 − a; the noise standard deviation is √0.1:
    Pe = ½Q((1 + a)/√0.1) + ½Q((1 − a)/√0.1)
  2. (b) Ideal zero forcing: \(C(z)=\dfrac{1}{1+az^{-1}}=\sum_{k\ge0}(-a)^kz^{-k}\) (converges for |a| < 1); the output is \(b_n\) plus filtered noise.
  3. Noise variance = 0.1 × sum of squared coefficients = \(0.1\sum_k a^{2k}=\dfrac{0.1}{1-a^2}\).
  4. \(P_e=Q\!\left(\dfrac{1}{\sqrt{0.1/(1-a^2)}}\right)=Q\!\left(\sqrt{\dfrac{1-a^2}{0.1}}\right)\).
(a) ½Q((1+a)/√0.1) + ½Q((1−a)/√0.1); (b) Q(√((1−a²)/0.1))
Official answer: same as above ✓
Comparison: the ZF Q argument is √(1−a²)/√0.1, the worst no-equaliser term is (1−a)/√0.1. Since √(1−a²) = √((1−a)(1+a)) > 1−a, ZF is better at high SNR; but as a → 1 ZF amplifies the noise heavily.
◆ Key points
What it tests
Error rate with direct decisions (no equaliser) and with an ideal zero-forcing equaliser (Ch 6 p.23–28).
Background
Average the conditional error rates; ZF: C(z) = 1/H(z); geometric series Σa2k = 1/(1 − a²); filtered-noise variance σ²Σc².
Method
(a) Two cases bn−1 = ±1, distances 1 ± a from the threshold, standard deviation √0.1. (b) 1/(1 + az⁻¹) = Σ(−a)kz−k; ISI vanishes, noise variance 0.1/(1 − a²), a single Q term.
Numbers
a = 0.5: (a) ½[Q(4.74) + Q(1.58)] ≈ 0.028; (b) Q(√7.5) = Q(2.74) ≈ 0.0031, ZF about 9 times better.
Comparison
At high SNR compare the worst Q arguments: ZF √(1 − a²), no equaliser 1 − a; √(1 − a²) = √((1 − a)(1 + a)) > 1 − a, so ZF is better. But as a → 1 the noise amplification 1/(1 − a²) blows up.
Common mistakes
√0.1 is the standard deviation, 0.1 the variance; after ZF there is no ISI, so no case split; without the equaliser do not keep only the Q((1 − a)/σ) term.
P6 · Q3

MMSE 线性均衡 vs 判决反馈均衡

Original question · 中英对照Practice 6

Consider transmitting i.i.d. and equally likely binary amplitudes \(A_n\in\{\pm1\}\) over a 2-tap discrete-time ISI channel. The received samples can be expressed as, \(y_n=A_nx_0+A_{n-1}x_1+z_n\), where \(\{z_n\}\) is i.i.d. zero mean Gaussian noise, with variance \(\sigma^2\). Assume \(x_0=1\), \(x_1=1/2\), and \(\sigma^2=1\).

考虑在 2 抽头离散时间 ISI 信道上传输 i.i.d.、等概的二进制幅度 \(A_n\in\{\pm1\}\)。接收样本为 \(y_n=A_nx_0+A_{n-1}x_1+z_n\)，其中 \(\{z_n\}\) 是 i.i.d. 零均值高斯噪声，方差为 \(\sigma^2\)。设 \(x_0=1\)，\(x_1=1/2\)，\(\sigma^2=1\)。

(a) Consider a linear equalizer, that has a parameter q and the decision variable, \(u_n=y_n+qy_{n+1}\). Determine q such that \(E[(u_n-A_n)^2]\) is minimized. With decisions based on the sign of \(u_n\), i.e. \(\hat A_n=\mathrm{sgn}(u_n)\), what is the resulting error probability?

(a) 考虑一个带参数 q 的线性均衡器，判决变量为 \(u_n=y_n+qy_{n+1}\)。求使 \(E[(u_n-A_n)^2]\) 最小的 q。若按 \(u_n\) 的正负号判决，即 \(\hat A_n=\mathrm{sgn}(u_n)\)，错误概率是多少？

(b) Consider a simple decision-feedback equalizer, that forms the decision variable, \(u_n=y_n-\hat A_{n-1}x_1\). \(\hat A_n\) is determined based on the sign of \(u_n\), \(\hat A_{n-1}\) is determined based on the sign of \(u_{n-1}\), etc. Assume that "time" starts at n = 1 and that \(A_0=0\). Determine the resulting error probability for large n (n → ∞).

(b) 考虑一个简单的判决反馈均衡器（DFE），判决变量为 \(u_n=y_n-\hat A_{n-1}x_1\)。\(\hat A_n\) 由 \(u_n\) 的正负号决定，\(\hat A_{n-1}\) 由 \(u_{n-1}\) 的正负号决定，依此类推。设“时间”从 n = 1 开始，且 \(A_0=0\)。求 n 很大（n → ∞）时的错误概率。

MMSE 求最优系数DFE 错误传播马尔可夫稳态讲义第 6 章 p.26–34
  1. (a) 展开：\(u_n=A_n+\tfrac12A_{n-1}+z_n+q\big(A_{n+1}+\tfrac12A_n+z_{n+1}\big)\)，所以 \(u_n-A_n=\tfrac q2A_n+\tfrac12A_{n-1}+qA_{n+1}+z_n+qz_{n+1}\)。
  2. 各项独立、均值 0，均方值相加：\(E[(u_n-A_n)^2]=\tfrac{q^2}4+\tfrac14+q^2+1+q^2=1.25+2.25q^2\)，q = 0 最小。
  3. q = 0 时 \(u_n=y_n\)，幅度 1.5 或 0.5：
    Pe = ½Q(1.5) + ½Q(0.5) = ½(0.0668) + ½(0.3085) = 0.188
  4. (b) 上一次判对：ISI 完全减掉，\(u_n=A_n+z_n\)，出错概率 \(Q(1)=0.159\)。
  5. 上一次判错（\(\hat A_{n-1}=-A_{n-1}\)）：\(u_n=A_n+A_{n-1}+z_n\)，幅度 2 或 0 各一半，出错概率 \(\tfrac12Q(2)+\tfrac12\cdot\tfrac12=0.261\)。
  6. 设长期误码率 p：\(p=(1-p)\times0.159+p\times0.261\) → \(p=\dfrac{0.159}{1-0.261+0.159}=0.177\)。
(a) q = 0，Pe ≈ 0.19；(b) Pe ≈ 0.18
官方答案：(a) q = 0，Pe ≈ 0.19；(b) Pe ≈ 0.18 ✓
如果没有错误传播，DFE 的误码率就是 Q(1) = 0.159；错误传播让它升到 0.177，但仍比线性均衡的 0.188 好。
◆ 本题知识点
考什么
MMSE 线性均衡和判决反馈均衡 DFE 的误码率；DFE 的错误传播（第 6 章 p.26–34）。
前置知识
独立零均值随机变量的均方值相加；An² = 1；全概率公式；线性方程求稳态。
解题套路
(a) 把 un − An 拆成独立项 → 均方误差 1.25 + 2.25q² → 求导得 q = 0 → un = yn，幅度 1.5 或 0.5 → 平均。(b) 列条件误码率：上次对 → Q(1)；上次错 → ½Q(2) + ½ × ½ → 解稳态方程。
为什么 q = 0
用未来样本 yn+1 能多拿到 ½An 的有用信号，但同时带进 An+1 的干扰和 zn+1 的噪声，得不偿失，所以最优是不用它。
关键公式
DFE 稳态：p = (1 − p)·0.159 + p·0.261 → p = 0.159/(1 − 0.261 + 0.159) = 0.177。
易错
展开时漏了 (q/2)An 项；上次判错时幅度是 2 或 0（ISI 加倍），幅度 0 时误码 ½；稳态方程别解错。
结论
线性 0.188 > DFE 0.177 > 无错误传播的 DFE 0.159：DFE 不放大噪声，但错误传播吃掉了一部分优势（p.34）。
  1. (a) Expand: \(u_n=A_n+\tfrac12A_{n-1}+z_n+q\big(A_{n+1}+\tfrac12A_n+z_{n+1}\big)\), so \(u_n-A_n=\tfrac q2A_n+\tfrac12A_{n-1}+qA_{n+1}+z_n+qz_{n+1}\).
  2. All terms are independent with zero mean, so their mean squares add: \(E[(u_n-A_n)^2]=\tfrac{q^2}4+\tfrac14+q^2+1+q^2=1.25+2.25q^2\), minimised at q = 0.
  3. With q = 0, \(u_n=y_n\) and the amplitude is 1.5 or 0.5:
    Pe = ½Q(1.5) + ½Q(0.5) = ½(0.0668) + ½(0.3085) = 0.188
  4. (b) Previous decision correct: the ISI is cancelled exactly, \(u_n=A_n+z_n\), error probability \(Q(1)=0.159\).
  5. Previous decision wrong (\(\hat A_{n-1}=-A_{n-1}\)): \(u_n=A_n+A_{n-1}+z_n\), amplitude 2 or 0 with equal probability, error probability \(\tfrac12Q(2)+\tfrac12\cdot\tfrac12=0.261\).
  6. Let p be the long-run error rate: \(p=(1-p)\times0.159+p\times0.261\) → \(p=\dfrac{0.159}{1-0.261+0.159}=0.177\).
(a) q = 0, Pe ≈ 0.19; (b) Pe ≈ 0.18
Official answer: (a) q = 0, Pe ≈ 0.19; (b) Pe ≈ 0.18 ✓
Without error propagation the DFE error rate would be Q(1) = 0.159; error propagation raises it to 0.177, still better than the linear equaliser's 0.188.
◆ Key points
What it tests
Error rates of an MMSE linear equaliser and a decision-feedback equaliser; DFE error propagation (Ch 6 p.26–34).
Background
Mean squares of independent zero-mean variables add; An² = 1; total probability; solving a linear equation for the steady state.
Method
(a) Split un − An into independent terms → MSE 1.25 + 2.25q² → derivative gives q = 0 → un = yn, amplitude 1.5 or 0.5 → average. (b) Conditional error rates: previous correct → Q(1); previous wrong → ½Q(2) + ½ × ½ → solve the steady-state equation.
Why q = 0
Using the future sample yn+1 adds ½An of useful signal but also brings in An+1 interference and zn+1 noise; the net effect is negative, so the best choice is not to use it.
Key formula
DFE steady state: p = (1 − p)·0.159 + p·0.261 → p = 0.159/(1 − 0.261 + 0.159) = 0.177.
Common mistakes
Dropping the (q/2)An term when expanding; after a wrong decision the amplitude is 2 or 0 (the ISI doubles), and amplitude 0 gives error probability ½; solving the steady-state equation incorrectly.
Conclusion
Linear 0.188 > DFE 0.177 > DFE without error propagation 0.159: the DFE does not amplify noise, but error propagation eats part of the advantage (p.34).
