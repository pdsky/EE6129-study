题意讲解：这道题到底要干嘛

场景题目在讲一件什么事

二进制 PAM：发 ±1。信道 H(z) = 1 + αz⁻¹ 的意思是：每个接收样本 = 当前符号 + α × 上一个符号（回声）+ 噪声，上一个符号漏进来就是码间干扰（ISI）。检测器按 z(n) 的正负判决。

有人提议加一个均衡器 U(z) = 1 − αz⁻¹，想抵消回声。但均衡器不只作用在信号上，也作用在噪声上。

符号题目里每个量是什么

\(a(n)=\pm1\)发送符号，等概、独立
\(E_b\)比特能量
\(R_w(k)=\tfrac{N_0}{2}\delta(k)\)白噪声，方差 N₀/2
α（0 < α < ½）回声强度
\(z^{-1}\)延迟一个采样

要求每一问在问什么

  • (a) 分别求不加均衡器、加均衡器时的平均误码率。要考虑上一个（或前两个）符号是同号还是异号，两种情况各占一半。
  • (b) 高 SNR 时，加还是不加更好？解释理由。

注意读题容易误会的地方

  • 这个均衡器并没有把 ISI 完全消掉：总响应是 1 − α²z⁻²，剩下一个更小的回声 α²，在两个采样之后。
  • 噪声也经过 U(z)，方差变成 (N₀/2)(1 + α²)，被放大了。
  • 高 SNR 时，误码率由 Q 参数最小的那一项（最坏情况）决定，比较最坏情况即可。

目的这道题想让你明白什么

均衡器是在"减少 ISI"和"放大噪声"之间做交换，要比较的是最坏情况下的有效距离。

一句话：信道有一个强度 α 的回声，比较不均衡和用 1 − αz⁻¹ 均衡时的误码率，看高 SNR 下哪个更好。
  1. 记 \(A=\sqrt{2E_b/N_0}\)。没有 ISI 时 \(P_e=Q(A)\)：信号幅度 \(\sqrt{E_b}\)，噪声标准差 \(\sqrt{N_0/2}\)。
  2. (a) 不均衡：\(z(n)=\sqrt{E_b}(a_n+\alpha a_{n-1})+w(n)\)。前一个符号同号时幅度 \((1+\alpha)\sqrt{E_b}\)，异号时 \((1-\alpha)\sqrt{E_b}\)，各一半：
    Pe = ½Q((1 − α)A) + ½Q((1 + α)A)
  3. 加均衡：总响应 \(H(z)U(z)=(1+\alpha z^{-1})(1-\alpha z^{-1})=1-\alpha^2z^{-2}\)，ISI 从 α 降到 α²，但噪声也经过 U(z)：方差变成 \(\tfrac{N_0}{2}(1+\alpha^2)\)（系数平方和）。
  4. \(z(n)=\sqrt{E_b}(a_n-\alpha^2a_{n-2})+w'(n)\)，幅度 \((1\pm\alpha^2)\sqrt{E_b}\)，标准差放大 \(\sqrt{1+\alpha^2}\)：
    Pe = ½Q( (1 − α²)/√(1 + α²) · A ) + ½Q( (1 + α²)/√(1 + α²) · A )
  5. (b) 高 SNR 时误码率由 Q 参数最小的那一项决定。比较：不均衡 \(1-\alpha\)；均衡 \((1-\alpha^2)/\sqrt{1+\alpha^2}\)。
  6. \(\dfrac{1-\alpha^2}{\sqrt{1+\alpha^2}}>1-\alpha\ \Leftrightarrow\ \dfrac{1+\alpha}{\sqrt{1+\alpha^2}}>1\ \Leftrightarrow\ (1+\alpha)^2>1+\alpha^2\ \Leftrightarrow\ 2\alpha>0\)，对 α > 0 总成立。
(b) 加均衡器更好：最坏情况的"有效距离"更大。例 α = 0.4：不均衡 0.6，均衡 0.78
官方答案：表达式同上；(b) Better to operate with the proposed equalizer ✓
知识讲解 + 详细解析：ISI 误码率与均衡器的取舍

知识讲解ISI 信道、Z 变换和"滤波后的噪声"

离散时间 ISI 模型（第 6 章 p.22）：接收样本 = 当前符号 + 前面符号漏过来的部分（码间干扰 ISI）+ 噪声。用 Z 变换写：z⁻¹ 表示"晚一个采样"，所以 H(z) = 1 + αz⁻¹ 的意思是"当前符号 × 1 + 上一个符号 × α"。两个滤波器串联，Z 变换相乘：Q(z) = H(z)U(z)。

关键：信号和噪声走的路不一样。信号先过信道 H(z) 再过均衡器 U(z)；噪声是在信道之后加进来的，只过 U(z)。白噪声（方差 σ²）过一个系数为 c₀, c₁, … 的 FIR 滤波器后，方差变成 σ²(c₀² + c₁² + …)（各项独立，方差相加，p.25、p.27）。老师课上强调：均衡器有几个抽头，噪声就变成几项，每项平方再相加，这就是噪声增强（noise enhancement）。

有 ISI 时的误码率（p.27–28）：先固定 ISI 符号，算条件误码率 Q(信号到门限的距离 / 噪声标准差)，再按 ISI 符号每种取值的概率平均。没有 ISI 时：幅度 √Eb，噪声标准差 √(N₀/2)，Pe = Q(√Eb / √(N₀/2)) = Q(√(2Eb/N₀))。下面记 A = √(2Eb/N₀)。

高 SNR 怎么比：Q(x) 随 x 增大下降得极快（大约像 e−x²/2）。几个 Q 相加时，参数最小的那一项远大于其他项，误码率几乎就等于它。所以高 SNR 时只比"最坏情况的 Q 参数"。

详细解析(a) 不加均衡器

  1. 写出判决变量。z(n) = √Eb(an + α an−1) + w(n)。
  2. 只算 an = +1。为什么：±1 等概、判决门限 0 对称，两种情况误码率一样。出错 ⇔ z(n) < 0。
  3. 按上一个符号分两种情况，各占 ½。an−1 = +1（同号）：均值 (1 + α)√Eb，回声帮忙，P = Q((1 + α)A)；an−1 = −1（异号）：均值 (1 − α)√Eb，回声捣乱，P = Q((1 − α)A)。
Pe = ½Q((1 − α)A) + ½Q((1 + α)A)，A = √(2Eb/N₀)

详细解析(a) 加均衡器 U(z) = 1 − αz⁻¹

  1. 信号的总响应。(1 + αz⁻¹)(1 − αz⁻¹) = 1 − α²z⁻²。ISI 没有完全消掉，只是从"上一个符号 × α"变成"前两个符号 × (−α²)"，小了很多（α < ½ 时 α² < ¼）。原因：1/H(z) = 1 − αz⁻¹ + α²z⁻² − …（长除法），U(z) 只取了前两项，是截断的迫零均衡器。
  2. 噪声。w′(n) = w(n) − αw(n − 1)，方差 = (N₀/2)(1² + α²) = (N₀/2)(1 + α²)，标准差放大 √(1 + α²) 倍。w′(n) 在相邻时刻相关，但每次判决只看一个样本，只需要它的方差。
  3. 两种情况。z(n) = √Eb(an − α²an−2) + w′(n)。an−2 = +1：幅度 (1 − α²)√Eb（注意现在是同号时变差）；an−2 = −1：幅度 (1 + α²)√Eb。Q 的参数 = 幅度 / 标准差 = (1 ∓ α²)√Eb / √((N₀/2)(1 + α²)) = (1 ∓ α²)/√(1 + α²) · A。
Pe = ½Q( (1 − α²)/√(1 + α²) · A ) + ½Q( (1 + α²)/√(1 + α²) · A )

详细解析(b) 高 SNR 加不加

比较两种情况最坏项的 Q 参数（都去掉公共的 A）：不加是 1 − α，加是 (1 − α²)/√(1 + α²)。

(1 − α²)/√(1 + α²) > 1 − α ⇔ (1 + α)/√(1 + α²) > 1 ⇔ (1 + α)² > 1 + α² ⇔ 2α > 0

第一步两边同除以 (1 − α) > 0；平方时两边都为正，不改变方向。α > 0 时总成立，所以加均衡器更好：ISI 减小带来的好处大于噪声放大的损失。

α = 0.4最坏项参数A = 2A = 3
不加0.6APe = 0.0588Pe = 0.0180
加0.84/1.077·A = 0.78APe = 0.0375Pe = 0.0051

A = 3 时，不加均衡器的 Pe = 0.0180 几乎全来自 ½Q(1.8) = 0.0180，另一项 ½Q(4.2) 只有约 7 × 10⁻⁶，这就是"高 SNR 只看最坏项"。

课外补充为什么题目要说"高 SNR"

讲义没有这一点，是用上面的公式算的：α = 0.4 时，如果 A 小于约 1.06（Eb/N₀ 低于约 −2.5 dB），不加均衡器反而略好（A = 1：不加 0.1775，加 0.1792）。噪声占主导时，均衡器放大噪声的坏处更明显。所以结论要加"高 SNR"这个前提。

易错常见丢分点

  • 噪声只经过 U(z)，不经过 H(z)；不要把噪声方差也乘上 H(z) 的系数。
  • 均衡后的残余 ISI 是 −α²，位置在 n − 2，不是 0，也不是 n − 1。
  • Q 里分母是标准差 √(1 + α²)·√(N₀/2)，不是方差。
  • 只写最坏项、漏了 ½ 或漏了另一项；(a) 要的是完整表达式。
  • (b) 只给结论不给比较过程拿不到满分，要写出 2α > 0 那一串。

Concept + walkthrough: ISI error rate, equaliser trade-off

ConceptISI channel, Z-transform and "filtered noise"

Discrete-time ISI model (Ch 6 p.22): received sample = current symbol + leakage from earlier symbols (inter-symbol interference, ISI) + noise. In Z-transform notation z⁻¹ means "one sample later", so H(z) = 1 + αz⁻¹ means "current symbol × 1 + previous symbol × α". Two filters in cascade multiply their Z-transforms: Q(z) = H(z)U(z).

Key point: signal and noise take different paths. The signal goes through the channel H(z) and then the equaliser U(z); the noise is added after the channel and goes only through U(z). White noise (variance σ²) through an FIR filter with coefficients c₀, c₁, … has variance σ²(c₀² + c₁² + …) (independent terms, variances add; p.25, p.27). Lecturer's emphasis: the noise becomes as many terms as the equaliser has taps; square each and add to get the output noise power. This is noise enhancement.

Error rate with ISI (p.27–28): first fix the ISI symbols and compute the conditional error rate Q(distance from signal to threshold / noise standard deviation), then average over the probabilities of the ISI symbol values. Without ISI: amplitude √Eb, noise standard deviation √(N₀/2), Pe = Q(√Eb / √(N₀/2)) = Q(√(2Eb/N₀)). Below, A = √(2Eb/N₀).

How to compare at high SNR: Q(x) falls extremely fast as x grows (roughly like e−x²/2). In a sum of Q terms the one with the smallest argument is far larger than the others and the error rate is essentially that term. So at high SNR we compare only the "worst-case Q arguments".

Step by step(a) Without the equaliser

  1. Write the decision variable. z(n) = √Eb(an + α an−1) + w(n).
  2. Take only an = +1. Why: ±1 are equally likely and the threshold 0 is symmetric, so both cases have the same error rate. Error ⇔ z(n) < 0.
  3. Two cases for the previous symbol, ½ each. an−1 = +1 (same sign): mean (1 + α)√Eb, the echo helps, P = Q((1 + α)A); an−1 = −1 (opposite sign): mean (1 − α)√Eb, the echo hurts, P = Q((1 − α)A).
Pe = ½Q((1 − α)A) + ½Q((1 + α)A), A = √(2Eb/N₀)

Step by step(a) With the equaliser U(z) = 1 − αz⁻¹

  1. Overall signal response. (1 + αz⁻¹)(1 − αz⁻¹) = 1 − α²z⁻². The ISI is not removed completely; it changes from "previous symbol × α" to "symbol two back × (−α²)", much smaller (α < ½ gives α² < ¼). Reason: 1/H(z) = 1 − αz⁻¹ + α²z⁻² − … (long division), and U(z) keeps only the first two terms: a truncated zero-forcing equaliser.
  2. Noise. w′(n) = w(n) − αw(n − 1), variance = (N₀/2)(1² + α²) = (N₀/2)(1 + α²); the standard deviation grows by √(1 + α²). w′(n) is correlated between neighbouring instants, but each decision uses one sample, so only its variance matters.
  3. Two cases. z(n) = √Eb(an − α²an−2) + w′(n). an−2 = +1: amplitude (1 − α²)√Eb (note: now the same sign is the bad case); an−2 = −1: amplitude (1 + α²)√Eb. Q argument = amplitude / standard deviation = (1 ∓ α²)√Eb / √((N₀/2)(1 + α²)) = (1 ∓ α²)/√(1 + α²) · A.
Pe = ½Q( (1 − α²)/√(1 + α²) · A ) + ½Q( (1 + α²)/√(1 + α²) · A )

Step by step(b) With or without at high SNR

Compare the worst-case Q arguments (dropping the common A): without, 1 − α; with, (1 − α²)/√(1 + α²).

(1 − α²)/√(1 + α²) > 1 − α ⇔ (1 + α)/√(1 + α²) > 1 ⇔ (1 + α)² > 1 + α² ⇔ 2α > 0

The first step divides both sides by (1 − α) > 0; squaring keeps the direction because both sides are positive. This holds for every α > 0, so it is better with the equaliser: the gain from less ISI outweighs the loss from noise enhancement.

PitfallsWhere marks are lost

  • The noise goes through U(z) only, not H(z); do not multiply the noise variance by the coefficients of H(z).
  • After equalisation the residual ISI is −α² at position n − 2, not 0 and not at n − 1.
  • The denominator inside Q is the standard deviation √(1 + α²)·√(N₀/2), not the variance.
  • Writing only the worst term, or dropping the ½ or the other term; (a) asks for the full expression.
  • In (b) a bare conclusion without the comparison does not earn full marks; write out the chain down to 2α > 0.

Amplitudes \((1\mp\alpha^2)\sqrt{E_b}\): \(P_e=\tfrac12Q\big(\tfrac{1-\alpha^2}{\sqrt{1+\alpha^2}}A\big)+\tfrac12Q\big(\tfrac{1+\alpha^2}{\sqrt{1+\alpha^2}}A\big)\).

(b) At high SNR \(P_e\) is dominated by the smallest Q argument. \(\tfrac{1-\alpha^2}{\sqrt{1+\alpha^2}}\gt1-\alpha\Leftrightarrow(1+\alpha)^2\gt1+\alpha^2\Leftrightarrow2\alpha\gt0\), true for α > 0. Hence it is better to operate with the equaliser: the reduction in ISI outweighs the noise enhancement.

In one line: without: ½Q((1 − α)A) + ½Q((1 + α)A); with 1 − αz⁻¹: ISI becomes −α² and the noise variance is multiplied by (1 + α²), giving ½Q((1 − α²)A/√(1 + α²)) + ½Q((1 + α²)A/√(1 + α²)); at high SNR compare the worst terms, (1 + α)² > 1 + α², so the equaliser is better.

知识讲解迫零均衡器（ZF）和噪声放大

迫零（zero-forcing）的目标是把 ISI 压到零（第 6 章 p.23）：让信道和均衡器串起来的总响应等于 1，即 H(z)C(z) = 1，C(z) = 1/H(z)。"理想"迫零就是这个逆滤波器的所有抽头都用上，输出完全没有 ISI。

怎么求 1/H(z)：长除法（p.24 例题；老师课上强调：迫零的长除法必须会）。1 除以 (1 + az⁻¹)：

  1. 商的第一项 1：1 − 1·(1 + az⁻¹) = −az⁻¹（余数）。
  2. 商的第二项 −az⁻¹：−az⁻¹ − (−az⁻¹)(1 + az⁻¹) = a²z⁻²。
  3. 商的第三项 a²z⁻²，余数 −a³z⁻³ ……每次乘 −a。
C(z) = 1/(1 + az⁻¹) = 1 − az⁻¹ + a²z⁻² − a³z⁻³ + … = Σk≥0 (−a)kz−k

|a| < 1 时这个无穷级数收敛。抽头有无穷多个，实际只能取前几个（取前两个就是 P6 Q1 的 1 − αz⁻¹）。

噪声放大：噪声只过 C(z)，方差 = σ² × 系数平方和（p.25、p.27）。等比级数 1 + a² + a⁴ + … = 1/(1 − a²)，所以输出噪声方差 = σ²/(1 − a²)，比 σ² 大；a 越接近 1，放大越厉害。老师说：迫零只管 ISI、不管噪声，所以在 p.35 的比较图里它最差。

详细解析(a) 直接按 yn 的正负判决

  1. 只算 bn = +1。±1 对称，误码率一样；出错 ⇔ yn < 0。

Pe = ½Q((1 + a)/√0.1) + ½Q((1 − a)/√0.1)

详细解析(b) 理想迫零后判决

  1. 信号：H(z)C(z) = 1，输出就是 bn，没有 ISI，不用再分情况。
  2. 噪声：wn 过 C(z)，系数 1, −a, a², −a³, …，平方和 1 + a² + a⁴ + … = 1/(1 − a²)：
    输出噪声方差 = 0.1/(1 − a²)
  3. 误码率：距离 1，标准差 √(0.1/(1 − a²))：

Concept + walkthrough: direct decision vs ideal ZF

ConceptZero-forcing (ZF) equaliser and noise enhancement

The goal of zero forcing is to drive the ISI to zero (Ch 6 p.23): make the cascade of channel and equaliser equal to 1, i.e. H(z)C(z) = 1, C(z) = 1/H(z). "Ideal" zero forcing uses all taps of this inverse filter, so the output has no ISI at all.

How to find 1/H(z): long division (example on p.24; lecturer's emphasis: ZF long division is a must). Divide 1 by (1 + az⁻¹):

  1. First quotient term 1: 1 − 1·(1 + az⁻¹) = −az⁻¹ (remainder).
  2. Second quotient term −az⁻¹: −az⁻¹ − (−az⁻¹)(1 + az⁻¹) = a²z⁻².
  3. Third quotient term a²z⁻², remainder −a³z⁻³ … each step multiplies by −a.
C(z) = 1/(1 + az⁻¹) = 1 − az⁻¹ + a²z⁻² − a³z⁻³ + … = Σk≥0 (−a)kz−k

For |a| < 1 this infinite series converges. It has infinitely many taps; in practice only the first few are used (the first two give the 1 − αz⁻¹ of P6 Q1).

Noise enhancement: the noise passes only through C(z), so its variance = σ² × sum of squared coefficients (p.25, p.27). The geometric series 1 + a² + a⁴ + … = 1/(1 − a²), so the output noise variance is σ²/(1 − a²), larger than σ²; the closer a is to 1, the worse. The lecturer says ZF only cares about ISI, not noise, which is why it is the worst in the comparison figure on p.35.

Step by step(a) Decide directly on the sign of yn

  1. Take only bn = +1. ±1 are symmetric, same error rate; error ⇔ yn < 0.
  2. Two cases for the previous bit, ½ each. bn−1 = +1: yn = 1 + a + wn, distance 1 + a from the threshold; bn−1 = −1: distance 1 − a.
  3. Noise standard deviation. Variance 0.1 → standard deviation √0.1 = 0.316. P(1 + a + w < 0) = P(w < −(1 + a)) = Q((1 + a)/√0.1).
Pe = ½Q((1 + a)/√0.1) + ½Q((1 − a)/√0.1)

Step by step(b) Decide after ideal zero forcing

  1. Signal: H(z)C(z) = 1, the output is just bn, no ISI, no case split.
  2. Noise: wn goes through C(z) with coefficients 1, −a, a², −a³, …; sum of squares 1 + a² + a⁴ + … = 1/(1 − a²):
    Output noise variance = 0.1/(1 − a²)
  3. Error rate: distance 1, standard deviation √(0.1/(1 − a²)):
    Pe = Q(1/√(0.1/(1 − a²))) = Q(√((1 − a²)/0.1))

知识讲解 + 详细解析：MMSE 均衡与 DFE 错误传播

知识讲解MMSE 准则和判决反馈均衡（DFE）

MMSE（最小均方误差，minimum mean-square error）（第 6 章 p.26）：选均衡器系数，让输出和真实符号的差的平方的平均值 E[(un − An)²] 最小。它同时考虑 ISI 和噪声，不像迫零只管 ISI。

求法的关键工具：如果 X₁, X₂, … 相互独立、均值都是 0，那么 E[(X₁ + X₂ + …)²] = E[X₁²] + E[X₂²] + …（交叉项的期望都是 0）。这里 An² = 1，噪声 E[z²] = σ² = 1。

DFE（decision-feedback equalizer）（p.29–34）：前馈部分处理"未来"符号的 ISI，反馈部分用已经判出来的过去符号把它们的 ISI 直接减掉。好处：减法不经过滤波器，不会放大噪声。坏处：如果上一次判错，减掉的是错的值，ISI 反而变大，下一次更容易错，叫错误传播（error propagation，p.34）。老师课上强调：DFE 不用从头推到尾，但要知道两个滤波器各管什么，这类题"靠逻辑多于靠记忆"。

长期误码率：第 n 次出错的概率取决于第 n − 1 次对不对（全概率公式）：pn = P(错 | 上次对)(1 − pn−1) + P(错 | 上次错)pn−1。n → ∞ 时 pn = pn−1 = p，解一个一次方程就行。

详细解析(a) 求最优 q 和误码率

  1. 展开 un。yn = An + ½An−1 + zn，yn+1 = An+1 + ½An + zn+1，所以
    un − An = (q/2)An + ½An−1 + qAn+1 + zn + qzn+1
    注意 (q/2)An：un 里 An 的系数是 1 + q/2，多出来的 q/2 也算误差。
  2. 求均方误差。五项独立、均值 0，平方的期望直接相加：
    E[(un − An)²] = q²/4 + 1/4 + q² + 1 + q² = 1.25 + 2.25q²
  3. 求最小。对 q 求导：4.5q = 0 → q = 0，最小均方误差 1.25。直观理由：yn+1 里只有 An+1、An 和 zn+1，根本不含 An−1，没法抵消 ½An−1 这个 ISI；它带进来的全是新的误差，所以最好不用它。
  4. 误码率。q = 0 时 un = yn。设 An = +1：An−1 = +1 时幅度 1.5，An−1 = −1 时幅度 0.5，噪声标准差 1：
    Pe = ½Q(1.5) + ½Q(0.5) = ½(0.0668) + ½(0.3085) = 0.188 ≈ 0.19

详细解析(b) DFE 的长期误码率

  1. 写出判决变量。un = yn − ½Ân−1 = An + ½(An−1 − Ân−1) + zn。
  2. 上一次判对（Ân−1 = An−1）：括号为 0，un = An + zn，ISI 被完全减掉：
    P(错 | 上次对) = Q(1) = 0.159
  3. 上一次判错（Ân−1 = −An−1）：括号 = 2An−1，un = An + An−1 + zn，ISI 从 ½ 变成 1（加倍）。设 An = +1：同号时幅度 2，出错 Q(2) = 0.0228；异号时幅度 0，纯靠噪声正负，出错 ½。两种各 ½（An 和过去无关）：
    P(错 | 上次错) = ½Q(2) + ½ × ½ = 0.0114 + 0.25 = 0.261
  4. 列稳态方程。
    p = (1 − p) × 0.159 + p × 0.261 → p(1 − 0.261 + 0.159) = 0.159 → p = 0.159/0.898 = 0.177 ≈ 0.18

"时间从 n = 1 开始、A₀ = 0"的作用：第一个符号前面没有 ISI，p₁ = Q(1) = 0.159。之后按上面的递推：p₂ = 0.175，p₃ = 0.1766，p₄ = 0.1768，很快收敛到 0.177。

Concept + walkthrough: MMSE linear eq. vs DFE

ConceptThe MMSE criterion and the decision-feedback equaliser (DFE)

MMSE (minimum mean-square error) (Ch 6 p.26): choose the equaliser coefficients to minimise the average squared difference between the output and the true symbol, E[(un − An)²]. It accounts for both ISI and noise, unlike zero forcing, which only cares about ISI.

The key tool: if X₁, X₂, … are independent with zero mean, then E[(X₁ + X₂ + …)²] = E[X₁²] + E[X₂²] + … (all cross terms have zero expectation). Here An² = 1 and the noise has E[z²] = σ² = 1.

DFE (decision-feedback equaliser) (p.29–34): the feedforward part handles ISI from "future" symbols; the feedback part uses past symbols that have already been decided to subtract their ISI directly. Advantage: the subtraction does not pass through a filter, so the noise is not enhanced. Drawback: if the previous decision was wrong, the wrong value is subtracted and the ISI grows, making the next decision more likely to fail: error propagation (p.34). Lecturer's emphasis: you need not derive the DFE end to end, but you must know what each filter does; such questions rely "more on logic than on memory".

Long-run error rate: the probability of an error at time n depends on whether decision n − 1 was right (total probability): pn = P(error | previous correct)(1 − pn−1) + P(error | previous wrong)pn−1. As n → ∞, pn = pn−1 = p, and one linear equation gives p.

Step by step(a) Optimal q and error rate

  1. Expand un. yn = An + ½An−1 + zn, yn+1 = An+1 + ½An + zn+1, so
    un − An = (q/2)An + ½An−1 + qAn+1 + zn + qzn+1
    Note the (q/2)An: the coefficient of An in un is 1 + q/2, and the extra q/2 also counts as error.
  2. Mean-square error. Five independent zero-mean terms, so the squared expectations simply add:
    E[(un − An)²] = q²/4 + 1/4 + q² + 1 + q² = 1.25 + 2.25q²
  3. Minimise. Differentiate with respect to q: 4.5q = 0 → q = 0, minimum MSE 1.25. Intuition: yn+1 contains only An+1, An and zn+1 and does not contain An−1 at all, so it cannot cancel the ISI term ½An−1; everything it brings in is new error, so it is best not to use it.
  4. Error rate. With q = 0, un = yn. Take An = +1: amplitude 1.5 if An−1 = +1, 0.5 if An−1 = −1; noise standard deviation 1:
    Pe = ½Q(1.5) + ½Q(0.5) = ½(0.0668) + ½(0.3085) = 0.188 ≈ 0.19

Step by step(b) Long-run error rate of the DFE

  1. Write the decision variable. un = yn − ½Ân−1 = An + ½(An−1 − Ân−1) + zn.
  2. Previous decision correct (Ân−1 = An−1): the bracket is 0, un = An + zn, the ISI is removed completely:
    P(error | previous correct) = Q(1) = 0.159
  3. Previous decision wrong (Ân−1 = −An−1): the bracket is 2An−1, un = An + An−1 + zn, the ISI grows from ½ to 1 (doubles). Take An = +1: same sign gives amplitude 2, error Q(2) = 0.0228; opposite sign gives amplitude 0, decided purely by the sign of the noise, error ½. Each case has prob. ½ (An is independent of the past):
    P(error | previous wrong) = ½Q(2) + ½ × ½ = 0.0114 + 0.25 = 0.261
  4. Steady-state equation.
    p = (1 − p) × 0.159 + p × 0.261 → p(1 − 0.261 + 0.159) = 0.159 → p = 0.159/0.898 = 0.177 ≈ 0.18

What "time starts at n = 1 and A₀ = 0" does: the first symbol has no ISI, so p₁ = Q(1) = 0.159. Then by the recursion above: p₂ = 0.175, p₃ = 0.1766, p₄ = 0.1768, quickly converging to 0.177.
