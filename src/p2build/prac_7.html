P7 · Q1

两径信道上的 OFDM：选 N、算 H_k、分功率

Original question · 中英对照Practice 7

An OFDM signal x(t) is transmitted through a multi-path channel. The received signals can be expressed as, \(y(t)=h_0x(t)+h_1x(t-\tau)+w(t)\), where \(h_0,h_1\) are independent channel gains, τ is the time delay, and w(t) is the AWGN with zero-mean and variance \(\sigma^2=1\). The Doppler spread and Coherence bandwidth have been measured to be \(B_d\) and \(B_C\) respectively.

OFDM 信号 x(t) 经过多径信道传输，接收信号为 \(y(t)=h_0x(t)+h_1x(t-\tau)+w(t)\)，其中 \(h_0,h_1\) 是相互独立的信道增益，τ 是时延，w(t) 是零均值、方差 \(\sigma^2=1\) 的 AWGN。测得多普勒扩展为 \(B_d\)，相干带宽为 \(B_C\)。

(a) Given a fixed total bandwidth B Hz, the number of sub-carriers N needs to be carefully selected so that each sub-channel could be regarded as experiencing slow flat fading. Explain the principle of how the value of N is selected.

(a) 在总带宽 B Hz 固定的情况下，需要合理选择子载波数 N，使每个子信道都可以看作慢、平坦衰落。说明 N 的选取原则。

(b) For N = 4, \(h_0\) = 0.8, and \(h_1\) = 0.6, find the values of the channel gain coefficients \(H_k\) for each sub-channel.

(b) 当 N = 4、\(h_0\) = 0.8、\(h_1\) = 0.6 时，求各子信道的信道增益系数 \(H_k\)。

(c) Given the value of \(H_k\) from (b), the transmitter allocates power \(P_k\) to the kth sub-channel such that each sub-channel has the same capacity. Under the sum-power constraint, \(\sum_{k=1}^{N}P_k=10\), find the value of \(P_k\) for each sub-channel.

(c) 已知 (b) 中的 \(H_k\)，发射端给第 k 个子信道分配功率 \(P_k\)，使所有子信道的容量相同。在总功率约束 \(\sum_{k=1}^{N}P_k=10\) 下，求每个子信道的 \(P_k\)。

(d) Given the same value of \(H_k\) and the sum-power constraint from (c), find the maximum sum capacity in bits per second per Hertz.

(d) 在相同的 \(H_k\) 和 (c) 的总功率约束下，求最大和容量（bit/s/Hz）。

慢平坦衰落条件H_k = DFT{h}等容量分配注水讲义第 7 章 p.5、p.15、p.24
  1. (a) 平坦：子信道宽 B/N 要远小于相干带宽 → \(N\gg B/B_C\)。慢衰落：OFDM 符号时长约 N/B，要远小于相干时间 1/B_d → \(N\ll B/B_d\)。所以 \(B/B_C\ll N\ll B/B_d\)。
  2. (b) \(H_k=h_0+h_1e^{-j2\pi k/N}=0.8+0.6e^{-j\pi k/2}\)：
    H₀ = H₄ = 1.4，H₁ = 0.8 − 0.6j，H₂ = 0.2，H₃ = 0.8 + 0.6j
    功率增益 |H_k|²（k = 1, 2, 3, 4）：1、0.04、1、1.96。
  3. (c) 容量 \(\log_2(1+|H_k|^2P_k)\) 相等 ⇔ \(|H_k|^2P_k=c\) 相同：\(P_k=c/|H_k|^2\)。
    c(1/1 + 1/0.04 + 1/1 + 1/1.96) = c × 27.51 = 10 → c = 0.3635
    P₁ = 0.36，P₂ = 9.09，P₃ = 0.36，P₄ = 0.19
  4. (d) 注水：池底 \(1/|H_k|^2\) = 1、25、1、0.51。四个都放水：水面 (10 + 27.51)/4 = 9.38 < 25，第 2 个子信道去掉。
  5. 剩三个：水面 μ = (10 + 1 + 1 + 0.51)/3 = 4.17，功率 3.17、3.17、3.66（都为正）。
    C = log₂(4.17 × 1) + log₂(4.17 × 1) + log₂(4.17 × 1.96) = 2.06 + 2.06 + 3.03 = 7.15 bit
  6. 这是 4 个子载波一起传的，每个子载波只占 B/4 带宽，所以每赫兹：7.15/4 = 1.79 bit/s/Hz。
(a) B/B_C ≪ N ≪ B/B_d；(b) 1.4, 0.8−0.6j, 0.2, 0.8+0.6j；(c) 0.36, 9.09, 0.36, 0.19；(d) ≈ 1.8 bit/s/Hz
官方答案：完全一致 ✓（官方把 k = 1…4 记为 H₁…H₄，H₄ = H₀ = 1.4）
对比 (c) 和 (d)：为了"人人平等"，(c) 把 91% 的功率砸在最差的子信道上；注水 (d) 干脆放弃最差的那个，总容量高得多。
◆ 本题知识点
考什么
OFDM 的四个核心计算：N 的选择、Hk、等容量功率分配、注水容量（第 7 章 p.5、p.15、p.24；第 2 章注水）。
前置知识
相干带宽 / 相干时间；欧拉公式 e−jπk/2 依次为 1、−j、−1、j；注水公式；log₂。
解题套路
(a) 平坦 N ≫ B/BC，慢衰落 N ≪ B/Bd；(b) Hk = h₀ + h₁e−j2πk/N；(c) |Hk|²Pk = c，由 ΣPk = 10 求 c；(d) 池底 1/|Hk|²，水面 μ，去掉池底高过水面的子信道。
关键数字
|Hk|² = 1、0.04、1、1.96；c = 10/27.51 = 0.3635；注水水面 4.17，功率 3.17、0、3.17、3.66；7.15 bit / 4 = 1.79 bit/s/Hz。
自检
Σ|Hk|² = N Σhi² = 4 × (0.64 + 0.36) = 4；(c)(d) 的功率加起来都是 10；被去掉的子信道 2 的池底 25 高于水面。
易错
编号 k = 1…4（H₄ = H₀）；用 |Hk|² 不是 |Hk|；噪声 σ² = 1；最后除以 N 换成 bit/s/Hz。
对比结论
等容量把 91% 的功率砸在最差的子信道上；注水干脆放弃它。要公平用 (c)，要总容量最大用 (d)。
  1. (a) Flat: the sub-channel width B/N must be much smaller than the coherence bandwidth → \(N\gg B/B_C\). Slow: the OFDM symbol duration ≈ N/B must be much shorter than the coherence time 1/Bd → \(N\ll B/B_d\). Hence \(B/B_C\ll N\ll B/B_d\).
  2. (b) \(H_k=h_0+h_1e^{-j2\pi k/N}=0.8+0.6e^{-j\pi k/2}\):
    H₀ = H₄ = 1.4, H₁ = 0.8 − 0.6j, H₂ = 0.2, H₃ = 0.8 + 0.6j
    Power gains |Hk|² (k = 1, 2, 3, 4): 1, 0.04, 1, 1.96.
  3. (c) Equal capacity \(\log_2(1+|H_k|^2P_k)\) ⇔ the same \(|H_k|^2P_k=c\): \(P_k=c/|H_k|^2\).
    c(1/1 + 1/0.04 + 1/1 + 1/1.96) = c × 27.51 = 10 → c = 0.3635
    P₁ = 0.36, P₂ = 9.09, P₃ = 0.36, P₄ = 0.19
  4. (d) Water-filling: floor levels \(1/|H_k|^2\) = 1, 25, 1, 0.51. Filling all four gives a water level (10 + 27.51)/4 = 9.38 < 25, so sub-channel 2 is dropped.
  5. With three left: level μ = (10 + 1 + 1 + 0.51)/3 = 4.17, powers 3.17, 3.17, 3.66 (all positive).
    C = log₂(4.17 × 1) + log₂(4.17 × 1) + log₂(4.17 × 1.96) = 2.06 + 2.06 + 3.03 = 7.15 bit
  6. These 7.15 bit are carried by 4 sub-carriers, each occupying B/4, so per hertz: 7.15/4 = 1.79 bit/s/Hz.
(a) B/BC ≪ N ≪ B/Bd; (b) 1.4, 0.8−0.6j, 0.2, 0.8+0.6j; (c) 0.36, 9.09, 0.36, 0.19; (d) ≈ 1.8 bit/s/Hz
Official answer: identical ✓ (the official solution labels k = 1…4 as H₁…H₄, with H₄ = H₀ = 1.4)
Compare (c) and (d): to make every sub-channel "equal", (c) spends 91% of the power on the worst sub-channel; water-filling (d) simply abandons it and gets a much higher total capacity.
◆ Key points
What it tests
The four core OFDM calculations: choosing N, Hk, equal-capacity power allocation, water-filling capacity (Ch 7 p.5, p.15, p.24; water-filling from Ch 2).
Background
Coherence bandwidth and coherence time; Euler: e−jπk/2 is 1, −j, −1, j in turn; water-filling; log₂.
Method
(a) Flat N ≫ B/BC, slow N ≪ B/Bd; (b) Hk = h₀ + h₁e−j2πk/N; (c) |Hk|²Pk = c, find c from ΣPk = 10; (d) floors 1/|Hk|², water level μ, drop sub-channels whose floor is above the water.
Key numbers
|Hk|² = 1, 0.04, 1, 1.96; c = 10/27.51 = 0.3635; water level 4.17, powers 3.17, 0, 3.17, 3.66; 7.15 bit / 4 = 1.79 bit/s/Hz.
Check
Σ|Hk|² = N Σhi² = 4 × (0.64 + 0.36) = 4; the powers in (c) and (d) both sum to 10; the dropped sub-channel 2 has floor 25, above the water level.
Common mistakes
Index k = 1…4 (H₄ = H₀); use |Hk|², not |Hk|; noise σ² = 1; divide by N at the end to get bit/s/Hz.
Conclusion
Equal capacity pours 91% of the power into the worst sub-channel; water-filling gives up on it. Use (c) for fairness, (d) for maximum total capacity.
P7 · Q2

设计一个 2 Mbps 的 OFDM 系统

Original question · 中英对照Practice 7

Consider the design of an OFDM system. The goal is to transmit data at a rate of 2 Mbps using 16-QAM with an available bandwidth of 600 kHz. It is known that the delay spread of the channel is up to a maximum of 20 μs. You can assume the cyclic prefix to be equal to the maximum delay spread. Find the total number of sub-carriers and the OFDM symbol duration.

考虑一个 OFDM 系统的设计：目标是在 600 kHz 的可用带宽内，用 16-QAM 以 2 Mbps 的速率传输数据。已知信道时延扩展最大为 20 μs，可设循环前缀等于最大时延扩展。求子载波总数和 OFDM 符号周期。

Δf = B/N循环前缀开销讲义第 7 章 p.8、p.17–18
  1. 16-QAM 每符号 4 bit：需要的总符号速率 2 Mbps / 4 = 500 k 符号/秒。
  2. N 个子载波：有用符号时长 T = N/B = N/600k，加 CP 后一个 OFDM 符号长 T + 20 µs，期间 N 个子载波各发一个符号。
  3. \(\dfrac{N}{N/600\text{k}+20\,\mu s}=500\text{k}\) → \(N=0.8333N+10\) → N = 60。
  4. T = 60/600 kHz = 100 µs；OFDM 符号总长 100 + 20 = 120 µs = 0.12 ms。
N = 60，OFDM 符号时长 0.12 ms
官方答案：60；0.12 ms ✓
如果不加 CP，600 kHz 本来就够发 500 k 符号/秒，N 取多少都行，题目就没有唯一解。正是 CP 的开销决定了 N：N 越大，CP 占的比例越小。CP 占 20/120 = 1/6 的时间，所以带宽必须比 500 k 多出 1/5，正好是 600 kHz。
◆ 本题知识点
考什么
OFDM 系统设计：子载波数、OFDM 符号时长、CP 开销（第 7 章 p.8、p.17–18）。
前置知识
有用符号时长 T = N/B = 1/Δf；一个 OFDM 块 = T + TG，期间每个子载波发一个符号。
解题套路
① 比特速率 ÷ log₂M = 需要的符号速率；② 列方程 N / (N/B + TG) = 符号速率；③ 解 N；④ T = N/B，总时长 T + TG。
关键数字
2 Mbps / 4 = 500 k 符号/秒；N = 0.8333N + 10 → N = 60；T = 100 µs，总长 120 µs。
检验
60 × 4 bit / 120 µs = 2 Mbps；CP 占 1/6 的时间，功率损失 10 log(120/100) = 0.79 dB。
举一反三
时延扩展变成 40 µs：N = 0.8333N + 20 → N = 120，T = 200 µs，总长 240 µs。时延扩展越大，需要的 N 越大，CP 的占比才不至于太高。
易错
没有 CP 时 N 取多少都行，题目就没有唯一解，所以一定要把 CP 算进时长；速率是比特速率，要先除以 4。
  1. 16-QAM carries 4 bits per symbol: the required total symbol rate is 2 Mbps / 4 = 500 k symbols/s.
  2. With N sub-carriers: useful symbol duration T = N/B = N/600k; with the CP one OFDM symbol lasts T + 20 µs, during which each of the N sub-carriers sends one symbol.
  3. \(\dfrac{N}{N/600\text{k}+20\,\mu s}=500\text{k}\) → \(N=0.8333N+10\) → N = 60.
  4. T = 60/600 kHz = 100 µs; total OFDM symbol 100 + 20 = 120 µs = 0.12 ms.
N = 60, OFDM symbol duration 0.12 ms
Official answer: 60; 0.12 ms ✓
Without the CP, 600 kHz would carry 500 k symbols/s for any N and the problem would have no unique answer. The CP overhead is what fixes N: the larger N, the smaller the CP fraction. Here the CP takes 20/120 = 1/6 of the time, so the bandwidth must exceed 500 k by 1/5, exactly 600 kHz.
◆ Key points
What it tests
OFDM system design: number of sub-carriers, OFDM symbol duration, CP overhead (Ch 7 p.8, p.17–18).
Background
Useful symbol duration T = N/B = 1/Δf; one OFDM block lasts T + TG, during which each sub-carrier sends one symbol.
Method
① Bit rate ÷ log₂M = required symbol rate; ② write N / (N/B + TG) = symbol rate; ③ solve for N; ④ T = N/B, total T + TG.
Key numbers
2 Mbps / 4 = 500 k symbols/s; N = 0.8333N + 10 → N = 60; T = 100 µs, total 120 µs.
Check
60 × 4 bit / 120 µs = 2 Mbps; the CP takes 1/6 of the time, power loss 10 log(120/100) = 0.79 dB.
Variations
With a 40 µs delay spread: N = 0.8333N + 20 → N = 120, T = 200 µs, total 240 µs. A larger delay spread needs a larger N to keep the CP fraction small.
Common mistakes
Without a CP any N would do and there would be no unique answer, so the CP must be included in the duration; the given rate is a bit rate, divide by 4 first.
P7 · Q3

最短的循环前缀

Original question · 中英对照Practice 7

The Z–transform of a mobile channel is \(H(Z)=1+0.9Z^{-1}\). In order to mitigate the ISI of this channel, the system is now designed with OFDM. What is the minimum cyclic-prefix required. Explain your answer.

某移动信道的 Z 变换为 \(H(Z)=1+0.9Z^{-1}\)。为抑制该信道的 ISI，系统改用 OFDM 设计。所需的最小循环前缀是多少？说明理由。

信道长度CP ≥ L − 1讲义第 7 章 p.17–22
  1. 冲激响应 h = [1, 0.9]：一条直射，加一条晚一个采样到达的回波，信道长度 L = 2，最大时延扩展 = 1 个采样。
  2. 上一个 OFDM 块的最后一个采样，会通过 0.9z⁻¹ 漏进下一个块的第一个采样。CP 至少要盖住这 1 个采样，才能把 ISI 挡在 CP 里（接收端丢掉 CP）。
  3. CP 用块尾的复制品，线性卷积在接收窗口里等价于循环卷积，DFT 后正好得到 \(H_ks_k\)，子载波保持正交。
最短 CP = 1 个采样（符号）长度 = L − 1
官方答案：1 symbol length ✓
◆ 本题知识点
考什么
循环前缀的最短长度（第 7 章 p.17–22）。
前置知识
Z 变换：Z⁻¹ 表示晚一个采样；L 个抽头的信道，最长回波晚 L − 1 个采样。
解题套路
由 H(Z) 读出冲激响应 h = [1, 0.9] → L = 2 → CP ≥ L − 1 = 1 个采样。
为什么够
CP ≥ L − 1 时，接收端保留的 N 个采样只含本块的数据，线性卷积变成循环卷积，DFT 后 rk = Hksk + wk（讲解页 7.4 节推导框）。
为什么复制块尾
只放一段空白也能挡住上一块的回声，但接收窗口里看到的不再是完整的周期信号，子载波失去正交，会有 ICI；复制块尾才能保持循环结构。
易错
是 L − 1 = 1 个，不是 L = 2 个；系数 0.9 的大小不影响 CP 长度，只看延迟几个采样。
举一反三
H(Z) = 1 + 0.5Z⁻³ → 延迟 3 个采样 → CP ≥ 3；换成时间就是 TG ≥ 最大时延扩展 TD。CP 每多 1 个采样，效率降为 N/(N + G)。
  1. Impulse response h = [1, 0.9]: a direct path plus an echo one sample later; channel length L = 2, maximum delay spread = 1 sample.
  2. The last sample of the previous OFDM block leaks into the first sample of the next block through 0.9z⁻¹. The CP must cover at least this 1 sample so the ISI stays inside the CP, which the receiver discards.
  3. Because the CP is a copy of the block tail, the linear convolution looks like a circular convolution inside the receive window; after the DFT this gives exactly \(H_ks_k\), and the sub-carriers stay orthogonal.
Minimum CP = 1 sample (symbol) = L − 1
Official answer: 1 symbol length ✓
◆ Key points
What it tests
The minimum cyclic-prefix length (Ch 7 p.17–22).
Background
Z-transform: Z⁻¹ means one sample later; a channel with L taps has its longest echo L − 1 samples late.
Method
Read the impulse response h = [1, 0.9] from H(Z) → L = 2 → CP ≥ L − 1 = 1 sample.
Why it is enough
With CP ≥ L − 1 the N samples kept by the receiver contain only data from the current block, the linear convolution becomes circular, and after the DFT rk = Hksk + wk (derivation box in Section 7.4 of the learning page).
Why copy the tail
An empty guard interval would also block the previous block's echo, but the receive window would no longer see a complete periodic signal, the sub-carriers would lose orthogonality and ICI would appear. Only copying the tail keeps the circular structure.
Common mistakes
It is L − 1 = 1 sample, not L = 2; the size of the coefficient 0.9 does not matter, only how many samples the echo is delayed.
Variations
H(Z) = 1 + 0.5Z⁻³ → delay 3 samples → CP ≥ 3; in time, TG ≥ the maximum delay spread TD. Each extra CP sample lowers the efficiency to N/(N + G).
