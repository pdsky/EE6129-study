Original question · 中英对照Practice 7

An OFDM signal x(t) is transmitted through a multi-path channel. The received signals can be expressed as, \(y(t)=h_0x(t)+h_1x(t-\tau)+w(t)\), where \(h_0,h_1\) are independent channel gains, τ is the time delay, and w(t) is the AWGN with zero-mean and variance \(\sigma^2=1\). The Doppler spread and Coherence bandwidth have been measured to be \(B_d\) and \(B_C\) respectively.

OFDM 信号 x(t) 经过多径信道传输，接收信号为 \(y(t)=h_0x(t)+h_1x(t-\tau)+w(t)\)，其中 \(h_0,h_1\) 是相互独立的信道增益，τ 是时延，w(t) 是零均值、方差 \(\sigma^2=1\) 的 AWGN。测得多普勒扩展为 \(B_d\)，相干带宽为 \(B_C\)。

(a) Given a fixed total bandwidth B Hz, the number of sub-carriers N needs to be carefully selected so that each sub-channel could be regarded as experiencing slow flat fading. Explain the principle of how the value of N is selected.

(a) 在总带宽 B Hz 固定的情况下，需要合理选择子载波数 N，使每个子信道都可以看作慢、平坦衰落。说明 N 的选取原则。

(b) For N = 4, \(h_0\) = 0.8, and \(h_1\) = 0.6, find the values of the channel gain coefficients \(H_k\) for each sub-channel.

(b) 当 N = 4、\(h_0\) = 0.8、\(h_1\) = 0.6 时，求各子信道的信道增益系数 \(H_k\)。

(c) Given the value of \(H_k\) from (b), the transmitter allocates power \(P_k\) to the kth sub-channel such that each sub-channel has the same capacity. Under the sum-power constraint, \(\sum_{k=1}^{N}P_k=10\), find the value of \(P_k\) for each sub-channel.

场景题目在讲一件什么事

OFDM 信号经过两径信道：\(y(t)=h_0x(t)+h_1x(t-\tau)+w(t)\)，直射一条加延迟 τ 的回波一条。

OFDM 把总带宽 B 切成 N 个子载波。题目先问 N 怎么选，再算每个子载波的增益，最后在两种原则下给子载波分功率。

符号题目里每个量是什么

\(B_d\)多普勒扩展：信道随时间变化有多快（相干时间约 1/B_d）
\(B_C\)相干带宽：频率相差多远，信道就不一样了
\(H_k\)第 k 个子载波的信道增益（复数），等于 [h₀, h₁] 的 DFT
\(P_k\)分给第 k 个子载波的功率，总和 10
σ² = 1噪声方差，所以子载波 k 的 SNR = |H_k|²P_k

要求每一问在问什么

  • (a) 解释 N 怎么选：每个子载波要窄到感受到的是平坦衰落（B/N 远小于 B_C），同时一个 OFDM 符号要短到信道在这期间几乎不变（慢衰落）。
  • (b) N = 4、h₀ = 0.8、h₁ = 0.6：算出 4 个子载波各自的 H_k。
  • (c) 按"每个子载波容量一样"的原则分配总功率 10。
  • (d) 按"总容量最大"的原则（注水）分配，求每秒每赫兹的最大总容量。

注意读题容易误会的地方

  • 题目把子载波编号成 k = 1…4，注意和 0…3 的对应关系（H₄ = H₀）。
  • (d) 要"每赫兹"：4 个子载波各占 B/4，总比特数要除以 4。
  • 注水时先检查最差的子载波要不要放弃。

知识讲解 + 详细解析：OFDM 选 N、算 H_k、分功率

知识讲解OFDM 把频率选择性信道切成 N 条平坦子信道

多径信道 y(t) = h₀x(t) + h₁x(t − τ) + w(t) 的频率响应随频率起伏（频率选择性衰落），单载波传输会有 ISI。OFDM 把总带宽 B 切成 N 个子载波，每个宽 Δf = B/N（第 7 章 p.8），一个 OFDM 符号长 T = N/B（p.7）。只要每个子载波足够窄，它在自己那一小段频率里看到的增益就近似是常数，即平坦衰落；接收端 DFT 以后得到 rk = Hksk + wk（p.6、p.17）。

两个条件（第 2 章 p.31–37）：

  • 平坦（flat）：信号带宽 < 相干带宽 BC。这里"信号"是一个子载波，所以 B/N ≪ BC。
  • 慢衰落（slow）：符号时长 < 相干时间 TC ≈ 1/Bd（p.36：相干时间是多普勒扩展的对偶）。这里"符号"是一个 OFDM 符号，所以 N/B ≪ 1/Bd。

子信道增益（第 7 章 p.15）：Hk = Σi hi e−j2πik/N，就是冲激响应 [h₀, h₁, …] 的 N 点 DFT。这里假设回波延迟 τ 正好是一个采样间隔（i = 0, 1）。讲义注明 HN = H₀，所以 k = 1…N 和 k = 0…N − 1 是同一组值。

容量（第 7 章 p.24）：N 条独立的并行高斯子信道，C = Σk log₂(1 + |Hk|²Pk/Nk)，本题噪声 Nk = σ² = 1。功率怎么分，(c)(d) 给了两种原则。

详细解析(a) N 的选取原则

  1. 平坦：B/N ≪ BC → N ≫ B/BC（N 太小，子载波太宽，又变回频率选择性）。
  2. 慢衰落：T = N/B ≪ 1/Bd → N ≪ B/Bd（N 太大，OFDM 符号太长，信道在一个符号内就变了，子载波失去正交，产生载波间干扰 ICI）。
  3. 合起来：B/BC ≪ N ≪ B/Bd。能找到这样的 N 的前提是 Bd ≪ BC，实际系统一般满足。

详细解析(b) 算 Hk

N = 4：e−j2πk/4 = e−jπk/2，k = 0, 1, 2, 3 依次是 1、−j、−1、j（在单位圆上每次顺时针转 90°）。

H₀ = H₄ = 0.8 + 0.6 = 1.4，|H|² = 1.96
H₁ = 0.8 + 0.6(−j) = 0.8 − 0.6j，|H|² = 0.64 + 0.36 = 1
H₂ = 0.8 − 0.6 = 0.2，|H|² = 0.04
H₃ = 0.8 + 0.6j，|H|² = 1

自检：Σ|Hk|² = 1.96 + 1 + 0.04 + 1 = 4 = N(h₀² + h₁²) = 4 × 1 ✓（帕塞瓦尔定理，课外补充）。子信道 2 的增益只有 0.2：两条路径反相抵消，这就是频率选择性衰落里的"深衰落"。按题目编号 k = 1, 2, 3, 4，功率增益为 1、0.04、1、1.96。

详细解析(c) 等容量分配

  1. 容量 log₂(1 + |Hk|²Pk) 都相等 ⇔ 每条的 SNR |Hk|²Pk 都等于同一个常数 c → Pk = c/|Hk|²。增益越差，分的功率越多（"劫富济贫"）。
  2. 由总功率求 c：
    c(1/1 + 1/0.04 + 1/1 + 1/1.96) = c(1 + 25 + 1 + 0.51) = 27.51c = 10 → c = 0.3635
  3. 各子信道：
    P₁ = 0.3635/1 = 0.36，P₂ = 0.3635/0.04 = 9.09，P₃ = 0.36，P₄ = 0.3635/1.96 = 0.19
    加起来 0.36 + 9.09 + 0.36 + 0.19 = 10 ✓。

详细解析(d) 注水求最大和容量

  1. 池底 = 噪声/增益 = 1/|Hk|²：1、25、1、0.51。功率 Pk = μ − 1/|Hk|²（μ 是水面），水面以下的子信道才分功率。
  2. 先全放水：4μ − 27.51 = 10 → μ = 37.51/4 = 9.38。但子信道 2 的池底 25 > 9.38，它会分到负功率，不行，去掉。
  3. 剩三条：3μ − (1 + 1 + 0.51) = 10 → μ = 12.51/3 = 4.17。功率 4.17 − 1 = 3.17、3.17、4.17 − 0.51 = 3.66，都为正 ✓，加起来 10 ✓。
  4. 容量：分到功率后每条的 SNR = |Hk|²Pk，1 + SNR = |Hk|²μ：
    C = log₂(4.17) + log₂(4.17) + log₂(4.17 × 1.96) = 2.06 + 2.06 + 3.03 = 7.15 bit
  5. 换成每赫兹：这 7.15 bit 是 4 个子载波一起传的，每个子载波只占 B/4，所以每赫兹总带宽：7.15/4 = 1.79 ≈ 1.8 bit/s/Hz（官方答案 1.8）。

和第 2 章的写法对上：每条的满功率 SNR γk = |Hk|² × 10 = 10、0.4、10、19.6，用 Σ(1/γ₀ − 1/γk) = 1 解出 γ₀ = 2.40，γ₂ = 0.4 < γ₀ 被去掉，C = Σ log₂(γk/γ₀) = 7.15 bit，结果一样（μ = P/γ₀）。

ConceptOFDM cuts a frequency-selective channel into N flat sub-channels

The multipath channel y(t) = h₀x(t) + h₁x(t − τ) + w(t) has a frequency response that varies with frequency (frequency-selective fading), and single-carrier transmission suffers ISI. OFDM cuts the total bandwidth B into N sub-carriers, each Δf = B/N wide (Ch 7 p.8); one OFDM symbol lasts T = N/B (p.7). As long as each sub-carrier is narrow enough, the gain it sees over its small band is nearly constant, i.e. flat fading; after the DFT the receiver gets rk = Hksk + wk (p.6, p.17).多径信道 y(t) = h₀x(t) + h₁x(t − τ) + w(t) 的频率响应随频率起伏（频率选择性衰落），单载波传输会有 ISI。OFDM 把总带宽 B 切成 N 个子载波，每个宽 Δf = B/N（第 7 章 p.8），一个 OFDM 符号长 T = N/B（p.7）。只要每个子载波足够窄，它在自己那一小段频率里看到的增益就近似是常数，即平坦衰落；接收端 DFT 以后得到 rk = Hksk + wk（p.6、p.17）。

Two conditions (Ch 2 p.31–37):两个条件（第 2 章 p.31–37）：

  • Flat: signal bandwidth < coherence bandwidth BC. Here the "signal" is one sub-carrier, so B/N ≪ BC.平坦（flat）：信号带宽 < 相干带宽 BC。这里"信号"是一个子载波，所以 B/N ≪ BC。

During this time each of the N sub-carriers sends one modulated symbol.OFDM 把带宽 B 分成 N 个子载波，子载波间隔 Δf = B/N（第 7 章 p.8）。为了让子载波相互正交，有用符号时长必须是 T = 1/Δf = N/B（p.7）。在这段时间里，N 个子载波各发一个调制符号。

Each OFDM block is also preceded by a guard interval TG (implemented as a cyclic prefix, CP), with TG ≥ the maximum delay spread TD, to block the echo of the previous block (p.5, p.17). 知识讲解信道"记忆"和循环前缀

从 H(z) 读冲激响应：z⁻¹ 表示晚一个采样，H(z) = 1 + 0.9z⁻¹ → h = [1, 0.9]，一条直射 + 一条晚 1 个采样、强度 0.9 的回波。抽头数 L = 2，信道的"记忆"（最大时延）是 L − 1 = 1 个采样：每个输出样本 ri = xi + 0.9xi−1，会用到前一个输入样本。

问题在块边界：OFDM 一块一块地发（每块是 N 个子载波符号做 IDFT 得到的 N 个采样，第 7 章 p.19）。一个块的第一个采样 r₀ = x₀ + 0.9 × (上一块的最后一个采样)，混进了上一块的数据，这就是块间的 ISI。

循环前缀 CP（p.21–22）：把每块最后 G 个采样复制一份放到块前面，接收端把这 G 个采样丢掉，只留后 N 个。G ≥ L − 1 时，上一块的回波只会落在被丢掉的 CP 里。

为什么要"复制块尾"而不是放空白：放 CP 后，块的第一个采样前面"看到"的是本块的最后一个采样，线性卷积在接收窗口里就变成循环卷积。循环卷积做 DFT 正好变成乘法：Rk = HkSk + Wk（p.17、p.22），每个子载波只乘一个复数，子载波之间保持正交。如果只放空白（补零），能挡住 ISI，但接收窗口里不再是循环结构，子载波失去正交，产生载波间干扰（ICI）。

详细解析用 N = 4 的小例子看清楚

  1. 发送：一块的采样是 x₀ x₁ x₂ x₃，加 1 个采样的 CP 后发 [x₃ | x₀ x₁ x₂ x₃]。
  2. 接收（ri = xi + 0.9xi−1）：
    CP 位置：x₃ + 0.9 × (上一块最后一个采样) ← 有 ISI，但会被丢掉
    r₀ = x₀ + 0.9x₃（前一个采样正好是 CP 里的 x₃）
    r₁ = x₁ + 0.9x₀，r₂ = x₂ + 0.9x₁，r₃ = x₃ + 0.9x₂
  3. 看结构：留下的 r₀…r₃ 里每个 x 都只和它"循环意义下的前一个"相加（x₀ 的前一个是 x₃），这就是 h 和 x 的 4 点循环卷积，完全没有上一块的数据。
  4. DFT 后：Rk = HkSk，Hk = 1 + 0.9e−j2πk/4 = 1.9、1 − 0.9j、0.1、1 + 0.9j。接收端每个子载波除以 Hk 就完成均衡（p.25–26）。
  5. 结论：最短 CP = L − 1 = 1 个采样（1 个符号长度）。再短（0 个）就挡不住 ISI；更长也可以，但浪费时间，效率 N/(N + G)。

附带一点：H₂ = 0.1，第 2 个子载波几乎被两条路径抵消。OFDM 不能消除衰落，只是把频率选择性衰落变成每个子载波上的平坦衰落，这时就需要编码或 P7 Q1 那样的功率分配。

易错常见丢分点

  • 答成 L = 2 个采样。CP 要盖住的是"回波晚到的那部分"，是 L − 1，不是 L。
  • 以为系数 0.9 越大 CP 要越长。CP 长度只看延迟几个采样，和回波强弱无关。
  • 只说"挡住 ISI"，不说为什么要用块尾的复制品（保持循环卷积 / 子载波正交，避免 ICI）。题目要求 Explain，这一点是得分点。
  • 换成时间单位：CP ≥ 1 个采样间隔 Ts，即 TG ≥ 最大时延扩展 TD。

ExamHow to write it

From \(H(z)=1+0.9z^{-1}\), the channel impulse response is h = [1, 0.9]: L = 2 taps, so the channel memory (maximum delay spread) is L − 1 = 1 sample.

The last sample of each OFDM block therefore leaks into the first sample of the next block (ISI). A cyclic prefix of G ≥ L − 1 samples, i.e. a copy of the last sample of the block placed in front of it, absorbs this leakage, and the receiver discards the CP.

Because the prefix is cyclic, the linear convolution with h becomes a circular convolution over the N retained samples, so after the DFT \(r_k=H_ks_k+w_k\): no ISI and no ICI, and each sub-carrier is equalised by one complex gain.

Minimum cyclic prefix = 1 symbol (sample) length.

In one line: h = [1, 0.9], the echo is 1 sample late → minimum CP = L − 1 = 1 symbol length; a prefix copied from the block tail keeps the ISI inside the discarded CP and turns the linear convolution into a circular one, so after the DFT rk = Hksk + wk.一句话：h = [1, 0.9]，回波晚 1 个采样 → 最短 CP = L − 1 = 1 个符号长度；用块尾复制品做前缀，既把 ISI 留在被丢掉的 CP 里，又让线性卷积变成循环卷积，DFT 后 rk = Hksk + wk。
◆ Key points
What it tests
The minimum cyclic-prefix length (Ch 7 p.17–22).
Background
Z-transform: Z⁻¹ means one sample later; a channel with L taps has its longest echo L − 1 samples late.
Method
Read the impulse response h = [1, 0.9] from H(Z) → L = 2 → CP ≥ L − 1 = 1 sample.
Why it is enough
With CP ≥ L − 1 the N samples kept by the receiver contain only data from the current block, the linear convolution becomes circular, and after the DFT rk = Hksk + wk (derivation box in Section 7.4 of the learning page).
Why copy the tail
An empty guard interval would also block the previous block's echo, but the receive window would no longer see a complete periodic signal, the sub-carriers would lose orthogonality and ICI would appear. Only copying the tail keeps the circular structure.
Common mistakes
It is L − 1 = 1 sample, not L = 2; the size of the coefficient 0.9 does not matter, only how many samples the echo is delayed.
Variations
H(Z) = 1 + 0.5Z⁻³ → delay 3 samples → CP ≥ 3; in time, TG ≥ the maximum delay spread TD. Each extra CP sample lowers the efficiency to N/(N + G).
