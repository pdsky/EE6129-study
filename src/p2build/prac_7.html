两径信道上的 OFDM：选 N、算 H_k、分功率

Original questionPractice 7

An OFDM signal x(t) is transmitted through a multi-path channel. The received signals can be expressed as, \(y(t)=h_0x(t)+h_1x(t-\tau)+w(t)\), where \(h_0,h_1\) are independent channel gains, τ is the time delay, and w(t) is the AWGN with zero-mean and variance \(\sigma^2=1\). The Doppler spread and Coherence bandwidth have been measured to be \(B_d\) and \(B_C\) respectively.

(a) Given a fixed total bandwidth B Hz, the number of sub-carriers N needs to be carefully selected so that each sub-channel could be regarded as experiencing slow flat fading. Explain the principle of how the value of N is selected.

(b) For N = 4, \(h_0\) = 0.8, and \(h_1\) = 0.6, find the values of the channel gain coefficients \(H_k\) for each sub-channel.

(c) Given the value of \(H_k\) from (b), the transmitter allocates power \(P_k\) to the kth sub-channel such that each sub-channel has the same capacity. Under the sum-power constraint, \(\sum_{k=1}^{N}P_k=10\), find the value of \(P_k\) for each sub-channel.

(d) Given the same value of \(H_k\) and the sum-power constraint from (c), find the maximum sum capacity in bits per second per Hertz.

慢平坦衰落条件H_k = DFT{h}等容量分配注水讲义第 7 章 p.5、p.15、p.24
  1. (a) 平坦：子信道宽 B/N 要远小于相干带宽 → \(N\gg B/B_C\)。慢衰落：OFDM 符号时长约 N/B，要远小于相干时间 1/B_d → \(N\ll B/B_d\)。所以 \(B/B_C\ll N\ll B/B_d\)。
  2. (b) \(H_k=h_0+h_1e^{-j2\pi k/N}=0.8+0.6e^{-j\pi k/2}\)：
    H₀ = H₄ = 1.4，H₁ = 0.8 − 0.6j，H₂ = 0.2，H₃ = 0.8 + 0.6j
    功率增益 |H_k|²（k = 1, 2, 3, 4）：1、0.04、1、1.96。
  3. (c) 容量 \(\log_2(1+|H_k|^2P_k)\) 相等 ⇔ \(|H_k|^2P_k=c\) 相同：\(P_k=c/|H_k|^2\)。
    c(1/1 + 1/0.04 + 1/1 + 1/1.96) = c × 27.51 = 10 → c = 0.3635
    P₁ = 0.36，P₂ = 9.09，P₃ = 0.36，P₄ = 0.19
  4. (d) 注水：池底 \(1/|H_k|^2\) = 1、25、1、0.51。四个都放水：水面 (10 + 27.51)/4 = 9.38 < 25，第 2 个子信道去掉。
  5. 剩三个：水面 μ = (10 + 1 + 1 + 0.51)/3 = 4.17，功率 3.17、3.17、3.66（都为正）。
    C = log₂(4.17 × 1) + log₂(4.17 × 1) + log₂(4.17 × 1.96) = 2.06 + 2.06 + 3.03 = 7.15 bit
  6. 这是 4 个子载波一起传的，每个子载波只占 B/4 带宽，所以每赫兹：7.15/4 = 1.79 bit/s/Hz。
(a) B/B_C ≪ N ≪ B/B_d；(b) 1.4, 0.8−0.6j, 0.2, 0.8+0.6j；(c) 0.36, 9.09, 0.36, 0.19；(d) ≈ 1.8 bit/s/Hz
官方答案：完全一致 ✓（官方把 k = 1…4 记为 H₁…H₄，H₄ = H₀ = 1.4）
对比 (c) 和 (d)：为了"人人平等"，(c) 把 91% 的功率砸在最差的子信道上；注水 (d) 干脆放弃最差的那个，总容量高得多。
P7 · Q2

设计一个 2 Mbps 的 OFDM 系统

Original questionPractice 7

Consider the design of an OFDM system. The goal is to transmit data at a rate of 2 Mbps using 16-QAM with an available bandwidth of 600 kHz. It is known that the delay spread of the channel is up to a maximum of 20 μs. You can assume the cyclic prefix to be equal to the maximum delay spread. Find the total number of sub-carriers and the OFDM symbol duration.

Δf = B/N循环前缀开销讲义第 7 章 p.8、p.17–18
  1. 16-QAM 每符号 4 bit：需要的总符号速率 2 Mbps / 4 = 500 k 符号/秒。
  2. N 个子载波：有用符号时长 T = N/B = N/600k，加 CP 后一个 OFDM 符号长 T + 20 µs，期间 N 个子载波各发一个符号。
  3. \(\dfrac{N}{N/600\text{k}+20\,\mu s}=500\text{k}\) → \(N=0.8333N+10\) → N = 60。
  4. T = 60/600 kHz = 100 µs；OFDM 符号总长 100 + 20 = 120 µs = 0.12 ms。
N = 60，OFDM 符号时长 0.12 ms
官方答案：60；0.12 ms ✓
如果不加 CP，600 kHz 本来就够发 500 k 符号/秒，N 取多少都行，题目就没有唯一解。正是 CP 的开销决定了 N：N 越大，CP 占的比例越小。CP 占 20/120 = 1/6 的时间，所以带宽必须比 500 k 多出 1/5，正好是 600 kHz。
P7 · Q3

最短的循环前缀

Original questionPractice 7

The Z–transform of a mobile channel is \(H(Z)=1+0.9Z^{-1}\). In order to mitigate the ISI of this channel, the system is now designed with OFDM. What is the minimum cyclic-prefix required. Explain your answer.

信道长度CP ≥ L − 1讲义第 7 章 p.17–22
  1. 冲激响应 h = [1, 0.9]：一条直射，加一条晚一个采样到达的回波，信道长度 L = 2，最大时延扩展 = 1 个采样。
  2. 上一个 OFDM 块的最后一个采样，会通过 0.9z⁻¹ 漏进下一个块的第一个采样。CP 至少要盖住这 1 个采样，才能把 ISI 挡在 CP 里（接收端丢掉 CP）。
  3. CP 用块尾的复制品，线性卷积在接收窗口里等价于循环卷积，DFT 后正好得到 \(H_ks_k\)，子载波保持正交。
最短 CP = 1 个采样（符号）长度 = L − 1
官方答案：1 symbol length ✓
