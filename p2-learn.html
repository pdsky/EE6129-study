    1.2事件的概率：四条规则★★ 常考

    第 2–7 章几乎每个公式都是"某件坏事发生的概率"：中断概率、误码率、深衰落的概率。第 1b 章（Quiz 范围）就是把算这些概率要用的工具捋一遍。先从最简单的"事件"讲起。

    几个名词：做一次随机试验（掷一次骰子），所有可能结果的集合叫样本空间（{1, 2, 3, 4, 5, 6}，讲义叫 Universe）；样本空间里的一部分叫事件（"出偶数" = {2, 4, 6}）。每个结果等可能时，事件的概率 = 它包含的结果数 ÷ 总结果数。

    例题掷骰子与摸弹珠（第 1b 章 p.3–4）

    事件 A：骰子出偶数 {2, 4, 6}；事件 B：出质数 {2, 3, 5}。

    1
    各自概率：\(P(A) = 3/6\)，\(P(B) = 3/6\)，整个样本空间 \(P(\text{Universe}) = 6/6 = 1\)。
    2
    "A 且 B"（交集 ∩，两件事同时发生）：既是偶数又是质数，只有 2 一个数：\(P(A\cap B) = 1/6\)。
    3
    "A 或 B"（并集 ∪，至少一件发生）：{2, 3, 4, 5, 6}，共 5 个：\(P(A\cup B) = 5/6\)。用加法规则验证：\(3/6 + 3/6 - 1/6 = 5/6\)。减去的 1/6 就是 2 被数了两遍。
    4
    条件概率 \(P(A\mid B)\) 读作"已知 B 发生了，A 发生的概率"。弹珠：袋里 3 红 4 蓝。B = 先摸出一个蓝的，\(P(B) = 4/7\)。B 发生以后袋里剩 3 红 3 蓝，这时 A = 摸出红的，\(P(A\mid B) = 3/6 = 1/2\)。已知条件改变了袋子里的情况，所以条件概率和原来的 \(P(A)=3/7\) 不一样。
    P(A∪B) = 5/6，P(A∩B) = 1/6；摸弹珠 P(B) = 4/7，P(A|B) = 1/2
    四条规则（第 1b 章 p.5–9）
    加法：\(P(A\cup B)=P(A)+P(B)-P(A\cap B)\)
    乘法：\(P(A\cap B)=P(A)\,P(B\mid A)=P(B)\,P(A\mid B)\)
    全概率：\(P(B)=\sum_i P(A_i)\,P(B\mid A_i)\)
    贝叶斯：\(P(A_i\mid B)=\dfrac{P(A_i)P(B\mid A_i)}{\sum_j P(A_j)P(B\mid A_j)}\)
    加法算"或"；A、B 互斥（不可能同时发生）时交集为 0，直接相加。乘法算"且"：先 A 发生，再在 A 发生的条件下 B 发生。全概率是"分情况讨论再加起来"：把所有可能的情况 \(A_1, A_2,\dots\)（互斥、合起来是全部）各自算一遍再加权。贝叶斯反过来：已经看到结果 B，问是哪种情况造成的。

    独立：如果 A 发不发生完全不影响 B，即 \(P(B\mid A)=P(B)\)，乘法规则就简化成 \(P(A\cap B)=P(A)P(B)\)，独立事件同时发生的概率等于各自概率相乘（p.6）。这一条是第 4 章分集的全部基础：两条独立的路各有 10% 的时间中断，同时中断只有 0.1 × 0.1 = 1%。Practice 2 第 2 题"两个基站同时收不到"也是这个道理：\(P_{out}=[Q(\Delta/\sigma)]^2\)。

    例题全概率与贝叶斯：信道好坏与误码（自编）

    已知条件：信道有 80% 的时间是"好"状态，误码率 10⁻⁴；20% 的时间是"深衰落"状态，误码率 10⁻²。

    1
    全概率：平均误码率 = 分两种情况再加权。
    P(错) = 0.8 × 10⁻⁴ + 0.2 × 10⁻² = 0.00008 + 0.002 = 0.00208
    平均误码率几乎全由那 20% 的深衰落决定。
    2
    贝叶斯：收到一个错比特，它发生在深衰落期间的概率是多少？
    P(衰落 | 错) = 0.2 × 10⁻² / 0.00208 = 0.002 / 0.00208 ≈ 96%
    平均误码率 2.08×10⁻³；出错时 96% 是在深衰落里

    这个例子正是第 4 章"离散 SNR 分布求平均误码率"的套路：期末 2023-24 Q1(b)(i)、2025-26 S1 Q1(b)(i) 都是先列出每种 SNR 的概率，算出各自的误码率，再按概率加权。

    1.3随机变量、期望和方差★★★ 必考

    随机变量就是"取值随机的数"，比如信噪比 γ、噪声 w、接收功率的 dB 值。描述它最重要的两个数：

    • 期望（均值） \(E[X]\)：按概率加权的平均值，"平均来说是多少"；
    • 方差 \(\mathrm{Var}(X)=\sigma^2\)：偏离平均值的平方的平均，"抖得有多厉害"。标准差 σ = √方差，和 X 同单位。
    定义（第 1b 章 p.10–11）
    \(E[X]=\sum_x x\,P_X(x)\)　　\(\mathrm{Var}(X)=E\big[(X-E[X])^2\big]=E[X^2]-(E[X])^2\)
    第二个等号最常用：先算平方的平均，再减去平均的平方。
    必须记住的五条性质（p.10–11、p.14）
    \(E[aX+b]=aE[X]+b\)　　\(\mathrm{Var}(aX+b)=a^2\,\mathrm{Var}(X)\)
    \(E[X+Y]=E[X]+E[Y]\)（任何时候都成立）
    X、Y 独立：\(\mathrm{Var}(X+Y)=\mathrm{Var}(X)+\mathrm{Var}(Y)\)，\(E[XY]=E[X]E[Y]\)
    记忆方法：加常数只挪位置、不改变抖动（方差不变）；乘 a 把抖动放大 a 倍，方差放大 a² 倍；独立的抖动叠在一起，方差相加（标准差不相加）。

    这几条性质在期末卷里反复出现：

    • y = s + w（2025-26 S1 Q1(a)）：s = +1 固定时，E[y] = 1 + E[w] = 1，Var[y] = Var[w]。加常数不改变方差。
    • 均衡器输出噪声（2025-26 S1 Q2(a)、S2 Q2(a)）：w′ = c₁w₁ + c₂w₂ + …，各 w 独立、方差 σ²，于是 Var[w′] = σ²(c₁² + c₂² + …)：系数要平方，再相加。
    • Alamouti 检测（2025-26 S2 Q1(b)(iii)）：ŝ = s + Gw/‖h‖²，乘常数 1/‖h‖²，方差乘 1/‖h‖⁴。
    例题离散 SNR 分布的均值、方差和 aX + b（自编，Quiz 题型）

    已知条件：某链路的 SNR（线性值）X 以 1/3 的概率是 8，2/3 的概率是 11（Practice 4 第 2 题的数）。另有 Y = 2X + 3。

    1
    均值：
    E[X] = 8 × 1/3 + 11 × 2/3 = 2.667 + 7.333 = 10
    2
    方差先算平方的平均：
    E[X²] = 64 × 1/3 + 121 × 2/3 = 21.33 + 80.67 = 102
    Var(X) = 102 − 10² = 2，σ = √2 = 1.414
    3
    Y = 2X + 3：
    E[Y] = 2 × 10 + 3 = 23；Var(Y) = 2² × 2 = 8
    "+3"对方差没有影响。
    4
    两条独立链路的 SNR 相加（MRC，第 4 章）：
    E[X₁ + X₂] = 20；Var(X₁ + X₂) = 2 + 2 = 4
    E[X] = 10，Var(X) = 2；E[Y] = 23，Var(Y) = 8；两路之和均值 20、方差 4
    ⚠ 易错
    • 方差和标准差搞混：题目给"variance"、"MSE"、"σ²"时，进 Q 函数之前一定要先开根号。
    • Var(aX) 写成 a·Var(X)：系数要平方。Var(−X) = Var(X)，减号也会被平方掉。
    • 独立变量相加时把标准差相加：要加的是方差。
    • SNR 用 dB 求平均：要先把 dB 换成线性值再平均，最后再换回 dB（期末 2023-24 Q1(b)(i) 就考这个）。

    1.4连续随机变量：PDF 和 CDF★★ 常考

    噪声、衰落这类量可以取任意实数，叫连续随机变量。它取"某一个确切值"的概率是 0，只能问"落在某个区间里"的概率，所以要用概率密度函数（PDF） \(p_X(x)\) 来描述（p.12）：

    PDF 与 CDF（第 1b 章 p.12–13）
    \(P(a\le X\le b)=\displaystyle\int_a^b p_X(x)\,dx\)　　\(\displaystyle\int_{-\infty}^{\infty}p_X(x)\,dx=1\)
    \(F_X(x)=P(X\le x)=\displaystyle\int_{-\infty}^{x}p_X(t)\,dt\)　　\(E[X]=\displaystyle\int x\,p_X(x)\,dx\)
    概率 = PDF 曲线下的面积。PDF 的值本身不是概率，可以大于 1；整条曲线下的总面积是 1。CDF \(F_X(x)\) 是"X 不超过 x 的概率"，从 0 单调涨到 1；PDF 是 CDF 的导数。离散变量把积分换成求和。

    例题由 PDF 求 CDF：瑞利衰落下 SNR 低于门限的概率

    已知条件：SNR 服从指数分布，平均 \(\bar\gamma\) = 100（20 dB）。求 SNR 低于 10（10 dB）的概率。

    1
    CDF 就是 PDF 从 0 积到门限：
    P(γ < γ₀) = ∫₀^γ₀ (1/γ̄) e^(−γ/γ̄) dγ = 1 − e^(−γ₀/γ̄)
    2
    代入 γ₀/γ̄ = 10/100 = 0.1：
    P = 1 − e^(−0.1) = 0.095
    约 9.5%：平均 20 dB 的瑞利信道，近一成时间比平均低 10 dB 以上

    1.5高斯分布和 Q 函数：本课最常用的一张表★★★ 必考

    噪声、阴影衰落的 dB 值，都服从高斯（正态）分布 \(\mathcal N(\mu,\sigma^2)\)（p.14）。μ 决定钟形曲线的中心在哪，σ 决定它有多胖。我们最常问的问题是：它比平均值低（或高）超过一定量的概率是多少？这个概率没有初等公式，要查 Q 函数表（考试附录会给）。

    Q 函数（第 2 章 p.15；考卷 Appendix A 给 Q 函数表）
    \(Q(x)=\displaystyle\int_x^{\infty}\frac{1}{\sqrt{2\pi}}e^{-u^2/2}\,du=P(Z>x),\quad Z\sim\mathcal N(0,1)\)
    Q(x) 是标准正态变量 Z（均值 0、方差 1）大于 x 的概率，也就是钟形曲线右边那条"尾巴"的面积。x 越大，尾巴越小。
    ★ 考试重点 · 任何高斯概率都三步转成 Q 函数
    1. 找距离：门限离均值多远？距离 = |门限 − μ|。
    2. 除以标准差：k = 距离 / σ，意思是"离均值 k 个标准差"。σ 一定是标准差，给的是方差要先开根号。
    3. 查表：\(P(X>\mu+k\sigma)=Q(k)\)，由对称性 \(P(X\lt \mu-k\sigma)=Q(k)\)。问的是"靠近均值那一侧"时用 \(1-Q(k)\)。

    还有两个常用关系：\(Q(0)=0.5\)；\(Q(-x)=1-Q(x)\)。反过来用（已知概率求 k）要会倒查表：Q(k) = 0.01 → k ≈ 2.33。

    例题Practice 1 第 2 题：正着用和倒着用 Q 函数

    已知条件：接收功率（dBm）服从对数正态分布，即 dB 值 \(\sim\mathcal N(\mu_\psi,\sigma_\psi^2)\)，要高于 10 dBm 才不中断。

    1
    (a) μ = 15 dBm、σ = 8 dB。门限比均值低 15 − 10 = 5 dB，是 5/8 = 0.625 个标准差：
    P_out = P(X < μ − 0.625σ) = Q(0.625) ≈ 0.266
    2
    (b) σ = 4 dB，要 Pout < 1%，求 μ。倒着查表：Q(k) = 0.01 → k = 2.33。门限要比均值低 2.33 个标准差以上：
    μ − 10 > 2.33 × 4 = 9.3 → μ > 19.3 dBm
    (a) 约 26%；(b) μ > 19.3 dBm（官方答案 19.32）

    第二章

    无线信道：信号在路上会遇到三种麻烦

    ★ 本章是 10 月 23 日 Quiz 的主体，也是期末 Q1(a) 的固定来源

    四份期末卷有三份的 Q1(a) 出自这一章；Practice 1、2 全部在这一章。下面每一节都标了星级，★★★ 的六块要做到看见题就会算：路径损耗 dB 式、阴影中断概率、时延扩展与平坦衰落判别、快慢衰落判别、LCR/AFD 数错误、衰落余量。

    讲义第 2 章 p.2 把信号变坏分成三层，尺度从大到小：

    1. 路径损耗（path loss）：离得越远越弱，是平均意义上的衰减，几百米到几公里才看得出变化；
    2. 阴影衰落（shadowing，大尺度衰落）：被楼房、树挡住，信号在平均值上下随机起伏，几十米变化一次；
    3. 多径衰落（multipath fading，小尺度衰落）：很多条反射路径叠在一起，走半个波长（900 MHz 时约 17 cm）信号就可能剧烈变化。
    类比

    在山里打电话：走得越远声音越小（路径损耗）；转到山背面声音突然闷了一截（阴影）；站在山谷里，回声和原声叠在一起，同一句话有时清楚、有时含糊（多径）。

    三层是叠加的：接收功率(dB) = 发射功率 − 路径损耗（平均值）+ 阴影起伏（高斯，几 dB）+ 多径起伏（瑞利，可以深到 −20、−30 dB）。前两层在 2.1–2.2 节，多径在 2.3–2.6 节，2.7–2.8 节问"这样的信道最多能传多快"。

    2.1路径损耗：平均来看离多远、弱多少★★★ 必考

    讲义 p.3 列了四类模型：自由空间（太简单）、射线追踪（需要现场几何数据）、经验模型（Okumura、Hata、COST 231，换个环境就不准）、简化路径损耗模型（最适合做分析，考试主要用它）。

    自由空间（p.4）与双径模型（p.5）
    \(P_r=P_t\dfrac{G_tG_r\lambda^2}{(4\pi d)^2}\)　　\(P_r\approx P_t\dfrac{G_tG_r(h_th_r)^2}{d^4}\ \ (d>d_c=\tfrac{4h_th_r}{\lambda})\)
    自由空间：功率和 \(d^2\) 成反比，和频率的平方成反比（频率越高 λ 越小，越吃亏）。双径：直射波加一条地面反射，超过临界距离 \(d_c\) 以后变成和 \(d^4\) 成反比。Part A 第五章讲过同样的结论（n = 2 和 n = 4）。
    简化路径损耗模型（p.8）—— 必背
    \(P_r=P_tK\left(\dfrac{d_0}{d}\right)^{\gamma}\ \Longrightarrow\ P_{r,\mathrm{dB}}=P_{t,\mathrm{dB}}+K_{\mathrm{dB}}-10\gamma\log_{10}\dfrac{d}{d_0}\)
    γ 就是 Part A 的路径损耗指数 n。K 是和天线有关的常数（dB 时通常是负数），\(d_0\) 是参考距离，一般取 1 m。γ 和 K 都靠实测拟合（p.8）。p.9 给了典型 γ：城区宏蜂窝 3.7–6.5、城区微蜂窝 2.7–3.5、同层办公楼 1.6–3.5、住宅 3；频率越高 γ 越大。

    怎么从左边的式子得到右边：两边取 \(10\log_{10}\)，乘法变加法、幂变成乘系数：\(10\log_{10}(d_0/d)^{\gamma}=-10\gamma\log_{10}(d/d_0)\)。功率用 dBm（相对 1 mW）时，\(P_{t,\mathrm{dB}}\) 和 \(P_{r,\mathrm{dB}}\) 都是 dBm，\(K_{\mathrm{dB}}\) 和其他项是 dB，直接加减。

    把它画成图（期末 2023-24 Q1(a)(i)、2024-25 Q1(a)(i) 都考）：路径损耗 \(P_{L,\mathrm{dB}}=P_{t,\mathrm{dB}}-P_{r,\mathrm{dB}}=-K_{\mathrm{dB}}+10\gamma\log_{10}d\)。以 \(\log_{10}d\) 为横轴，它是一条直线：

    • 截距（d = d₀ = 1 m 处）= −KdB；斜率 = 10γ dB/十倍距离（横轴用 \(10\log_{10}d\) 时斜率就是 γ）；
    • 纵轴如果画的是 \(P_r/P_t\)（dB），线就往下走，截距是 +KdB，斜率是 −10γ；
    • 有阴影时，实测点散布在这条线两侧（2.2 节）。
    例题150 m 处收到多少功率（第 2 章 p.10）

    已知条件：\(K_{\mathrm{dB}}=-26.67\) dB，γ = 3.97，发射功率 1 mW，求 150 m 处的接收功率（\(d_0\) = 1 m）。

    1
    先把发射功率换成 dBm：1 mW = 10 log₁₀(1 mW / 1 mW) = 0 dBm。
    2
    距离项：\(10\times3.97\times\log_{10}150 = 39.7\times2.176 = 86.39\) dB。
    3
    代入：
    P_r = 0 − 26.67 − 86.39 = −113.06 dBm
    约 −113 dBm

    用实测数据拟合 K 和 γ（p.13，Practice 1 第 1 题）

    实测了几组"距离 di、损耗 Mi = (Pr/Pt)dB"，要找一条直线 \(M=K_{\mathrm{dB}}-10\gamma\log_{10}d\) 最贴近这些点。讲义的做法是最小二乘：让误差平方的平均（MSE）最小。令 \(x_i=10\log_{10}d_i\)，就是普通的直线拟合：

    最小二乘拟合（p.13）
    \(F(K,\gamma)=\dfrac1n\displaystyle\sum_i\big(M_i-K_{\mathrm{dB}}+\gamma x_i\big)^2\)，令 \(\dfrac{\partial F}{\partial K}=0,\ \dfrac{\partial F}{\partial\gamma}=0\)
    两个偏导等于零，得到关于 K 和 γ 的两个一次方程，解出来就是最佳直线。最后剩下的最小 MSE 就是阴影方差 \(\sigma_\psi^2\)：实测点偏离直线的程度，正是阴影造成的随机起伏。

    2.2阴影衰落与中断概率★★★ 必考

    信号在路上要穿过 M 个障碍物，每个都把功率乘上一个衰减因子 \(A_i\)，总衰减 \(\psi=\prod A_i\)（p.11）。取对数以后乘法变成加法：\(\log\psi=\sum\log A_i\)。很多个随机量相加，按中心极限定理近似服从高斯分布，所以 ψ 的 dB 值是高斯的，ψ 本身叫对数正态（log-normal）分布。讲义给的典型值：均值 0，方差 4–12 dB²。

    路径损耗 + 阴影（p.12）
    \(\left.\dfrac{P_r}{P_t}\right|_{\mathrm{dB}}=K_{\mathrm{dB}}-10\gamma\log_{10}\dfrac{d}{d_0}+\psi_{\mathrm{dB}},\qquad \psi_{\mathrm{dB}}\sim\mathcal N(0,\sigma_{\psi}^2)\)
    前两项是"平均值"，第三项是围绕平均值的随机起伏。所以接收功率（dB）是一个高斯随机变量：均值 = 无阴影时的路径损耗结果，方差 = \(\sigma_\psi^2\)。

    中断概率怎么推出来（p.14–15）：中断就是接收功率低于能工作的最低值 \(P_{m,\mathrm{dB}}\)：

    1. \(P_{\mathrm{out}}=P\big(P_{r,\mathrm{dB}}^{\text{无阴影}}+\psi_{\mathrm{dB}}\lt P_{m,\mathrm{dB}}\big)=P(\psi_{\mathrm{dB}}<-x)\)，其中 \(x=P_{r,\mathrm{dB}}^{\text{无阴影}}-P_{m,\mathrm{dB}}\) 叫余量（平均值比门限高多少 dB）。
    2. ψ 是均值 0 的高斯，"比均值低 x 以上"的概率，由对称性等于"比均值高 x 以上"的概率。
    3. 除以标准差变成标准高斯，就是 Q 函数。
    中断概率（p.15）—— 必背
    \(P_{\mathrm{out}}=Q\!\left(\dfrac{P_{r,\mathrm{dB}}(\text{无阴影})-P_{m,\mathrm{dB}}}{\sigma_{\psi_{\mathrm{dB}}}}\right)=Q\!\left(\dfrac{\text{余量}}{\text{标准差}}\right)\)
    余量越大、阴影越小，中断越少。讲义说典型目标是中断概率小于 1%（p.16），对应 余量 ≥ 2.33σ。
    例题150 m 处的中断概率（第 2 章 p.16）

    已知条件：MSE = 3.36，\(K_{\mathrm{dB}}=-26.67\) dB，γ = 3.97，d = 150 m，\(P_t\) = 0 dBm，门限 \(P_m=-118\) dBm。

    1
    无阴影时的平均接收功率，上一题算过：−113.06 dBm。
    2
    余量：−113.06 − (−118) = 4.94 dB。实际功率 = −113.06 + ψ，低于 −118 就是 ψ < −4.94 dB。
    3
    阴影方差 \(\sigma_\psi^2\) = MSE = 3.36，标准差 \(\sigma_\psi=\sqrt{3.36}=1.833\) dB。4.94 dB 是 4.94 / 1.833 = 2.69 个标准差：
    P_out = Q(4.94 / 1.833) = Q(2.69) ≈ 0.0036
    中断概率约 0.36%，低于 1% 的目标

    易错：分母是 \(\sqrt{3.36}=1.833\)（讲义 p.16 写的就是 √3.36），不是 3.36。题目给的 MSE 是方差 σ²，单位 dB²；Q 函数里要除的是标准差 σ，单位 dB，这样"余量 ÷ σ"才是没有单位的"几个标准差"。错除 3.36 会得到 Q(1.47) ≈ 0.071，比正确答案大 20 倍。

    ★ 考试重点 · 一个方程，四种问法

    Pout = Q(余量 / σ) 里有三个量，题目给两个求第三个：

    • 求 Pout：先用路径损耗式算平均功率 → 余量 → 除以 σ → 查表（p.16 例题、Practice 1 第 1(b) 题）。
    • 求 σ 或方差上限：Pout < 1% → 余量/σ > 2.33 → σ < 余量/2.33（期末 2023-24 Q1(a)(ii)：余量 10 dB → σ² < 18.5 dB²）。
    • 求需要的平均功率：μ − 门限 > 2.33σ（Practice 1 第 2(b) 题：μ > 19.3 dBm）。
    • 两个基站（宏分集）：两路阴影独立时，两路同时低于门限才中断：\(P_{\mathrm{out}}=[Q(\Delta/\sigma)]^2\)（Practice 2 第 2(b) 题）。

    2.3多径衰落：很多条回波叠在一起★★ 常考

    同一个信号沿很多条路到达接收机，每条路有自己的幅度 \(\alpha_n\)、相位 \(\phi_n\)、时延 \(\tau_n\)、多普勒频移，而且这些量都随时间变（p.19–22）。讲义用时变冲激响应描述：

    时变冲激响应（p.20）
    \(c(\tau,t)=\displaystyle\sum_{n=1}^{N}\alpha_n(t)\,e^{-j\phi_n(t)}\,\delta(\tau-\tau_n(t))\)
    t 是"现在"，τ 是"这一条回波比最早那条晚到多久"。p.21 的图：t = 1 s 时有两条回波（2 µs、5 µs），t = 4 s 时变成三条（3 µs、7 µs、10 µs）。信道在不停变化。

    窄带假设（p.23）：如果所有回波之间的时延差，比一个符号的长度小得多，那么各条回波"对得齐"，只是被乘了不同的复数系数后加在一起。效果是信号整体被乘上一个随机的复数增益，波形本身不变形。这就是平坦衰落。

    这个复数增益的实部 \(r_I\) 和虚部 \(r_Q\) 都是很多个随机量之和，所以都是高斯的（p.24）。它的包络（模长）\(z=\sqrt{r_I^2+r_Q^2}\) 服从瑞利（Rayleigh）分布：

    瑞利衰落（p.25–26）
    \(p_z(z)=\dfrac{z}{\sigma^2}e^{-z^2/(2\sigma^2)}\)　　\(p_\gamma(\gamma)=\dfrac{1}{\bar\gamma}e^{-\gamma/\bar\gamma}\)　　\(P(\gamma\lt \gamma_0)=1-e^{-\gamma_0/\bar\gamma}\)
    包络是瑞利分布；功率 \(z^2\) 和 SNR γ 是指数分布，平均功率 \(2\sigma^2\)、平均 SNR \(\bar\gamma\)。\(P(\gamma\lt \gamma_0)=1-e^{-\gamma_0/\bar\gamma}\) 是后面所有"瑞利信道中断概率"的起点：第 2.7 节的衰落余量、第 3 章的中断、第 4 章的选择分集都从它出发。

    一张图看懂瑞利衰落：①多条回波怎样叠成包络 z；②z 的分布为什么是这个形状；③手机移动时 z 怎样随时间起伏、什么叫"深衰落"。两个独立的零均值高斯（实部、虚部）合成向量的长度，就服从瑞利分布。

    ① 12 条回波（灰色）相位随机，首尾相接；橙色合成箭头的长度就是包络 z。实部、虚部都是很多随机量之和，所以都是高斯的。
    ② 统计很多时刻的 z，得到瑞利分布。阴影面积 = z 低于门限的概率 = 1 − e−ρ² = 8.6%。
    ③ 手机移动时（fm = 20 Hz，画 1 秒，以 rms 为 0 dB），包络在 +6 dB 到 -30 dB 之间起伏。橙色虚线是门限 ρ = 0.3（-10.5 dB），每次跌到虚线以下就是一次深衰落：这段仿真里有 13 次，LCR 公式给出 √(2π)·fm·ρ·e−ρ² ≈ 13.7 次/秒（公式是长时间平均，一秒的样本会有随机出入）。

    如果除了散射波还有一条直射波（LOS，line of sight），比如开阔地能直接看到基站，包络就变成莱斯（Rician）分布（p.27）：

    莱斯分布与莱斯因子（p.27–28）
    \(p_z(z)=\dfrac{z}{\sigma^2}\,e^{-\frac{z^2+s^2}{2\sigma^2}}\,I_0\!\left(\dfrac{zs}{\sigma^2}\right),\ z\ge0\)　　\(K=\dfrac{s^2}{2\sigma^2}\)
    s² 是直射波功率，2σ² 是散射波总功率，\(I_0(\cdot)\) 是零阶修正贝塞尔函数（不用会算，知道它出现在莱斯分布里即可）。K = 直射功率 ÷ 散射功率：K = 0 退化成瑞利（最糟）；K → ∞ 几乎不衰落，接近 AWGN。K 常用 dB 表示，讲义 p.28 的图画了 K = −∞ dB（瑞利）、6 dB、∞ dB 三条。

    直观理解：瑞利信道里所有回波都是"随机相位"的，有可能恰好互相抵消到接近 0；莱斯信道里有一支"主力"直射波，散射波只能在它周围晃，要把它抵消掉，散射波必须恰好全部反向，这很难发生。所以 K 越大，深衰落越少。

    ① 绿色直射波长度固定；灰色散射波相位随机，只能让合成箭头（橙色）在直射波的箭头尖附近摆动，很难抵消到 0。
    ② 总功率都归一化为 1。K 越大，曲线越窄、越集中在 z ≈ 1，靠近 0（深衰落）的部分越小；K → ∞ 时趋于一根尖峰，就是不衰落（讲义 p.28 的图）。
    ③ 同一组散射波：灰色是没有直射波（瑞利，K = 0），绿色是加了直射波（K = 10）。瑞利下包络多次跌破门限（橙色虚线，ρ = 0.3），K = 10 时只在 0 dB 上下几 dB 摆动。
    K直射 / 散射功率包络低于 ρ = 0.3（−10.5 dB）的概率
    0（瑞利）0% / 100%8.6%
    1（0 dB）50% / 50%6.6%
    4（6 dB）80% / 20%1.4%
    10（10 dB）91% / 9%0.06%

    同样的门限，K 从 0 到 10，深衰落的概率从 8.6% 降到 0.06%，降了一百多倍（数值由莱斯 PDF 积分得到，总功率归一化为 1）。

    比平均 SNR 低γ₀/γ̄瑞利信道下发生的概率
    3 dB0.51 − e−0.5 = 39%
    10 dB0.11 − e−0.1 ≈ 9.5%
    20 dB0.01≈ 1%
    30 dB0.001≈ 0.1%

    规律：γ₀/γ̄ 很小时 \(1-e^{-x}\approx x\)，"低 10k dB 的概率约是 10⁻ᵏ"。这就是 p.51 说"中断概率 1% 需要 20 dB 衰落余量"的来源。

    2.4时延扩展：回声拖了多长的尾巴★★★ 必考

    功率时延分布（power delay profile）\(P_r(\tau)\) 记录"晚到 τ 秒的那些回波有多少功率"，第一条到达的回波 τ = 0（p.30）。用它算两个数：

    平均时延与 rms 时延扩展（p.30）
    \(\mu_{T_m}=\dfrac{\sum_k\tau_kP_r(\tau_k)}{\sum_kP_r(\tau_k)}\)　　\(\sigma_{T_m}=\sqrt{\dfrac{\sum_k(\tau_k-\mu_{T_m})^2P_r(\tau_k)}{\sum_kP_r(\tau_k)}}\)（连续时把求和换成积分）
    把功率当成"权重"：\(\mu_{T_m}\) 是按功率加权的平均晚到时间，\(\sigma_{T_m}\) 是晚到时间的加权标准差，也就是回波拖尾有多散。和第一章的期望、方差是同一套算法，只是概率换成了"功率占比"。
    例题三条回波的离散功率时延分布（自编）

    已知条件：回波在 τ = 0、1、2 µs，功率分别是 0、−3、−6 dB。

    1
    先把 dB 换成线性值：0 dB → 1，−3 dB → 0.5，−6 dB → 0.25，总功率 1.75。
    2
    平均时延：
    μ = (0 × 1 + 1 × 0.5 + 2 × 0.25)/1.75 = 1/1.75 = 0.571 µs
    3
    先算 τ² 的加权平均，再减 μ²：
    E[τ²] = (0 + 1 × 0.5 + 4 × 0.25)/1.75 = 0.857；σ² = 0.857 − 0.571² = 0.531；σ = 0.73 µs
    4
    平坦衰落要 σ/Ts < 0.1 → Ts > 7.3 µs → 符号速率 < 137 ksps。
    μ ≈ 0.57 µs，σ ≈ 0.73 µs；符号速率低于约 137 ksps 才是平坦衰落
    例题均匀功率时延分布（Practice 1 第 3 题）

    已知条件：\(P_r(\tau)=1\)（0 ≤ τ ≤ 10 µs），其他为 0。

    1
    这相当于 0–10 µs 上的均匀分布，平均值在正中间：\(\mu_{T_m}=5\) µs。
    2
    \(E[\tau^2]=\frac{1}{10}\int_0^{10}\tau^2d\tau=\frac{100}{3}=33.33\)，所以 \(\sigma_{T_m}^2=33.33-25=8.33\)，\(\sigma_{T_m}=2.89\) µs（也可以直接用均匀分布方差 a²/12 = 100/12）。
    3
    平坦衰落的经验条件 \(\sigma_{T_m}/T_s<0.1\)（p.33）：\(T_s>28.9\) µs，即符号速率 \(R_s<34.6\) ksps。
    μ = 5 µs，σ = 2.89 µs；R_s < 34.6 ksps 时是平坦衰落

    时延扩展在频域的对应量是相干带宽 \(B_C\)（p.31）：两个频率相隔超过 \(B_C\)，它们的衰落就互不相关。时延扩展越大，相干带宽越小。于是（p.31–33）：

    • 信号带宽 < \(B_C\)，或者 \(\sigma_{T_m}/T_s<0.1\)：平坦衰落，整个信号一起起伏，波形不失真；
    • 信号带宽 > \(B_C\)，或者 \(\sigma_{T_m}\) 和 \(T_s\) 相当：不同频率衰落不同，频率选择性衰落，在时域表现为码间干扰（ISI）：上一个符号的回波拖进了下一个符号。第 6 章（均衡）和第 7 章（OFDM）就是治这个病的。
    类比

    在大教堂里说话：说得慢（符号长），每个字的回声在下一个字开始前就消失了，听得清；说得快（符号短），上一个字的回声和下一个字重叠，就含糊了。回声拖多长是房间决定的（时延扩展），说多快是你决定的（符号速率）。

    ⚠ 易错
    • 功率时延分布给的是 dB 时，先换成线性功率再加权，不能拿 dB 值当权重。
    • "平坦"看的是 rms 时延扩展 σ，不是最大时延；题目给最大时延扩展时（OFDM 的保护间隔用它），别拿它去套 0.1 的法则。

    2.5多普勒：信道变化有多快★★★ 必考

    多普勒频移与相干时间（p.34–36）
    \(f_d=\dfrac{v}{\lambda}\cos\theta=\dfrac{v}{c}f_c\cos\theta\)　　\(f_m=\dfrac{v}{c}f_c\)　　\(B_D=f_m\)　　\(T_C\approx\dfrac{1}{B_D}=\dfrac{1}{f_m}\)
    手机朝着信号来的方向走，频率变高；背着走，频率变低。各条回波从不同方向来，频移不同，原本一根谱线被展宽成多普勒谱，宽度就是多普勒扩展 \(B_D\)（讲义取 \(f_m\)）。相干时间 \(T_C\) 是信道"基本不变"的时长：动得越快，\(T_C\) 越短。

    一张图看懂多普勒：fd = (v/c)·fc·cos θ，迎着电波走（θ < 90°）频率升高，背着走降低，横着走（θ = 90°）不变。手机周围各个方向都有回波，每条移的量不同，于是原来一根谱线被展宽成多普勒谱。

    ① 俯视图：手机以 v 向右开，θ 是电波来的方向和前进方向的夹角。橙色那条 θ = 45°。
    ② 取讲义的数：v = 120 km/h、fc = 5 GHz → fm = 556 Hz。θ = 45° 的回波移了 556 × cos45° ≈ +393 Hz。所有方向的回波合起来，一根谱线被展宽成 fc ± fm 之间的 U 形谱（两端回波最密，因为 cos θ 在 0° 和 180° 附近变化最慢）。

    例：120 km/h（33.3 m/s）、载频 5 GHz：\(f_m=33.3\times5\times10^9/(3\times10^8)=555.6\) Hz，\(T_C\approx1.8\) ms。速度先换成 m/s（km/h ÷ 3.6）。

    • 符号时长 ≪ \(T_C\)（信号带宽 ≫ \(B_D\)）：一个符号内信道几乎不变，慢衰落；
    • 符号时长和 \(T_C\) 相当或更长：一个符号内信道就在变，快衰落（p.37）。
    ★ 考试重点 · 判断衰落类型 = 两个独立的比较
    比较决定什么结论
    Bs vs BC（或 Ts vs σTm）平坦 / 频率选择性Bs < BC，σTm/Ts < 0.1 → 平坦
    Bs vs BD（或 Ts vs TC）慢 / 快衰落Bs ≫ BD，Ts ≪ TC → 慢

    两组判断互相独立，组合出四种信道：平坦慢、平坦快、频选慢、频选快（p.38–39 两张图）。"平坦"不代表"慢"：符号越长越容易平坦，却越容易快衰落，方向正好相反。

    期末原题：2025-26 S2 Q1(a)(i) 直接问"怎样用 BC、多普勒扩展和信号带宽判断衰落类型"；2023-24 Q1(a)(iii)：Ts = 1 ms、σ = 0.01 ms、信道时不变 → σ/Ts = 0.01 < 0.1 平坦，时不变即没有多普勒 → 慢，结论"平坦慢衰落"。

    2.6电平通过率与平均衰落时长★★★ 必考

    设能正常工作的最低信号强度是 \(Z_{\min}\)，记 \(\rho=Z_{\min}/Z_{\mathrm{rms}}\)（门限和信号 rms 值之比）。信号在门限上下起伏，每往下穿过一次门限就进入一次"深衰落"。

    瑞利衰落的 LCR 与 AFD（p.41–43）
    \(L_Z=\sqrt{2\pi}\,f_m\,\rho\,e^{-\rho^2}\)　（次/秒）　　\(\bar\tau_Z=\dfrac{e^{\rho^2}-1}{\sqrt{2\pi}\,f_m\,\rho}\)　（秒）
    电平通过率 LCR：每秒有多少次信号"往下穿过"门限，也就是每秒进入几次深衰落。平均衰落时长 AFD：每次掉到门限以下平均持续多久。两者的乘积等于"信号低于门限的时间比例"：\(L_Z\bar\tau_Z=P(z\lt Z_{\min})=1-e^{-\rho^2}\)。
    ★ 考试重点 · 数错误的两个公式
    • 每次衰落连错几个符号 = AFD ÷ 符号时长 = AFD × 符号速率。
    • 每秒错几个符号 = LCR × 每次连错的个数。
    • LCR 也可以从观测次数直接算：10 秒里看到 40 次深衰落 → LCR = 4 次/秒（2025-26 S2 Q1(a)(ii)：AFD 20 ms、Ts 5 ms → 每次 4 个，每秒 16 个）。
    • 反过来：已知 AFD 正好盖住 3 个符号 → Ts = AFD/3（2024-25 Q1(a)(ii)：6 µs → 2 µs，LCR 5 → 每秒 15 个错）。
    例题一次衰落会连错几个符号（第 2 章 p.45–47）

    已知条件：门限是 rms 值的 10%（ρ = 0.1），车速最高 120 km/h，载频 5 GHz，符号速率 1 Msps，瑞利衰落；符号只要有一部分落在衰落里就算错。

    1
    \(f_m=33.33\times5\times10^9/(3\times10^8)=555.56\) Hz。
    2
    \(L_Z=\sqrt{2\pi}\times555.56\times0.1\times e^{-0.01}=2.5066\times55.556\times0.990=137.87\) 次/秒。
    3
    \(\bar\tau_Z=\dfrac{e^{0.01}-1}{2.5066\times55.556}=\dfrac{0.01005}{139.26}=72.17\) µs。
    4
    (a) 每次衰落连错的符号数 = AFD ÷ 符号时长 = \(72.17\times10^{-6}\times10^6\approx72\) 个。
    5
    (b) 每秒错的符号数 = 每次错的个数 × 每秒衰落次数 = 72.17 × 137.87 ≈ 9950 个，误符号率约 \(9.95\times10^{-3}\)。
    每次衰落连错约 72 个符号；每秒约 9950 个错误，SER ≈ 1%
    课外补充 · 讲义数值和公式对不上

    讲义 p.47 写的是 AFD = 71.17 µs、每秒 9812 个错误。按讲义自己的公式精确算是 72.17 µs，每秒 9950 个。可以用另一个办法核对：每秒错误数 = 低于门限的时间比例 × 符号速率 = \((1-e^{-0.01})\times10^6=9950\)，和 72.17 µs 的结果一致。考试按公式自己算即可，差别不大。

    Practice 2 第 1 题：\(f_D\) = 50 Hz，ρ = 0.1，\(\bar\tau=\dfrac{e^{0.01}-1}{\sqrt{2\pi}\times50\times0.1}=\dfrac{0.01005}{12.53}=0.80\) ms。

    ⚠ 易错
    • ρ 是幅度之比（"门限是 rms 值的 10%"→ ρ = 0.1），公式里用的是 ρ²，别再平方一次或换成 dB。
    • AFD 算出来是秒，乘符号速率（个/秒）才是个数；单位 µs、ms 要统一。
    • "错误符号数/秒"不是 LCR：LCR 是"衰落次数/秒"，每次衰落可能连错很多个符号。

    2.7信道容量：最多能传多快★★★ 必考

    AWGN 信道的香农容量（p.48）
    \(C=B\log_2(1+\gamma),\qquad \gamma=\dfrac{P}{N_0B}\)
    只要传输速率 R < C，就存在能让误码率任意小的编码；R > C 则误码率不可能趋于零。带宽翻倍容量差不多翻倍；SNR 翻倍只多 1 bit/s/Hz 左右（高 SNR 时）。γ 用线性值，不能直接代 dB。
    例题两个用户同时发（Practice 2 第 3 题）

    已知条件：每个用户收到 10 mW，噪声 0.1 mW，每个用户带宽 20 MHz。

    1
    (a) 先解用户 1，用户 2 当噪声：\(\gamma_1=10/(10+0.1)=0.990\)。
    C₁ = 20 MHz × log₂(1.990) = 19.86 Mbps
    2
    (b) 多用户检测（MUD）把用户 1 完全减掉，用户 2 只剩噪声：\(\gamma_2=10/0.1=100\)。
    C₂ = 20 MHz × log₂(101) = 133.16 Mbps
    用户 1：19.86 Mbps；用户 2：133.16 Mbps。这就是第 1 章 p.16 "干扰能解码就不再是敌人"的例子

    衰落信道里 SNR 是随机的。讲义给了两种容量：

    • 遍历容量（ergodic，p.49）：\(C_E=E[B\log_2(1+\gamma)]\)，对 SNR 的分布求平均。由 Jensen 不等式，\(C_E\le B\log_2(1+\bar\gamma)\)：平均 SNR 相同时，衰落信道的容量不会超过 AWGN 信道。
    • 中断容量（outage，p.50）：允许 ε 的时间中断，能保证的最高速率 \(C_\varepsilon=B\log_2(1+\gamma_{\min})\)，其中 \(P(\gamma\lt \gamma_{\min})=\varepsilon\)。适合慢衰落。平均无错速率是 \((1-\varepsilon)C_\varepsilon\)。

    衰落余量怎么推（p.51），一共三步：

    1. 瑞利信道 \(P(\gamma\lt \gamma_{\min})=1-e^{-\gamma_{\min}/\bar\gamma}\)，令它等于 ε。
    2. 解出 \(\gamma_{\min}=\bar\gamma\ln\frac{1}{1-\varepsilon}\)。这就是中断容量公式里 "1 + γ̄R ln(1/(1−ε))" 的来历：中断概率 ε 下能保证的最低 SNR。
    3. 要和 SNR 为 γAWGN 的 AWGN 信道一样快，需要 γmin = γAWGN，于是平均 SNR 要高出 \(\bar\gamma/\gamma_{\min}\) 倍：
    瑞利衰落的衰落余量（p.51）—— 必背
    \(\text{FM}=\bar\gamma_{\mathrm{dB}}-\gamma_{\mathrm{AWGN,dB}}=10\log_{10}\dfrac{1}{\ln\frac{1}{1-\varepsilon}}\ \text{dB}\approx10\log_{10}\dfrac1\varepsilon\)
    ε 很小时 \(\ln\frac{1}{1-\varepsilon}\approx\varepsilon\)，所以 ε = 1% → 20 dB，0.5% → 23 dB，0.1% → 30 dB。中断要求每严 10 倍，余量多 10 dB。
    例题期末原题：最小 SNR 与衰落余量（2025-26 S2 Q1(a)(iii)）

    已知条件：瑞利信道，平均 SNR \(\bar\gamma_R\) = 25 dB，ε = 0.005。

    1
    25 dB → 316.2（线性）。\(\ln(1/0.995)=0.005013\)。
    2
    最小 SNR：
    γ_min = 316.2 × 0.005013 = 1.585 → 10 log₁₀1.585 = 2.0 dB
    3
    衰落余量 = 25 − 2.0 = 23.0 dB（等于 10 log₁₀(1/0.005013)）。
    γ_min ≈ 2.0 dB，FM ≈ 23 dB

    2.8注水法：功率该怎么分★★ 常考

    频率选择性信道可以切成很多段子带，每段宽度约等于相干带宽，各自近似平坦（p.52–53）。每段是一个增益不同的 AWGN 信道。总功率有限时怎么分？答案是注水（water-filling）：好的子信道多分，太差的干脆不给。

    注水法（p.54）
    \(\dfrac{P_j}{P}=\begin{cases}\dfrac{1}{\gamma_0}-\dfrac{1}{\gamma_j}, & \gamma_j\ge\gamma_0\\ 0, & \gamma_j\lt \gamma_0\end{cases}\qquad \sum_j\Big(\dfrac1{\gamma_0}-\dfrac1{\gamma_j}\Big)=1\qquad C=\sum_{\gamma_j\ge\gamma_0}B_j\log_2\dfrac{\gamma_j}{\gamma_0}\)
    \(\gamma_j\) 是"把全部功率都给第 j 个子信道时的 SNR"。\(1/\gamma_0\) 是"水面高度"，\(1/\gamma_j\) 是"池底高度"：池底越低（信道越好），注的水越多；池底高过水面的子信道不分功率。
    类比

    往一个底部高低不平的水池里倒固定量的水。水会先填满最深的坑（最好的信道），倒到一定程度水面高过某个坑，那个坑才开始有水。有些地方地势太高（信道太差），水根本漫不过去。

    ★ 考试重点 · 注水三步
    1. SNR 换成线性值。假设 k 个子信道都分到功率：\(k/\gamma_0=1+\sum 1/\gamma_j\)，解出 γ₀。
    2. 检查：有 γj < γ₀ 的，把最差的去掉，k 减 1，回到第 1 步重算。
    3. 全部 γj ≥ γ₀ 后，\(P_j/P=1/\gamma_0-1/\gamma_j\)，容量 \(\sum\log_2(\gamma_j/\gamma_0)\)。各功率加起来应等于 P，用来自检。
    例题三个子信道的注水（第 2 章 p.56–57）

    已知条件：γ₁ = 17.77，γ₂ = 2.63，γ₃ = 0.087，发射端知道信道。

    1
    先假设三个都分到功率：\(3/\gamma_0=1+1/17.77+1/2.63+1/0.087=12.97\)，γ₀ = 0.23。可是 γ₃ = 0.087 < γ₀，矛盾，第三个不该分功率。
    2
    只用前两个：\(2/\gamma_0=1+1/17.77+1/2.63=1.436\)，γ₀ = 1.39。这次 γ₂ = 2.63 > 1.39，成立。
    3
    功率：\(P_1=(1/1.39-1/17.77)P=0.66P\)，\(P_2=(1/1.39-1/2.63)P=0.34P\)，0.66 + 0.34 = 1 ✓。
    4
    容量：\(\log_2(17.77/1.39)+\log_2(2.63/1.39)=3.68+0.92=4.59\) bit/s/Hz。
    P₁ = 0.66P，P₂ = 0.34P，P₃ = 0；C ≈ 4.59 bit/s/Hz

    第三章

    信号检测：从一堆带噪声的波形里认出符号

    发射端把比特变成波形（调制），接收端反过来：先把收到的波形变成几个数（解调，得到"判决变量"），再根据这几个数判断发的是哪个符号（检测）（p.2、p.13）。

    3.1用"坐标"表示波形★★ 常考

    关键想法：波形虽然是连续的函数，但调制用的那一组波形，往往只需要两三个"基本波形"就能拼出来，就像平面上任何一点都能用 x、y 两个坐标表示。

    正交基展开（p.4）
    \(s_i(t)=\displaystyle\sum_{j=1}^{D}s_{ij}\psi_j(t),\qquad s_{ij}=\int_0^T s_i(t)\psi_j(t)dt,\qquad \int_0^T\psi_i\psi_j\,dt=\begin{cases}1&i=j\\0&i\ne j\end{cases}\)
    \(\psi_j(t)\) 叫正交归一基函数（orthonormal basis），互相"垂直"、各自能量为 1。D 是基函数个数，叫信号空间的维数，D ≤ M（M 是信号个数）。\(s_{ij}\) 就是第 i 个信号在第 j 个方向上的"坐标"，用内积（相乘再积分）求出来。

    最常用的一对基（p.6）：\(\psi_1=\sqrt{2/T}\cos(2\pi f_ct)\)，\(\psi_2=\sqrt{2/T}\sin(2\pi f_ct)\)。前面的 \(\sqrt{2/T}\) 是为了让能量正好等于 1。

    例题找正交基和维数（Practice 3 第 1 题）

    已知条件：信号 \(A_i\cos(2\pi t/T+\phi_j)\)，0 < t < T，信息同时调制在幅度 \(A_i\) 和相位 \(\phi_j\) 上。

    1
    用和角公式拆开：\(A_i\cos(2\pi t/T+\phi_j)=A_i\cos\phi_j\cos(2\pi t/T)-A_i\sin\phi_j\sin(2\pi t/T)\)。
    2
    所有信号都是 \(\cos(2\pi t/T)\) 和 \(\sin(2\pi t/T)\) 的线性组合。它们在 [0, T] 上正交，能量都是 T/2，所以乘上 \(\sqrt{2/T}\) 归一化。
    基：{ √(2/T)·cos(2πt/T), √(2/T)·sin(2πt/T) }，维数 D = 2

    把每个信号的坐标画在平面上，就是星座图（constellation，p.8）：

    调制信号维数星座
    PAM（p.9）\(A_ip(t)\cos2\pi f_ct\)，\(A_i=2i-1-M\)14-PAM：−3, −1, +1, +3 排在一条线上
    PSK（p.10）\(Ap(t)\cos(2\pi f_ct+\phi_i)\)，\(\phi_i=2\pi(i-1)/M\)2M 个点均匀排在一个圆上
    QAM（p.11）幅度和相位都变216-QAM：4×4 方阵
    ★ 考试重点 · 星座的维数和距离
    • 维数 = 拼出所有信号需要的正交基函数个数：只用一个 cos（PAM、二进制 ±A）是 1 维；cos 和 sin 都用（PSK、QPSK、QAM）是 2 维。
    • 两点间的距离就是坐标差的长度：±1 两点距离 2；QPSK 四点 (±1, ±1) 相邻点距离 2、对角距离 2√2。
    • 期末 2025-26 S1 Q1(a)(i) 原题：画 ±1 的星座，求维数（1）和距离（2）。

    3.2AWGN 信道：每个坐标上加一点高斯噪声★★ 常考

    收到的信号 \(x(t)=s_i(t)+w(t)\)，\(w(t)\) 是加性高斯白噪声，双边功率谱密度 \(N_0/2\)（p.12）。把 \(x(t)\) 分别和各个基函数做内积，得到 D 个判决变量（p.14–15）：

    向量信道（p.15）
    \(\mathbf y=\mathbf s_i+\mathbf w,\qquad \mathbf w\sim\mathcal N\!\left(\mathbf 0,\tfrac{N_0}{2}\mathbf I\right)\)
    每个坐标上的噪声独立、均值 0、方差 \(N_0/2\)。这 D 个数是充分统计量：判断发了哪个符号需要的信息全在里面，不会因为只看这几个数而损失性能。
    SNR 的几种写法（p.16–17）
    \(\mathrm{SNR}=\dfrac{P_r}{N_0B}=\dfrac{E_s}{N_0BT_s}=\dfrac{E_b}{N_0BT_b}\)　　\(\gamma_s=\dfrac{E_s}{N_0}\)　\(\gamma_b=\dfrac{E_b}{N_0}=\dfrac{\gamma_s}{\log_2M}\)
    \(E_s\)：每个符号的能量；\(E_b\)：每个比特的能量。一个 M 进制符号装 \(\log_2M\) 个比特，所以 \(E_s=E_b\log_2M\)。比较不同调制方式时用每比特 SNR \(\gamma_b\) 和误比特率 \(P_b\)，因为"比特"是共同单位。

    3.3最优检测：选离收到的点最近的那个★★★ 必考

    • MAP（最大后验，p.18）：选"收到 y 以后，最可能被发送"的符号，最大化 \(p(\mathbf s_i\mid\mathbf y)\)。理论最优，但需要先验概率。
    • ML（最大似然，p.19）：选"发了它以后，最可能收到 y"的符号，最大化 \(p(\mathbf y\mid\mathbf s_i)\)。各符号等概时，ML 和 MAP 一样。
    AWGN 下 ML = 最小距离（p.19–20）
    \(p(\mathbf y\mid\mathbf s_i)\propto\exp\!\left(-\dfrac{\|\mathbf y-\mathbf s_i\|^2}{N_0}\right)\ \Longrightarrow\ \hat{\mathbf s}=\arg\min_{\mathbf s_i}\|\mathbf y-\mathbf s_i\|^2\)
    高斯噪声下，概率随距离的平方指数下降，所以"最可能"就是"最近"。在星座图上，每个星座点"管"离它最近的一块区域（判决区域 \(Z_i\)），收到的点落在哪块就判成哪个符号。
    误符号率的上界与 BPSK（p.20–21）
    \(P_s\le(M-1)\,Q\!\left(\dfrac{d_{\min}}{\sqrt{2N_0}}\right)\)　　BPSK：\(P_b=Q\!\left(\dfrac{d_{\min}}{\sqrt{2N_0}}\right)=Q\!\left(\sqrt{\dfrac{2E_b}{N_0}}\right)=Q(\sqrt{2\gamma_b})\)
    BPSK 两个点在 ±A，\(E_b=A^2\)，\(d_{\min}=2A\)，代入 \(2A/\sqrt{2N_0}=\sqrt{2A^2/N_0}=\sqrt{2E_b/N_0}\)。星座点之间的最小距离决定误码率：M 越大，点越挤，距离越小，误码越多，但每个符号装的比特越多（p.22）。
    例题噪声方差不同时的 ML 判决（Practice 3 第 2 题）

    已知条件：\(y_n=x_n+w_n\)，\(x_n\in\{0,1\}\) 等概；发 0 时噪声方差 \(\sigma_0^2\)，发 1 时 \(\sigma_1^2\)，且 \(\sigma_1^2>\sigma_0^2\)。

    1
    ML：比较两个似然。判 1 的条件是 \(\dfrac{1}{\sigma_1}e^{-(y-1)^2/2\sigma_1^2}>\dfrac{1}{\sigma_0}e^{-y^2/2\sigma_0^2}\)。
    2
    两边取对数整理：
    g(y) = y²/(2σ₀²) − (y−1)²/(2σ₁²) + ln(σ₀/σ₁) > 0 → 判 1
    令 g(ỹ) = 0，在 0 和 1 之间解出门限 ỹ。方差相等时门限就是 0.5；σ₁ 更大时门限往 0 那边移，因为发 1 时噪声大，需要给它更宽的判决区。
    3
    规则：\(y_n>\tilde y\) 判 1，\(y_n\lt \tilde y\) 判 0。
    4
    误码率：发 0 却超过门限的概率 \(Q(\tilde y/\sigma_0)\)，发 1 却低于门限的概率 \(Q((1-\tilde y)/\sigma_1)\)，各占一半：
    P_e = ½ [ Q((1 − ỹ)/σ₁) + Q(ỹ/σ₀) ]
    y > ỹ 判 1，否则判 0；P_e = ½[Q((1−ỹ)/σ₁) + Q(ỹ/σ₀)]

    课外补充：g(y) 是开口向上的二次函数，严格说在很负的 y 处还有第二个根（y 极小时也会判 1，因为发 1 的噪声更宽）。那个区域概率极小，讲义答案忽略了它。

    二进制检测：一张图看懂 Pb = Q(d/2σ)

    这是第 3 章最常考的计算，也是第 4、6 章所有误码率题的底子。设发 s = +A 或 −A（等概），收到 y = s + w，w ~ N(0, σ²)：

    σ = 0.5 时的示意。阴影是"发 +1、噪声把 y 拉到 0 以下"的概率：距离门限 1，等于 2 个标准差，面积 = Q(1/0.5) = Q(2)。
    1. 条件分布：s 固定时 y 只是把噪声平移了 s，所以 y | s = +A ~ N(+A, σ²)，y | s = −A ~ N(−A, σ²)（第 1 章：加常数只改均值，方差不变）。
    2. 判决门限：两个钟形曲线一样胖、一样高（等概），ML 判决就是"离谁近判谁"，门限在中点 0：y > 0 判 +A，y ≤ 0 判 −A。
    3. 误码率：发 +A 却判成 −A，要噪声把 y 拉到 0 以下，即 w < −A。A 是 A/σ 个标准差：Pb = Q(A/σ) = Q(d/(2σ))，d = 2A 是两点距离。发 −A 由对称性一样。
    4. 换成 Eb/N0：Eb = A²，σ² = N0/2，得到 BPSK 的 Q(√(2Eb/N0))。
    例题噪声方差 0.25 的 ±1 系统
    1
    σ = √0.25 = 0.5。门限 0，信号到门限的距离 1 = 2σ。
    2
    P_b = Q(1/0.5) = Q(2) ≈ 0.0228
    3
    噪声方差降到 0.09（σ = 0.3）：Q(1/0.3) = Q(3.33) ≈ 4×10⁻⁴。噪声标准差减小 40%，误码率降了 50 多倍：AWGN 下误码率随 SNR 指数下降。
    P_b = Q(2) ≈ 0.023（期末 2025-26 S1 Q1(a)(iii) 就是这组数）
    ⚠ 易错
    • Q 里放的是"信号到门限的距离 ÷ 标准差"，是 d/2，不是整个距离 d。
    • 先验概率不等或两边噪声方差不同时，门限不在中点（Practice 3 第 2 题），要用 ML / MAP 条件重新解门限。
    • 有 ISI 时信号到门限的距离会随前一个符号变化，要分情况算再平均（第 6 章）。

    3.4功率效率 vs 带宽效率★ 了解

    讲义 p.23–30 讨论怎么公平地比较不同系统：

    • 功率效率：在发射功率有限时，误码率能做到多低。卫星、蓝牙、GSM 看重这个。
    • 带宽效率：在带宽有限时，速率能做到多高。WiFi（802.11g）、WiMAX 看重这个。
    比较用的三个量（p.24–27）
    \(D=2BT\)　　\(\eta=\dfrac{R}{B}=\dfrac{2b}{D}\)　　\(\bar b=\dfrac bD=\dfrac\eta2\)　　\(\bar\varepsilon_x=\dfrac{\varepsilon_x}{D}\)　　\(\bar P_s=\dfrac{P_s}{D}\)
    D：一个符号周期 T、带宽 B 内可用的维数；b：每符号比特数；\(\bar b\)：每维比特数（衡量带宽效率）；\(\bar\varepsilon_x\)：每维平均能量（衡量功率效率）；\(\bar P_s\)：每维误符号率。经验法则：给定误码率和 \(\bar b\)，\(\bar\varepsilon_x\) 越小越好。

    p.28–30 的例子：系统 I（D = 1）\(\bar b=1\)、\(\bar P_s=Q(1/\sigma)\)；系统 II（D = 2）\(\bar b=1/2\)、\(\bar P_s=\tfrac12Q(\sqrt2/\sigma)\)，两者每维能量都是 1。系统 II 误码率更好，但多用了一倍带宽：用带宽效率换功率效率。

    3.5衰落信道里的误码率★★ 常考

    衰落时 SNR 是随机的，误码率也跟着随机。两种看法（p.31）：

    平均误码率与中断概率（p.31）
    \(\bar P_s=\displaystyle\int_0^\infty P_s(\gamma)\,p_\gamma(\gamma)\,d\gamma\)　　\(P_{\mathrm{out}}=P(\gamma\lt \gamma_0)=1-e^{-\gamma_0/\bar\gamma}\)（瑞利）
    平均误码率：把 AWGN 下的误码率按 SNR 的概率加权平均。中断概率：SNR 低于最低要求的时间比例。p.32 的结论很重要：AWGN 中误码率随 SNR 指数下降，瑞利衰落中只按线性（1/SNR）下降，要达到同样误码率需要多几十 dB 功率。
    例题BPSK 在瑞利衰落下需要多大平均 SNR（第 3 章 p.33–34）

    已知条件：要求 95% 的时间 SNR 高于最低需要的 8.5 dB。

    1
    中断概率 \(P_{\mathrm{out}}=1-0.95=0.05\)。
    2
    由 \(P_{\mathrm{out}}=1-e^{-\gamma_0/\bar\gamma}\) 解出 \(\bar\gamma=\dfrac{\gamma_0}{-\ln(1-P_{\mathrm{out}})}\)。
    3
    \(\gamma_0=10^{0.85}=7.08\)，\(-\ln0.95=0.0513\)：
    γ̄ = 7.08 / 0.0513 = 138 → 21.4 dB
    平均 SNR 需要 21.4 dB，衰落余量 = 21.4 − 8.5 = 12.9 dB

    不可消除的误码平台（error floor，p.35）：衰落太快（多普勒）或时延扩展太大时，即使 SNR 趋于无穷，误码率也降不到零，停在一个"地板"上。讲义的两个近似公式：

    误码平台（第 3 章 p.35；Practice 3）
    多普勒（DPSK）：\(P_{\mathrm{floor}}\approx\tfrac12(\pi f_DT_b)^2\)　　时延扩展（BPSK）：\(P_{\mathrm{floor}}\approx\left(\dfrac{\sigma_{T_m}}{T_b}\right)^2\)
    多普勒平台：符号越长，一个符号内信道变化越大，所以要速率足够高。时延扩展平台：符号越短，回声占的比例越大，所以要速率足够低。两者正好方向相反。
    例题多普勒平台下的最低速率（第 3 章 p.36）

    已知条件：瑞利衰落、均匀散射，\(f_D\) = 80 Hz，要求 DPSK 的误码平台低于 10⁻⁴。

    1
    \(\tfrac12(\pi\cdot80\cdot T_b)^2\le10^{-4}\Rightarrow\pi\cdot80\cdot T_b\le\sqrt{2\times10^{-4}}=0.01414\)。
    2
    \(T_b\le0.01414/251.3=5.63\times10^{-5}\) s。
    R = 1/T_b ≥ 17.77 kbps（讲义算式里 π 在 PDF 转文字时丢了，原式有 π）
    例题时延扩展平台下的最高速率（Practice 3 第 3 题）

    已知条件：\(\sigma_{T_m}\) = 3 µs，要求平台 10⁻³，用 QPSK。

    1
    \((3\,\mu s/T)^2\le10^{-3}\Rightarrow T\ge3/0.03162=94.9\) µs。这个 T 是符号时长：ISI 取决于回声相对于一个符号有多长。
    2
    BPSK 每符号 1 bit：10.54 kbps；QPSK 每符号 2 bit：
    R = 2 / 94.9 µs = 21.08 kbps
    QPSK 最高约 21.08 kbps
    ★ 考试重点 · 衰落下的误码率
    • 平均误码率 = 把 AWGN 误码率按 SNR 的分布加权平均：连续分布用积分，离散分布直接按概率加权求和（第 4 章期末题都是离散的）。
    • 瑞利衰落中断：Pout = 1 − e−γ₀/γ̄，反求 γ̄ = γ₀ / (−ln(1 − Pout))。
    • 误码平台：多普勒要速率高，时延扩展要速率低，两个公式方向相反。

    1. (a) A binary signal is transmitted over an Additive White Gaussian Noise (AWGN) channel, where the Gaussian noise has a zero mean and a variance of 0.25. The received signal can be expressed as, y = s + w, where s is a transmitted symbol which is equally likely to be +1 or −1, and w is the AWGN component. Note: The probability density function of a Gaussian random variable x with mean μ, variance σ2 is, p(x) = (1/√(2πσ2)) e−(x−μ)2/(2σ2)

    (i) Sketch the signal constellation of s. Find the dimension of this constellation and the distance between the two possible signal vectors.

    (ii) y can be shown to be a random variable with a Gaussian distribution. Determine the expected values and variances of y when s = 1 and when s = −1. Hence, derive the corresponding probability density function of y.

    (iii) If the decision rule is, ŝ = +1 when y > 0 and ŝ = −1 when y ≤ 0, determine the bit error probability of this system. Note: The Q-function of z is, Q(z) = ∫z+∞ (1/√(2π)) e−x2/2 dx

    (12 Marks)

    看解答（建议先自己做一遍）
    1
    (i) 两个点 +1 和 −1 都在实轴上：维数 = 1，两点距离 = |1 − (−1)| = 2。
    两个信号点都在一条直线（实轴）上，所以星座是一维的。
    2
    (ii) s 给定时 y = s + w 只是把零均值噪声平移了 s：
    s = +1：E[y] = 1，Var[y] = 0.25；　s = −1：E[y] = −1，Var[y] = 0.25
    （常数加随机变量，均值加上常数、方差不变，Ch1b 的性质。）条件概率密度：
    p(y | s = ±1) = (1/√(0.5π)) e−(y ∓ 1)²/0.5
    两者等概，y 的（无条件）概率密度是两个高斯的平均：
    p(y) = ½ · (1/√(0.5π)) [e−(y−1)²/0.5 + e−(y+1)²/0.5]
    3
    (iii) 发 +1、判成 −1 的条件是 y ≤ 0，即噪声 w ≤ −1。σ = 0.5：
    P(y ≤ 0 | s = +1) = P(w ≤ −1) = Q(1/0.5) = Q(2) ≈ 0.0228
    由对称性，发 −1 出错的概率也是 Q(2)，所以 Pb = Q(2) ≈ 0.023。一般式：Pb = Q(d/(2σ))，d = 2 是 (i) 求的距离。
    (i) 1 维，距离 2　(ii) 均值 ±1，方差 0.25　(iii) Pb = Q(2) ≈ 0.0228

    第四章

    分集：别把鸡蛋放在一个篮子里

    第 3 章的坏消息是：瑞利衰落下误码率只按 1/SNR 下降，靠加功率很不划算。根本原因是信道偶尔会掉进深衰落，掉进去以后加多少功率都救不回来。第 4 章的思路是：同一份信息走几条独立衰落的路，几条路同时掉进深衰落的概率很小（p.2–3）。

    分集的核心公式（p.3）
    \(P_{\mathrm{out,diversity}}=P(\text{M 条路的 SNR 同时}\lt \gamma_{\min})=P_{\mathrm{out}}^M\)
    前提是各条路独立。一条路中断 10%，两条独立的路同时中断只有 1%，三条只有 0.1%。
    类比

    重要文件同时用快递、邮件、U 盘三种方式寄出。任何一种出问题的概率都不小，但三种同时出问题的概率很小。前提是三种方式"不相关"：如果都要经过同一个已经被淹的仓库，就没用了。

    4.1宏分集与微分集★★ 常考

    • 宏分集（macroscopic，p.4）：一个手机同时连几个不同位置的基站，选信号最强的。用来对付阴影衰落：阴影是大尺度的，同一个基站方向上被楼挡住了，换个方向的基站很可能没被挡。Practice 4 第 1 题、Practice 2 第 2 题就是这个。
    • 微分集（microscopic，p.5）：对付多径衰落（小尺度）。几根天线隔开几个波长，衰落就基本独立了。
    分集方式（p.6）怎么做优点
    路径利用信道里本来就有的多条独立路径不用多天线，不多占功率和带宽
    空间基站上放几根隔开的天线分支数可选，不多占功率和带宽
    频率同一数据在两个以上载频上发分支数可选
    时间同一信息在不同时间重复发分支数可选，不需要额外空间
    极化利用信号在多径中发生的去极化不需要额外空间和带宽

    4.2三种合并方法★★★ 必考

    系统模型（p.8）：第 i 路收到 \(r_i(t)=A_ie^{j\theta_i}s(t)+w_i(t)\)，\(A_ie^{j\theta_i}\) 是这一路的衰落增益。理想分集时各路增益独立同分布。

    选择分集 SD（p.10–12）
    \(\gamma_{SD}=\max(\gamma_1,\dots,\gamma_M)\)　　\(P_{\mathrm{out}}(\gamma_0)=\left(1-e^{-\gamma_0/\bar\gamma}\right)^M\)　　\(\bar\gamma_{SD}=\bar\gamma\displaystyle\sum_{i=1}^{M}\frac1i\)
    只挑 SNR 最高的那一路。中断要求每一路都低于门限，独立时概率相乘。平均 SNR 只按 1 + 1/2 + 1/3 + … 增长：M = 2 时 1.5 倍，M = 3 时 1.83 倍。
    例题选择分集的中断概率（第 4 章 p.13）

    已知条件：BPSK，要求 \(P_b=10^{-3}\)，瑞利衰落，每路平均 SNR 15 dB，比较 M = 1、2、3。

    1
    AWGN 下 \(Q(\sqrt{2\gamma_0})=10^{-3}\) → \(\sqrt{2\gamma_0}=3.09\) → \(\gamma_0=4.77\) = 6.8 dB，这就是最低 SNR。
    2
    \(\gamma_0/\bar\gamma=10^{0.68}/10^{1.5}=4.79/31.6=0.151\)，\(1-e^{-0.151}=0.140\)。
    3
    M = 1：0.140；M = 2：0.140² = 0.020；M = 3：0.140³ = 0.003。
    中断概率 14% → 2% → 0.3%，每多一路就降约 7 倍
    最大比合并 MRC（p.15–16）
    \(y(t)=\displaystyle\sum_iA_ie^{-j\theta_i}r_i(t)\)　　\(\gamma_{MRC}=\dfrac{\sum_iA_i^2E_b}{N_0}=\sum_i\gamma_i\)
    每一路先乘上自己增益的共轭：相位对齐（\(e^{-j\theta_i}\)），按信号强度加权（\(A_i\)，强的路说话分量重）。结果是输出 SNR 等于各路 SNR 之和，这是线性合并能达到的最优。代价：每一路都要估计信道（p.17）。
    等增益合并 EGC（p.19–20）
    \(y(t)=\displaystyle\sum_ie^{-j\theta_i}r_i(t)\)　　\(\gamma_{EGC}=\dfrac{\left(\sum_iA_i\right)^2E_b}{MN_0}\)
    只对齐相位、不加权，所有路等权相加。不需要估计幅度 \(A_i\)，性能和 MRC 非常接近（p.20 的图）。
    小例子三种合并方法比一比

    两路某一时刻的增益 \(A_1=1\)、\(A_2=0.5\)，\(E_b/N_0=1\)，即两路 SNR 分别为 1 和 0.25。

    1
    SD：选大的，γ = 1。
    2
    MRC：相加，γ = 1 + 0.25 = 1.25。
    3
    EGC：\((1+0.5)^2/2=1.125\)。
    MRC 1.25 ≥ EGC 1.125 ≥ SD 1：MRC 最好，EGC 接近，SD 最简单

    相关性的影响（p.21）：两路如果相关，一路掉进深衰落时另一路也倾向于掉进去，\(P(\text{两路都深衰落})\ge P(\text{一路})\times P(\text{另一路})\)。只有不相关时才取等号，分集效果最好。Practice 4 第 2(c) 题就是"两路共享同一个阴影项 β"的相关情况。

    ★ 考试重点 · 离散 SNR 分布下的 SD 和 MRC（期末 4 年考了 3 次）
    1. dB 全部换成线性值。
    2. 列出两个支路的所有组合和概率（独立 → 概率相乘）。两个取值就是 4 种组合，三个取值就是 9 种。
    3. 每种组合的输出 SNR：SD 取较大的 max(γ₁, γ₂)；MRC 取和 γ₁ + γ₂。
    4. 加权平均：平均输出 SNR = Σ 概率 × 输出 SNR；平均误码率 = Σ 概率 × Pe(输出 SNR)，比如 DPSK 的 ½e−γ。

    捷径：MRC 的平均输出 SNR = 各支路平均 SNR 之和，不用列组合；但平均误码率仍要列组合（e−γ 不是线性的）。

    例题SD 和 MRC 同一组数比一比（自编）

    已知条件：两支路独立，每支路 SNR 以 0.5 的概率是 4、0.5 的概率是 9（线性值），DPSK，Ps = ½e−γ。

    1
    组合和概率：(4,4) 0.25，(4,9) 0.25，(9,4) 0.25，(9,9) 0.25。
    2
    SD：输出 4（只有两支都是 4 时，0.25）或 9（0.75）。
    平均 = 0.25 × 4 + 0.75 × 9 = 7.75；P̄_s = 0.25 × ½e⁻⁴ + 0.75 × ½e⁻⁹ = 2.29×10⁻³ + 4.6×10⁻⁵ ≈ 2.3×10⁻³
    3
    MRC：输出 8（0.25）、13（0.5）、18（0.25）。
    平均 = 2 + 6.5 + 4.5 = 13（= 6.5 + 6.5）；P̄_s = 0.25 × ½e⁻⁸ + 0.5 × ½e⁻¹³ + 0.25 × ½e⁻¹⁸ ≈ 4.3×10⁻⁵
    4
    单支路：P̄s = 0.5 × ½e⁻⁴ + 0.5 × ½e⁻⁹ ≈ 4.6×10⁻³。
    误码率：单支路 4.6×10⁻³ → SD 2.3×10⁻³ → MRC 4.3×10⁻⁵；MRC 好得多，因为它把两路能量加起来

    4.3分集后的误码率★★★ 必考

    平均误码率还是"按 SNR 的分布加权平均"：\(\bar P_s=\int P_s(\gamma)p_\gamma(\gamma)d\gamma\)（p.23）。以 DPSK + 选择分集为例（p.24–26）：

    DPSK + 选择分集（p.25–26）
    \(\bar P_b=\dfrac M2\displaystyle\sum_{n=0}^{M-1}(-1)^n\binom{M-1}{n}\frac{1}{\bar\gamma+n+1}\)　　M = 1：\(\dfrac{1}{2(1+\bar\gamma)}\approx\dfrac{1}{2\bar\gamma}\)　　M = 2：\(\dfrac{1}{(\bar\gamma+1)(\bar\gamma+2)}\approx\dfrac{1}{\bar\gamma^2}\)
    一路时误码率和 \(\bar\gamma\) 成反比；两路时和 \(\bar\gamma^2\) 成反比。SNR 提高 10 dB，一路只降 10 倍，两路降 100 倍。指数 M 就是"分集阶数"。
    阵列增益与分集增益（p.27–28）
    \(g\approx\dfrac{\bar\gamma_\Sigma}{\bar\gamma}\)　　\(\bar P_e\approx\bar\gamma^{-d}\ \Longrightarrow\ d\approx\dfrac{-\log_{10}\bar P_e}{\log_{10}\bar\gamma}\)
    阵列增益 g：合并后平均 SNR 比单路高多少倍，是曲线的"平移"。分集增益 d：误码率曲线在高 SNR 时的"斜率"，d ≤ M；N 发 M 收的 MIMO，d ≤ N × M，满分集时取等号。
    例题离散 SNR 分布下的 MRC（Practice 4 第 2 题）

    已知条件：DPSK，\(P_s=\tfrac12e^{-\gamma}\)；单路 SNR γ = 8（概率 1/3）或 11（概率 2/3）；发射功率和噪声都是 1 W。

    1
    (a) 单路：\(\bar\gamma=8\cdot\tfrac13+11\cdot\tfrac23=10\)；\(\bar P_s=\tfrac13\cdot\tfrac12e^{-8}+\tfrac23\cdot\tfrac12e^{-11}=6.15\times10^{-5}\)。
    2
    (b) 两路 MRC，输出 \(\gamma_\Sigma=\gamma_1+\gamma_2\)。两路独立，四种组合：16（1/9）、19（4/9）、22（4/9）。
    γ̄_Σ = 16/9 + 19·4/9 + 22·4/9 = 20
    P̄_s = ½[e⁻¹⁶/9 + 4e⁻¹⁹/9 + 4e⁻²²/9] = 7.56 × 10⁻⁹
    3
    阵列增益 g = 20/10 = 2；分集增益 \(d=-\log_{10}(7.56\times10^{-9})/\log_{10}10=8.1\)。
    4
    (c) 两路共享阴影项：\(\gamma_i=r_i+\beta\)。平均仍是 2 × (1 + 9) = 20。因为 \(e^{-\gamma_\Sigma}=e^{-r_1}e^{-r_2}e^{-2\beta}\) 且三者独立：
    E[e^{−r}] = ⅓e^{−0.6} + ⅔e^{−1.2} = 0.3837
    E[e^{−2β}] = ⅓e^{−14} + ⅔e^{−20} = 2.786 × 10⁻⁷
    P̄_s = ½ × 0.3837² × 2.786 × 10⁻⁷ = 2.05 × 10⁻⁸，d = 7.7
    (a) γ̄ = 10，P̄s = 6.15×10⁻⁵；(b) γ̄Σ = 20，P̄s = 7.6×10⁻⁹，g = 2，d = 8.1；(c) γ̄Σ = 20，P̄s = 2.05×10⁻⁸，g = 2，d = 7.7

    (b) 和 (c) 平均 SNR 一样，但 (c) 的误码率高了近 3 倍：两路共享阴影 β，一起变差，这就是"相关性削弱分集"。

    ★ 考试重点 · 阵列增益 g 和分集增益 d（2025-26 两次期末都考）
    • g = γ̄Σ / γ̄：合并器输出平均 SNR ÷ 输入平均 SNR；dB 下就是两者相减（15 dB − 12 dB = 3 dB → g = 2）。
    • P̄e ≈ γ̄−d，d ≈ −log₁₀P̄e / log₁₀γ̄，这里的 γ̄ 是合并器输入的平均 SNR（Practice 4 官方答案 d = 8.1 就是用输入 γ̄ = 10 算的）。
    • 已知 d 求误码率：P̄e = γ̄−d（2025-26 S2：12 dB、d = 3.7 → 15.85−3.7 ≈ 3.6×10⁻⁵）。
    • 理论上 d ≤ M（M 支路），MIMO 满分集 d = N × M。由单个误码率点反算的 d 可能超过 M，这是高 SNR 近似的结果，按公式写即可。
    ⚠ 易错
    • 用输出 SNR 代 d 的公式；或者 g 用 dB 值相除（应该相减，或者先换线性再相除）。
    • DPSK 的误码率是 ½e−γ，BPSK 是 Q(√(2γ))，题目会给，别混。

    4.4空间复用与分集-复用折中★★★ 必考

    空间复用（p.30）：N 根发射天线各发不同的数据，速率变成 N 倍，但没有分集增益，衰落下性能可能很差；接收天线数 M ≥ N 才解得开。

    多天线能不能同时要分集（误码率低）和复用（速率高）？p.31–33 定义了两个量：

    分集-复用折中（p.32–33）
    \(d=\lim\dfrac{-\log_2P_e}{\log_2\mathrm{SNR}}\)　　\(r=\lim\dfrac{R}{\log_2\mathrm{SNR}}\)　　\(d(r)=(N-r)(M-r),\ r=0,1,\dots,\min(N,M)\)
    d：SNR 每翻一倍，误码率降多快，最大 N × M。r：SNR 每翻一倍，速率多几 bit/s/Hz，最大 min(N, M)。两者此消彼长：r = 0 时分集最大 N × M；r = min(N, M) 时分集为 0。高 SNR 时容量 \(\approx\min(N,M)\log_2\mathrm{SNR}\)（p.31）。

    第五章

    MIMO：多根天线，既抗衰落又提速

    MIMO（Multiple-Input Multiple-Output）就是发射端 N 根天线、接收端 M 根天线。第 4 章已经提到它能提供空间分集，这一章讲四件事：信号模型、用 MIMO 做分集、空时编码、MIMO 容量（p.2）。

    5.1信号模型：y = Hx + v★★★ 必考

    平坦、时不变 MIMO 信道（p.5–6）
    \(y_m=\displaystyle\sum_{n=1}^{N}h_{m,n}x_n+v_m\quad\Longleftrightarrow\quad\mathbf y=\mathbf H\mathbf x+\mathbf v\)
    第 m 根接收天线收到的，是 N 根发射天线信号的加权和，再加噪声。\(h_{m,n}\) 是"第 n 根发射天线到第 m 根接收天线"的信道增益，排成 M 行 N 列的矩阵 \(\mathbf H\)。噪声在各天线间独立、方差 \(\sigma^2\)。

    多个时刻叠起来就是块模型 \(\mathbf Y=\mathbf H\mathbf X+\mathbf V\)（p.7）。频率选择性信道会有记忆：\(\mathbf y_i=\sum_{l=0}^{L}\mathbf H_l\mathbf x_{i-l}+\mathbf v_i\)，当前输出受前面 L 个输入影响，这就是 ISI（p.8，第 6 章的主题）。

    ★ 考试重点 · 写出 MIMO 模型（2025-26 S2 Q1(b)(ii)）
    • N 根发射、M 根接收：y（M×1）= H（M×N）x（N×1）+ v（M×1）。H 的行对应接收天线、列对应发射天线，hij 是第 j 根发射到第 i 根接收的增益。
    • 为什么每对天线只有一个增益：平坦衰落下各条回波在一个符号内叠成一个复数，没有可分辨的多个抽头，也就没有 ISI。频率选择性时才会出现 H0, H1, … 多个矩阵（p.8）。
    • 例：4 发 6 收 → H 是 6×4，yi = Σj=1..4 hijxj + vi。

    5.2接收分集 SIMO：最大比合并的推导★★★ 必考

    1 发 2 收（p.12–15）：\(y_1=h_1x+v_1\)，\(y_2=h_2x+v_2\)，写成 \(\mathbf y=x\mathbf h+\mathbf v\)。接收端用权重线性合并：\(\hat x=\mathbf w^H\mathbf y=x\,\mathbf w^H\mathbf h+\mathbf w^H\mathbf v\)。

    推导权重怎么选，SNR 最大（第 5 章 p.13–15）
    1
    信噪比：\(\mathrm{SNR}=\dfrac{E\{|x|^2\}\,|\mathbf w^H\mathbf h|^2}{\sigma^2\,\mathbf w^H\mathbf w}\)（噪声空间白，\(E\{\mathbf v\mathbf v^H\}=\sigma^2\mathbf I\)）。
    2
    分子是两个向量内积的平方。由柯西-施瓦茨不等式，\(|\mathbf w^H\mathbf h|^2\le\|\mathbf w\|^2\|\mathbf h\|^2\)，当 \(\mathbf w\) 和 \(\mathbf h\) 同方向时取等号：\(\mathbf w=\alpha\mathbf h\)。
    3
    代回：
    SNR_max = E{|x|²}/σ² · ‖h‖² = E{|x|²}/σ² · (|h₁|² + |h₂|²)
    w ∝ h，就是第 4 章的 MRC；SNR 正比于 |h₁|² + |h₂|²

    直觉：只要 h₁、h₂ 不同时很小，SNR 就不会太差。两者独立时，同时很小的概率远低于其中一个很小的概率（p.15）。

    ★ 答题模板 · SIMO 为什么能得到分集（2025-26 S1 Q1(b)(ii)）
    1. 为什么是 SIMO：只有一个发送符号 s（单输入），收到两个信号 y₁、y₂（多输出）。
    2. 独立：两根接收天线隔开足够远，h₁、h₂ 独立衰落，同时深衰落的概率是各自概率的乘积。
    3. 合并：MRC 用 h₁*、h₂* 加权相加，有效增益 |h₁|² + |h₂|²，只要有一路好，输出 SNR 就不会太差 → 分集阶数 2。

    5.3发射分集 MISO：知不知道信道很关键★★ 常考

    2 发 1 收（p.16–18），两根天线发同一个 x，各乘一个权重：\(y=x\,\mathbf w^H\mathbf h+v\)。

    • 发射端知道信道（informed）：取 \(\mathbf w=\alpha\mathbf h\)，SNR ∝ \(|h_1|^2+|h_2|^2\)，有分集（p.17）。相当于发射端提前把两路信号的相位对齐，让它们在接收端同相相加，叫波束成形。
    • 发射端不知道信道（uninformed）：权重是固定的，\(|w_1^*h_1+w_2^*h_2|^2\) 和单个 \(|h|^2\) 分布一样（只差一个比例），没有分集（p.18）。两路信号随机地时而相加、时而抵消，和一根天线没区别。

    发射端不知道信道时怎么办？答案是下面的空时编码。

    特征子信道（p.19）
    \(\mathbf H=\mathbf U\boldsymbol\Sigma\mathbf G^H\)，发端乘 \(\mathbf G\)、收端乘 \(\mathbf U^H\)：\(\tilde{\mathbf y}=\mathbf U^H\mathbf H\mathbf G\mathbf x=\boldsymbol\Sigma\mathbf x\)
    奇异值分解（SVD）把 MIMO 信道拆成几条互不干扰的并行 SISO "特征子信道"，增益就是奇异值。前提是发射端知道 \(\mathbf H\)。这是 5.5 节 MIMO 容量公式的来历。

    5.4Alamouti 空时块码：发射端不知道信道也能分集★★★ 必考

    空时块码（STBC）把符号同时在空间（哪根天线）和时间（哪个时隙）上编排（p.20）。最经典的是 Alamouti 码：2 根发射天线、2 个时隙、发 2 个符号（p.21）：

    Alamouti 编码矩阵（p.21–22）
    \(\mathbf X(\mathbf s)=\begin{bmatrix}s_1 & s_2\\ -s_2^* & s_1^*\end{bmatrix}\)（行：时隙 1、2；列：天线 1、2）　　\(\mathbf X\mathbf X^H=\|\mathbf s\|^2\mathbf I\)
    时隙 1：天线 1 发 \(s_1\)、天线 2 发 \(s_2\)；时隙 2：天线 1 发 \(-s_2^*\)、天线 2 发 \(s_1^*\)。码率 R = K/T = 2 个符号 / 2 个时隙 = 1（全速率，p.29）。关键性质是正交：\(\mathbf X\mathbf X^H=(|s_1|^2+|s_2|^2)\mathbf I\)，正是这个性质让接收端能用很简单的线性运算把两个符号分开。
    推导Alamouti 的判决变量（Practice 5 第 2 题）

    已知条件：符号 \(u_1,u_2\)；时隙 1：A 发 \(u_1\)、B 发 \(u_2\)；时隙 2：A 发 \(-u_2^*\)、B 发 \(u_1^*\)。两个时隙信道不变（\(h_A,h_B\)），1 根接收天线，噪声 \(\mathcal N(0,N_0)\)。

    1
    两个时隙收到：
    y₁ = h_A u₁ + h_B u₂ + w₁
    y₂ = −h_A u₂* + h_B u₁* + w₂
    2
    第二式取共轭：\(y_2^*=-h_A^*u_2+h_B^*u_1+w_2^*\)。现在两个式子都是 \(u_1,u_2\) 的线性组合：
    [y₁, y₂*]ᵀ = F [u₁, u₂]ᵀ + [w₁, w₂*]ᵀ，F = [[h_A, h_B], [h_B*, −h_A*]]
    3
    F 的两列正交：\(\mathbf F^H\mathbf F=(|h_A|^2+|h_B|^2)\mathbf I\)。两边左乘 \(\mathbf F^H\)：
    z₁ = h_A* y₁ + h_B y₂* = (|h_A|² + |h_B|²) u₁ + h_A* w₁ + h_B w₂*
    z₂ = h_B* y₁ − h_A y₂* = (|h_A|² + |h_B|²) u₂ + h_B* w₁ − h_A w₂*
    4
    除以 \(\|\mathbf h\|=\sqrt{|h_A|^2+|h_B|^2}\) 归一化，噪声方差回到 \(N_0\)。
    z₁ = ‖h‖u₁ + w̃₁，z₂ = ‖h‖u₂ + w̃₂，w̃ ~ N(0, N₀)：两个符号完全分开，每个都得到 |h_A|² + |h_B|² 的二阶分集

    官方答案写成 ‖h₁‖、‖h₂‖，其实两个都是同一个 ‖h‖ = √(|h_A|² + |h_B|²)。

    SNR 对比（p.26、p.30）
    MRC（1 发 2 收）：\(\dfrac{\|\mathbf h\|^2E_b}{\sigma^2}\)　　OSTBC：\(\dfrac{T\|\mathbf h\|^2E_b}{KN\sigma^2}\)　　Alamouti：\(\dfrac12\dfrac{\|\mathbf h\|^2E_b}{\sigma^2}\)
    Alamouti 和 MRC 的分集阶数一样（都是 2），但 SNR 低 3 dB：发射端的总功率要分给两根天线，每根只有一半。所以 MRC 比 Alamouti 多一个"阵列增益"。

    正交空时块码 OSTBC（Tarokh 1998，p.27–28）把 Alamouti 推广到 N > 2 根天线：元素是符号及其共轭的线性组合，且满足 \(\mathbf X\mathbf X^H=\|\mathbf s\|^2\mathbf I\)，能达到满分集 d = N × M。p.28 的 3 天线例子用 8 个时隙发 4 个符号，码率只有 1/2。p.29 的对角码 \(\mathrm{diag}(s_1,s_2)\) 不满足正交条件，不是 OSTBC。WiMAX、802.11n、LTE 都采用了 OSTBC（p.27）。

    ★ 考试重点 · Alamouti 三件事
    • 验证正交（2023-24 Q1(b)(iii)）：算 X XH。逐行做内积：同一行和自己的内积 = |s₁|² + |s₂|²；不同两行的内积要抵消为 0。成立就是 X XH = (|s₁|² + |s₂|²) I，正交 STBC。行列交换（转置）不影响结论。
    • 有没有分集（2023-24 Q1(b)(iv)）：有，2 发 1 收是 2 阶，2 发 M 收是 2M 阶（满分集），而且发射端不需要知道信道；代价是比 MRC 少 3 dB 阵列增益（p.30）。
    • 检测后的统计量（2025-26 S2 Q1(b)(iii)）：ŝ = s + Gw/‖h‖²。均值 E[ŝ] = s（噪声零均值，无偏）；方差乘了 1/‖h‖⁴：σ²‖h‖²/‖h‖⁴ = σ²/‖h‖²。两路增益相加让噪声变小，这就是分集。

    5.5MIMO 容量：几根天线 = 几条并行的数据管道★★★ 必考

    MIMO 容量（Telatar 1999，p.32–36）
    \(C(\mathbf H)=B\log_2\det\!\Big(\mathbf I+\dfrac{1}{\sigma^2}\mathbf H\mathbf P\mathbf H^H\Big)=B\displaystyle\sum_{i=1}^{r}\log_2\!\Big(1+\frac{\lambda_i}{\sigma^2}\Big)\)
    第二个等号的推导（p.34–35）：对 \(\mathbf H\mathbf P\mathbf H^H\) 做特征分解 \(\mathbf U\boldsymbol\Lambda\mathbf U^H\)，再用 \(\det(\mathbf I+\mathbf A\mathbf B)=\det(\mathbf I+\mathbf B\mathbf A)\) 和 \(\mathbf U^H\mathbf U=\mathbf I\)，行列式变成对角线元素之积，log 把积变成和。r 是矩阵的秩，\(\lambda_i\) 是特征值。MIMO 容量 = r 条并行 SISO 信道容量之和。
    • SISO（N = M = 1）：退化成 \(B\log_2(1+P|h|^2/\sigma^2)\)，就是香农公式（p.33）。
    • SIMO / MISO（p.38–39）：只有 1 条空间管道，加天线只让 SNR 变大，容量按 log 增长。
    • MIMO：秩 r 可以到 min(N, M)，容量按 min(N, M) 倍线性增长，这是 MIMO 最大的价值。
    • 发射端不知道信道（p.37）：每根天线平均分功率，\(\mathbf P=\frac PN\mathbf I\)，\(C=B\log_2\det(\mathbf I+\frac{P}{N\sigma^2}\mathbf H\mathbf H^H)\)。
    • 发射端知道信道（p.40）：用第 2 章的注水法给各特征子信道分功率。
    • 遍历容量（p.41–42）：H 随机时对 H 取平均。高 SNR 时知不知道信道差别很小。
    • 慢衰落的中断（p.43）：\(P_{\mathrm{out}}(R)=P(C(\mathbf H)\lt R)\)，有效速率 \((1-P_{\mathrm{out}})R\)。

    均衡：把拖进下一个符号的回声抵消掉

    第 2 章说过，信号带宽超过相干带宽时会出现频率选择性衰落，在时域表现为码间干扰 ISI：前一个符号的回波拖进了后一个符号（p.4）。均衡器放在接收端，在采样时刻把 ISI 压下去（p.2）。

    6.1ISI 从哪来：奈奎斯特准则★★★ 必考

    发射信号 \(s(t)=\sum_n m_n\psi(t-nT)\)。如果 \(\psi(t)\) 和它平移 nT 后的版本正交，采样时就互不干扰。两种做法（p.6–7）：

    • \(\psi(t)\) 只在 [0, T] 内非零（矩形脉冲）：带宽无限大，不现实；
    • \(\psi(t)=\frac{1}{\sqrt T}\mathrm{sinc}(t/T)\)：在自己的采样时刻是 1，在别的采样时刻都是 0，带宽只要 1/T。

    可是信道本身也是个滤波器。即使发射脉冲正交，经过信道 h(t) 以后的等效脉冲 \(p(t)=\psi(t)*h(t)\) 就未必正交了（p.8–9）。例：\(\psi(t)=\mathrm{sinc}(t)\)，\(h(t)=\delta(t)+\delta(t-1)\)，T = 1，则 \(p(t)=\mathrm{sinc}(t)+\mathrm{sinc}(t-1)\)，相邻脉冲的内积是 1 ≠ 0，解调输出变成 \(\hat m_1=m_0+m_1\)。

    奈奎斯特无 ISI 准则（p.12）
    \(y(nT)=m[n]g_e(0)+\displaystyle\sum_{i\ne n}m[i]\,g_e(nT-iT)+w(nT)\)，要求 \(g_e(nT-iT)=\begin{cases}1&n=i\\0&n\ne i\end{cases}\)
    \(g_e=g_T*g_C*g_R\) 是"发送滤波 × 信道 × 接收滤波"的总冲激响应。中间那个求和就是 ISI。只要总响应在其他采样点上都为 0，就没有 ISI。最优接收滤波是匹配滤波 \(p^*(-t)\)（p.11）。

    对付 ISI 有三类办法（p.13）：最优检测（MAP / MLSE）、均衡、多载波（OFDM，第 7 章）。

    ★ 先学会读 Z 变换（Q2(a) 四年都要用）
    • Z⁻¹ 就是"晚一个符号"。H(Z) = 1 + 0.3Z⁻¹ 的意思是：收到的 = 1 × 当前符号 + 0.3 × 上一个符号，即 h = {1, 0.3}，信道长度 L = 2（2025-26 S1 Q2(a)(i)）。
    • Z 的次数就是延迟几个符号：H(Z) = 1 + 0.6Z⁻² → 只有当前符号和前两个符号有关，中间那个系数是 0（2023-24 Q2(a)(ii)：按 r[i] = Σ h[n]m[i−n+1] 的编号，h[1] = 1、h[2] = 0、h[3] = 0.6）。
    • 两个滤波器串起来 = 多项式相乘：(1 − 0.6Z⁻²)(1 + 0.6Z⁻²) = 1 − 0.36Z⁻⁴。噪声只经过后一个滤波器。
    • 写离散模型：r[n] = Σi=1..L h[i] m[n − i + 1] + w[n]，除 i = 1 以外的项都是 ISI。

    6.2最优：最大似然序列估计 MLSE 和维特比算法★ 了解

    ISI 把相邻符号绑在一起，单独判每个符号不再最优。MLSE 把整个序列当成一个整体，找最可能的那一串（p.16）：

    MLSE（p.16–17）
    \(\hat{\mathbf m}=\arg\max_{\mathbf m}p(\mathbf r\mid\mathbf m)\)　　穷举 \(M^K\) 种 → 维特比算法只需跟踪 \(M^L\) 个状态
    K 个 M 进制符号共有 \(M^K\) 种可能的序列，穷举不现实。如果 ISI 只涉及最近 L 个符号（L ≪ K），用维特比算法只需要跟踪 \(M^L\) 个"状态"（最近 L 个符号的组合）。例：QPSK（M = 4）、信道记忆 L = 2，状态数 4² = 16（p.35）。但复杂度仍随 L 指数增长。

    6.4判决反馈均衡 DFE★★ 常考

    线性均衡的缺点是放大噪声（p.29）。DFE 换个思路：过去的符号已经判决过了，直接把它们造成的 ISI 减掉。

    • 前馈滤波器：线性地压制未来符号的 ISI；
    • 反馈滤波器：用已判决的过去符号 \(\hat m[n-1],\hat m[n-2],\dots\) 重构并减去它们的 ISI（p.32–33）。

    如果过去的判决都对，减掉 ISI 不放大任何噪声，性能接近最优。问题是错误传播（p.34）：一旦判错一个，减的就是错误的 ISI，反而加大干扰，后面可能连着错，直到连续判对几个以后才恢复。

    6.5信道估计：均衡器需要先知道信道★ 了解

    最小二乘信道估计（p.38–40）
    \(\mathbf Y=\mathbf H\mathbf X+\mathbf V\)，\(\hat{\mathbf H}_{LS}=\mathbf Y\mathbf X^\dagger,\ \mathbf X^\dagger=\mathbf X^H(\mathbf X\mathbf X^H)^{-1}\)　　最优训练：\(\mathbf X\mathbf X^H=\dfrac PN\mathbf I\)
    发一段双方都知道的训练序列 X，收到 Y，反解出 H 使 \(\|\mathbf Y-\mathbf H\mathbf X\|^2\) 最小。训练矩阵各行正交、功率平均分时最好，此时 \(\hat{\mathbf H}_{LS}=\frac NP\mathbf Y\mathbf X^H=\mathbf H+\frac NP\mathbf V\mathbf X^H\)，估计误差的 MSE 和 N² 成正比。

    OFDM：把一条坑洼的宽路，改成很多条平整的窄路

    单载波系统速率越高，符号越短，ISI 拖的符号越多，时域均衡器越复杂（p.3）。OFDM 换个思路：不把一条高速数据流塞进一个宽带信道，而是拆成 N 条低速子流，每条用一个窄带子载波发（p.2、p.4）。

    类比

    一辆卡车在坑洼的宽马路上飞驰，颠得厉害（频率选择性衰落、ISI）；把货分给 N 辆小推车，每辆走一条很窄、很平整的小道，每辆都慢慢走，但加起来运量一样。每条小道窄到"路面平整"（平坦衰落），每辆车慢到"颠簸的回声来不及影响下一趟"（无 ISI）。

    7.1两条设计原则★★★ 必考

    OFDM 设计（p.5）
    \(\dfrac1T\lt B_C\)（每个子载波上平坦衰落）　　\(T_G>T_D\)（保护间隔长于最大时延扩展）
    T 是 OFDM 符号时长，1/T 约等于子载波宽度，要小于相干带宽，每个子信道才是平坦的。再在每个 OFDM 符号前加一段保护间隔 \(T_G\)，长度超过最大时延扩展 \(T_D\)，上一个符号的回声就全落在保护间隔里，不影响下一个符号。
    子载波数与速率（p.8）
    \(\Delta f=\dfrac BN\)　　\(T=NT_S\)　　每个子载波的符号速率 \(R=\dfrac1T=\dfrac{R_S}{N}\)
    总带宽 B 分成 N 份，每份 Δf。原来单载波的符号时长是 \(T_S\)，现在每个子载波上的符号拉长 N 倍。N 越大，子信道越窄越平坦、符号越长，越不怕 ISI。
    例题N 该怎么选（Practice 7 第 1(a) 题）

    已知条件：总带宽 B，多普勒扩展 \(B_d\)，相干带宽 \(B_C\)；要求每个子信道都是慢平坦衰落。

    1
    平坦：子信道宽度远小于相干带宽：\(B/N\ll B_C\) → \(N\gg B/B_C\)。
    2
    慢衰落：子载波符号时长 \(N/B\) 远小于相干时长 \(1/B_d\) → \(N\ll B/B_d\)。
    B/B_C ≪ N ≪ B/B_d：N 太小，子信道不平坦；N 太大，符号太长，一个符号内信道就变了
    ★ 考试重点 · 子载波数和速率（期末每年都有一问）
    • 平坦条件：每个子载波带宽 B/N 要小于相干带宽：N > B/BC，取整往上（2025-26 S1：500/30 = 16.7 → 17；2023-24：子载波带宽取 BC/2 → N = 1 MHz / 250 kHz = 4）。
    • 时间关系：原始符号时长 Ts = 1/B；一个 OFDM 块 T = N Ts（N 个符号并行，每个拉长 N 倍）。
    • 速率：每个 OFDM 块传 N log₂M 比特。不加保护间隔速率 = N log₂M / T；加了 TG 后有效速率 = N log₂M / (T + TG)（2025-26 S1：100 bit / 110 µs ≈ 909 kbit/s）。每个子载波的速率 = 总速率 / N（2024-25：10 Mbit/s → 每个 2.5 Mbit/s）。

    7.2子载波为什么能挤在一起而不干扰：正交★★★ 必考

    子载波正交（p.7）与 OFDM 信号（p.9）
    \(\dfrac1T\displaystyle\int_0^Te^{j2\pi(f_j-f_k)t}dt=\begin{cases}1&j=k\\0&j\ne k\end{cases}\)　　\(x(t)=\dfrac{1}{\sqrt T}\sum_{k=0}^{N-1}s_ke^{j2\pi kt/T}\)
    子载波间隔正好是 1/T，任意两个子载波在一个符号周期内都相差整数个周期，相乘积分为 0。所以虽然各子载波的频谱（sinc 形状）互相重叠，在每个子载波的中心频率处，其他子载波正好过零（p.10–11）。接收端在 \(f=k/T\) 处采样频谱，就能把 \(s_k\) 单独取出来。

    频谱互相重叠，所以 OFDM 比传统频分复用（各子载波之间要留保护带）省带宽（p.27）。功率谱 \(\sum_n\mathrm{sinc}^2(fT-n)\)，N 很大时总带宽趋于 N/T（p.11）。

    实现：发射端的"N 个子载波相加"在离散时间就是 IDFT，接收端的"N 个相关器"就是 DFT（p.19–20），都用 FFT 快速计算。

    ★ 两个证明题的答题要点
    • 相关器输出 = sn（2025-26 S1 Q2(b)(iii)）：乘 (1/√T)e−j2πnt/T 在 [0, T] 积分，得 (1/T)Σk sk∫ej2π(k−n)t/Tdt。k = n 时被积函数为 1，积分 = T；k ≠ n 时是整数个周期的复指数，积分 = 0。所以只剩 sn。
    • 为什么是 IDFT（2025-26 S2 Q2(b)(ii)）：在一个块内按 t = iT/N 采样，xi = (1/√T)Σ skej2πki/N，和 N 点 IDFT 的式子只差一个常数。频域的 N 个符号变成时域的 N 个采样，发端用 IFFT、收端用 FFT。

    7.3多径信道下：子信道增益 H_k★★★ 必考

    子信道增益（p.15）
    \(H_k=\displaystyle\sum_{i=0}^{L-1}h_i\,e^{-j2\pi ik/N}\)
    \(h_i\) 是信道冲激响应的第 i 个抽头。\(H_k\) 就是冲激响应的 DFT 在第 k 个子载波上的值。不同子载波的增益不同，这就是"频率选择性"；但每个子载波内部增益是一个常数，所以是平坦的。
    例题4 个子载波的信道增益（Practice 7 第 1(b) 题）

    已知条件：\(y(t)=h_0x(t)+h_1x(t-\tau)+w(t)\)，\(h_0=0.8\)，\(h_1=0.6\)，N = 4，延迟正好一个采样。

    1
    \(H_k=0.8+0.6e^{-j2\pi k/4}=0.8+0.6e^{-j\pi k/2}\)。
    2
    逐个代入：\(e^{-j\pi k/2}\) 依次是 1、−j、−1、j：
    H₀ = 0.8 + 0.6 = 1.4；H₁ = 0.8 − 0.6j；H₂ = 0.8 − 0.6 = 0.2；H₃ = 0.8 + 0.6j；H₄ = H₀ = 1.4
    |H|²：H₁、H₃ 为 1，H₂ 只有 0.04（深衰落），H₄ 为 1.96

    直观看：子载波 2 上，直射和延迟两路正好反相相减，只剩 0.2；子载波 0（= 4）上同相相加，有 1.4。

    ★ 考试重点 · 手算 Hk（N = 4 的速算表）

    Hk = Σi hi e−j2πik/N，k = 1…N，HN = H0。N = 4 时 e−j2πk/4 依次是：

    k1234（= 0）
    e−j2πk/4（乘 h₁）−j−1j1
    e−j2π·2k/4（乘 h₂）−11−11

    例：h = {1, 0.3}（2025-26 S2）→ H₁ = 1 − 0.3j，H₂ = 0.7，H₃ = 1 + 0.3j，H₄ = 1.3。h = {1, −0.6, 0.2}（2023-24）→ 0.8 + 0.6j、1.8、0.8 − 0.6j、0.6。自检：H₄ = 所有抽头之和；H₁ 和 H₃ 互为共轭（抽头是实数时）。

    7.4保护间隔与循环前缀★★★ 必考

    多径会带来两种干扰（p.16）：上一个 OFDM 符号的回声（时延扩展），和子载波之间失去正交（子载波间干扰 ICI）。

    • 保护间隔（p.17–18）：每个 OFDM 块前面延长 \(T_G\ge T_D\)，接收端把这段丢掉，只看后面的 N 个采样，上一块的回声就进不来。代价是多花了时间和功率，功率损失 \(=10\log_{10}\dfrac{NT_S+T_G}{NT_S}\) dB。
    • 循环前缀 CP（p.21–22）：保护间隔里放的不是空白，而是把这个块最后 G 个采样复制到最前面。这样信道的线性卷积在接收窗口里等价于循环卷积，DFT 以后正好变成相乘：\(r_k=H_ks_k+w_k\)。子载波之间保持正交，没有 ICI。
    例题最短需要多长的循环前缀（Practice 7 第 3 题）

    已知条件：信道 \(H(z)=1+0.9z^{-1}\)。

    1
    冲激响应只有两个抽头：当前采样，加上晚一个采样的回声（系数 0.9）。最大时延扩展 = 1 个采样。
    2
    CP 长度要 ≥ 信道长度 − 1 = 2 − 1 = 1，才能把上一个块的回声挡住。
    最短 CP = 1 个采样（符号）长度
    例题设计一个 OFDM 系统（Practice 7 第 2 题）

    已知条件：速率 2 Mbps，16-QAM，可用带宽 600 kHz，最大时延扩展 20 µs，CP 等于最大时延扩展。求子载波数和 OFDM 符号时长。

    1
    16-QAM 每符号 4 bit，需要的总符号速率：2 Mbps ÷ 4 = 500 k 符号/秒。
    2
    N 个子载波，每个宽 600k/N Hz，有用符号时长 \(T=N/600\text{k}\)；加上 CP，一个 OFDM 符号总长 \(T+20\) µs，期间发出 N 个符号：
    N / (N/600k + 20 µs) = 500k

    ★ 考试重点 · 循环前缀
    • 表达式（2024-25 Q2(b)(ii)）：式子不变，只把时间范围往前延长 TG：x(t) = (1/√T)Σ skej2πkt/T，nT − TG ≤ t < (n+1)T。ej2πkt/T 以 T 为周期，所以前面多出来的一段正好是块尾的复制。
    • 功率损失：10 log₁₀[(NTs + TG)/(NTs)] dB（2023-24：4 µs + 1 µs → 0.97 dB；2025-26 S2：8 µs + 20 µs → 5.44 dB）。
    • 长度：TG ≥ 最大时延扩展；离散时 CP ≥ 信道长度 − 1 个采样（Practice 7 第 3 题）。

    7.5OFDM 的容量和均衡★★ 常考

    OFDM 容量（p.24）
    \(C(\mathbf P)=\displaystyle\sum_{k=1}^{N}\log_2\!\left(1+\frac{|H_k|^2P_k}{N_k}\right)\)
    N 个独立的平行高斯信道，最优功率分配还是第 2 章的注水法。
    例题等容量分配 vs 注水（Practice 7 第 1(c)(d) 题）

    已知条件：沿用上面的 \(|H_k|^2=\{1,\ 0.04,\ 1,\ 1.96\}\)，噪声 1，总功率 10。

    1
    (c) 要每个子信道容量相等，就要 \(|H_k|^2P_k\) 都相等，记为 c：\(P_k=c/|H_k|^2\)。
    c(1 + 25 + 1 + 0.510) = 10 → c = 0.3635
    P₁ = 0.36，P₂ = 9.09，P₃ = 0.36，P₄ = 0.19
    为了"拉平"，最差的子信道吃掉了 91% 的功率。
    2
    (d) 求最大总容量用注水。把"噪声/增益" \(1/|H_k|^2=\{1,25,1,0.51\}\) 当池底，水面 μ 满足 \(\sum(\mu-1/|H_k|^2)=10\)。

    4

    频域均衡（p.25–26）
    \(R_k=s_kH_k+W_k\ \Longrightarrow\ \hat s_k=\dfrac{R_k}{H_k}\)
    每个子载波只要除以一个复数（估计出的信道增益），比第 6 章的时域均衡器简单得多。这是 OFDM 能做高速率的根本原因（p.27）：把频率选择性信道变成 N 条平行的平坦信道，不需要复杂的时域均衡。

    • 给的是 |Hk|，公式里要平方：|H₂| = 0.2 → |H₂|² = 0.04。
    ★ 第七章考试重点
    • N > B/BC；T = NTs；速率 N log₂M/(T + TG)。
    • 子载波正交 → 相关器输出 sn；发端是 IDFT。
    • Hk = Σ hie−j2πik/N，N = 4 速算。
    • CP 表达式（nT − TG ≤ t）和功率损失 10 log((NTs + TG)/NTs)。
    • OFDM 容量 = Σ log₂(1 + |Hk|²Pk/Nk)，最优是注水；频域均衡 ŝk = Rk/Hk。

    (i) 每个子载波带宽 500/N 要小于相干带宽 30 kHz：
    N > 500/30 = 16.7 → Nmin = 17
    2
    (ii) N = 50：子载波带宽 10 kHz → 子载波符号时长 T = 1/10 kHz = 100 µs。为消除时延扩展的 ISI 要加保护间隔 TG ≥ 10 µs，块长 110 µs。每个 OFDM 块携带 50 × 2 = 100 bit（4-QAM 每符号 2 bit）：
    Reff = 100 bit / 110 µs ≈ 909 kbit/s
    不计保护间隔的原始速率是 100/100 µs = 1 Mbit/s；"effective" 指扣掉保护间隔后的速率。
    3
    (iii) 第 n 个相关器把 r(t) 乘以 (1/√T)e−j2πnt/T 再在一个符号期 T 内积分（T = TOFDM，sk 在符号期内为常数）：
    (1/√T)∫₀T x(t)e−j2πnt/Tdt = (1/T) Σk sk ∫₀T ej2π(k−n)t/Tdt
    当 k = n，被积函数是 1，积分 = T；当 k ≠ n，积分的是整数个完整周期的复指数，结果为 0（子载波正交）：
    ∫₀T ej2π(k−n)t/Tdt = T·δ[k − n] → 输出 = (1/T)·sn·T = sn(t)
    噪声项另算，所以信号部分只剩 sn，其他子载波对它没有干扰。
    (i) N ≥ 17　(ii) ≈ 909 kbit/s（不计保护间隔 1 Mbit/s）　(iii) 子载波正交 → 输出 sn
