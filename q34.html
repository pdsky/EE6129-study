出题规律

  • Q3 = Part A 蜂窝计算，约 25 分四套卷的第一步都是「数信道，每小区信道 = S/N」，然后查话务表，再反推用户数、密度、半径或小区数。题目只是从这条链上截一段。
  • 查哪张表看关键词2023-24、2024-25 用 Erlang B（blocked calls cleared、blocking probability）。2025-26 两套都是 Erlang C（probability of delay），而且信道数不在表上，要线性插值。两张表都要会。
  • Au = λH 每套都出现要么用它求用户数，要么反过来问平均通话时长 H = Au/λ（2025-26 两套都问了秒数）。H 一定先换成小时。
  • SIR 选簇、扇区化隔年出现Qn/6、Q = √(3N)、120° 公式。凡是扇区化都要写评论：SIR 变好，但每扇区信道少、中继效率下降、切换变多；只有配合缩小 N 才能增容。
  • Q3 末尾常挂 4–5 分概念考过多址 FDMA/TDMA/CDMA 和 FCA/DCA。最近一套换成了 M/M/m 状态转移图和 Pk 推导（12 分左右）。
  • Q4 以描述为主，物联网每套必考通信网络层四子层考了 3 次，雾计算 2 次，五个难点 1 次。另配 1–3 个「系统流程」题：HLR/VLR、硬/软切换、802.11 入网、卫星四种切换、传感网架构。
  • Q4 也可能夹 9–12 分计算2023-24 考了 SIR 推导和求 n，2024-25 考了 Erlang B 中继效率。近两年 Q4 全是概念，但不能赌。
  • 评论题的固定说法「信道池越大，中继效率越高」「分裂不改 SIR、不改每小区信道，只改面积」「扇区化用容量换 SIR」。这三句几乎每套都能用上。

Q3 / Q4 计算部分全部公式

看到什么词，用哪条公式

课件说考试有附录公式，但附录不会告诉你什么时候用哪条。每张卡片先写「触发词」，再写公式和易错点，最后是考过它的题。

一、数信道

带宽 → 双工信道数

触发词：FDD、each link uses … for control、carrier 200 kHz、timeslots per frame、guard band

每方向业务带宽 = 总带宽/2 − 每链路控制 载波数 = 业务带宽 ÷ 载波带宽（向下取整） TDMA：双工信道 = 载波数 × 每帧时隙数 FDMA：双工信道 = (总带宽 − 保护带) ÷ 全双工信道带宽

易错：先对半分再扣控制（每条链路各扣）。按一个方向数出来的已经是双工信道，不用再 ×2。「full-duplex channel bandwidth 30 kHz」已经是一对，直接用总带宽除。

每小区信道、系统容量

触发词：channels per cell、cluster replicated、system capacity、number of cells

每小区 M = S/N（向下取整） 簇面积 = N × 小区面积 复制次数 = 系统面积 ÷ 簇面积 系统容量 C = S × 复制次数 = M × 小区总数 小区数 = 总面积 ÷ 2.598R²（向上取整）

易错：有控制信道时先扣掉再 ÷N。小区数覆盖面积要向上取整，用户数、信道数向下取整。

频谱效率

触发词：spectral efficiency in channels/MHz/km²

η = (总带宽/Bc) ÷ (总带宽 × Acell × N) = 1 / (Bc × Acell × N) 例：1/(0.03 MHz × 10.39 km² × 9) = 0.356

易错：Bc 用 MHz（30 kHz = 0.03 MHz），面积用 km²。

二、SIR 与选簇

合法簇大小：为什么只有 1, 3, 4, 7, 9, 12 …

触发词：cluster size、算出 N ≥ 8.25 这种非整数

N = i² + ij + j² （i, j 是非负整数） 从一个小区走 i 格，左转 60°，再走 j 格， 就到最近的同频小区。

为什么不能取 8：没有任何整数 i、j 能让 i² + ij + j² = 8，六边形铺不出 8 个一簇的图案。所以算出 N ≥ 8.25 时，取不小于它的最小合法值 9。

为什么还要验算两个：算 N = 9 的 SIR 证明它够（18.7 dB ≥ 18 ✓），再算前一个合法值 N = 7 证明它不够（16.7 dB ✗）。这样才说明 9 是「最小」的。

24-25 Q3(a)

四种 SIR 公式

触发词：first tier、equidistant、edge of the cell → 简化式；worst case → 最坏式；120°/60° sector

Q = D/R = √(3N) 全向简化（6 个干扰都在 D）：SIR = Qn/6 全向最坏（手机在角上）： SIR = 1 / [2(Q−1)−n + 2Q−n + 2(Q+1)−n] 120° 扇区（剩 2 个干扰）： SIR = 1 / [Q−n + (Q+0.7)−n] 60° 扇区（剩 1 个干扰）：SIR = (Q+0.7)n

来源：接收功率 ∝ d−n。信号来自自己的基站（距离 R），干扰来自 6 个同频基站（距离 D）：SIR = R−n/(6D−n) = (D/R)n/6。

三、话务与查表

选表：B 还是 C

B 表触发词：blocked calls cleared、blocking probability、GOS、call blocking

C 表触发词：queued、delayed、probability of delaying a call、Erlang C system

每用户话务、用户数、密度、半径

触发词：calls per hour、holding time、traffic per user、users per km²、cell radius

Au = λH（H 用小时） H = Au/λ 用户数 m = A / Au（向下取整） 密度 = m / 小区面积 面积 = m / 密度，R = √(面积 / 2.598) 需求 = 面积 × 密度 × Au vs 容量 = 查表 A

易错：90 s = 0.025 h；15 min × 2 次/h = 0.5 E。供给（查表）和需求（m × Au）分清楚。

承载话务、中继效率、集群增益

触发词：carried load、trunking efficiency、trunking gain

承载话务 = A(1 − PB) 中继效率 η = A / M（也可用承载话务 / M） 集群增益 Tg = 用户数 / 信道数（23-24 的定义）

评论必写：信道池越大，η 越高。N 变小 → 每小区信道多 → η 升、容量升，但同频小区更近，SIR 下降。

四、扩容与排队模型

小区分裂

触发词：cell splitting、new cell radius

D、R 同比缩小 → Q 不变 → SIR、N、每小区信道都不变 每小区面积 ≤ 容量 A ÷ (密度 × Au) Rnew = R × √(容量 / 需求)

易错：分裂后每小区信道不变，变多的是全系统信道（小区多了）。R 是上限，写「R ≤ 0.647 km」。

24-25 Q3(c)：0.65 km

扇区化

触发词：120° sector、3-sector directional antenna

干扰：6 → 2（120°）→ 1（60°） 每扇区信道 = M / 3，单独查表，再 × 3 N 不变：容量下降（中继效率降），只换来 SIR N 变小：用更好的 SIR 换更小的簇，才增容

易错：不能拿整个小区的信道数查表。半个载波时两扇区共用一个载波（各 4 个时隙）。

触发词：state transition diagram、derive Pk

向右：λ；向左：kμ（k ≤ m），mμ（k ≥ m） 平衡：λPk−1 = μkPk，ρ = λ/μ k ≤ m：Pk = P0 ρk / k! k ≥ m：Pk = P0 ρk / (m! · mk−m)
