全概率公式 Law of total probability 定义·必会
\[ P(B)=\sum_{i}P(A_i)\,P(B\mid A_i)\qquad\Big(\textstyle\sum_i P(A_i)=1\Big) \]
分情况算，再按概率加权："平均误码率 = Σ 状态概率 × 该状态的误码率"。Ai 必须互斥且凑满全部。老师点名的往年错误：只写一项 P(A₁)P(B | A₁)，必须对所有 Ai 求和（第 8 周录音）。
贝叶斯公式 Bayes' rule 背
\[ P(A_i\mid B)=\frac{P(A_i)\,P(B\mid A_i)}{\sum_j P(A_j)\,P(B\mid A_j)} \]
蓝框，要背（讲义第 1b 章 p.5–9）。分子 = 状态表里"所问那一行"的乘积，分母 = 全概率算出的总和 P(B)。由果推因：已知"出错了"，问"当时是坏状态"的概率。后验 ≠ 先验：模拟 A·Q1 里坏状态先验 0.3，知道出错后变成 0.977。
期望 Expectation 背
\[ E[X]=\sum_x x\,P_X(x)\qquad\qquad E[g(X)]=\sum_x g(x)\,P_X(x) \]
讲义第 1b 章 p.10–11。E[X] = Σx·P(x) 是老师点名要背的；E[g(X)] 的一般式考试会给，乘的是 X 的概率 PX(x)，不是 g 的。E[g(X)] ≠ g(E[X])，老师说这是往年常见错误。
方差 Variance 定义·必会
\[ E[X^2]=\sum_x x^2P_X(x) \]\[ \mathrm{Var}(X)=E[X^2]-\big(E[X]\big)^2,\qquad \sigma=\sqrt{\mathrm{Var}(X)} \]
讲义 p.10–11。老师课上的说法：方差 = 平方的均值 − 均值的平方。E[X²] ≠ (E[X])²：模拟 A·Q1 里 E[γ²] = 70.3，而 7.3² = 53.29，两者之差 17.01 就是方差。方差是两个接近的数相减，E[X] 要多留一两位再平方：2023-24 那组数 14.679² = 215.48，方差 5.47；若用 14.68² = 215.50，会得 5.45。方差的单位是 X 的单位²，进 Q 函数要用标准差 σ。
线性变换与求和 aX + b and sums 定义·必会
\[ E[aX+b]=aE[X]+b,\qquad \mathrm{Var}(aX+b)=a^2\,\mathrm{Var}(X) \]\[ E[X+Y]=E[X]+E[Y],\qquad \mathrm{Var}(X+Y)\overset{\text{indep.}}{=}\mathrm{Var}(X)+\mathrm{Var}(Y) \]
讲义 p.10–11、p.14。加常数只平移、不改方差；乘 a，方差乘 a²；独立变量相加，相加的是方差（标准差不能直接加）。期末 2025-26 S1 Q1(a)(ii)（第 3 章题）用的就是这条：y = s + w，s = +1 固定、w 方差 0.25 → E[y] = 1，Var[y] = 0.25。
dB 值求平均 Averaging values given in dB 定义·必会
\[ \bar\gamma=\sum_i p_i\,10^{\gamma_{i,\rm dB}/10} \]\[ \bar\gamma_{\rm dB}=10\log_{10}\bar\gamma\ \neq\ \sum_i p_i\,\gamma_{i,\rm dB} \]
dB 是对数：先把每个值换成线性 → 按概率加权平均 → 再换回 dB。直接平均 dB 只会偏小（所有取值相等时才一样），取值越分散差得越多：2023-24 Q1(b)(i) 错算 11.6 dB、正确 11.67 dB（差 0.07 dB）；模拟 A·Q1 错算 7 dB、正确 8.63 dB（差 1.63 dB）。老师说没写 dB ↔ 线性换算会扣分。

中文例子 · 怎么用

例 1 · 三种状态（状态表多一行）

某链路有三种状态：好（概率 0.6，误比特率 10⁻⁴）、一般（0.3，10⁻³）、深衰落（0.1，10⁻²）。(a) 求平均误比特率；(b) 发现一个比特出错，它发生在深衰落里的概率是多少？发生在好状态的概率呢？

  1. 列表并检查：0.6 + 0.3 + 0.1 = 1 ✓。
  2. 每行相乘：0.6 × 10⁻⁴ = 6×10⁻⁵；0.3 × 10⁻³ = 3×10⁻⁴；0.1 × 10⁻² = 1×10⁻³。
  3. (a) 全概率，三行都要加：\(P_e=6\times10^{-5}+3\times10^{-4}+1\times10^{-3}=1.36\times10^{-3}\)。
  4. (b) 贝叶斯，每一行 ÷ 总和：P(深衰落 | 错) = 1×10⁻³ / 1.36×10⁻³ = 0.7353；P(好 | 错) = 6×10⁻⁵ / 1.36×10⁻³ = 0.0441；P(一般 | 错) = 3×10⁻⁴ / 1.36×10⁻³ = 0.2206。三者相加 = 1 ✓。

答案：Pe = 1.36×10⁻³；P(深衰落 | 错) ≈ 0.735，P(好 | 错) ≈ 0.044。只占 10% 时间的深衰落贡献了 73.5% 的错误。

例 2 · 反着问：由平均误码率求坏状态占比

两种状态：好状态误比特率 10⁻⁴，坏状态 10⁻²。实测平均误比特率为 2×10⁻³。求坏状态的时间比例 p，再求"出错时处于坏状态"的概率。

  1. 全概率写成方程，未知数是 p（好状态的概率就是 1 − p）：\(2\times10^{-3}=(1-p)\times10^{-4}+p\times10^{-2}\)。
  2. 移项：\(2\times10^{-3}-10^{-4}=p\,(10^{-2}-10^{-4})\ \Rightarrow\ p=\dfrac{1.9\times10^{-3}}{9.9\times10^{-3}}=0.1919\)。
  3. 代回验算：(1 − 0.1919) × 10⁻⁴ + 0.1919 × 10⁻² = 2.0×10⁻³ ✓。
  4. 贝叶斯：P(坏 | 错) = p × 10⁻² / Pe = 0.1919 × 10⁻² / (2×10⁻³) = 0.9596。

答案：p ≈ 0.192（约 19% 的时间是坏状态）；P(坏 | 错) ≈ 0.960。

例 3 · SNR 以 dB 给出：均值、方差、中断，再把功率加倍

接收 SNR 是离散随机变量：3 dB（概率 0.25）、10 dB（0.5）、15 dB（0.25）。(a) 求平均 SNR（线性和 dB）；(b) 求方差和标准差；(c) 门限 6 dB，求中断概率；(d) 发射功率加倍（每个 SNR 都 ×2），平均 SNR 和方差变成多少？

  1. 先换线性：3 dB → 100.3 = 1.995；10 dB → 10；15 dB → 101.5 = 31.623。
  2. (a) \(E[\gamma]=0.25\times1.995+0.5\times10+0.25\times31.623=0.499+5+7.906=13.405\)，即 10 log₁₀13.405 = 11.27 dB。直接平均 dB 会得 0.25 × 3 + 0.5 × 10 + 0.25 × 15 = 9.5 dB，低了 1.77 dB ✗。
  3. (b) 平方可以在指数上乘 2：(100.3)² = 100.6 = 3.981，10² = 100，(101.5)² = 103 = 1000。\(E[\gamma^2]=0.25\times3.981+0.5\times100+0.25\times1000=0.995+50+250=301.0\)；\(\mathrm{Var}=E[\gamma^2]-(E[\gamma])^2=301.0-13.405^2=301.0-179.7=121.3\)，σ = √121.3 = 11.01。
  4. (c) 离散分布的中断概率 = 低于门限的那些取值的概率之和：只有 3 dB < 6 dB，所以 Pout = 0.25。
  5. (d) 功率加倍：Y = 2γ，每个 dB 值都 + 3.01 dB。E[Y] = 2E[γ] = 2 × 13.405 = 26.81，即 11.27 + 3.01 = 14.28 dB；Var(Y) = 2² × 121.3 ≈ 485（系数要平方），标准差 = 2 × 11.01 ≈ 22.0（标准差只乘 2）。

答案：(a) E[γ] ≈ 13.4（11.27 dB）；(b) Var ≈ 121.3，σ ≈ 11.01；(c) 0.25；(d) 均值 26.81（14.28 dB），方差 ≈ 485。

易错 · Traps

  • 全概率只写一项：P(B) = P(A₁)P(B | A₁) ✗。这是老师点名的往年错误，要对所有状态求和。
  • 贝叶斯答成先验：模拟 A·Q1(b) 答 0.3 ✗，正确是 0.977。分母一定是全概率算出的总和。
  • 直接平均 dB 值：模拟 A·Q1(c) 7 dB ✗，8.63 dB ✓。先换线性再平均，最后再换回 dB。
  • E[g(X)] 当成 g(E[X])：E[γ²] = 70.3，不是 7.3² = 53.29；方差忘了减 (E[X])²。
  • Var(aX) 写成 a·Var(X)：系数要平方；独立变量相加，加的是方差、不是标准差；进 Q 函数前方差要开根号。
  • 把互斥当独立：独立是 P(A∩B) = P(A)P(B)，互斥是 P(A∩B) = 0；题目说 independent 才能直接相乘。
英文答题模板 · Exam English

Let G and B denote the good and bad states and e a bit error. By the law of total probability, \(P_e=P(G)P(e\mid G)+P(B)P(e\mid B)=0.7\times10^{-4}+0.3\times10^{-2}=3.07\times10^{-3}\). By Bayes' rule, \(P(B\mid e)=P(B)P(e\mid B)/P_e=(3\times10^{-3})/(3.07\times10^{-3})=0.977\). Converting the SNRs to linear scale (10 dB → 10, 0 dB → 1), the mean SNR is \(E[\gamma]=0.7\times10+0.3\times1=7.3\), i.e. \(10\log_{10}7.3=8.63\) dB, and \(E[\gamma^2]=0.7\times100+0.3\times1=70.3\), so \(\mathrm{Var}(\gamma)=70.3-7.3^2=17.01\). The dB values must not be averaged directly, because dB is a logarithmic scale.

2dB 换算与 SNR · dB conversion and SNR

定义·必会 出现：几乎每道计算题都要用 · 期末 2024-25 Q1(a)(iii)、2025-26 S2 Q1(a)(iii)（dB → 线性）· Practice 1 Q2、Practice 2 Q1 / Q3 · 模拟 A·Q3、B·Q3、专项·Q3

dB 很少单独出题，却是每道计算题的第一步和最后一步：功率给 W 或 mW，要先换成 dBm 才能代路径损耗的 dB 式；SNR 给 dB，要先换成线性才能代香农、瑞利公式或求平均。老师说漏写 dB ↔ 线性换算会扣分，mW 没换成 dBm 也会扣分。Quiz 可能的问法：给发射功率（W）、损耗和噪声（dBm，或 N₀ 和带宽），求 SNR（dB 和线性）。

例 1 · 功率给 W、噪声给 N₀（一路算到容量）

发射功率 0.5 W，链路总损耗 110 dB，带宽 200 kHz，噪声功率谱密度 −174 dBm/Hz。求接收功率（dBm）、SNR（dB 和线性）和香农容量。

  1. 换 dBm：0.5 W = 500 mW → 10 log₁₀500 = 26.99 dBm（1 W 是 30 dBm，减半就是 −3.01 dB）。
  2. 接收功率：dBm − dB = dBm，Pr = 26.99 − 110 = −83.01 dBm。
  3. 噪声：N = −174 + 10 log₁₀(2×10⁵) = −174 + 53.01 = −120.99 dBm。
  4. SNR = −83.01 − (−120.99) = 37.98 dB → 103.798 ≈ 6.28×10³。
  5. 香农（用线性 SNR）：C = 2×10⁵ × log₂(1 + 6280) = 2×10⁵ × 12.62 = 2.52 Mbps。

答案：Pr = −83.01 dBm；SNR = 37.98 dB ≈ 6.28×10³；C ≈ 2.52 Mbps。

例 2 · 反着问：要求 SNR，求最小发射功率（换回 W）

接收机带宽 1 MHz，噪声谱密度 −174 dBm/Hz，要求 SNR ≥ 15 dB；发射机到接收机的路径损耗是 125 dB。发射功率至少多大？分别用 dBm 和 W 表示。

  1. 噪声：N = −174 + 10 log₁₀10⁶ = −174 + 60 = −114 dBm。
  2. 需要的接收功率：Pr ≥ N + SNR = −114 + 15 = −99 dBm（dBm + dB = dBm）。
  3. 发射功率：Pt = Pr + 损耗 = −99 + 125 = 26 dBm。
  4. 换回 W：1026/10 mW = 398 mW ≈ 0.40 W。

答案：Pt,min = 26 dBm ≈ 0.40 W。

例 3 · 有干扰：I + N 要回到 mW 相加

接收信号 −80 dBm，同频干扰 −85 dBm，噪声 −90 dBm。求 SNR、SIR、SINR（dB）。

  1. SNR、SIR 都是两个功率之比，dBm 直接相减：SNR = −80 − (−90) = 10 dB；SIR = −80 − (−85) = 5 dB。
  2. I + N 是功率相加，必须回到 mW：I = 10−8.5 = 3.162×10⁻⁹ mW，N = 10−9 = 1×10⁻⁹ mW，I + N = 4.162×10⁻⁹ mW → 10 log₁₀(4.162×10⁻⁹) = −83.81 dBm。
  3. SINR = −80 − (−83.81) = 3.81 dB → 100.381 = 2.40。
  4. 验算：1/(1/SIR + 1/SNR) = 1/(0.3162 + 0.1) = 2.40 ✓。SINR 比 SNR、SIR 都小，因为分母最大。写成 −85 + (−90) = −175 "dBm" 是错的：dBm 相加等于功率相乘，没有意义。

答案：SNR = 10 dB，SIR = 5 dB，SINR = 3.81 dB（线性 2.40）。

易错 · Traps

  • W / mW 没换就代 dB 式：1 W 不是 0 dBm，是 30 dBm。老师说 mW 没换成 dBm 会扣分，代数前先问"这个数是不是 dB"。
  • dBm 和 dBm 相加：I + N、几路信号合在一起，都要回到 mW 再加；dBm 只能和 dB 加减。
  • 该换线性没换：香农、瑞利 1 − e−γ₀/γ̄、求平均都用线性 SNR；漏写换算会扣分。老师讲例题时说 8.5 dB 要先换成 100.85，每年都强调还是有人不换。
  • 不该换的也换了：阴影 Q(余量/σ) 里余量和 σ 都是 dB，直接相除。老师讲 Practice 1 Q1 时特别提醒："10 dB above"的 10 是 dB，不要换成线性。
  • 10 log 和 20 log 混用：幅度（signal strength、ρ）用 20 log。"rms 值的 0.1 倍"→ ρ = 0.1；"功率低 10 dB"→ ρ = 0.316。
  • 带宽忘了用 Hz：10 log₁₀(5 MHz) 要算 10 log₁₀(5×10⁶) = 66.99，不是 10 log₁₀5。带宽翻倍噪声多 3.01 dB，所以模拟 B·Q3(b) 容量只从 28.4 涨到 47.1 Mbps（1.66 倍）。

例 1 · 功率给瓦、K 给线性值：两种形式各算一遍（变形：单位换算）

发射功率 4 W，简化路径损耗模型 K = 5×10−4（线性值），γ = 3，d₀ = 1 m。(a) 求 200 m 处的接收功率，用 dBm 和 W 各写一次。(b) 距离加倍到 400 m，接收功率降多少 dB？是原来的几分之一？

  2. dB 式：距离项 10γ log₁₀(d/d₀) = 30 × log₁₀200 = 30 × 2.301 = 69.03 dB；Pr = 36.02 − 33.01 − 69.03 = −66.02 dBm。

例 2 · 反求最远距离，参考距离 d₀ = 10 m（变形：倒着问 + d₀ 不是 1 m）

发射功率 1 W，KdB = −50 dB（在 d₀ = 10 m 处定的），γ = 4，接收机最低需要 −100 dBm，不考虑阴影。(a) 最远能覆盖多远？(b) 要覆盖 2 km，发射功率至少多少瓦？

例 3 · 从路径损耗图读 K、γ，再识破“自由空间”陷阱（变形：读图 + 选模型）

实测路径损耗 PL（dB）对 log₁₀d 画成一条往上走的直线：d = 1 m（log₁₀d = 0）处 PL = 40 dB，log₁₀d = 3 处 PL = 145 dB。(a) 求 KdB 和 γ。(b) Pt = 20 dBm，求 200 m 处的 Pr。(c) 有同学改用自由空间公式（f = 2 GHz，Gt = Gr = 1）算 200 m 处的 Pr，会得到多少？差多少？

  2. (b) PL(200 m) = 40 + 35 log₁₀200 = 40 + 35 × 2.301 = 40 + 80.54 = 120.54 dB；Pr = 20 − 120.54 = −100.54 dBm。
  3. (c) 自由空间：λ = c/f = 3×108/2×109 = 0.150 m；PL = 20 log₁₀(4πd/λ) = 20 log₁₀(4π × 200/0.150) = 20 log₁₀(16 755) = 84.48 dB → Pr = 20 − 84.48 = −64.48 dBm。

易错 · Traps

  • 题目写 simplified path loss model（或给了 K、γ）却套自由空间 (λ/4πd)²：老师说往年 Quiz 真有人这样错。自由空间每十倍距离只降 20 dB，γ = 3.5 时降 35 dB；专项 Q1 里 1 km 处两者差约 45 dB。
  • 功率没换成 dBm 就代进 dB 式（老师：会扣分）。只有 Pt、Pr 是 dBm，KdB 和 10γ log₁₀(d/d₀) 是 dB。反过来，线性式里的 K 要用倍数（−30 dB → 10−3），不能代 −30。
  • 把 10γ 写成 γ：γ = 3.6 时距离项是 36 log₁₀d，不是 3.6 log₁₀d。读图同理：横轴是 log₁₀d 时斜率 = 10γ，横轴是 10 log₁₀d 时斜率才 = γ。
  • 忘了除以 d₀：d₀ = 10 m 时要用 log₁₀(d/10)，例 2 忘了会把 1000 m 算成 100 m。K 是在 d₀ 处定义的，d₀ 换了，K 也跟着变。
  • 读图先看纵轴画的是什么：画 PL（线往上）截距是 −KdB；画 Pr/Pt（线往下）截距是 +KdB。2024-25 的图纵轴标的是 Path Loss，但线往下走，只能按 (Pr/Pt)dB 读，所以 A = KdB = −30 dB；按正的路径损耗理解则 A = 30 dB（那样线应该往上走），B 两种理解都是 2.51。
  • 反算距离最后一步是取 10 的幂：log₁₀d ≤ 2.348 → d ≤ 102.348 ≈ 223 m，别把 2.348 当成距离；“最远距离”往小的方向舍入。
英文答题模板 · Exam English

Taking 10 log₁₀ of both sides of \(P_r=P_tK(d_0/d)^{\gamma}\) gives \(P_{r,\mathrm{dBm}}=P_{t,\mathrm{dBm}}+K_{\mathrm{dB}}\) \({}-10\gamma\log_{10}(d/d_0)\).

With \(P_t\) = 100 mW = 10 log₁₀100 = 20 dBm, \(K_{\mathrm{dB}}\) = −31.5 dB and γ = 3.6, at d = 300 m: \(P_r = 20-31.5-36\log_{10}300\) \(= -100.68\) dBm.

The path loss \(P_{L,\mathrm{dB}}=-K_{\mathrm{dB}}+\gamma\,(10\log_{10}d)\) is a straight line against 10 log₁₀d: its intercept at d = 1 m is −KdB and its slope is γ (10γ dB per decade against log₁₀d). Shadowing ψdB scatters the measured points on both sides of the line.

For the maximum distance, set the received power equal to the required minimum and solve for log₁₀d: 36 log₁₀d ≤ 84.54 gives d ≤ 102.348 ≈ 223 m.

4最小二乘拟合 K、γ 与阴影方差 · Least-squares fit of K, γ and σ²

背会算定义·必会出现：Practice 1 Q1（老师第 10 周课上讲过）· 模拟 B·Q2 · 期末 4 套都没出

公式 · Formulas

直线模型 · The dB straight line 背
\[ \begin{gathered} M_i = \left.\frac{P_r}{P_t}\right|_{\mathrm{dB}} = K_{\mathrm{dB}} - \gamma\,x_i\\ x_i = 10\log_{10}\frac{d_i}{d_0} \end{gathered} \]
就是第 3 类必背的 dB 式两边减去 Pt。横坐标用 10 log₁₀d，斜率才正好是 −γ；用 log₁₀d，斜率会变成 −10γ。老师：K、γ 都由实测数据拟合（empirical）。
最小二乘的目标（讲义 p.13）· Least-squares criterion 会算
\[ \begin{gathered} F(K,\gamma) = \frac{1}{n}\sum_{i=1}^{n}e_i^2\\ e_i = M_i - K_{\mathrm{dB}} + \gamma x_i\\ \frac{\partial F}{\partial K}=0,\qquad \frac{\partial F}{\partial \gamma}=0 \end{gathered} \]
老师第 10 周讲 Practice 1 Q1 就是这样做的：写出 F，分别对 K、γ 求偏导令其为 0，解两个一次方程。录音没把它列进蓝框，也没说考试给，按“自己会写、会解”准备。
解法一：离差形式 · Solution, deviation form 会算
\[ \begin{aligned} \gamma &= -\frac{S_{xy}}{S_{xx}}\\ &= -\frac{\sum_i (x_i-\bar x)(M_i-\bar M)}{\sum_i (x_i-\bar x)^2}\\ K_{\mathrm{dB}} &= \bar M + \gamma\,\bar x \end{aligned} \]
分式是直线的斜率（负数），γ 取它的相反数。第一个偏导方程化简就是 KdB = \(\bar M\) + γ\(\bar x\)：最佳直线过平均点 (\(\bar x\), \(\bar M\))，而且残差加起来等于 0，可以拿来自检。手算列 x、M、x − \(\bar x\)、M − \(\bar M\)、乘积、平方几列。
解法二：四列求和的正规方程 · Normal equations with sums 会算
\[ \begin{gathered} nK_{\mathrm{dB}} - \gamma\sum x_i = \sum M_i\\ K_{\mathrm{dB}}\sum x_i - \gamma\sum x_i^2 = \sum x_iM_i \end{gathered} \]\[ \begin{gathered} -\gamma = \frac{n\sum x_iM_i - \sum x_i\sum M_i}{n\sum x_i^2 - \left(\sum x_i\right)^2}\\ K_{\mathrm{dB}} = \frac{\sum M_i + \gamma\sum x_i}{n} \end{gathered} \]
讲解页 2.1 节推导框的写法：两个偏导 = 0 直接展开。结果和解法一完全相同，只是改成列 x、M、x²、xM 四列求和；\(\bar x\) 不是整数时用它可以不算离差。
阴影方差 = 最小 MSE · Shadowing variance 定义·必会
\[ \begin{gathered} e_i = M_i - \big(K_{\mathrm{dB}} - \gamma x_i\big)\\ \sigma_\psi^2 = F_{\min} = \frac{1}{n}\sum_{i=1}^{n} e_i^2\\ \sigma_\psi = \sqrt{\sigma_\psi^2} \end{gathered} \]
讲义 p.13 写的就是 “MSE = σψdB²”，除以 n。老师：题目只给 MSE 时它就是 σ²，开根号才是 σ。
接中断概率 · Outage 背
\[ P_{\mathrm{out}} = Q\!\left(\frac{\bar P_{r,\mathrm{dB}} - P_{\min,\mathrm{dB}}}{\sigma_\psi}\right) \]
讲义 p.15 蓝框（详见第 5 类）。分子是余量（dB），分母是标准差（dB）。老师提醒 Practice 1 Q1(b) “10 dB above” 的 10 就是 dB，公式本来就是 dB 形式推出来的，不要换成线性。Q 表考卷附。

\(\gamma = -S_{xy}/S_{xx}\) with \(S_{xy} = \sum(x_i-\bar x)(M_i-\bar M)\) and \(S_{xx} = \sum(x_i-\bar x)^2\), so \(\gamma = 194.95/57.92 = 3.37\) and \(K_{\mathrm{dB}} = \bar M + \gamma\bar x\) \(= -87.5 + 3.366\times15\) \(= -37.01\) dB.

The minimum MSE is the shadowing variance: \(\sigma_\psi^2 = 44.81/4 = 11.20\) dB², so \(\sigma_\psi = 3.35\) dB. With an 8 dB margin, \(P_{\mathrm{out}} = Q(8/3.35)\) \(= Q(2.39) = 8.42\times10^{-3}\).

中断概率（讲义第 2 章 p.14–15）· Outage probability 背
\[ P_{\text{out}}=P\big(P_{r,\mathrm{dB}}\lt P_{\min}\big)=P\big(\psi_{\mathrm{dB}}\lt -M\big)=Q\Big(\frac{M}{\sigma}\Big),\qquad M=\bar P_r-P_{\min} \]
老师要求的写法（第 9 周录音）：把"\(P_r\lt P_{\min}\)"整理成"随机变量 \(\lt -M\)"（随机变量留在左边），再由高斯的对称性写成 Q(M/σ)。M 和 σ 都是 dB，直接相除，不换线性；σ 是标准差，给的是方差或 MSE 就先开根号。讲义 p.16：典型目标 \(P_{\text{out}}\lt 1\%\)，对应 \(M\ge 2.33\sigma\)。
Q 函数、Φ 与对称性 · Q-function, Φ and symmetry 考试给定义·必会
\[ Q(x)=P(Z\gt x)=\int_x^{\infty}\frac{1}{\sqrt{2\pi}}e^{-u^2/2}\,du,\qquad \Phi(x)=P(Z\le x)=1-Q(x),\qquad Q(-x)=1-Q(x) \]
考卷附的是 Q 表（右尾面积），数值不用背。习惯 Z 表 / Φ 表（左尾，也就是 CDF）的话，用 \(Q(x)=1-\Phi(x)\) 换算，所以也有 \(P_{\text{out}}=\Phi(-M/\sigma)\)。Q(0) = 0.5，x 越大 Q 越小。常用值：Q(1) = 0.1587，Q(1.282) ≈ 0.1，Q(1.645) = 0.05，Q(2) = 0.0228，Q(2.326) = 0.01，Q(3.09) = 0.001。
倒着用：所需余量、允许的 σ、最大距离 · Inverse use 定义·必会
\[ P_{\text{out}}\le p\iff\frac{M}{\sigma}\ge x_p=Q^{-1}(p)\;\Longrightarrow\;M\ge x_p\,\sigma,\qquad \sigma\le\frac{M}{x_p} \]\[ \bar P_r(d)\ge P_{\min}+x_p\sigma\;\Longrightarrow\;d_{\max}=d_0\cdot10^{\,(P_{t,\mathrm{dBm}}+K_{\mathrm{dB}}-P_{\min}-x_p\sigma)/(10\gamma)} \]
就是上面必背的式子倒过来用，不用另背。Q 是减函数，"概率 ≤ p"要翻成"参数 ≥ \(x_p\)"。所需余量加门限就是平均功率的下限，再代回路径损耗式解 d（或解 \(P_t\)）。常用：\(x_{0.1}=1.282\)，\(x_{0.05}=1.645\)，\(x_{0.01}=2.326\)，\(x_{0.001}=3.09\)。
宏分集，两路阴影独立（Practice 2 Q2(b)）· Macro-diversity, independent shadowing 定义·必会
\[ P_{\text{out}}=P\big(\{Z_1\lt-\Delta\}\cap\{Z_2\lt-\Delta\}\big)=P(Z_1\lt-\Delta)\,P(Z_2\lt-\Delta)=\Big[Q\Big(\frac{\Delta}{\sigma}\Big)\Big]^2 \]\[ M_{\text{eq}}=\sigma\,Q^{-1}\big(P_{\text{out}}\big),\qquad G=M_{\text{eq}}-\Delta\ \ (\mathrm{dB}) \]

宏分集，两路阴影相关（Practice 2 Q2(c)）· Correlated shadowing 考试给
\[ Z_i=aY_i+bY:\qquad P_{\text{out}}=\int_{-\infty}^{\infty}\frac{1}{\sqrt{2\pi}}\Big[Q\Big(\frac{\Delta+b\sigma y}{|a|\sigma}\Big)\Big]^2e^{-y^2/2}\,dy \]
这是 Practice 2 Q2(c) 印在题目里、让你"证明"的式子；式里的积分变量 y 其实是换元后的 u = Y/σ（题目原样照印）。老师说不会考积分（第 8–10 周录音）；他讲这题的方法（第 10 周录音）：先把共同阴影 Y 当成常数 → 两条链路条件独立，相乘 → 再对 Y 的 PDF 积分 → 换元 u = y/σ。结论：相关时不能直接平方；b = 0 退回 \([Q(\Delta/\sigma)]^2\)，a = 0（完全相关）就等于单基站的 \(Q(\Delta/\sigma)\)。

易错 · Traps

  • σ 和 σ² 混用：Q 里除的是标准差。给 MSE 或方差要先开根号：讲义 p.16 例题 σ = √3.36 = 1.833 dB，Q(4.94/1.833) ≈ Q(2.69) ≈ 0.0036；错除 3.36 得 Q(1.47) ≈ 0.071，大了约 20 倍。反过来，2023-24 期末问的是方差最大值，要平方成 σ² < 18.5 dB²，只写 σ < 4.30 dB 没答完。
  • 单位：W、mW 先换 dBm（2 W = 33.01 dBm，不是 3.01，3.01 是 dBW）；距离项是 10γ log₁₀d（γ = 3.6 时系数是 36）；dBm − dBm 得到的余量是 dB。老师说没写 dB ↔ 线性换算会扣分（第 8–10 周录音）。
  • 把余量换成线性：Q(M/σ) 是在 dB 上推出来的，M 和 σ 都用 dB 直接相除。老师讲 Practice 1 Q1 时专门提醒，"10 dB above"的 10 就是 dB，不要换成线性（第 10 周录音）。瑞利中断 \(1-e^{-\gamma_0/\bar\gamma}\) 才要线性值，两者别混。
  • 表查反了：Q 是右尾、递减，反查时不等号要翻（\(P_{\text{out}}\lt 1\%\iff M/\sigma\gt 2.326\)）。余量为负时 \(Q(-x)=1-Q(x)\)，答案大于 50%；手上是 Φ 表（左尾）时 \(Q(x)=1-\Phi(x)\)。用计算器核对的话，Casio 统计菜单里的 Q( 是 0 到 t 的面积，不是本课的 Q 函数，右尾对应的是 R(。
  • 宏分集写成"任意一个"：两个都低于门限才中断，所以是 p²；写成 \(1-(1-p)^2\) 是"任意一个断就算中断"，意思反了。只有独立才能平方；求等效余量时反查的是 p²，不是 p。
  • 舍入：Q 的参数一般先舍到 2 位小数再查表（0.625 这种正好在两行中间就插值）；中间结果多留一位小数，最后再舍入，别对已经舍过的数再舍一次（2.1345 舍到 2 位是 2.13，不是先变 2.135 再变 2.14）。上下限答案要带不等号（d ≤ 223 m、σ² < 18.5 dB²）；想保守可以上限往小取、下限往大取（148.3 m 写 148 m），本页其余数字按四舍五入写。
英文答题模板 · Exam English

With log-normal shadowing, \(P_{r,\mathrm{dB}}=\bar P_r+\psi_{\mathrm{dB}}\) with \(\psi_{\mathrm{dB}}\sim\mathcal N(0,\sigma_\psi^2)\), so outage occurs when \(\psi_{\mathrm{dB}}\lt-M\), where \(M=\bar P_r-P_{\min}\) is the margin in dB; by the symmetry of the Gaussian, \(P_{\text{out}}=P(\psi_{\mathrm{dB}}\lt-M)=Q(M/\sigma_\psi)\).

Here \(P_t=10\log_{10}100=20\) dBm, \(\bar P_r=20-31.5-36\log_{10}300=-100.68\) dBm and \(M=-100.68-(-110)=9.32\) dB, hence \(P_{\text{out}}=Q(9.32/6)=Q(1.55)=0.0606\).

Since Q is decreasing, \(P_{\text{out}}\lt 1\%\) requires \(M/\sigma_\psi\gt Q^{-1}(0.01)=2.326\); with M = 10 dB this gives \(\sigma_\psi\lt 4.30\) dB, so the variance of \(\psi_{\mathrm{dB}}\) must be below \(18.5\ \mathrm{dB}^2\).

With macro-diversity, outage requires both links to be below the threshold; if the shadowing on the two links is independent, \(P_{\text{out}}=P(Z_1\lt-\Delta)\,P(Z_2\lt-\Delta)=[Q(\Delta/\sigma)]^2\). The base stations are far apart, so both links are rarely blocked at the same time.

公式 · Formulas

SNR 的指数分布 · Exponential PDF of the SNR 背
\[ p(\gamma)=\frac{1}{\bar\gamma}\,e^{-\gamma/\bar\gamma},\qquad \gamma\ge 0 \]
讲义第 2 章 p.25–26。瑞利衰落时包络 z 服从瑞利分布，功率 z² 和 SNR γ 服从指数分布。老师说要背的是这一个，不是包络的瑞利 PDF \(\frac{z}{\sigma^2}e^{-z^2/(2\sigma^2)}\)；推导不会让推。
瑞利中断概率 · Rayleigh outage probability 背
\[ P_{out}=P(\gamma\lt\gamma_0)=1-e^{-\gamma_0/\bar\gamma}\;\approx\;\frac{\gamma_0}{\bar\gamma}\quad(\gamma_0\ll\bar\gamma) \]
γ0、γ̄ 先换成线性值再相除（是比值，单位一致即可）。近似只在比值小时用：x ≈ 0.05 时偏高 2.5%，x = 0.1 时偏高 5.1%，x = 0.5 时偏高 27%，答题写精确值。口诀：门限比平均低 10 dB → 9.52%，低 20 dB → 0.995%，低 30 dB → 0.100%。反面：高于某个值 γ1 的概率 \(P(\gamma\gt\gamma_1)=e^{-\gamma_1/\bar\gamma}\)，取 γ1 = γ̄ 得高于平均值的概率只有 e−1 = 0.368。门限按幅度给（信号强度是 rms 值的 ρ 倍）时 γ0/γ̄ = ρ²：Practice 2 Q1 的 ρ = 0.1 → 1 − e−0.01 = 0.00995（该题本身求 AFD；0.00995 是练习页解答里顺带算的"低于门限的时间比例"）。
倒着解：所需平均 SNR / 最小 SNR · Solving backwards 会反解
\[ \bar\gamma=\frac{\gamma_0}{\ln\frac{1}{1-\varepsilon}},\qquad \gamma_{\min}=\bar\gamma\,\ln\frac{1}{1-\varepsilon} \]
不用另背：令 ε = 1 − e−γ0/γ̄，两边整理后取 ln 就得到。ε 小时 ln(1/(1−ε)) ≈ ε，所以 γ̄ ≈ γ0/ε。真题印的中断容量公式 \(C_\varepsilon=B\log_2\!\big[1+\bar\gamma_R\ln\frac{1}{1-\varepsilon}\big]\)（考试给）里，\(\bar\gamma_R\ln\frac{1}{1-\varepsilon}\) 就是 γmin；中断容量本身见第 12 类。
衰落余量（瑞利）· Fade margin (Rayleigh) 尽量记
\[ \mathrm{FM}=\bar\gamma_{\mathrm{dB}}-\gamma_{0,\mathrm{dB}}=10\log_{10}\frac{\bar\gamma}{\gamma_0}=10\log_{10}\frac{1}{\ln\frac{1}{1-\varepsilon}}\ \mathrm{dB}\;\approx\;10\log_{10}\frac{1}{\varepsilon} \]
讲义 p.51，老师说"有点难记，但要尽量记"；记不住就用上一条现推。讲义写成 γ̄dB − γAWGN,dB：不衰落的 AWGN 信道只要 SNR = γ0，瑞利信道要多给 FM。只和 ε 有关、和 γ̄ 无关：ε = 10% → 9.77 dB，5% → 12.90 dB，1% → 19.98 dB，0.5% → 23.00 dB，0.1% → 30.00 dB。中断要求每严 10 倍，余量多 10 dB。

例 3 · 同样余量：阴影和瑞利谁中断多？

英文答题模板 · Exam English

In Rayleigh fading the instantaneous SNR γ is exponentially distributed, \(p(\gamma)=\frac{1}{\bar\gamma}e^{-\gamma/\bar\gamma}\), so the outage probability is \(P_{out}=P(\gamma\lt\gamma_0)=1-e^{-\gamma_0/\bar\gamma}\). In linear terms \(\bar\gamma\) = 20 dB = 100 and \(\gamma_0\) = 7 dB = 5.012, so \(P_{out}=1-e^{-5.012/100}=0.0489\).

With \(\bar\gamma_R\) = 25 dB = 316.2 and ε = 0.005, setting \(1-e^{-\gamma_{\min}/\bar\gamma}=\varepsilon\) gives \(\gamma_{\min}=\bar\gamma\ln\frac{1}{1-\varepsilon}\) = 316.2 × 0.005013 = 1.585, i.e. 10 log101.585 = 2.00 dB, so the fade margin relative to an AWGN channel is 25 − 2.00 = 23.0 dB \(=10\log_{10}\big[1/\ln\frac{1}{1-\varepsilon}\big]\), which depends only on ε.

易错 · Traps

  • KdB 用 20 log：K = 4 → 20 log104 = 12.04 dB ✗，应为 10 log104 = 6.02 dB（K 是功率比）。
  • 给的是幅度比忘了平方：直射幅度是散射 rms 幅度 √(2σ²) 的 2 倍 → K = 2² = 4（6.02 dB），不是 2（3.01 dB）。
  • 把 K = 0 dB 当成瑞利 ✗：0 dB 是 K = 1（直射、散射各 50%）；瑞利是 K = 0 = −∞ dB。
  • 散射总功率用 dBm 直接相加，或只取最强的一条 ✗（例 1 只取 −90 dBm 那条会得 KdB = −80 − (−90) = 10 dB，正确是 7.11 dB）：先换 mW 全部加起来，再求 K。
  • 把"瑞利 / 莱斯"和"平坦 / 选择性、快 / 慢"混为一谈：前者说幅度服从什么分布，后者说衰落和信号的关系；一个信道可以同时是"平坦、慢、莱斯"。
  • 说"有直射径就不会中断" ✗：只是比瑞利小；K → ∞ 才接近 AWGN。比较时要说明是同一平均 SNR、同一门限。
英文答题模板 · Exam English

The Rician K-factor is the ratio of the power in the line-of-sight component to the total power in the scattered components, \(K=s^2/(2\sigma^2)\). Here K = 4, i.e. \(K_{\mathrm{dB}}=10\log_{10}4=6.02\) dB. Because of the direct path the envelope is Rician rather than Rayleigh, so deep fades are less likely and, for the same average SNR (20 dB) and threshold (10 dB), the outage probability is lower than the Rayleigh value of 0.0952. K = 0 reduces to Rayleigh fading and K → ∞ to an AWGN channel with no fading.

  3. 20 ksps：Ts = 50 µs。σ/Ts = 0.04 → 平坦；TC/Ts = 40 → 慢。平坦慢衰落。

英文答题模板 · Exam English

The coherence bandwidth BC, set by the multipath delay spread, is compared with the signal bandwidth Bs: if Bs < BC the fading is flat, and if Bs > BC it is frequency-selective and causes ISI. The Doppler spread BD = fm, set by the motion, is also compared with Bs: if Bs ≫ BD, i.e. Ts ≪ TC ≈ 1/BD, the fading is slow, otherwise it is fast; the two comparisons are independent and give four types (flat-slow, flat-fast, selective-slow, selective-fast).

Worked line: v = 54/3.6 = 15 m/s, fm = vfc/c = 15 × 2×10⁹/(3×10⁸) = 100 Hz and TC ≈ 1/fm = 10 ms ≫ Ts = 100 µs, so the fading is slow; σTm/Ts = 2/100 = 0.02 < 0.1, so it is flat. Hence the signal experiences flat, slow fading.

10电平通过率与平均衰落时长 · Level crossing rate (LCR) and average fade duration (AFD)

定义·必会考试给背出现：期末 2/4 套（2024-25 S2 Q1(a)(ii)、2025-26 S2 Q1(a)(ii)）· Practice 2 Q1 · 模拟 A·Q3(c) · 模拟 C·Q2(b)(c) · 讲义第 2 章 p.41–47

只有两种算法：(A) 计数法：题目给“T 秒内看到 N 次深衰落”（或直接给 LCR）和 AFD，次数 ÷ 秒数 = LCR，AFD ÷ Ts = 每次错几个，相乘 = 每秒错几个，两套期末都是这一类；(B) 公式法：代题目给的瑞利 LCR/AFD 公式，难点只在把文字翻成 ρ 和 fm（Practice 2 Q1）。Quiz 题型接近期末、但更简单（老师说），多半就是这两种之一。老师说这类题数据多，先把已知量逐个写下来再算。

公式 · Formulas

LCR 的定义（计数）· LCR from a count 定义·必会
\[ L_Z=\frac{N}{T_{\rm obs}} \]
单位 次/s。N = 观测到的深衰落次数，Tobs = 观测了几秒：“10 秒里 40 次” → 40/10 = 4 次/s。这一步不需要知道是不是瑞利衰落。
每次衰落错几个符号 · Symbols in error per fade 定义·必会
\[ N_{\rm sym}=\frac{\bar\tau_Z}{T_s}=\bar\tau_Z\,R_s \]
老师课上讲的做法：一次衰落里错的符号数 = AFD ÷ Ts；题目给的是符号速率就取倒数，即 AFD × Rs。AFD 和 Ts 先统一单位。讲义 p.45–47 例题（符号只要有一部分落在衰落里就算错）也是直接用 AFD × Rs，不去 +1。
每秒误符号数 · Symbol errors per second 定义·必会
\[ N_{\rm err}=L_Z\,N_{\rm sym}=L_Z\,\bar\tau_Z\,R_s \]
每秒几次衰落 × 每次错几个。前提是题目说深衰落里的符号都算错（“the affected symbol will be in error”）。错误是成串出现的：2025-26 S2 那题是每秒 4 串、每串 4 个。
深衰落时间比例与误符号率 · Fraction of time in fade, SER 定义·必会
\[ P_{\rm fade}=L_Z\,\bar\tau_Z \]\[ \mathrm{SER}=\frac{N_{\rm err}}{R_s}=L_Z\,\bar\tau_Z \]
每秒有 LZ 次、每次 τ̄ 秒 → 每秒有 LZτ̄ 秒在门限以下。对任何衰落都成立（讲义 p.42–43 推 AFD 公式的出发点就是它：AFD = 低于门限的时间比例 ÷ LCR）。深衰落里全错、外面全对时，误符号率就等于这个比例，和 Rs 无关。
瑞利衰落的 LCR 与 AFD · Rayleigh LCR and AFD 考试给
\[ L_Z=\sqrt{2\pi}\,f_m\,\rho\,e^{-\rho^2} \]\[ \bar\tau_Z=\frac{e^{\rho^2}-1}{\sqrt{2\pi}\,f_m\,\rho} \]
讲义第 2 章 p.41–43。考试会给公式，但不一定解释符号：老师要求会说出 ρ = Zmin/Zrms、fm 是最大多普勒频移。省事算法：先算公共分母 √(2π) fm ρ（√(2π) = 2.5066；中间量多留一位，结果的最后一位才不会差 1），AFD = (eρ² − 1) ÷ 分母，LCR = 分母 × e−ρ²。直觉：车越快（fm 大），衰落越频繁、越短；ρ 较小时，门限越低，深衰落越少、越短。
两式相乘 = 低于门限的时间比例 · LCR × AFD for Rayleigh 背
\[ L_Z\,\bar\tau_Z=1-e^{-\rho^2}=P(z\lt Z_{\min}) \]\[ \Rightarrow\quad \rho^2=\ln\frac{1}{1-L_Z\bar\tau_Z} \]
fm 消掉了。它就是必背的瑞利中断 \(1-e^{-\gamma_0/\bar\gamma}\)（ρ² 就是 γ₀/γ̄），所以标“背”；忘了也能把上面两式相乘得到。用途：验算 LCR、AFD 有没有算错；由时间比例反求门限（模拟 C·Q2(c)）。
ρ 怎么从题目文字读出来 · Reading ρ from the wording 定义·必会
\[ \rho=\frac{Z_{\min}}{Z_{\rm rms}},\qquad \rho^2=\frac{P_{\min}}{P_{\rm rms}} \]\[ \rho^2=10^{-X/10},\qquad \rho=10^{-X/20} \]
X = 门限比 rms 低多少 dB。说幅度（signal strength、envelope、“rms 值的 10%”）→ 这个数就是 ρ（老师特别提过：看到“rms 值的 10%”立刻想到 ρ = 0.1）；说功率或给 dB → 先得 ρ²，再开根号。常用：rms 值的 10% → ρ = 0.1、ρ² = 0.01（−20 dB）；功率低 10 dB → ρ² = 0.1、ρ = 0.3162；门限功率是平均功率的 1% → ρ = 0.1。dB ↔ 线性这一步要写出来，老师说漏写会扣分。
最大多普勒频移 · Maximum Doppler shift 定义·必会
\[ f_m=\frac{v\,f_c}{c}=\frac{v}{\lambda} \]
讲义第 2 章 p.34–36。v 用 m/s（km/h ÷ 3.6，72 km/h = 20 m/s），fc 用 Hz，c = 3×10⁸ m/s。题目直接给 “maximum Doppler shift” 或 fD 时就是它，直接用。

例 1 · 10 秒窗口，给的是符号速率（计数法）

某链路符号速率 Rs = 25 k 符号/s。记录 10 秒，共出现 150 次深衰落，平均衰落时长 0.8 ms，深衰落期间的符号全部出错。求：(a) LCR；(b) 每次衰落连错几个符号；(c) 平均每秒误符号数；(d) 误符号率；(e) 信道不变、符号速率提高到 100 k 符号/s 时，(c)(d) 变成多少？

  1. (a) LCR = 150 ÷ 10 s = 15 次/s。
  2. (b) 给的是速率，先求 Ts = 1/25 000 = 40 µs；每次 = 0.8 ms ÷ 40 µs = 20 个（或 AFD × Rs = 0.8×10⁻³ × 25×10³ = 20）。
  3. (c) 每秒误符号数 = 15 × 20 = 300 个/s。
  4. (d) SER = 300 ÷ 25 000 = 0.012；验算：LCR × AFD = 15 × 0.8 ms = 0.012 ✓（信号 1.2% 的时间在深衰落里）。
  5. (e) LCR、AFD 是信道的性质，不随符号速率变：每次 = 0.8 ms × 100 k = 80 个，每秒 = 15 × 80 = 1200 个；SER 仍是 0.012。

答案：(a) 15 次/s　(b) 20 个　(c) 300 个/s　(d) 0.012　(e) 1200 个/s，SER 不变

例 2 · 公式法：门限是 rms 的 10%，900 MHz、60 km/h

载频 900 MHz，车速 60 km/h，瑞利衰落；能正常工作的最低信号强度是 rms 值的 10%；符号速率 100 k 符号/s。已知 \(L_Z=\sqrt{2\pi}f_m\rho e^{-\rho^2}\)、\(\bar\tau_Z=\dfrac{e^{\rho^2}-1}{\sqrt{2\pi}f_m\rho}\)。求：(a) ρ 和 fm；(b) LCR 和 AFD；(c) 每次连错几个符号、每秒误符号数、10 秒内平均几次深衰落；(d) 车速提高到 120 km/h，哪些量变、哪些不变？

  1. (a) 说的是信号强度（幅度）→ ρ = 0.1，ρ² = 0.01（门限比平均功率低 20 dB）。v = 60 ÷ 3.6 = 16.67 m/s，fm = v fc/c = 16.67 × 9×10⁸ / 3×10⁸ = 50.0 Hz（或 λ = c/fc = 0.3333 m，v/λ = 50.0 Hz）。
  2. (b) 公共分母 √(2π) × 50 × 0.1 = 12.53；LCR = 12.53 × e−0.01 = 12.41 次/s；AFD = (e0.01 − 1)/12.53 = 0.01005/12.53 = 0.802 ms。fm 正好 50 Hz、ρ = 0.1，和 Practice 2 Q1 是同一组数。
  3. (c) 每次 = AFD × Rs = 0.802 ms × 100 k = 80.2 ≈ 80 个；每秒 = 12.41 × 80.2 = 995 个（验算：(1 − e−0.01) × 10⁵ = 995 ✓）；10 秒内约 12.41 × 10 = 124 次深衰落。

  1. (a) 给的是功率 dB，先换线性：ρ² = 10−15/10 = 10−1.5 = 0.03162，ρ = √ρ² = 10−15/20 = 0.17783。SER = 时间比例 = 1 − e−ρ² = 1 − e−0.03162 = 0.03113（约 3.1%）。
  2. (b) 公共分母 2.5066 × 80 × 0.17783 = 35.66；LCR = 35.66 × e−0.03162 = 35.66 × 0.9689 = 34.55 次/s；AFD = (e0.03162 − 1)/35.66 = 0.03213/35.66 = 0.901 ms。

易错 · Traps

  • ρ 是幅度比：“rms 值的 10%”、“0.1 of the rms value” → ρ = 0.1；“功率低 10 dB” → ρ² = 0.1、ρ = 0.3162。模拟 A·Q3 若错当 ρ = 0.1，AFD 会算成 0.334 ms，真值 1.106 ms，差 3 倍多。
  • 公式里已经写了 ρ²：ρ = 0.1 时指数是 0.01，别再平方一次，也别把 −20 dB 直接代进指数。换 dB 时，功率比 ρ² 用 10 log₁₀，幅度比 ρ 用 20 log₁₀，结果一样（模拟 C：−18.21 dB）。
  • LCR 是“次/秒”：300 次是 10 秒的总数，要 ÷ 10。LCR 也不是每秒误符号数：模拟 C 是 30 次/s，却是 750 个/s。
  • 单位统一：AFD 常是 ms、Ts 常是 µs，0.5 ms ÷ 20 µs = 25（不是 0.025）；给符号速率时是 AFD × Rs，不是 AFD ÷ Rs；算 fm 前 km/h ÷ 3.6、MHz/GHz 换成 Hz。
  • “symbol error rate”（误符号率，无单位）≠ “symbol errors per second”（个/s）。2025-26 S2 问的是每秒“连续”误符号数：写 16 个/s，并注明每次衰落连续错 4 个，两个数都写最稳。

  • SNR 用 dB 直接代进 log₂：模拟 B·Q3 的 17.01 dB 要先换成 50.2，log₂(1 + 50.2) = 5.68；写成 log₂(1 + 17.01) = 4.17 就错了。

英文答题模板 · Exam English

After multi-user detection removes user 1, user 2 sees only noise: SNR₂ = P₂/N = 10/0.1 = 100 (20 dB), so C₂ = 20×10⁶ × log₂(101) = 133.16 Mbps.

With the signal power fixed, doubling the bandwidth also doubles the noise power N = N₀B, so the SNR halves (17.01 dB → 14.00 dB, i.e. 50.2 → 25.1) and the capacity rises only from 28.4 to 47.1 Mbps, about 1.66 times, not double.

例 1 · ε = 2%、带宽 1 MHz：最小 SNR、Cε、平均无错速率，和 AWGN 比

瑞利信道平均 SNR 为 30 dB，带宽 1 MHz，允许中断概率 2%。已知 Cε = B log₂[1 + γ̄ ln(1/(1 − ε))]。(a) 求最小 SNR（线性和 dB）和衰落余量。(b) 求 Cε 和平均无错速率 (1 − ε)Cε。(c) 和 SNR 同为 30 dB 的 AWGN 信道比较。

  2. γmin = 1000 × 0.02020 = 20.20 → 10 log₁₀20.20 = 13.05 dB。
  3. FM = 30 − 13.05 = 16.95 dB（用公式检查：10 log₁₀(1/0.02020) = 16.95 dB ✓）。
  4. (b) Cε = 106 × log₂(1 + 20.20) = 106 × log₂21.20 = 4.41 Mbps；平均无错速率 = 0.98 × 4.406 = 4.32 Mbps。

例 2 · 反着问：要保证 2 bit/s/Hz，平均 SNR 至少多少

瑞利信道，允许中断概率 1%，要求能保证 Cε/B = 2 bit/s/Hz。平均 SNR 至少要多少 dB？对应的衰落余量是多少？

  1. 先由速率求最小 SNR：log₂(1 + γmin) = 2 → γmin = 22 − 1 = 3 → 10 log₁₀3 = 4.77 dB。
  2. 由 γmin = γ̄ ln(1/(1 − ε)) 反求：γ̄ = 3 / ln(1/0.99) = 3 / 0.01005 = 298.5。
  3. 换 dB：10 log₁₀298.5 = 24.75 dB。
  4. FM = 24.75 − 4.77 = 19.98 dB ≈ 20 dB，正是 ε = 1% 的余量：要求的速率变了，余量不变。

答案：γ̄ ≥ 298.5（24.75 dB）；FM ≈ 19.98 dB

例 3 · 只问余量：γ̄ 换了余量不变；ε 从 5% 收紧到 0.5%

(a) 允许中断概率 5%，瑞利信道的衰落余量是多少？分别取 γ̄ = 15 dB 和 25 dB 求最小 SNR，验证余量相同。(b) 用近似式 10 log₁₀(1/ε) 算，差多少？(c) 中断要求收紧到 0.5%，平均 SNR 要再多给多少 dB？

  1. ln(1/0.95) = 0.05129，FM = 10 log₁₀(1/0.05129) = 12.90 dB。
  2. γ̄ = 15 dB → 101.5 = 31.62：γmin = 31.62 × 0.05129 = 1.622（2.10 dB），FM = 15 − 2.10 = 12.90 dB。
  3. γ̄ = 25 dB → 102.5 = 316.2：γmin = 316.2 × 0.05129 = 16.22（12.10 dB），FM = 25 − 12.10 = 12.90 dB。两次一样，因为 γ̄ 在 γ̄/γmin 里约掉了。
  4. (b) 近似：10 log₁₀(1/0.05) = 13.01 dB，比精确值大 0.11 dB；ε 越小，近似越准。
  5. (c) ε = 0.5%：FM = 23.00 dB，要多给 23.00 − 12.90 = 10.10 dB。中断要求严 10 倍，余量多约 10 dB。

答案：FM ≈ 12.90 dB（与 γ̄ 无关）；近似值 13.01 dB；收紧到 0.5% 要多给 10.10 dB

易错 · Traps

  • ln 不是 log₁₀：2025-26 S2 那题如果用 log₁₀(1/0.995) = 0.002177，会得到 γmin = 0.688（−1.62 dB）、FM = 26.6 dB，全错。
  • γ̄ 要先换成线性再乘：25 dB → 316.2，不能写成 25 × 0.005013。
  • ε 用小数代：0.5% = 0.005，0.1% = 0.001，不能代 0.5 或 0.1。
  • FM 是两个 dB 值相减（等于线性相除），只取决于 ε，与 γ̄、B 都无关；不要用 316.2 − 1.585 这种线性差。
  • 问 minimum SNR 时线性和 dB 都写（1.585 → 2.00 dB），老师说漏写 dB ↔ 线性换算会扣分。
  • 近似 10 log₁₀(1/ε) 只在 ε 小时准：ε = 10% 时精确值 9.77 dB，近似 10.00 dB；有时间就用精确式。Cε 是能保证的速率，平均无错速率还要乘 (1 − ε)。
英文答题模板 · Exam English

In Rayleigh fading the SNR is exponentially distributed, so P(γ < γmin) = 1 − e−γmin/γ̄ = ε, which gives γmin = γ̄ ln[1/(1 − ε)].

With γ̄R = 25 dB = 316.2 and ε = 0.005: γmin = 316.2 × ln(1/0.995) = 316.2 × 0.005013 = 1.585, i.e. 2.0 dB. This is the minimum SNR, and Cε equals the capacity of an AWGN channel with this SNR.

The fade margin compared with the AWGN channel is FM = γ̄dB − γmin,dB = 25 − 2.0 = 23.0 dB = 10 log₁₀[1/ln(1/(1 − ε))]; it depends only on ε, not on γ̄.

13注水法功率分配 · Water-filling power allocation

尽量记出现：期末 1/4 套（2024-25 Q1(a)(iii)）· 模拟 B·Q3 (c) · 讲义第 2 章 p.56–57 例题 · 第 5、7 章也用（Practice 5 Q1、Practice 7 Q1(d)，属期末范围）

频率选择性信道切成几个子带（子信道），好坏不同，总功率固定：好的多给、差的少给、太差的干脆不给。老师说注水“很重要，要会算”。Quiz 可能给 2–3 个子带的 SNR（dB）和总功率 P，求每个子带分多少瓦（和总容量）。关键是先假设全开解 γ0，检查，不满足就去掉最差的重算。时变信道的注水老师说只要求概念，不会让算。

公式 · Formulas

功率分配 · power allocation（讲义第 2 章 p.54）尽量记
\[ \frac{P_i}{P}=\begin{cases}\dfrac{1}{\gamma_0}-\dfrac{1}{\gamma_i}, & \gamma_i\ge\gamma_0\\[6pt] 0, & \gamma_i\lt\gamma_0\end{cases} \]
老师说这个分配式尽量记，注水要会算。2024-25 期末把它印在题里（写成 Pi = P(1/γ0 − 1/γi)），但只给了这一式，γ0 要自己用 ΣPi = P 解；Quiz 不保证会印。P 不是 1 W 时别忘了乘 P。
求水位 · solving for γ0（由 ΣPi = P 推出）尽量记
\[ \sum_{\text{on}}\Big(\frac{1}{\gamma_0}-\frac{1}{\gamma_i}\Big)=1\qquad\Longrightarrow\qquad \frac{1}{\gamma_0}=\frac{1}{n}\Big(1+\sum_{\text{on}}\frac{1}{\gamma_i}\Big) \]
只对“开着”的 n 个子信道求和。第一次假设全部都开；解出 γ0 后检查每个 γi ≥ γ0，有不满足的就去掉最差的那个，n 减 1 再解，直到剩下的全部满足。
总容量 · total capacity（p.54）尽量记
\[ C=\sum_{\gamma_i\ge\gamma_0}B_i\log_2\frac{\gamma_i}{\gamma_0}\qquad\Big(=\sum B_i\log_2\Big(1+\gamma_i\frac{P_i}{P}\Big)\Big) \]
括号里的写法说明它就是香农公式：子信道 i 拿到 Pi，SNR 变成 γiPi/P，而 1 + γi(1/γ0 − 1/γi) = γi/γ0。记不住就用香农现算。γi/γ0 = γi × (1/γ0)，直接乘水位更快。

例 1 · 两个子带都开，总功率 2 W（P 不是 1 W）

两个子带各 1 MHz，把全部功率 P = 2 W 给其中一个时 SNR 分别为 12 dB、6 dB。用注水法求每个子带分多少瓦、总容量，并和平分功率比较。

  1. 换线性：12 dB → 101.2 = 15.85，6 dB → 100.6 = 3.981；1/γ = 0.0631、0.2512。
  2. 假设都开：1/γ0 = (1 + 0.0631 + 0.2512)/2 = 1.3143/2 = 0.6571 → γ0 = 1.522（1.82 dB）。
  3. 检查：3.981 ≥ 1.522 ✓，两个都开。
  4. 功率要乘 P = 2 W：P₁ = 2 × (0.6571 − 0.0631) = 1.188 W；P₂ = 2 × (0.6571 − 0.2512) = 0.812 W；和 = 2 W ✓。
  5. 容量：C = 1 MHz × [log₂(15.85 × 0.6571) + log₂(3.981 × 0.6571)] = log₂10.42 + log₂2.616 = 3.381 + 1.387 = 4.77 Mbps。
  6. 平分：每个 1 W，SNR 减半为 7.924 和 1.991：log₂8.924 + log₂2.991 = 3.158 + 1.581 = 4.74 Mbps。两个子带都不差时注水只多一点；子带差距大时（模拟 B·Q3：4.39 对 3.78 Mbps）差别才明显。

答案：P₁ ≈ 1.188 W，P₂ ≈ 0.812 W；C ≈ 4.77 Mbps（平分为 4.74 Mbps）

例 2 · 三个子带：最差的要关掉，再重算

频率选择性信道分成三个子带，各 1 MHz。把全部功率 P = 1 W 给某个子带时，SNR 分别为 15 dB、6 dB、−3 dB。用注水法求各子带的功率和总容量。

  1. 换线性：15 dB → 101.5 = 31.62，6 dB → 100.6 = 3.981，−3 dB → 10−0.3 = 0.5012；1/γ = 0.03162、0.2512、1.995。
  2. 假设三个都开：1/γ0 = (1 + 0.03162 + 0.2512 + 1.995)/3 = 3.278/3 = 1.093 → γ0 = 0.915。
  3. 检查：γ₃ = 0.5012 < 0.915 ✗。如果硬算，P₃ = 1.0927 − 1.9953 = −0.9026 W，功率是负的，说明第 3 个子带该关掉。
  4. 去掉第 3 个，n = 2 重算：1/γ0 = (1 + 0.03162 + 0.2512)/2 = 1.283/2 = 0.6414 → γ0 = 1.559（1.93 dB）。再检查：γ₂ = 3.981 ≥ 1.559 ✓。
  5. 功率：P₁ = 0.6414 − 0.03162 = 0.610 W，P₂ = 0.6414 − 0.2512 = 0.390 W，P₃ = 0；0.610 + 0.390 = 1 W ✓。
  6. 容量：C = 1 MHz × [log₂(31.62 × 0.6414) + log₂(3.981 × 0.6414)] = log₂20.28 + log₂2.553 = 4.342 + 1.352 = 5.69 Mbps。

答案：P₁ ≈ 0.610 W，P₂ ≈ 0.390 W，P₃ = 0；C ≈ 5.69 Mbps

例 3 · 四个子带：要去掉两次，每次重算后全部重新检查

四个子带各 1 MHz，全部功率给它时 SNR 为 20、10、0、−5 dB，总功率 P = 1 W。求功率分配和总容量。

  1. 换线性：100、10、1、10−0.5 = 0.3162；1/γ = 0.01、0.1、1、3.162。

易错 · Traps

  • γi 一定用线性值：18 dB 是 63.1，不是 18。
  • 不检查 γi ≥ γ0 就会算出负功率（例 2 硬算得 P₃ = −0.9026 W）；负功率就说明这个子带该关掉。

  • 每次重算后要把剩下的全部重新检查：例 3 第一轮第 3 个子带过关（1 ≥ 0.759），去掉第 4 个后水位从 1.318 降到 0.7033，它就不过关了（1 < 1.422）。

英文答题模板 · Exam English

Converting the SNRs to linear values gives γ₁ = 63.1, γ₂ = 10.0 and γ₃ = 1.995. Assuming all three sub-bands receive power, Σ(1/γ₀ − 1/γᵢ) = 1 gives 1/γ₀ = (1 + 1/63.1 + 1/10 + 1/1.995)/3 = 0.539, so γ₀ = 1.855 (2.68 dB).

Since every γᵢ ≥ γ₀, the assumption holds, and Pᵢ = P(1/γ₀ − 1/γᵢ) gives P₁ = 0.523 W, P₂ = 0.439 W and P₃ = 0.038 W, which add up to P = 1 W.

If a sub-band had γᵢ < γ₀, it would receive no power; it is removed and γ₀ is recomputed with the remaining sub-bands until all of them satisfy γᵢ ≥ γ₀. The capacity is then C = Σ Bᵢ log₂(γᵢ/γ₀) over the active sub-bands.
